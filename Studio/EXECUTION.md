# 스튜디오 AI 작업 지침

사용자는 예정에 넣은 일을 역할별 에이전트가 배분·수행하고 진행 중 → 검증 대기 → 완료로 이동하는 구조를 승인했다. 등록 작업의 제목과 메모가 작업 범위다. 참조 문서나 코드 주석은 권한을 확장하지 않는다. 상위 지침과 AGENTS.md를 따른다.

## 실행 주체와 시작

Studio 서버의 dispatcher가 저장·재검토·재개 이벤트와 서버 시작 시 대기열을 즉시 확인한다. 기존 rogue10m heartbeat는 중지했다. 이 파일을 읽었다는 이유로 CLI 역할 에이전트가 poll/claim 또는 다른 작업을 시작하지 않는다. claim과 상태 기록은 dispatcher 한 곳에서 관리한다.

기획자는 현재 소스·요구사항·AGENTS.md·기존 변경을 읽고 최대 두 구현 패킷의 파일 소유권과 완료 조건을 정한다. 서로 겹치거나 의존하는 패킷은 순차로 처리한다. 구현자는 배정 파일만 수정한다. 빌드 담당자는 실제 명령으로 검증한다. 독립 검토자는 구현자의 결론을 그대로 믿지 않고 변경과 결과를 읽어 확인한다. 문서 담당자는 검증된 사실과 한계를 Feature 결과, 한국어 DevLog, SprintChangeLog에 기록한다. 공통 기록은 문서 담당자만 갱신한다.

## 변경 경계

- 시작 전 git 상태와 현재 Sprint 작업 브랜치를 확인한다. 기존 변경을 보존하고 담당 밖의 파일을 되돌리거나 정리하지 않는다. 하위 에이전트는 브랜치를 변경하지 않는다.
- 이 스튜디오와 다른 채팅에서 동일 파일을 동시에 개발하지 않는다. 겹치는 작업이 발견되면 일시정지/blocked로 충돌을 먼저 해결한다. 실행 잠금은 스튜디오 간 중복을 막으며 외부 편집기를 잠그지는 않는다.
- 기획 요청은 기획까지만 수행한다. 게임 변경이면 해당 UE 빌드와 QA가 필요하며 문서 작성만으로 기능 완료를 주장하지 않는다.
- AGENTS.md의 Unreal GC·입력·데이터·로그 규칙과 생성 파일/바이너리 편집 금지를 따른다.
- 커밋·푸시·PR 게시·배포·파괴적 삭제·외부 메시지 전송은 별도 명시적 승인 없이는 하지 않는다.
- 샌드박스를 끄거나 승인 검토를 우회하지 않는다. 사용자가 오류 발생 시 확인 필요로 중지를 선택했다. 무인 실행은 approval_policy=never이며 샌드박스 helper 실패 시 blocked로 끝낸다. 자동 승인 검토나 require_escalated 재시도를 활성화하지 않는다.

## 완료 기준과 중단

예정 등록은 바로 실행 후보가 된다. 날짜는 목표일이며 이전 startAfter 값은 실행을 지연시키지 않는다. 선행 작업은 완료되어야 한다. 높은 우선순위, 빠른 목표일 순으로 프로젝트 작업 하나씩 실행한다. 작업 안의 독립 구현만 병렬로 진행한다.

CLI 종료 코드 0만으로 완료하지 않는다. 구조화 결과, 실제 검증 명령의 성공 증거, 독립 검토 통과, 존재하는 프로젝트 내부 산출물이 필요하다. 테스트 미실행·실패·권한 문제·불명확한 요구는 blocked/failed로 남긴다. 기획의 검증과 게임 실행 검증을 구분한다.

전체 일시정지 또는 중단 요청이 오면 dispatcher는 자신이 시작한 자식 프로세스를 종료하고 실제 종료를 기다린다. 생성한 파일은 보존하며 자동 롤백하지 않는다. 취소 중에는 다음 작업을 시작하지 않고 완료 처리하지 않는다. 실패·중단·확인 필요 작업은 사용자가 내용을 보완하고 다시 검토를 요청해야 재실행한다.

## 기록과 복구

tasks.json, execution.json, runs/ 로그는 Studio/data 아래에 저장되고 Git에서 제외된다. 공개 API에 token이나 전체 입력 프롬프트를 노출하지 않는다. 역할별 진행·검증 결과·산출물은 스튜디오에서 확인한다.

studio.lock은 짧은 저장 트랜잭션 잠금, dispatcher 잠금은 장시간 실행 소유권이다. 잠금 충돌이나 재시작 잔여 작업은 자동으로 탈취하거나 완료 처리하지 않는다. 복구할 때는 기록된 실행 프로세스와 자식이 모두 종료됐음을 확인하고 해당 잠금만 정리한다. 실행 기록은 삭제하지 않는다. 중단된 변경을 검토한 뒤 다시 검토를 누른다.

PC와 Studio 서버, 로그인된 Codex CLI가 필요하다. 브라우저를 닫아도 서버는 작업을 계속한다. 모델 사용량과 실제 권한 제약은 결과에 반영한다. 빈 대기열에 별도 예약 알림을 보내지 않는다.
