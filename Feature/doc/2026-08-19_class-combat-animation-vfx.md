# 직업·무기별 전투 애니메이션 및 1인칭 안전 VFX 결과

## 완료 범위

- 단검 도적, 표창 도적, 쌍단검 도적, 장검 전사, 대검 전사, 쌍검 전사, 방패 전사, 한손검·작은방패 전사, 마법사, 권사 전투 프로필을 구성했다.
- 각 프로필은 기본 3연계, 특수 공격, 차징 공격으로 구성되며 총 50개 Attack Skill Data Asset과 50개 Animation Montage를 사용한다.
- 종족별 캐릭터는 공통 Manny 애니메이션 소스를 사용하므로 같은 공격 스킬에서 같은 모션을 재생한다.
- 공격 애니메이션과 Niagara는 서로 독립된 경로와 데이터 필드로 관리한다. 기존 이동 파티클 비활성 상태는 유지했다.

### 1인칭 VFX 안전 조정

- 로컬 1인칭 효과는 1인칭 손 메시를 기준으로 생성하고, 화면 중앙에서 바깥쪽·아래쪽으로 이동한다.
- 최종 실제 배율 상한은 Cast 0.08, Charge 0.0312, Impact 0.232로 제한했다.
- Cast/Impact 방출 시간은 최대 약 0.082초로 제한해 잔상이 조준점을 오래 덮지 않게 했다.
- 쌍단검, 쌍검, 권사의 양손 효과는 별도 소켓과 보정값을 사용한다.
- 차징 종료와 일회성 효과 타이머에서 Niagara를 즉시 비활성화하고 컴포넌트를 파괴해 누적을 막았다.

### 데이터와 런타임

- `URogue10mAttackSkillData`에 애니메이션 재생 속도, 보조 손 VFX, 1인칭 위치·회전·크기·시간 보정값을 추가했다.
- `URogue10mCombatComponent`가 로컬 1인칭과 원격/3인칭 효과를 분기하고, Attack Skill 설정에 따라 Montage 재생과 VFX 생명주기를 처리한다.
- `ERogue10mWeaponType`의 기존 직렬화 순서를 보존하면서 Shuriken, DualDaggers, LongSword, Shield, SwordBuckler를 추가했다.
- 신규 자산은 `/Game/Rogue10m/Animation/Combat`, `/Game/Rogue10m/VFX/Character/Combat`, `/Game/DataAsset/AttackSkill/ClassCombat`, `/Game/DataAsset/SkillProfile`에 분리했다.

현재 작업 폴더에 별도로 존재하는 활 프로필은 요청 범위와 튜닝값이 다르므로 이 기능의 엄격한 1인칭 상한 검증에서 제외했다.

## 알려진 제한과 후속 작업

- 이번 세트는 프로젝트에 이미 포함된 Manny 전투·마법 원본 애니메이션을 조합한 첫 제작본이다. 전용 무기 메시와 모션 캡처 원본이 들어오면 손 위치와 타격 프레임을 스타일별로 한 번 더 다듬을 수 있다.
- 제공 영상은 검색 결과의 성격과 요청한 연출 방향을 참고했지만 프레임 단위 원본 분석은 접근 제한으로 수행하지 못했다.
- 신규 Niagara는 기존 프로젝트 효과를 안전하게 복제·튜닝했다. 화면 전체 왜곡, 장시간 점광원, 중앙 불투명 원판은 사용하지 않았다.
