# Rogue10m 개인 스튜디오

작성: 2026-09-28 / 작업: Sprint#4-44-personal-studio

## 결과

개발 일정, 현재 브랜치, 개선·수정 이력, 개발 일지, 설계·결과 문서를 보는 로컬 웹 작업실을 구현했다. `OpenPersonalStudio.bat`을 실행하거나 실행 중인 `http://127.0.0.1:4317`에 접속한다. Node 표준 라이브러리만 사용하며 패키지 설치나 Unreal 실행이 필요 없다.

## 구성

- 스튜디오 홈: 현재 Sprint/브랜치, 직접 등록한 진행 작업과 지연 일정, 주간 일정, 최근 변경, 결과 문서 연결 확인.
- 개발 일정: 작업 CRUD, 날짜 미정, 목표일, 상태, 분류, 우선순위, 메모, 상태별 보드/날짜순 목록, JSON 백업.
- 개선·수정: Sprint 원문 상태·변경·검증·출처와 검색. 보완 기록은 작업 ID로 병합한다. 제목 기반 자동 분류를 표시하고 원문을 판단 기준으로 안내한다.
- 개발 기록 및 문서 보관함: 실제 DevLog와 Feature 원문 조회·검색.
- 원본 새로고침으로 후속 문서 변경을 반영한다. 미래 일정은 임의 생성하지 않았다.

## 저장과 경계

원문은 읽기 전용이며 일정만 Git 제외된 `Studio/data/tasks.json`에 저장한다. 원자적 파일 교체, 저장 리비전 충돌 감지, 손상 파일 보존, 입력 크기·날짜 검증을 적용했다. 서버는 loopback에만 바인딩하고 Host/Origin 및 쓰기 요청 헤더를 검증한다. 원문 경로 허용 목록과 실제 경로 확인을 사용하며 임의 프로젝트 파일을 공개하지 않는다. 작업 데이터는 HTML로 실행하지 않는다.

이 화면의 검증 내역은 문서에 기록된 당시 결과다. 현재 게임의 자동 테스트나 현재 빌드 결과로 표시하지 않는다. 같은 이름의 결과 문서가 없는 설계는 확인 대상으로만 표시한다. 외부 호스팅·다른 PC 접속은 제공하지 않는다.

## Builder / Reviewer 검증

- `node --check`로 server.mjs, lib.mjs, public/app.js 구문 통과.
- Node 테스트 4건 통과: Sprint 보완 병합/다중행 근거, 날짜·중복 검증, 파일 재조회·동시 저장 충돌·손상 보존, HTTP 조회·저장·서버 재시작·경로/외부 쓰기 차단.
- 설치된 Playwright 및 Edge headless로 별도 임시 일정 저장소에서 UI QA 통과: 5개 뷰, 추가/수정/리로드/삭제, 다운로드, 검색, Sprint·DevLog·Feature 원문 모달, HTML 문자열 안전 표시, 390px 모바일, 200% root 글자 크기, 브라우저 실행 오류 0건.
- desktop.png / mobile.png를 직접 시각 확인했다. 모바일 테이블과 메뉴는 의도된 내부 가로 스크롤이며 페이지 전체 넘침 없음.
- 실제 서버 HTTP 200 및 프로젝트 기록 로딩 확인. 최초 통합 시 Sprint 작업 61개, DevLog 40개, 설계 102개, 결과 100개. 이번 결과/변경 기록 추가 후 수치는 자동 증가한다.
- Codex 브라우저 패널 열기 요청은 queued로 반환. 통합 브라우저 제어는 환경 ACL 초기화 오류로 사용할 수 없어 설치된 Edge 테스트로 검증했다.
- 게임 C++/설정/바이너리 에셋을 수정하지 않아 UE 빌드 생략. 기존 미커밋 작업을 보존했고 별도 작업 브랜치로 전환했다. 커밋·푸시 없음.
