# StartHub 시작 마을 환경 마감

2026-11-20 · `Sprint#14-5-start-hub-detail`

사용자와 만든 ImageGen 조감도의 주요 구성을 실제 `/Game/Rogue10m/Maps/StartHub`에 적용했다. 60×60m 마을과 기존 주택 열 채 안에서 남쪽 진입로의 아린과 중앙 우물, 북쪽 포탈이 이어진다. 우물 양쪽으로 돌아 나갈 수 있고, 원정 준비 공간은 주 통행로 양옆에 있다. [콘셉트와 프롬프트](2026-11-20_start-hub-concept.md) · [설계](../architect/2026-11-20_start-hub-detail.md)

| 공간 | 저장한 구성 |
| --- | --- |
| 진입로와 우물 광장 | 낮은 돌담, 목재 등주, 아린 앞 디딤돌, 석재 길 가장자리, 우물 지붕 밑면과 도르래·양동이 |
| 장비점과 강화소 | 천막, 기초 장비 진열대와 물약, 석조 화덕과 모루, 작업대와 담금질 통 |
| 원정 접수소와 기록소 | 차양과 구역별 깃발, 원정 지도와 보급품, 서가와 펼친 책·두루마리 |
| 서쪽 수련장 | 원정 접수소 뒤에 울타리와 허수아비 두 개를 배치했다. 기존 등주 남쪽으로 디딤돌 길이 이어진다. |
| 포탈과 외곽 | 돌기둥과 아치 장식, 안내판 받침, 등불과 돌 대기 구역, 기존 울타리 바깥의 나무와 바위 |

플레이어 스폰, 아린의 위치와 서비스, 단일 포탈의 목적지와 타이머 시작 조건을 기준으로 삼았다. 준비 구역 네 곳은 소품으로 용도를 보여 주며 서비스는 기존 아린 대화에서 이용한다. 수련장 허수아비는 환경 소품이다. 수련장을 조감도보다 북쪽으로 옮겨 주택 출입구와 원정 가판대를 피했다.

## 저장 범위

UE 5.8 Editor API로 정적 메시 378개와 국소 조명 10개를 저장했다. 기존 자리표시 소품 20개와 숨긴 옛 받침 5개의 외부 액터만 수정했다. 새 돌바닥 다섯 개에 보행 충돌을 부여했다. 추가 콘텐츠는 StartHub 외부 액터 388개와 폴더 외부 객체 10개다. 원본 Stylized Village 메시와 프로젝트의 기존 시작 마을 재질, 초급 무기 메시를 로컬에서 읽어 사용했다.

저작 진입점은 `Scripts/Editor/StartHubDetail/RunAuthor.ps1`이다. `Plan`은 초기 StartHub와 참조 자산을 검사하고 `Apply`는 초기 상태에 최종 배치를 저장한다. 저장 상태는 `Scripts/VerifyStartHubDetail.ps1 -OutputDir <새 출력 폴더>`로 재검사할 수 있다.

## 실제 화면과 검증

| 항목 | 결과 |
| --- | --- |
| Editor 빌드 | UE 5.8 Development Editor 성공. 최초에는 공유 Live Coding 세션이 일반 빌드 검사를 막았다. 독립 체크아웃의 출력 경로를 확인하고 IDE 핫 리로드를 적용하지 않는 빌드를 실행했다. |
| 독립 재로드 | 40개 검사 통과. 월드 파티션 디스크립터 1,066개와 장식 388개를 읽었다. 새 돌바닥 5개의 중앙·모서리 25점, 주요 동선 8개·캡슐 32회·바닥 122점과 경계 28회를 통과했다. |
| 렌더링 플레이 | 기본 3인칭 카메라에서 프로그램 입력으로 우물 양쪽을 걸었다. 12개 경유점과 접지 124개를 관찰했다. StartHub의 타이머는 1,200초를 유지했고 실제 포탈 진입 후 OpenRunMap에서 1,200초부터 1,198초로 줄었다. |
| 이전 프로필 | 격리한 Legacy1 검증에서 17개를 통과했다. 보행으로 실제 포탈에 들어가고 이전 프로필의 진척과 소지품을 확인했다. |
| 아린 | 실제 배치 NPC에 대한 F 입력, Slate 선택, 보급, 강화, 특성·난이도와 저장 복원 58개 통과. 사전에 있던 격리 QA 저장 5개의 해시가 같았다. |
| 에디터 출력 | 최종 저작·재로드·렌더링·아린 런의 Error/Fatal/ensure 0건. 모든 디스크립터를 로드한 Map Check는 기존 포탈의 빈 선택 메시 경고 1건을 냈다. 실제 포탈 이동은 통과했다. |

검증은 Development 환경의 프로그램 입력으로 진행했다. 최종 화면은 Unreal에서 렌더링했다. [진입 시점](../../DevLog/20261120_StartHubDetail/start-hub-arrival.png) · [전체 조감도](evidence/start-hub-detail-20261120/overview.png) · [포탈 플레이 화면](evidence/start-hub-detail-20261120/gameplay-portal.png)

첫 렌더에서 색 성분 순서가 뒤집힌 새 등불과 한쪽 면만 보이는 천막·지붕 밑면을 발견했다. RGB를 명시해 조명을 다시 저장하고 천막과 우물의 밑면을 추가했다. 첫 경로 검사는 기존 등주에 닿았고, 실제 통과할 수 있는 쪽에 디딤돌 길을 냈다. 마감 도중 검토용 에디터가 기존 받침 패키지 다섯 개를 잠가 부분 저장이 발생했다. 해당 세션을 닫은 뒤 저장된 액터와 남은 패키지를 대조해 복구했다. 마지막으로 보이는 돌바닥과 캐릭터가 밟는 충돌 모양을 맞춰 재검증했다. 로그 검사기가 정상 맵 로드 페이지 제목을 오류로 세던 경우도 바로잡고 기존 검사 15개를 통과했다.
