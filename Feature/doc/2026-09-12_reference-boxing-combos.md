- 날짜: 2026-09-12
- 브랜치: Sprint#4-28-reference-boxing-combos
- 엔진: 설치된 UE 5.8.2
- 상태: 소스·Editor 자산 적용 및 실제 게임 실행 검증 완료

## 적용한 조작

| 입력 | 동작 |
| --- | --- |
| 좌클릭 1타 | 왼손 잽 |
| 좌클릭 연계 2타 | 오른손 잽 |
| 우클릭 짧게 눌렀다 놓기 | 오른손 스트레이트 |
| 우클릭 0.85초 이상 모았다 놓기 | 오른손 훅 |

기본 Unarmed 직업에 적용했다. 기존 골격을 평가하는 C++ 절차형 애니메이션이며, 공유 원본 몽타주를 덮어쓰거나 외부 영상의 애니메이션 자산을 추출한 작업은 아니다. 스킬 데이터의 몽타주 길이·속도·명중 지연을 포즈 평가와 함께 사용한다. 기존 RightUppercut enum과 두 어퍼컷 자산은 호환성을 위해 남겼으며 기본 입력에서 해제했다.

## 동작과 타격 표현

잽은 짧은 준비와 빠른 신전으로 구분했다. 왼잽에서 오른잽이 예약되면 다음 준비 자세로 이어지고, 직전 손 위치에서 다음 공격을 시작한다. 스트레이트에는 더 큰 어깨·상체 전진을 적용했다. 훅은 오른쪽 외측 준비에서 중앙을 통과하는 수평 궤적을 사용하고 왼가드를 바깥·뒤로 이동시켜 두 주먹의 겹침을 줄인다. 충전 해제 시 팔꿈치 준비값도 직전 상태에서 연결한다. 팔 도달은 원래 두 뼈 길이의 94%로 제한한다.

명중 피해가 양수일 때 기존 Niagara 충격 효과와 피해 숫자에 적 움찔·플래시 및 짧은 카메라 충격을 함께 더한다. 적 충격은 메시만 최대2cm·3도 범위에서 움직이며0.18초 안에 복원한다. 카메라 충격은0.16초 동안 감쇠하며 공격 실행당 한 번만 발생한다. 기존 머리 반응에 합산한 최종 화면에만 제한을 적용해 실제 조준 CameraComponent와 ControlRotation을 유지한다.

공격을 시작한 무기를 기록하므로 다른 무기의 잔여 다단 공격을 기본 복싱 효과로 잘못 처리하지 않는다. 적의 기존 오버레이 재질은 보호한다. 사망·효과 끄기·무기 전환·잘못된 시간 값에서 표현 상태를 정리한다. 기존 판정은 겹침 기반이라 충격 효과 위치는 실제 접촉점이 아닌 공격자 쪽 경계면 추정이다.

## 소스와 자산

- BasicBrawlerComponent: 우클릭 시간에 따른 동작 구분, 오른잽 enum 추가, 명중 비율 및 다음 공격 예약 정보 전달.
- FistAnimInstance: 네 동작의 준비·신전·곡선 회수, 팔꿈치 전환과 반대손 가드, 상체·머리 움직임.
- CombatComponent / FirstPersonPresentationComponent / 새 HitFeedbackComponent: 확정 명중에 한정된 적·화면 반응.
- ConfigureBasicBrawler.py / ConfigureBrawlerHitFeedback.py: Editor API로 네 전용 스킬과 Unarmed 프로필 설정, M_BrawlerHitFlash 생성 및 기존 NS_Punch_Impact 연결.
- Tests: 네 공격·피해 시점, 팔 전용 아래보기, 명중·헛스윙·복수 대상·무피해·복원·충전 경계 검증.

전용 스킬은 DA_BasicBrawler_LeftJab, RightJab, RightStraight, RightHook이다. 잽 두 개는 재생 속도1.5·명중 정점0.34, 스트레이트는1.0·0.34, 훅은1.5·0.38을 사용한다. 피해·자원·쿨타임 등은 각 원본 스킬 설정을 계승한다. 팔 전용 SK_FirstPersonArms와 원본 Manny 메시를 수정하지 않았다.

스트레이트 손은 가드 대비 전방10.192cm까지 도달한다. 훅의 수평 이동 폭은38.02cm, 수직 변화는3.92cm로 확인했다. 양팔의 위팔27.771cm·아래팔27.251cm 길이는 가드와 명중 중 동일하다. 가드에서 오른 어깨가 뒤에 놓이는 원본 준비 자세로 인해 좌우 도달 거리는 비대칭이며 이를 팔 늘리기로 보정하지 않았다.

네 공격의 데이터상 명중 정점과 실제 피해의 최대 오차는0.0274초다. 별도로 실제 손의 전방/안쪽 도달 정점과 피해를 비교한 최대 차이는0.0667초다. 오른잽은 회수 초기에 전방 좌표가0.154cm 더 전진하는 차이가 있으므로 완전히 동일한 프레임이라고 기록하지 않는다. 프레임당 최대 손 이동은16.498cm, 충전 경계 해제의 최대 팔꿈치 이동은10.190cm다. 이는30fps 고정 시간 샘플이며 모든 프레임률이나 주관적인 멀미 감각을 보장하는 결과는 아니다.

원본 Manny SHA256은 이전 검증값 BE9F011191EE1887B97CD13BCE09886A6066C2FD62C619991070EC142184E1BF와 일치한다. 신규 소스 차이는 scoped-source.patch, 실제 손 계측은 actual-hand-peaks.json에 보관했다.

검증 과정에서 충전 해제 팔꿈치 불연속, 다른 무기 잔여 공격의 표현 소유권, 스트레이트 도달 부족과 훅의 반대손 겹침을 수정했다. 사망 시 즉시 제거되는 적을 다시 읽던 테스트 결함도 수정한 뒤 통과했다. 초기 실패 로그는 보관했으며 최종 결과와 구분한다. 독립 소스/시각 검토 내용은 source-review.md와 visual-review.md에 남겼다.
