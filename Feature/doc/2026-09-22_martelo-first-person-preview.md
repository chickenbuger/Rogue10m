# Martelo 2 실제 게임 캐릭터 1인칭 미리보기

- 날짜:2026-09-22
- 브랜치:Sprint#4-31-martelo-first-person-preview
- 요청:사용자가 제공한 Martelo 2.fbx를 게임 캐릭터에 적용한 실제1인칭 화면을 보여준다.

## 실제 적용과 촬영

Mixamo 원본65개 뼈의 애니메이션을 UE5.8의 IK 리타기팅으로 Manny 뼈대에 옮겼다. 새 전용 자산은 `/Game/Rogue10m/Animation/Preview/Martelo/A_Martelo2_Manny`다. 원본 파일에는 표면 메시가 없어, 임포트용 뼈대 생성에만 최소 스킨 삼각형을 추가한 파생 FBX를 사용했다. 원본·파생 파일의40프레임×65뼈 전역 위치는 모두 일치했다. 기준 자세는 애니메이션0프레임이 아닌 원본의 정적 기준 자세를 사용했다.

실제 Rogue10m 맵,HUD,플레이어의 SK_FirstPersonArms 메시에서 새 애니메이션을 재생했다. 기본자세1초→원본속도→기본자세1초→0.5배속→기본자세1초 순서다. 최종 영상은1280×720·30fps·209프레임·약6.967초 무음이다. 골격 시각화나 합성 캐릭터 장면이 아니다. 영상 상단의 속도/시야 표시는 촬영 후 설명용으로 더했다.

현재 팔 전용 시야와 고정 카메라를 사용한다. 원본은 왼발을 높이 차는 전신 동작이므로 다리 타격은 표면에 표시되지 않고, 균형을 잡는 양팔이 화면 안팎을 크게 이동한다. 동작 중 팔이 화면에서 완전히 빠지는 구간도 관찰했다. 종료 후 기존 기본 가드로 복귀한다.

이 영상은 원본 동작을 현재 시야에 적용한 비교용이다. 기본 가드와 원본 클립 시작/끝 자세의 전환은 블렌딩하지 않았으며 원본 포즈의 진입·복귀 차이가 그대로 보인다. 기존 FistAnimInstance 대신 SingleNode로 평가하므로 기존 머리 기반 카메라 연동도 적용되지 않는다. 완성된 발차기 전투 연출이나 부드러운 공격 연계로 표시하지 않는다.

## 검증

- UE5.8.2 Editor 빌드25.22초 성공.
- 베이크된 Manny 포즈를 별도 평가:길이1.30초,왼발 높이 변화136.73cm·오른발7.23cm. 왼발 주도 발차기 보존 확인.
- 실제게임 `Rogue10m.PreviewMartelo`:209프레임 실패0. 좌우 손 이동77.254/101.540cm,기존메시·시야·조준·공격승인번호 유지 및 기본AnimBP복원 확인.
- 명령은 독립 `-game` 실행 전용이며 PIE에서는 거부한다. 월드 종료 시 입력무시·고정시간·콜백을 정리한다.
- 원본Manny메시·MannySkeleton·팔전용메시·Unarmed프로필의 전후해시 확인.
- 기획1·개발2·검증2 역할로 생성/실행/소스/화면을 분담했다.

## 저장·재실행 및 최종 검토

최초 임포트에서 소스 메시만 저장되고 뼈대와 애니메이션이 메모리에 남는 문제를 발견했다. Source/Persistent 아래 세 자산을 명시적으로 저장하도록 고쳤다. 새 Editor 프로세스에서 원본·파생 FBX 해시와 정확한 자산 경로를 검증한 뒤 기존 소스를 재사용하고 리타기팅·포즈 평가를 통과했다. 재베이크 전후 포즈의 좌표축별 최대 차이는 0.338cm로 완전히 동일하지는 않았다. 최종 자산으로 게임을 다시 실행하고 209프레임 촬영을 재검증했다.

실패한 초기 소스 메시 한 개는 참조가 없음을 확인한 뒤 Editor API로 삭제했다. 공용 메시·뼈대·팔 메시·무장 프로필 네 파일의 작업 전후 SHA256은 모두 같다. 최종 소스 검토가 통과했고, 화면 검토에서는 팔이 시야 밖으로 빠지는 구간과 기본 가드 복귀를 확인했다. 대표 프레임에서 눈에 띄는 찢어짐은 없었지만 모션 블러가 강하므로 모든 순간의 손목 품질을 보증하지 않는다.

최종 MP4는 1280×720, 30fps, 209프레임, 6.966667초다. git diff --check 및 Harness 경로 검사를 통과했다. 경로 검사에는 이전 작업의 바이너리 변경 경고가 포함되며, 이번 미리보기 자산은 Unreal Editor에서 생성했다. 이전 작업의 변경은 유지했다.
