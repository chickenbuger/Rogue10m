# 시작 마을 면적 1/4 축소 결과

2026-11-18 · `Sprint#9-32-landscape-world-blockout`

`/Game/Rogue10m/Maps/StartHub`의 지면을 120×120m에서 60×60m로 줄였다. 지면은 14,400m²에서 3,600m², 경계 충돌 안쪽은 13,548.96m²에서 3,387.24m²로 바뀌었다. 두 기준 모두 원래 면적의 25%다.

남쪽 스폰에서 아린을 지나 우물 양옆으로 돌아 북쪽 포탈에 닿는 흐름을 유지했다. 중앙 광장과 흙길의 길이를 줄이고 길 폭은 유지했다. 주택 열 채와 네 준비 구역의 크기를 유지하며 부품을 함께 옮겼다. 북쪽 포탈 네 개와 표지를 Y 4,270cm에서 Y 2,135cm로 옮겼다. 트리거의 가로 간격, 목적지와 런 시작 조건을 유지했다. 기존 Stylized Village 메시와 시작 마을 재질을 재사용했다.

## 저장과 검증

- 월드 파티션에서 액터와 디스크립터 691개를 전부 읽었다. 기존 위치·스케일·회전의 변경 범위와 에셋 참조, 패키지 이름, 포탈 속성을 저장 전과 독립 재로드에서 대조했다.
- 내부 지면 121점은 Z 0cm였으며, 지면 밖 4점은 바닥 충돌이 없었다. 네 경계와 모서리에서 캐릭터 크기 캡슐 검사 28건을 통과했다. 두 방향 우물 우회로, 네 준비 구역과 포탈 발동 구간의 통행 검사 13건을 통과했다.
- 실제 이전 저장의 격리 복사본으로 정규 Development 모듈을 사용했다. 프로그램이 시작점에서 걷기 입력을 보내 기존 포탈로 진입했고 `OpenRunMap?StartRun=1`과 1,200초 런을 확인했다. 검증 17개와 종료 코드 0, 복사한 입력 저장 두 파일의 해시 일치를 확인했다. 달리기나 실제 키보드 조작을 별도로 측정하지 않았다.
- `StartHub`의 디스크 패키지 726개를 해시 검증해 물리 백업했다. 기존 외부 액터 660개만 저장됐다. 나머지 66개는 바이트가 같았고 추가·삭제는 없었다. 저장 전 정원 공간 부족, 텍스트 액터의 bounds 차이, 검사 순서 오류는 쓰기 전에 중단됐다. 정원 재배치와 위치 기준 보정, 프로브 순서 수정 후 통과했다. 기존 `Humanoid` 의존 참조 오류가 격리 게임 실행에서 재현됐다.

이번 범위는 기존 허브의 배치와 통행이다. NPC 서비스 결제, 보조 포탈의 실제 레벨 전환, 렌더링 화면 검수, 내비게이션 재빌드와 Shipping은 별도로 검증하지 않았다. 현재 에디터 세션에서 열려 있던 제작 맵은 그대로 두었다.
