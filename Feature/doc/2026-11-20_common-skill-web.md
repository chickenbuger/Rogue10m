# 공통 이동 스킬트리

K 창의 공통 탭에서 기초 단련을 시작으로 이동, 도약, 회피 능력 15개를 습득한다. 연결선 21개는 양방향이다. 이미 습득한 노드와 연결된 능력에 공용 성장 포인트 1P를 투자한다. 이단 점프 강화, 구르기 재사용 단축, 이동 속도 강화에는 각각의 기본 능력도 필요하다. 공중 속도 유지, 착지 안정, 회피 후 가속은 서로 다른 구역을 잇는다. [작업 계획](../architect/2026-11-20_common-skill-web.md) · [승인 시안](evidence/common-skill-web-20261120/approved-concept.png)

공통 탭의 `아이덴티티` 버튼으로 이전 내공·투지·마나 화면을 열 수 있다. 기존 전수와 검 공명 조건은 같은 기록을 사용한다. 예전 저장을 읽으면 무료 시작점이 생기며 기존 성장 지출은 그대로 복원된다. 단절된 연결이나 필수 선행을 건너뛴 투자 기록은 저장 검증에서 거부한다.

| 구역 | 능력과 기본 효과 |
| --- | --- |
| 도약 | 공중 제어 +25%, 이단 점프 최소 2회, 도약 속도 +8%, 두 번째 도약 속도 추가 +12% |
| 이동 | 이동 속도 +5%와 강화 +5%, 지상 방향 전환 마찰 +25%, 지상 가속 +15% |
| 회피 | 회피 동작 시간 15% 감소, Alt를 구르기로 전환하고 기준 거리 250cm 적용, 회피 거리 추가 보정 +15%, 구르기 재사용 대기 최대 20% 감소 |
| 교차 | 공중 무입력 감속 40% 감소, 착지 0.25초 동안 지상 마찰 +50%, 회피가 끝난 뒤 0.8초 동안 이동 속도 +10% |

구르기에 프로젝트의 기존 Manny 호환 이동 골격과 회피 효과를 활용했다. 전방 회전과 몸을 접는 자세는 C++에서 구르기 진행에 맞춰 적용하고, 캡슐 이동은 지면과 장애물 충돌을 처리하는 캐릭터 이동을 사용한다. 기본 지속 시간은 0.42초이며 회복 단축 습득 시 0.357초다. 안전한 일반 회피 스텝은 구르기 습득 전의 Alt 동작이다. 구르기 중에는 공격 수락을 잠시 막고, 몸이 회전할 때 1인칭 카메라는 기존 기준 높이와 조준 회전을 사용한다.

## 검증

최신 통합본의 독립 작업 복사본에서 UE 5.8 Development Editor 빌드, 공통·너클·대검 자동화 4개, StartHub 게임 검사 282개, 신규 프로세스 저장 복원 검사 109개를 통과했다. 세 실행의 출력 로그 오류는 각각 0개였다. 게임에서 Slate 포인터 입력으로 1P 이동 속도 증가를 사고, 교차 경로로 이단 점프에 도달했으며, 장비 해제와 대검 복원 뒤에도 공통 효과가 적용됐다. Space 두 번과 Alt는 게임의 일반 입력 경로를 사용했다. 별도 저장을 다시 읽어 공통 노드 16개와 기존 무기 및 아이덴티티 기록을 함께 확인했다.

첫 게임 검사에서는 대검 회피 데이터의 1,000cm 초기 속도 기준을 구르기의 실제 이동 거리로 재사용해 약 1,581cm를 이동했다. 구르기는 전용 250cm 기준을 적용하고, 검사에서는 마을 창을 닫아 공격 회복이 끝나고 무기 변경이 가능한 상태를 기다린 다음 실제 착지 뒤에 Alt를 입력했다. 최종 검사에서 회피 거리 강화와 함께 297.59cm를 이동했다.
