# Boxing.fbx 기반 권사 자세·공격 제작

- 작업 브랜치: Sprint#4-34-boxing-reference-stances
- 상태: 소스 구현·빌드·실제 게임 검증 완료. 커밋·푸시 없음.

## 구현 결과

Boxing.fbx의 왼발 전진, 왼손 직선 신전, 오른손 가드와 회수를 현재 전신 1인칭 권사에 반영했다. 원본 1.73초 동작을 그대로 재생하는 방식이 아니라 기존 C++ 절차형 네 공격의 가드·팔꿈치·골반·발 지지를 조정했다. 실제 피격 시각과 입력·피해 데이터는 유지한다.

| 입력 | 동작 |
|---|---|
| 좌클릭 첫 타 / 연계 두 번째 | 왼잽 / 오른잽 |
| 우클릭 짧게 눌렀다 떼기 | 오른 스트레이트 |
| 우클릭 길게 모았다 떼기 | 오른 훅 |

기본 CompactBoxing은 좁은 가드와 작은 발 디딤을 사용한다. LongGuard는 왼손을 더 앞에 두고 오른손 가드를 높이며 몸통 회전을 줄인다. RootedMartial은 양손을 조금 낮추고 골반 회전 참여와 발 지지를 강조한다. 프리셋은 `URogue10mFistAnimInstance.BasicCombatStance`에서 설정한다. 별도 선택 UI를 추가한 작업은 아니다. Blueprint 애니메이션 자식 클래스의 기본값으로 설정하거나 아래 독립 게임 검사 명령으로 비교한다.

```text
Rogue10m.TestBasicBrawler smooth boxing
Rogue10m.TestBasicBrawler smooth longguard
Rogue10m.TestBasicBrawler smooth rooted
```

위 명령은 검증용 게임 프로세스에서 타격·자원을 조작하고 검사 종료 시 프로세스를 종료한다. 일반 플레이용 자세 변경 명령은 아니다.

새 자세는 전신 맨손 경로에서만 활성화되며 Knuckle·팔 전용 경로를 유지한다. BasicStanceStrength 또는 BodyMotionStrength가0이면 신규 자세 효과가 해제된다. 앞발 스텝6cm·지지발 회전12도·들림2cm가 기본 튜닝 상한 입력이며 실제 포즈에는 몸 강도와 동작 가중치가 적용된다. 지형 충돌을 읽는 IK나 발볼 접지 피벗이 아니라 원래 발높이를 기준으로 한 포즈 지지 보정이다. 이동·공중 진입에서는 FK와 IK를 부드럽게 섞는다.

## 원본과 추가 참고

FBX의 Take 001은 완전 정적 T-pose이고 실제 mixamo.com 스택만 분석했다. 65본, 메시2개,1.73333초53샘플. 왼손 정점0.43333초, 어깨 기준 전방29.527→53.899cm, 오른손전방범위3.893cm. 파일에 오른손 스트레이트나 훅이 포함됐다고 해석하지 않았다.

England Boxing 코칭 교본의 반대손 보호·뒷발/골반 회전, Rajadamnern 공식 롱가드 설명의 앞손 거리재기, JKA 교본의 수평 골반 회전과 지지 개념을 참고했다. 정확한 출처와 게임용 해석은 짝 설계 문서에 정리했다. 자세별 수치는 원본 실측값의 직접 복사가 아닌 1인칭 게임용 튜닝이다.
