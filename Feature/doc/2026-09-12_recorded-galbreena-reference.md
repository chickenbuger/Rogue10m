- 방법: 로컬 디코더로 실제 프레임 추출. 전체 흐름을 약 2초 간격으로 살펴보고 18~21초 공격 및 36~39초 이동 구간은 8fps로 추가 확인. 아래 시간은 녹화 파일 기준이며 원본 쇼츠 시간과 다르다. 샘플 시간에는 한 샘플 이내의 오차가 있을 수 있다.
- 역할: 주 담당의 직접 영상 프레임 관찰과 서브에이전트의 현행 소스 분석·독립 프레임 대조. 이번 작업은 비교 기록이며 게임 코드 변경은 없다.

## 직접 확인한 내용

영상은 제목에 표시된 명조 갈브레나의 총기 동작과 이동·공중 동작, 후반의 다른 시점 및 연출 장면을 포함한다. 앞부분 약 17초는 같은 장면과 재생 UI가 오래 나타나므로 자연스러운 움직임을 판단하는 구간에서 제외했다. 후반 약 49~67초의 다른 시점도 기본 1인칭 가드의 기준으로 사용하지 않는다.

18.25초 부근에는 손이 화면 중앙으로 올라오고, 19.38~19.88초에는 무기가 좌우와 화면 높이를 크게 사용한다. 20.50초 대각선으로 가까워진 무기가 다음 샘플에서 화면 밖으로 빠진다. 팔·무기가 항상 동일한 두 지점에 머무르는 구성이 아니다. 보라색 발광과 광선이 일부 공격 구간의 대비·속도감을 더한다.

36~38초에는 바닥이 사선으로 보이며 전방 구조물이 커지고, 38.38~38.75초에는 아래쪽 바닥이 화면을 크게 차지하도록 시점이 변한다. 화면 변화는 관찰할 수 있지만 실제 이동·마우스 조준·본 기반 카메라·연출 카메라의 기여도를 녹화만으로 분리할 수 없다.

## 현재 Rogue10m과 비교

| 항목 | 현행 구현 | 녹화에서 얻은 적용 방향 |
| --- | --- | --- |
| 팔의 공간 사용 | 좌우 가드가 일정하고 잽·스트레이트가 주로 전방 중심으로 모임 | 잽은 짧고 읽기 쉽게 유지하고, 강공격은 옆·아래에서 안쪽으로 진입하는 별도 경로를 사용 |
| 회수·다음 공격 연결 | 이미 곡선 회수와 직전 손 위치부터 이어지는 연계가 있음. 정점 뒤 회수 구간은 공격 길이의 약30%이며 기본 가드로 수렴 | 연계 중에는 다음 준비 자세로 연결하고 마지막 공격에서만 가드로 복귀하도록 회수 목적을 구분 |
| 몸·머리·카메라 | 이미 상체 선행, 머리 후행 및 평가된 머리 기반 POV가 있음. 기본 pitch/yaw ±1.5도·roll ±0.8도와 이동2cm 상한 | 기존 동조를 기반으로 일반 공격·강공격·착지마다 다른 반응을 설계. 모든 상황의 흔들림을 일괄 확대하지 않음 |
| 명중 표현 | 팔 움직임과 피해 시점, 머리/POV 동조는 이전 회귀 검증으로 확인 | 실제 명중 시점에 적 반응·짧은 시각 효과를 함께 조율. 헛스윙과 명중을 구분 |
| 화면에 보이는 신체 | 팔 전용 메시로 몸통과 하체 표면을 제거한 상태 | 녹화에 신체 일부가 보이는 순간을 복제할 필요는 없음. 사용자가 요청한 팔 전용 시야 유지 |

적용 우선순위 제안은 공격별 팔 경로와 연계 회수, 다음으로 강공격·착지의 카메라 반응, 이후 명중 효과다. 이는 영상의 공간적 특징을 현재 주먹 전투에 맞게 옮기는 설계 제안이다. 총기 동작을 그대로 이식하거나 원본의 내부 구현을 알아냈다는 의미가 아니다.

## 분석 범위

이번 녹화 파일의 실제 영상 프레임은 확인했다. 브라우저 오류를 해결하거나 YouTube 링크를 직접 재생한 것은 아니다. 고릴라 암즈와 이전에 요청된 별도 복싱·요네 영상의 직접 비교까지 완료한 것은 아니다.

오디오가 없어 타격음·음악의 기여도는 평가하지 않았다. 원본 영상이 편집·배속됐는지 확인할 수 없으며 8fps 샘플로 정확한 히트스톱 길이, 입력 지연이나 세부 손목 각도를 단정하지 않는다. 화면 움직임을 캐릭터 뼈 애니메이션이나 카메라 수치로 직접 역산하지 않았다.
