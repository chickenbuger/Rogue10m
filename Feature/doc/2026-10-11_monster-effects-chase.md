# 몬스터 시야 추적 전투와 종별 이펙트

일반 몬스터 5종과 아자토르는 주변 플레이어를 시야로 인식하고, 내비게이션 경로로 추적한 뒤 사거리에서 공격한다. 공격 발동과 실제 명중을 별도로 표시하는 Niagara 8개를 제작해 현재 맵의 공격 프로필에 연결했다.

## 사용 방법

OpenRunMap에서 플레이하면 일반 몬스터 AI가 자동으로 실행된다. 가까이 가면 발견·추적·공격하며, 장애물에 가려져 일정 시간 보이지 않거나 홈 기준 추적 거리를 벗어나면 대상을 놓는다.

쉽게 확인하려면 **F6 → 몬스터 선택 → 소환 → 자동 AI 전투 시작**을 누른다. 테스트 소환 직후는 수동 패턴을 안전하게 확인할 수 있도록 AI 정지 상태이며, 자동 AI 시작은 실제 시야 인식을 사용한다. 패널을 열면 게임이 일시정지된다. 개별 공격·무적·회복·테스트 몬스터 정리 버튼도 그대로 사용할 수 있다.

## 동작과 검토

- AIPerception의 주변 360도 시야는 거리와 실제 장애물 가림 판정을 유지한다. 기존 몬스터별 인식·추적 거리 데이터는 보존했다.
- 정지 플래그로 시야·피해 콜백이 정지된 AI를 되살리지 않게 했다. 재개 시 현재 시야의 플레이어를 다시 수집한다. F6 자동 AI에서 가짜 피해 자극을 제거했다.
- 이동하는 Actor 목표는 이미 경로를 갱신하므로 동일 MoveTo를 0.25초마다 중단·재시작하지 않는다. 기존 중심 간 거리와 사거리 계약을 보존했다.
- 공격이 발동하면 공격 효과, 실제 양수 피해가 적용되면 명중 효과가 발생한다. 무적·불발에는 명중 효과가 나오지 않는다. 이펙트는 피해 범위나 보상에 관여하지 않는다.
- Niagara 완료 델리게이트에서 참조를 제거해 풀에 반환된 컴포넌트를 다른 몬스터가 사용해도 간섭하지 않는다. AI 정지·취소·사망·EndPlay는 효과를 즉시 정리한다. 전용 서버에서는 Niagara 로드를 생략한다.
- GC 보유 에셋은 UPROPERTY/TObjectPtr, 수명 관찰은 Weak 포인터이며 새 Tick은 추가하지 않았다. 기존 애니메이션·보스 경고·피해 판정을 유지했다.
- Remote Execution이 에디터를 여러 개 발견할 때 프로젝트 경로로 정확히 하나를 선택하도록 보강했다. 원본과 worktree 에디터에 잘못 명령하는 문제를 방지한다.

## 검증 기록

- 개발 브랜치: `Sprint#5-28-monster-effects-chase`, 별도 관리 worktree. 다른 채팅의 특성 개발 전 안정된 소스 사본으로 기능을 검증한 뒤 이번 변경 파일만 원본에 통합했다.
- Unreal Editor C++ 빌드 통과.
- Niagara 8개 모두 Editor를 열어 검사: UpToDate, 오류 0, 경고 0, 스택 오류·경고 0. 정보 항목 2개는 엔진 템플릿 모듈 버전 안내다.
- `sight`, `visual` standalone QA에서 6종 자연 인식·이동 추적·타격·실제 Niagara·정지·재개가 통과했다. `visual`은 리시 이탈·재인식 차단과 실제 게임 화면 캡처를 추가했다.
- 최초 QA에서 시야 사각과 Idle 상태 효과 정리 누락을 발견해 수정했다. 실패 로그도 증거 폴더에 보존했다.
- 추가 QA에서 사거리 120cm인 초록 점액체의 수동 테스트 위치가 정확히 사거리 경계에 놓여 부동소수점 오차로 실패하는 경우를 발견했다. 모든 기본 공격 테스트 위치에 20cm 여유를 두도록 수정했다. 느린 가시 수호자의 이동 검증은 최소 이동 20cm와 이동한 플레이어에 대한 실제 공격을 함께 확인한다.
- 최종 `final`과 원본 `integrated` 실제 게임에서 각각 110개 검증·실패0. 무적에서 공격 효과만 발생하고, 유한 효과가 자동 종료되며, 아자토르 정면/영역 효과가 공격 발동 시 표시되는 것을 확인했다. 캡처는 각 종과 두 특수 패턴을 포함한다.
- 기존 F6 UI 회귀 `monsterFX`: 실제 키·Slate 마우스·6종·패턴·피해·회복·무적·정리·보상 검증80개·실패0.
- 원본 통합 빌드32.42초 성공. 최초 통합 사본의 오래된 수정 시간으로 UHT 재생성이 생략된 문제는 소스 수정 시간 갱신과 정식 빌드로 해결했다. 생성 파일은 직접 수정하지 않았다.
- CheckGeneratedChanges, 관련 diff --check, Python4개 문법 검사 통과.
- 새 모듈로 원본 Editor를 재실행했다. 최종 OpenRunMap, PIE 종료, 미저장 콘텐츠/맵0, 저장된 아자토르 파동 Niagara 프로필 로드를 확인했다.

증거: `Feature/doc/evidence/monster-effects-chase-20261011/`. 재현: `Scripts/ValidateMonsterChaseEffects.ps1 -Label <새이름>`; 기존 F6 UI 회귀: `Scripts/ValidateCombatTestUI.ps1 -Label <새이름>`.
