# 개발 스튜디오 활성화와 후속 개발 목록

> 2026-10-11 후속 지시로 개인 개발 스튜디오와 실행기·전용 예약을 제거했다. 아래 내용은 제거 전의 조사·실행 이력이다. 현재 상태와 데이터 보존은 `Feature/doc/2026-10-11_remove-personal-studio.md`를 따른다.

확인일: 2026-10-11. 현재 브랜치: `Sprint#5-22-walking-palm-reference`.

## 스튜디오 상태

`Scripts/OpenPersonalStudio.ps1 -NoBrowser`로 로컬 서버를 활성화하고 실제 API 응답을 확인했다. 주소는 `http://127.0.0.1:4317/#schedule`이며 실행 엔진은 ready, 일시정지는 false, 진행 작업과 실행 가능한 대기 작업은 각각 0개다. Codex 패널에 개발 일정 화면을 여는 요청도 전달했다.

등록된 작업은 2개다. 원본 일정의 status 문자열보다 실행 레코드를 우선하면 모두 completed다.

- 무기 별 애니메이션 기획 작성: 기획 완료.
- 기획을 기반으로한 맨손,너클 애니메이션 제작: 제작·검증 완료.

완료된 작업을 다시 대기열에 넣지 않았다. 서버 시작과 상태 조회는 게임 코드·에셋을 변경하지 않았다.

## 후속 개발 후보

아래는 최근 결과 문서가 후속 범위로 남긴 내용을 정리한 목록이다. 새 예정 작업으로 등록된 상태는 아니며, 우선순위는 이번 검토 제안이다. 실제 구현을 시작할 때 현재 소스·에셋과 기존 변경을 다시 대조해 세부 범위를 확정한다.

| 순서 | 우선순위 제안 | 작업 | 확인된 근거와 목표 |
| --- | --- | --- | --- |
| 1 | 높음 | 보스 처치와 런 승리 연결 | OpenRunMap 결과에 처치→승리 종료 연결 미구현이 명시되어 있다. 보스 처치·시간 초과·결과 화면·재시작 흐름을 통합한다. |
| 2 | 높음 | 아자토르 전용 보스 패턴 | 현재는 고정 조우와 기본 공격이다. 예고 동작·회피 가능한 특수 공격·체력 단계 등을 작은 패킷으로 설계하고 실제 피해/취소를 검증한다. |
| 3 | 보통 | 마을 NPC 서비스와 특성 강화 | 현재 안내·보급 외 서비스는 후속 범위다. 아이템·특성·난이도 서비스를 기존 UI/데이터 소유권에 맞춰 확장한다. |
| 4 | 보통 | 성장·스킬 진행·인벤토리 저장 확장 | 기존 캐릭터 프로필과 키 SaveGame은 존재한다. 전투 수련/토벌 및 일반 인벤토리의 영구 저장을 이 기능들과 구분해 범위를 정한다. |
| 5 | 보통 | 맨손·너클 외 무기 전용 모션 | 무기별 기획의 후속 제작 패킷을 확인한다. 활·표창의 대체 동작 해소, 장검·대검·단검 등을 한 종류씩 적용·검증한다. 이번 조사에서 각 바이너리의 최신 연결을 재감사한 것은 아니다. |
| 6 | 출시 전 필수 | 전체 런 통합 QA와 패키징·성능 | 기존 집중 검사는 전체 20분 플레이·모든 경로 연속 순회·패키징·성능을 보장하지 않는다. WP 이동/Navigation, 시간 초과/승리, 쿠킹과 프레임·메모리를 실제 실행으로 확인한다. |

아린의 기본 Walk/Talk는 10월 9일 결과 기준 완료다. 전환 블렌딩·경사면 발 IK·립싱크·순찰은 추가 품질 작업 후보로 남아 있다. 이전 v1/v2 문서의 보행 미완료 표현을 최신 Walk/Talk 미완료로 오해하지 않는다.

결과 문서와 이름이 다른 설계 5개도 스튜디오에 표시되지만, 문서 연결 부재만으로 미구현이라고 판단하지 않는다.

## 후속 등록 — 아자토르 우선 개발 (2026-10-11)

사용자의 후속 지시로 위 후보 2번을 스튜디오에 등록했다. 제목은 **아자토르 보스 전용 패턴 제작 및 검증**, 작업 ID는 `a359620e-46c8-409f-a2e2-6e991387d1da`, 우선순위는 높음이다. 목표일은 정하지 않았으며 저장 직후 dispatcher가 실행을 시작했다.

범위는 예고가 있는 정면 특수 공격, 회피 가능한 범위 공격, 체력 50% 이하 강화 단계다. 실제 구현·빌드·PIE·저장 재로드·독립 리뷰를 완료 조건으로 두며, 보스 처치와 승리 연결은 별도 후보로 남긴다. 등록 직후 확인 상태는 reviewing/architect running이며 완료된 기능이라는 의미가 아니다. 이후 상태는 스튜디오의 실제 실행 기록을 따른다. 나머지 다섯 후보는 이번에 등록하지 않았다.

### 초기 검토 중단과 실행 안내 보완

첫 기획 실행 `d5cb3cf8-a32f-4a98-8f29-68e3b9a11f53`은 `python` 실행 파일이 PATH에 없어 blocked로 종료됐다. 설치된 번들 Python 3.12.14의 절대 경로를 확인하고 해당 작업 메모에 실제 명령을 추가했다.

그 경로를 사용한 읽기 전용 `Scripts/InvokeUnrealMCP.py --tool list_toolsets --timeout 8` 확인도 로컬 MCP 주소 `http://127.0.0.1:8001/mcp`에 대한 샌드박스 소켓 접근 거부 `WinError 10013`으로 실패했다(명령 종료 코드 1). 에디터 종료나 플러그인 비활성이라고 단정할 수 없으며 PIE·미저장 상태도 확인하지 못했다.

최종 저장 상태는 등록 3건 보존, 해당 작업 blocked, paused=true, activeId=null, engine=blocked다. 자동 재검토·권한 확대·정책 변경은 하지 않았다. 코드·에셋 구현과 UE 빌드/QA는 미실행이며 완료 조건을 충족하지 않았다. `Studio/EXECUTION.md`의 오류 시 중지 및 사용자 재검토 규칙에 따라 현재 차단 사유와 읽기 전용 확인 명령을 사용자에게 제시한다.

사용자가 위 목록 확인 명령 하나를 승인 심사에 제출하도록 허용해 해당 명령을 실제 실행했다. 결과는 `WinError 10061`(연결 거부), 종료 코드 1이다. 현재 `UnrealEditor` 프로세스 조회는 0개이며 `Config/DefaultEditorPerProjectUserSettings.ini`의 MCP 기본 설정은 자동 시작=true·포트8001·경로/mcp다. 도구 목록과 PIE/미저장 상태는 여전히 확인하지 못했다. 단일 명령 허용을 다른 명령의 권한 확대·무인 실행 설정 변경·자동 재검토 허용으로 해석하지 않았다. 작업 메모에 이 결과를 추가하고 blocked·일시정지를 보존했다.
