# 이전 맵 자료 로컬 정리 결과

`Feature/doc/evidence` 아래에 쌓인 미추적 파일 4,584개, 총 47,432,798바이트를 삭제했다.

| 정리한 자료 | 파일 수 | 복구 또는 보관 근거 |
| --- | ---: | --- |
| 11월 13일 초반 후보와 지형 편집 전의 중복 복구 사본 | 3,201 | 11월 18일 맵 통합 복구본 또는 현재 추적 파일에 동일한 원본이 있다. |
| 이전 StartHub의 중복 복구 사본 | 1,363 | 커밋 `207c5953` 또는 `f137e2a9`에서 같은 상대 경로와 원본 바이트를 확인했다. |
| 이전 맵 검증·RPC JSON | 20 | 최초 지형 추출 6개와 중간 메타데이터 10개는 대응 보관본과 같다. FiveVillage의 중간 성공 보고서 4개는 최종 보고서의 해당 검사 결과와 일치한다. |

파일마다 삭제 전 크기와 SHA-256을 확인했다. 복구에 쓸 로컬 파일과 Git 원본을 삭제 후 다시 읽어 SHA-256이 일치함을 확인했고, 삭제 경로 4,584개가 사라진 것도 확인했다. 삭제 작업 전후의 추적 파일 상태는 같았다.

체크포인트와 복구 목록, 자동저장 복구본, 고유한 이전 상태, 현행 맵 제작·복구 입력, 최종 검증과 별도 실패 기록을 보관했다. 과거 보고서에 기록된 원래 경로와 검사 상태는 당시 이력이다. 최초 지형 추출을 설명하는 문서에 바이트가 같은 독립 재로드 보관본의 로컬 경로를 명시했다.

`retained_path`가 `git:<커밋>:<경로>`이면 해당 Git blob이 복구 원본이다. 나머지 경로는 프로젝트 작업 사본 기준이다. `retained_sha256`이 비어 있으면 삭제 파일과 보관본의 SHA-256이 같다. 삭제는 로컬에서 수행했고, 정리 기록과 파일 목록은 현재 작업 브랜치에 게시한다. [파일별 목록](evidence/older-map-evidence-cleanup-20261119/removals.csv)
