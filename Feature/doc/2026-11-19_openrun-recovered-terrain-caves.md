# 보관 지형과 Q/Z 동굴 복구

기존 `/Game/Rogue10m/Maps/OpenRunMap`의 World Partition에서 북쪽 Landscape와 지하 훈련고 Q, 지하 작업함 Z를 복구했다. 플레이 가능한 프로젝트 레벨은 `StartHub`, `OpenRunMap` 두 개다.

## 적용

- 기존 1009×1009 Landscape의 합성 높이 177,014개를 `RecoveredTerrain20261119` 편집 레이어에 반영했다. 원래의 높이·페인트 레이어와 남쪽 580행, Landscape와 충돌 컴포넌트 각 256개, 스트리밍 프록시 16개를 보존했다.
- 중앙로 300m와 H·M·T 마을 터의 바닥을 Z 9,600cm로 맞췄다. 남쪽과 서쪽 연결부의 높이를 이어 붙이고, 보스 입구의 Landscape를 기존 플랫폼보다 2cm 낮게 유지했다. 기존 강·다리, 시작 위치와 진행 액터의 패키지는 그대로 유지했다.
- Q/Z의 바위 셸, 바닥·경사로, 갈림길·비밀방·지름길과 배치·조명을 담은 액터 네 개를 이전했다. 복구본과 비교한 컴포넌트는 54개, 인스턴스는 712개다. 동굴 메시·재질 13개를 프로젝트 소유 경로로 복제했다. 기본 암석의 Starter Content와 장식의 Stylized Village 에셋을 재사용했다.
- 가장자리에 풀이 이어지는 도로 29구간과 남쪽 연결로 7구간, 갈색 마을 바닥 세 곳을 기존 지형 위 데칼로 저장했다. 두 표면 재질은 보관본에서 옮겼다.

## 최종 결과

- 새 Unreal 프로세스에서 지형 높이 지문을 대조하고 동굴과 표면 39개를 재로드했다. 복구한 에셋 15개에서 보관 경로로 향하는 의존성은 0개였다. 중앙로와 마을의 충돌 높이는 45지점에서 9,599.99~9,600.00cm였다.
- 실제 게임의 기본 3인칭 카메라로 두 동굴의 16개 위치에서 방향을 3개씩 검사했다. 전체 48시야에서 충돌로 가린 카메라 경로는 0건이었다. 피벗과 카메라의 최단 거리는 235.69cm, 최대 당겨짐은 95.55cm였다.
- 시작 마을 보행 포탈 17항목, 보스 처치·승리 정산·Enter 귀환 77항목, 새 프로세스의 저장 재로드 17항목이 통과했다. 자동화가 전투 위치를 준비했고, 마지막 타격과 귀환은 게임 로직을 거쳤다.
- UE 5.8 Editor 빌드는 성공했다. 최종 카메라와 재로드 로그의 오류는 0건이었다. 포탈과 승리·저장 검사 로그에는 이전부터 있던 StylizedCharacter 스켈레톤의 `EngineMeshes/Humanoid` 누락 메시지가 남는다.

첫 카메라 실행은 훈련고 21시야를 통과한 뒤 작업함 경사로의 끝선을 찍은 탐침이 아래 Landscape에 닿아 중단됐다. 두 입구에서 바깥 지형과 경사로 안쪽 10cm를 각각 표본으로 삼아 두 공간을 다시 실행했다. 카메라 기준과 동굴 에셋은 동일하게 적용했다. 카메라는 지정된 위치와 방향에서 검사했다. 오픈 월드 전 구간을 연속으로 걷는 검사는 별도 범위다.

## 검증 방법

Landscape와 동굴은 보관본을 연결하지 않은 새 에디터 프로세스에서 다시 읽는다. 지형 합성 높이와 충돌 표본, 동굴의 메시·충돌·조명·변환, 도로와 마을 데칼의 저장 데이터 및 패키지 의존성을 확인한다. 렌더링된 게임에서는 기본 3인칭 카메라를 입구와 경사로, 굽은 통로, 비밀방, 귀환 출구에 배치해 카메라 거리와 가림을 검사한다.

시작 마을 포탈은 QA 이동 입력을 사용한다. 승리 검증은 같은 게임 흐름에서 포탈을 거쳐 보스를 플레이어의 마지막 타격으로 처치한 뒤 실제 입력 처리로 귀환하고, 별도 프로세스에서 정산과 진행 저장을 읽는다. 전투 위치는 QA가 준비한다.

카메라를 다시 검사할 때는 [검사 좌표](evidence/openrun-recovery-20261119/camera-plan.json)를 프로젝트 `tmp` 아래의 새 파일로 복사한다. UE 5.8의 `UnrealEditor-Cmd.exe`에 프로젝트 파일과 `/Game/Rogue10m/Maps/OpenRunMap -game -d3d11 -RenderOffscreen`을 전달하고, `-UserDir`와 `-RogueRecoveredCaveCameraPlan`을 절대 경로로 지정한다. 두 경로는 프로젝트 `tmp` 아래여야 한다. `-ExecCmds="t.MaxFPS 45,Rogue10m.TestRecoveredCaveCamera"`로 실행하면 검사 좌표 파일 옆에 결과를 저장한다.
