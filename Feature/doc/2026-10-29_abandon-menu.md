# 설정 메뉴의 탐험 포기

기존 설정(O / Esc / F10)에 탐험 포기 버튼과 확인 창을 연결했다. 런 물품·숙련·배운 기술 초기화, 공개 기술 정보 유지, 입장 직전 재화 복원과 마을 준비 비용 비환불을 안내한다. 취소/X/Escape는 확인 창만 닫고, 기본 포커스는 계속 탐험이다. 기존 Blueprint와 키 바인딩은 보존했다.

## 상태와 저장 경계

UI는 World/Profile/RunId를 캡처하고 제출 직전에 재검증한다. 프로필이나 런이 바뀐 확인창은 비활성화되며 닫고 다시 열어야 한다. 연타는 제출 가드와 터미널 상태로 한 번만 처리한다. UI 확인은 RequestAbandonCurrentRun을 직접 호출하며 기존 콘솔의 3초 이중 명령과 분리했다. UI 열기·취소·제출에서 콘솔 대기를 해제한다.

요청 수락 후 기존 결과 화면의 저장 대기·재시도·귀환으로 이어진다. 저장 실패 중 결과와 복원 값은 유지하며 보상을 지급하거나 중복 복원하지 않는다. 필드 문맥의 메뉴에서는 월드와 런 타이머가 계속 흐른다. 안전지대 메뉴 정지 정책이나 v5 저장 스키마를 이번 묶음에서 바꾸지 않았다.

## 실패 이력과 범위

빌드 A의 서로 다른 파생 포인터 조건식 오류를 고쳤다. 빌드 B에서 신규 QA CPP가 캐시된 목록에 누락되어 첫 렌더 실행은 QA를 시작하지 않았고, 해당 소유 프로세스만 종료했다. -NoUBTMakefiles로 C/D/E/F 빌드에서 새 소스를 포함해 통과했다. 실패 로그를 통과 결과에 합산하지 않는다. XGE의 기존 미활성 라이선스 경고는 standalone 빌드로 통과했으며 설치·활성화하지 않았다.

일시적으로 D3D11 887A0004 및 D3D12 adapter 선택 실패가 있었다. 이어 실행 연결이 끊겨 기존 PID17972의 최종 실패 QA 결과를 못 받았다. 부모의 재연결 확인 후 한 번 점검해 PID가 없고 결과 파일도 없음을 확인했다. 해당 불완전 로그를 보존하고 새 슬롯으로 진행했다. D3D11은 재연결 후 정상 작동하여 MenuResumeF1029와 배치 보완 후 MenuLayoutF1029가 통과했다. 드라이버·보안·프로젝트 그래픽 설정은 변경하지 않았다.

이 결과는 실제 UMG delegate와 합성 Slate 키 경로를 사용한 프로그램 검증이다. OS 물리 마우스 hit-test·키보드, 실제 OpenRunMap 수동 한 판 완주, 강제종료 복구는 미검증이다. QA는 StartHub 월드에 Running 상태를 부여하므로 실제 필드 경로·60초 이동·밸런스나 성능 보장은 아니다. 귀환 캡처의 기존 shader 준비·sky mesh 진단과 Humanoid 의존 패키지 로그는 이번 메뉴 변경과 별도로 남아 있다.
