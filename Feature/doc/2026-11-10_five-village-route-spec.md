# 다섯 마을 경로 보완 명세 결과

작성: 2026-11-10 / 상태: **설계 완료·정적 검사 통과 / 배치·런타임 미구현·주행 미검증**.

## 결과

사용자의 ‘콘텐츠를 거쳐 보스룸까지 약15분’ 요구에 맞춰 [별도 보완 명세](../architect/2026-11-10_five-village-route-spec.md)를 작성했다. 기존 초안의 ‘처치 포함15분’ 가정은 새 명세로 대체하고 원본 파일은 보존했다.

- 아래2·위3의 다섯 마을을 각각 보급/거래/전투/기록/위험 보상 역할로 구체화했다. 고유 선택 의뢰·현장 상점·던전·보상 후보를 제시했다.
- 교차로까지10개 지점·19개 양방향 연결을 정의했다. 모든 연결은 퀘스트 조건 없이 같은 월드에서 이동한다. 직행·서쪽 재방문·동쪽 성장·다섯 마을 방문·서쪽 생략 경로를 계산했다.
- 직행300m/50초는 가정 속도6m/s의 평면 하한이다. 실제60초 달성은 아직 확인하지 않았다.
- 두 대표 성장 경로는 각각 입구 도달900초 예산이다. 보스전180초와 여유120초를 더해 기존1200초 상한에 맞췄다. 활동 예산은 강제 대기·필수 의뢰가 아니다.
- 같은 RunId의 의뢰 재개·스트리밍·보상 중복 방지, 새 런 초기화, 안전 메뉴·던전 시계 연속성, 후속 QA 인수 기준을 기록했다.

## 변경 범위와 후속 작업

신규 보완 명세·이 결과·전용 JSON/검사 스크립트/결과를 추가했다. 당일 DevLog와 SprintChangeLog에는 이번 항목만 덧붙인다. 기존 초안·소스·설정·맵·에셋·저장·브랜치는 변경하지 않는다. 커밋·푸시를 하지 않는다.

기존 보스 구역을 유지하고 입장점/마을을 근처로 재구성하는 A안을 권장한다. 실제 월드 앵커·그림 원본의 필수 연결·품목/경제 수치·보스 교전 후 이탈 정책이 남았다. 다음 단계는 대검·보스·빌드 작업과 에디터 소유권을 조율한 뒤 블록아웃과 실제60초 보행 검증이다. 이후 마을1개의 의뢰 재개·안전 메뉴·보상부터 수직 검증하고 나머지를 확장한다.

도구 거부·승인 대기·실행 결과 불명인 동작은 없다. 후속 구현과 플레이 검증은 이번 별도 설계 위임 범위 밖이다.
