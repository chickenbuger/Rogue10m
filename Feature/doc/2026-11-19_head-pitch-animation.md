# 캐릭터 머리 상하 회전 분리

머리와 목은 수평 시선과 애니메이션에 담긴 자세를 따른다. 상하 시선은 카메라와 전투 조준에 쓰인다. 기존 1인칭 격투 포즈에서도 척추 조준 뒤에 머리와 목의 애니메이션 회전을 복원한다.

3인칭 맨손 대기에서 카메라를 아래로 기울이면 팔이 뒤로 크게 들리는 자세를 렌더에서 확인했다. 맨손 대기와 지상 이동 중에는 원래 팔 자세를 사용한다. 가드와 공격에 들어가면 기존 보간을 따라 상체가 조준 자세로 전환된다. 가드 없이 곧바로 공격하면 처음 몇 프레임 동안 조준 회전이 올라온다. 실제 공격 방향은 카메라가 가리키는 지점에서 결정한다. [팔 보정 전 측면](evidence/head-pitch-animation-20261119/look-down-before-arm-adjustment.png)

## Blender 동작 보정

Blender 4.5.14에서 실제 Manny 대기·전진 걷기·전진 달리기 클립의 머리·목 회전 키를 따로 보정해 비교했다. 기존 15%와 후보 35%, 50%를 같은 18/s 보간 속도로 비교했다. 35%에서 머리 회전 폭은 대기 0.89° → 2.17°, 걷기 0.69° → 1.85°, 달리기 2.23° → 4.82°였다. 다음 후보의 걷기 회전 폭은 1.89°였으며 고개가 더 아래로 향했다.

3인칭 지상 이동의 기본 가중치는 35%다. 최대 회전 범위는 300 cm/s까지 5°이며 600 cm/s에서 7°에 도달한다. 이 세 값은 에디터의 `Third Person Head Motion` 항목에서 조정할 수 있다. 점프·회피·공격 중에는 기존 보정 범위를 사용한다. Blender 비교에서는 루트·골반·손·발의 위치 차이가 0 cm였다. 게임에서는 기존 클립과 몽타주를 재생할 때 검토한 보정값을 적용한다.

## 검증 자료

UE 5.8 Editor 빌드를 통과했다. `VerifyThirdPersonGameplay.ps1 -Label HeadPitchTunedFinal -MouseInput`을 별도 작업 사본에서 실행해 1,007개 검사와 마우스 전투 입력 13개를 통과했다. 카메라 0°, +65°, −65°를 같은 클립 시점에서 비교했으며 원본과 표시용 리타깃 양쪽의 머리·목·손 회전 차이는 소수점 여섯 자리에서 모두 0°였다. 수평 조준은 20°로 고정했다. 위·아래를 가리키는 전투 조준과 이동·충돌·회피를 확인했다. 최종 게임 로그 오류는 0건이고 검증 사본의 기존 테스트 세이브 10개가 보존됐다.

카메라 회전은 게임 카메라에서 측정했다. 사진은 머리·목·팔이 보이게 같은 위치의 임시 측면 카메라에서 찍었다. 물리 마우스, 1인칭 렌더, 전체 런은 이번 검증 범위 밖이다. 별도 검사에서 전투 방향을 카메라 회전과 직접 비교하면 바닥에 가까운 조준점에서 실패했다. 최종 검사는 카메라 회전과 캐릭터가 조준점을 향하는 방향을 각각 확인한다. 최초 빌드는 실행 중인 에디터의 Live Coding 잠금에서 중단돼 독립 사본에서 `-NoHotReloadFromIDE`로 다시 빌드했다.

실행별 원본 로그와 중간 캡처는 작업 사본의 `tmp/head-pitch-qa-archive/`에 보관했다. 기능 검증 폴더에는 최종 회전 수치와 두 시선의 측면 화면, 팔 보정 전 아래 보기 화면을 남겼다.

피부색 기능이 먼저 반영된 `739a90fb`와 병합한 뒤 Editor를 다시 빌드하고 `HeadPitchIntegrated`를 렌더링했다. 통합본은 1,005개 검사, 마우스 전투 입력 13개, 캡처 7장을 통과했다. ±65°에서 머리·목·손의 최대 회전 차이는 0.000002°였다. 측면 렌더에서 대기 중 팔과 목이 안정적인 것을 확인했고 게임 로그 오류는 0건이며 기존 테스트 세이브 12개가 보존됐다. 피부색에 따른 화면 차이가 있어 팔 보정 전후 비교에는 피부색 통합 전의 같은 외형을 사용했다.
