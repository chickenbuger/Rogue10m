# 무기별 스킬트리 탭

K로 스킬 창을 열면 장착 무기의 탭을 맨 앞으로 옮기고 선택한다. 기준 순서는 공통 → 너클 → 검 → 마법이다. 너클을 장착하면 너클 → 공통 → 검 → 마법, 검을 장착하면 검 → 공통 → 너클 → 마법, 지팡이를 장착하면 마법 → 공통 → 너클 → 검으로 표시한다. 탭을 눌러 다른 계열을 살펴볼 수 있고, 장비를 바꾸거나 창을 다시 열면 해당 장비의 탭을 선택한다.

- **공통**은 내공·투지·마나 아이덴티티의 입문, 심화, 성질을 각 계열에 표시한다. 전수와 활성 조건은 장착 무기를 기준으로 평가한다.
- **너클**은 확정된 후속 시안을 적용해 기초 무공 네 개에서 시작한다. 실전 명중으로 격투 숙련을 쌓아 15개 연결을 따라 상위 무공을 전수한다. [너클 수련 트리](2026-11-20_knuckle-training-tree.md)
- **검**은 기본 동작에서 여러 방향으로 갈라지고 다시 이어지는 거미줄 형태다. 대검 숙련으로 선행 스탯을 열고, 분쇄참·회전참·파쇄참·대지파쇄·패왕참을 기술당 공용 성장 1P로 전수한다. 회전참과 파쇄참을 함께 배우면 대지파쇄로 이어지는 우회 경로가 열린다.
- **마법**은 탭을 선택하면 준비 중 화면을 표시한다. 검 탭은 대검·장검·쌍검·검과 버클러 장착에 반응하며, 이번 검 트리의 숙련과 전수는 기존 대검 계열에서 적용된다.

이전 저장에 자동 전수로 기록된 검 기술은 당시 선행 및 숙련 요구를 적용해 복원한다. 전체 재분배는 구매한 기술과 그로 인해 선행을 잃은 후속 단계를 정리하고, 남은 경로와 숙련 경험치를 복원한다. 기술 상세와 키 지정, HUD 드래그는 기존 위젯과 전투 슬롯을 사용한다.
