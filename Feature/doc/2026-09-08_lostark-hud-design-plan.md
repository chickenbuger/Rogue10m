# 로스트아크풍 HUD 개선 기획 결과

- 날짜: 2026-09-08
- 작업: Sprint#4-19-lostark-hud-design-plan
- 상태: 기획/콘셉트 준비 완료, 게임 적용 전.

사용자가 보고한 UI 크기와 구조 문제를 바탕으로 기획 1명·검증 2명이 현재 소스와 과거 자료를 조사했다. 전체 폭 stretch 배경과 1920 기준 고정 자식 좌표의 혼용을 주요 원인 후보로 정리했다. 과거 프리뷰는 실제 런타임 증거가 아니라는 점을 확인했다.

1920×1080 기준 중앙 1000×160 전투 코어, 56px 행동 슬롯5개, 76px 문장, 48px 아이템 표시4개, 경험치4px를 제안한다. 체력/자원은 상단, 핵심 행동과 문장은 중앙 하단에 모으고 로스트아크풍의 얇은 금속선·반투명 패널을 적용한다.

현재 아이템 입력1~5와 HUD 잠금4칸의 불일치를 별도 발견 항목으로 남겼다. 생성 시안도 잠긴4칸으로 맞췄다. 그림의 배경·스킬명·수치·로그는 예시이며 런타임 구현 상태를 나타내지 않는다.

## 검증 범위

- 현재 HUD 데이터와 Main/Bottom 소유·갱신 경로 소스 대조.
- 생성 콘셉트 육안 확인: 1인칭, 행동5개, 잠금4개, 중앙 문장, 상단 대상/타이머, 미니맵 없음.
- 그림의 외곽 폭·높이는 정확한 치수 규격이 아니며, 설계표 기준 후속 UMG 작업 필요.
- 문서 변경 검사는 CheckGeneratedChanges.ps1와 git diff --check로 수행한다.
- C++/설정/Widget Blueprint 변경 없음. Editor 빌드와 실제 PIE 검증은 이번 기획 범위에서 실행하지 않았다.
- 과거 작업의 미커밋 코드/바이너리 변경은 그대로 보존했다. 커밋/푸시 없음.

## 최종 시각 검토 보완

정확한 비율은 ui-concepts/2026-09-08/hud-layout-1920x1080.svg 치수 도면을 따른다. 생성 콘셉트의 본체는 약1155×237, 문장은 약160px로 추정되어 목표1000×160/문장76보다 크다. 이미지의 E 슬롯 Serene Form은 예시 레이블 오류이며 실제 설계에서는 회피로 표시한다. 도면에서 크기와 기능 레이블을 바로잡았다. 생성 이미지는 색감/재질 참고 전용으로 사용한다.
문서 검증 결과: git diff --check와 CheckGeneratedChanges.ps1가 통과했다. 기존 미커밋 바이너리에 대한 안내가 있었으며 이번 작업에서는 해당 바이너리를 변경하지 않았다. 신규 SVG는 XML 파싱과 1920×1080 선언을 확인했다.
