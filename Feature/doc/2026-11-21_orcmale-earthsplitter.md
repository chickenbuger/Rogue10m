# 오크 남성의 대지파쇄 양손 자세

오크 남성의 대지파쇄에서 자루를 잡은 두 손을 실제 외형의 팔 길이에 맞췄다. 두 손을 공통 손잡이에 맞춰 검을 정면 아래로 내리고, 검날이 바닥에 닿기 전에 기존 공격 자세에 이어 붙였다. 같은 정면 110cm 표적에서 표시 손바닥 간격은 첫 피해 때 49.65→20.01cm로 줄었다. 검날 앞쪽은 표적 캡슐 안으로 15.35cm 들어갔고 검 최저점은 전체 측정 구간의 캡슐 바닥보다 최소 8.94cm 높았다. 0.72초 차징 조건, 330cm 원호 판정, 기존 몽타주와 첫 피해 시점은 그대로 사용했다.

프로젝트가 만든 `ABP_Retarget_Or_M`을 Unreal Editor에서 기존 드워프와 인간 남성이 사용하는 네이티브 부모에 연결했다. `IKR_Manny_To_Or_M`, `SKEL_Or_M`, 부모 메시에서 포즈를 읽는 그래프와 LOD 설정을 유지했다. 표시 외형의 팔 보정은 바닥이 평평하고 현재 대지파쇄 차징에 참여하는 경우에만 켠다. 기존 Blender 대지파쇄 차징·발동 시퀀스의 손 방향을 사용했다.

별도 검증 클래스에서 보정을 끈 대검 기술 8건의 Manny와 표시 본 26,640개 좌표·회전이 기본 클래스와 일치했다. 실제 뒤쪽 구르기 22프레임과 관절 924개 표본도 두 클래스의 결과가 같았다. 검과 바닥의 간격은 모두 최소 +1.6632cm였다. 늦은 D 입력에서는 표시 자세가 기존 움직임으로 넘어간 뒤 같은 캡슐 이동 31.2803cm와 첫 피해 시점을 기록했다.

벽으로 몸을 급히 돌면 표시 전환을 시작하는 간격을 넓혔다. 기본 속도 회전의 경계 상자는 한 프레임에서 겹쳤지만 실제 검날과 벽 사이에는 6.04cm 이상의 간격이 있었다. 0.18초 동안 34° 도는 빠른 회전에서는 검 경계 상자까지 최소 6.41cm 떨어졌다. 두 회전 모두 실제 검 삼각형이 벽과 교차한 프레임은 없었다. [벽 검사](evidence/orcmale-earthsplitter-20261121/orc-wall-06-mesh-distance.json)
