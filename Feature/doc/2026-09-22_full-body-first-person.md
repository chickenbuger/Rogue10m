# 팔·몸통·다리가 보이는 전신 1인칭

- 날짜: 2026-09-22
- 브랜치: Sprint#4-32-full-body-first-person
- 요청: 기존 팔 전용 표시를 전신 표시로 다시 변경한다.

## 변경

기본 격투와 너클의 로컬 1인칭 메시를 전체 Manny로 바꿨다. 목·머리만 숨기고 몸통·골반·양다리·발을 표시한다. 월드용 캐릭터는 소유자에게 숨겨 같은 몸이 두 번 겹치지 않게 유지했다. 전신에는 일반 월드 투영을 사용한다. 기존 Manny 재질의 1인칭 가림·투영 분기로 몸통이 띠처럼 잘리는 현상을 피하고, 팔 전용 모드는 기존 표시 방식을 유지한다. 바이너리 자산을 새로 만들거나 기존 메시를 다시 편집하지 않았다.

전신 메시는 캡슐에 붙여 수직을 유지한다. 마우스로 아래를 볼 때 다리가 시선과 함께 회전해 도망가지 않는다. 전신 눈높이는 어깨보다 앞·위로 이동하고 손과 팔꿈치 목표도 함께 보정했다. 전신 모드에서는 -85도까지 아래를 볼 수 있다. 기존 주먹 자세 계산 뒤 어깨와 팔에 조준 높이를 반영한다. 아래보기에서 가슴이 다리를 가리지 않도록 시선에 따른 몸통 숙임은 기본값 0으로 둔다. 골반과 다리는 조준 보정 대상에서 제외하며 공격에 따른 카메라 움직임을 계산한 뒤 보정하므로 조준 자체가 카메라 흔들림에 섞이지 않는다.

bShowFullBody를 끄면 이전 팔 전용 모드를 선택할 수 있다. 모드·무기 전환은 메시, 부착 위치, 숨긴 뼈와 애니메이션 설정을 원래 상태로 복원한다. 기존 ArmsOnly 검증은 이 옵션을 명시적으로 선택하도록 갱신했다.

## 실제 화면과 검증

최종 기본값으로 별도 게임 프로세스 네 개를 실행했다.

- UE 5.8.2 Editor 빌드: 22.86초 성공.
- 기본 격투: 480프레임, 실패 0. 좌·우 잽, 짧은 우클릭 스트레이트, 긴 우클릭 훅, 차징·점프·피해·중단을 확인했다. 스트레이트 전체 전방 이동 폭은 약 14.93cm이며, 별도의 가드 대비 8cm 이상 신전 검사도 통과했다.
- 너클: 120프레임, 실패 0. 상하 시야와 2560×1080 화면비의 추가 3시점 검사를 통과했다. 손목 거리 20cm와 재진입 검사를 그대로 유지했다.
- 이전 팔 전용 옵션: 390프레임, 실패 0. 무기·표시 복원과 기존 시야 옵션을 확인했다.
- Martelo 전신 시연: 269프레임, 실패 0. 전신 -85도/팔 전용 -70도 시야 제한 전환, 몸체 수직 유지, 다리 표시, 원래 애니메이션·조준 복귀를 확인했다.
- 원본 메시·뼈대·팔 메시·무장 프로필 네 파일의 SHA256이 작업 전후 같다. 변경 경로와 공백 검사를 통과했다.

영상은 실제 게임 화면의 기본 자세 → 아래보기 → 원래 속도 → 0.5배속 → 기본 자세 순서다. 1280×720·30fps·269프레임, 약 8.97초다. 속도 표시는 촬영 후 설명용으로 더했다. 하단 HUD가 다리 일부를 가리며, 위보기에서 주먹 윗부분이 화면 경계에 일부 걸린다. 몸통·다리 표면의 이전 끊김과 너클 위보기 미노출은 해결됐다.

## 화면 문제의 원인과 보완

초기 전신 적용은 뼈·상태 검사를 통과했으나 몸통과 다리 표면이 띠처럼 잘려 보였다. 카메라 높이만 바꿔도 남았기 때문에 위치 조정을 반복하지 않고 원인을 분리했다. 원본 재질의 FirstPersonOutput, IsFirstPerson, CameraDepthFade, Head Cutout 경로를 확인했고, 같은 모델을 일반 렌더링으로 표시하자 표면 끊김이 사라졌다.

몸통의 시선 숙임을 제거하고 전신 카메라를 캡슐 기준 (20,0,76)에 두자 아래보기에서 몸통과 양다리·발이 함께 보였다. 손과 팔꿈치 목표는 메시 기준 (0,12,18)를 더해 보정하며, 기존 팔 길이 제한을 유지한다. 처음 손 목표를 카메라와 같은 만큼 전진시켰을 때 기본 가드가 팔 길이 상한에 닿아 스트레이트 전진 폭 검사를 실패했다. 전체 손 목표를 줄이는 조정만으로는 전진 여유가 부족해, 실측한 어깨와 손 좌표로 팔 길이 제한을 계산했다. 맨손의 가드만 14cm 후퇴시키고 8cm 안쪽으로 모아 팔 길이 상한에 닿지 않게 했다. 다른 계산 경로를 쓰는 너클에는 이 후퇴를 적용하지 않는다. 공격 끝점은 유지한다. 기존 검사 기준은 유지한다. 너클의 손목 거리 20cm 검사도 완화하지 않았다. 실제 상하 시야에서 가드가 너무 가까워지는 문제를 발견해 카메라를 X20으로 조정하고 맨손·너클의 가드 보정을 분리했다. 진단값만 바꾼 촬영과 최종 기본값 촬영을 구분하여 검증한다.

## 범위

좌클릭 왼잽·오른잽과 우클릭 짧게 스트레이트·길게 놓기 훅의 입력 및 피해 계산을 변경하지 않았다. Martelo는 전신 표시를 비교하는 별도 미리보기이며 공격 입력에 매핑하지 않았다. 새 보행 애니메이션이나 지형별 발 접지 보정은 추가하지 않았다.

기획 1·개발 2·검증 2 역할로 계획, 표시·조준 개발, 촬영 검증 개발, 소스 검토, 화면 검토를 분담한다. 커밋·푸시는 하지 않았다.
