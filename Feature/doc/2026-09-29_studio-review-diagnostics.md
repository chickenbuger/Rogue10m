# 스튜디오 Git 조회와 중단 단계 안내 수정

브랜치: Sprint#5-2-studio-review-diagnostics

## 원인

맨손·너클 제작 작업이 요구사항 검토에서 Git dubious ownership 오류로 멈췄다. Windows 샌드박스의 별도 계정과 저장소 소유자가 다른 것이 원인이다. 이 실행은 빌드 단계에 도달하지 않았으나 dispatcher가 모든 실패에 같은 ‘완료 검증을 통과하지 못했습니다’ 문구를 기록해 빌드 실패처럼 보였다.

## 수정

사용자가 지정한 프로젝트 루트에 한해 명령별 safe.directory와 -C 인자를 적용하는 Git 조회 지침을 역할 에이전트에 전달한다. 경로는 PowerShell 단일 인용부호 이스케이프를 적용한다. 전역 신뢰 설정, 와일드카드, 소유자·ACL, 샌드박스와 approval_policy=never는 변경하지 않는다.

중단한 역할을 기록하여 기획/구현 중단은 빌드·완료 검증 미실행으로, 빌드·독립 검토·문서 단계 중단은 전체 완료 미확인으로 구분한다. 상세 원인과 기존 로그는 보존한다. 완료 조건은 완화하지 않는다.

이미 존재하는 Feature/doc/2026-09-29_unarmed-knuckle-animation.md와 관련 소스·에셋은 기존 다른 작업의 결과로 보존한다. 역할 지침에 기존 구현과 증거를 먼저 대조하고 남은 범위만 계획하도록 명시했다. 이번 수정에서 애니메이션이나 게임 코드는 바꾸지 않았다.

## 검증

- Node 구문 검사와 22개 테스트 통과. planner 중단의 원인 보존 및 검증 미실행 표시, 경로 인용과 단일 저장소 지정 회귀 포함.
- 실제 Studio client의 read-only 에이전트가 Git status와 branch 두 명령을 모두 종료 코드0으로 실행했다. 현재 브랜치 일치 확인. 세션 01a0ecde-881d-7583-b491-a74a703d4c43.
- 실제 증거: Studio/data/git-read-diagnostic-20260929/git-read.evidence.json 및 git-read.result.json.
- diff 검토에서 기존 게임 변경 보존과 명령 인용, 중단 역할 기록, 완료 게이트 미변경을 확인했다. 게임 코드·에셋 변경이 없으므로 UE 빌드는 생략했다.

현재 Git 조사 경로의 오류는 해결했다. 기존 애니메이션 구현의 최신 QA나 스튜디오 자동 작업 완료까지 확인한 것은 아니다. 수정 적용을 위해 실행을 안전하게 중단하고 서버를 재시작한 뒤 기존 활성화 요청에 따라 재검토를 이어간다. 커밋·푸시 없음.
