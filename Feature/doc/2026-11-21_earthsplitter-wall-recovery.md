# 벽 옆 대지파쇄의 후속 가드 복귀

벽 옆에서 대지파쇄를 쓰면 피해가 들어간 뒤 기본 충전 공격의 넓은 후속 궤적이 벽을 지났다. 같은 기술의 Blender 편집본에서 검을 몸 가까이 가져오는 동작을 골라, 멀리 있는 장애물이 감지된 경우에 두 팔을 가드로 이었다. 현재 골격의 양손이 함께 닿는 위치에서 칼을 이동시키고, 캡슐과 하체는 기존 공격 그래프를 그대로 평가한다. [설계와 재현 절차](../architect/2026-11-21_earthsplitter-wall-recovery.md)

| 표시 외형 | 오른편 벽의 실제 칼 삼각형 교차 표본 | 보정 중 한 프레임 최대 검축 변화 |
| --- | ---: | ---: |
| 인간 남성 | 7 → 0 | 6.22° |
| 인간 여성 | 2 → 0 | 5.95° |
| 드워프 남성 | 7 → 0 | 5.87° |
| 드워프 여성 | 8 → 0 | 6.38° |
| 오크 남성 | 7 → 0 | 5.95° |
| 오크 여성 | 2 → 0 | 5.95° |

대지파쇄는 계속 우클릭을 놓은 수락 틱에 한 번 피해를 주고, 첫 원본 몽타주 표본은 0.010953초다. 칼이 벽에 닿던 것은 약 1.70~2.02초 뒤의 후속 동작이었다. 보정은 그 구간을 지나 원본 몽타주 1.62초까지 양손을 기본 자세에 돌려보낸다. 효과 타이머, 피해 지연과 판정, 캡슐 및 무기 입력은 기존 재생 경로를 사용한다.

드워프 남성의 반대편 벽에서도 실제 칼 교차는 11개 표본에서 0개로 줄었다. 발동 뒤 D로 25.21cm 이동했을 때 후속 가중치가 한 번에 사라져 65.54° 회전하던 첫 후보를 폐기했다. 최종은 이미 시작된 팔 동작을 짧게 끝내며 같은 이동 거리와 입력을 유지했다. 보정 전에는 해당 D 구간의 칼 메시가 8개 표본에서 벽을 통과했고 최종에서는 0개였다.

가까운 정면 벽은 회복에 필요한 여유가 적어 기본 자세를 유지한다. 인간 남성의 정면 대조에서는 양쪽 26,640개 본, 434개 검·손 표본이 일치했고 실제 검 교차 11개도 동일했다. 벽이 없는 인간 여성과 오크 여성에서도 같은 수의 본·검 표본이 일치했다. 두 외형의 차징 중 D는 31.28cm 이동했고 새 후속 보정의 가중치는 0이었다.
