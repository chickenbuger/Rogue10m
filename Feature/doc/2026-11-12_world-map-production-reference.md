# 월드맵 실제 제작 참조 통합 결과

2026-11-12 한국 시간. 작업 브랜치 `Sprint#9-31-world-map-production-reference`.

## 반영 내용

사용자가 요청한 “실제 맵 제작에 이 자료들 모두 참조”를 파일로 반영했다. [실제 제작 기준](../../Docs/WorldMapProductionGuide.md)에 대화에서 확정/수정한 규칙과 미정 항목, 시작 마을·NPC 대사·3큰마을·5초소·5사냥터·15일반/4중간/1최종·직업별 획득처·시간·검증 순서를 통합했다.

생성 지도를 프로젝트에 원본 바이트로 보존했다. [참조 묶음](../../Docs/References/WorldMap/README.md)은 이미지 해석·생성 이력·SHA와 배치/획득처 JSON을 연결한다. AGENTS.md·WorldMapMakerGuide·WorldStructure에 제작 전 읽을 진입 경로를 추가했다.

- 배치:21노드·29양방향간선·4예시경로. 로컬 미터이며 실제 월드 변환과 주행은 미검증이다.
- 콘텐츠: 일반15종·중간4·최종1을 분리한다. 종별 새 행동은 구현 계획이다.
- 획득처: 우선3직업·후속8직업, 전문가/안내12명, 특정무기3개, 너클10·대검10·마법3 비급. 직접 수련 보수3개와 현장 발견20개를 구분한다.
- 최신 수정: 무기별 동시·차징 선택 지원, Ctrl 한 번→첫Q부터 고정 기한→QQQ 자동발사, 일반 의뢰의 중상위 비급 직접 지급 금지를 반영했다.
- 모호함 보존: 제한시간 초수·시간초과 페널티·세부 밸런스·실제 앵커·교전 리셋 등은 미정으로 표시했다.
- 이미지의 몬스터 소문자 오기/장식 마름모는 규칙으로 채택하지 않으며 정확한 문서/JSON이 우선이다.

## 검증

최종 정적 검사와 Git 처리 결과는 [검증 기록](evidence/world-map-production-reference-20261112/validation.json)에 기록한다. 계획 데이터의 수치 검증과 실제 UE 검증을 구분한다. C++·에셋을 변경하지 않아 Editor 빌드·PIE·cook은 이번 작업에서 실행하지 않는다.

- 통합 정적 검사584개 실패0, 로컬 Markdown 링크36개 유효.21노드·29양방향간선·숨은 평면교차0과4경로 거리/시간을 확인했다.
- 일반15·중간4·최종1의 공용 로스터ID/로컬 자산 존재를 확인했다. 이는 신규 행동·배치의 실행 증거가 아니다.
- 직업11·NPC12·현장무기3·비급23의 참조와 직접 하급 수련3/현장발견20,학습·입력·Discovery 계약을 확인했다.
- PNG1536×1024·4,306,713바이트가 생성 원본과 SHA-256 일치한다. 생성경로 검사는 통과했으며 기존 Unreal 바이너리 변경 경고만 확인했다.
- 기존 tracked dirty68개 중 이번 Sprint append 대상1개를 제외한67개가 시작 전 해시와 같다.
- 독립 검토2건에서 S/B 명칭과 Ctrl 해제의 과확정, 마력미사일 표시명을 정합화했다.
