# 대검 장착·해제 자세

대검을 내려놓을 때 현재 가드 자세가 먼저 풀린 뒤 맨손 자세가 이어진다. 장착과 해제 순간에 두 리타깃 그래프를 교체하는 인간 남성은 직전에 보이던 자세를 0.18초 동안 새 그래프의 포즈와 섞는다. 이동할수록 기존 다리 자세의 가중치가 낮아져 진행 중인 보행이 지연되는 것을 줄인다. 같은 스켈레톤과 기존 보행·가드 클립을 사용했다. [작업 계획](../architect/2026-11-21_weapon-equip-pose-audit.md)

정지한 3인칭 상태에서 인벤토리 대검을 실제 장착·해제했다. 60Hz에서 바로 앞 프레임과 비교한 손목 위치 변화다.

| 표시 메시 | 장착 첫 프레임 | 해제 첫 프레임 |
| --- | ---: | ---: |
| 인간 남성 기존 | 16.27cm | 28.51cm |
| 인간 남성 가드 보정 | 16.27cm | 15.16cm |
| 인간 남성 가드와 리타깃 보정 | 0.40cm | 0.36cm |
| 인간 여성 기존 | 1.60cm | 32.67cm |
| 인간 여성 가드 보정 | 1.60cm | 1.04cm |

인간 남성의 해제 첫 프레임에서 기존 발 위치는 최대 25.57cm 바뀌었다. 두 보정을 적용한 뒤 첫 프레임의 발 차이는 0.08cm였다. 다음 8프레임의 최대 손목 이동은 11.31cm였다. 장착 자체는 즉시 적용돼 다음 프레임에 대검이 보였다. 해제하면 대검이 숨겨지고 팔이 서서히 내려간다. [동작 기록](../../DevLog/20261121_WeaponEquipPose/AnimationRecord.md)

| 표시 메시 | 해제 첫 프레임 손·발 최대 이동 |
| --- | ---: |
| 인간 남성 | 28.51 → 0.36cm |
| 인간 여성 | 32.67 → 1.04cm |
| 드워프 남성 | 36.74 → 1.39cm |
| 드워프 여성 | 25.83 → 1.09cm |
| 오크 남성 | 36.72 → 1.08cm |
| 오크 여성 | 32.57 → 1.04cm |

새 그래프가 초기화 중 먼저 평가되는 경로에도 이전 자세가 전달되도록 했다. 인간 남성의 인벤토리 호출 전후에 양손과 발 위치 차이는 모두 0cm였다. 기존 대검 가드에서 W로 걷기와 맨손 공격 후 이동을 포함한 통합 회귀 6,497개를 통과했다. 인간 남성의 장착 직전, 장착 첫 프레임, 안정된 가드, 해제 첫 프레임을 1280×720으로 확인했다. 첫 장착 사진에서는 왼쪽 화면 가장자리 밖으로 칼날 끝이 나간다. 렌더 시작에서 하드웨어 탐색 오류 한 건을 보존했으며 소프트웨어 렌더러 선택 후 Unreal 오류는 0건이다. 장착·해제 표본은 모두 정지 상태의 프로그램 입력이다. 달리는 중 인벤토리로 교체하거나 교체 도중 강제로 LOD를 바꾸는 경우는 미실시다.
