# 너클 시작 · 런/로비 성장 분리 결과 (2026-10-29)

## 동작

정상 신규 캐릭터는 실제 StarterKnuckle DataAsset을 장착한다. 대검 등 6종 레거시 테스트 무기와 가짜 UI 샘플 아이템을 무료 지급하지 않는다. 기존 비무기 스타터 구성은 유지했고, 기존 저장 인벤토리 복원은 필터링하지 않는다. 기존 너클 프로필/애니메이션/전투 자산을 재사용하며 신규 메시·아트 구매·맵 편집은 없다.

v4 저장은 기존 슬롯 이름에 `_v4`를 붙인 별도 파일이다. 기존 v1~3 슬롯을 먼저 검증해 읽으며 원본에 쓰지 않는다. v4 파일이 있으면 그것이 우선이고, 손상/미지원 버전에서 구버전으로 조용히 되돌아가지 않는다. 기존 실제 사용자 프로필은 이번 검증 실행 대상으로 선택하지 않았다.

런 영역은 Growth, Inventory(Gold/Crystals 포함), Combat, SkillTree 및 NPC 런 영수증이다. 로비 영역은 Town 투자 원장, 총획득 포인트, 최고 도달 레벨, 정보용 Discovery다. Town 지출은 런 스킬 포인트에서 차감하지 않는다. 레거시 Town의 이미 지출한 포인트만 로비 예산으로 보전하고 남은 런 포인트는 환산하지 않는다. 기존 특성 레벨 제한은 최고 도달 런 레벨로 보존하며 기존 랭크 상한을 재사용한다.

승리·사망·시간초과의 next-tick 정산에서 RunId 영수증으로 로비 보상을 1회 기록한다. 임시 보상 값은 처치당 1, 승리 보너스 10이며 확정 밸런스 수치가 아니다. v3 누적 처치는 기준선으로 제외한다. 저장 실패 중에는 메모리 보상을 재적용하지 않고 같은 영수증을 저장 재시도하며 귀환을 차단한다. 결과 화면의 런 상태는 유지하다가 실제 허브 귀환의 새 Pawn attach에서 초기 장비·빈 런 성장으로 교체한다. 로비 강화/재화/Discovery는 보존한다. Discovery는 런 학습/자동 습득 권한으로 사용하지 않는다.

## 검증

- UE 5.8.3 CL58210709 / MSVC 14.44 / WinSDK 10.0.22621 Editor 빌드 성공. 초기 QA 컴파일 오류(변수 shadow, 파일 API 선택)를 수정했다. 최종 빌드 로그는 로컬 작업 폴더에 보존. XGE 기존 라이선스 경고는 standalone 실행으로 통과했고 설정을 바꾸지 않았다.
- 기존 Automation Tests 24개 전부 PASS, 최종 Final1029 리포트에서 실패/경고 0.
- 실제 게임 인스턴스 격리 프로필: Victory 68, Defeat 68, Timeout 69 assertion PASS. 실제 ReturnToTown/OpenLevel, StartHub의 Waiting 타이머, 이전 결과 창 제거, 레벨1/숙련0/런 재화·획득 대검·런 영수증 제거, 영구 특성+로비 포인트 유지, Discovery가 학습 권한을 주지 않음, 저장 실패/재시도, 중복 정산, 레거시 대검 복원, 별도 v4 저장 및 원본 바이트 보존, 미래 버전 거부를 확인.
- Victory/Defeat는 종료 상태 fixture이며 실제 최종 보스 격파/적 공격 사망 플레이가 아니다. Timeout은 실제 타이머를 QA용 1초로 줄여 만료시켰다. 로비 강화는 유효한 구매 완료 상태 복원 fixture이며 상점 UI 직접 구매 검증은 아니다. 레거시 테스트는 격리된 v3 표시 fixture이다.
- 렌더링 InputKey 검증 34개 PASS: 정상 초기 무기 Knuckle, W 이동, 달리기 교체, 실제 LMB 명중, 공격·사망 상태 교체 거부, 0.5초 하한과 긴 쿨다운 보존. 테스트용 소유 아이템·AI 정지 표적·임시 5초 공격 쿨다운을 사용했다. 수동 물리 입력/정상 한 판 완주/밸런스·60초 이동 실측이 아니다.
- 최종 증거 PNG 9개 모두 1280×720 디코딩 확인. RunDomains 3장 중 02는 의도적 저장 실패 gate 화면, 03은 실제 허브 귀환 후 체력145/레벨1 화면이다. 03에는 스트리밍/셰이더 준비 문구와 기존 하늘 메시 경고가 보인다. 정상 시작 및 명중/쿨다운 화면도 별도 보존.
- 시작 전 102개 세이브와 기존 증거66개 파일을 백업하고 종료 시 168개 원본 SHA256가 모두 같음을 확인했다. QA에서 생성한 추가 파일은 삭제하지 않았다. 개인 경로·식별자가 포함될 수 있는 원본 로그, 세이브, 미디어는 Git에 추가하지 않는다. 원격 변경 없음.

## 발견·수정·제약

검증 V1에서 이전 프로필 저장 가드의 선택 순서 회귀를 발견해 실제 소유 Pawn ID 기준의 저장으로 복구했다. 정산은 선택된 프로필과 런 시작 시 캡처한 소유권을 별도로 검사한다. V2의 대검 인벤토리+너클 스킬 혼합 픽스처는 올바르게 Combat 복원에서 거부됐고 모든 도메인 rollback이 성공했다. 실제 대검을 장착하고 캡처한 일관된 픽스처로 고쳤다. 실패 로그는 보존했다.

레거시 Discovery/정산 필드 초기화 보완 시도는 자동 승인 검토에서 영구 정보 손실 위험으로 실행 전 거절됐다. 그 스크립트는 실행하지 않았다. 해당 보완은 제외하고 Discovery 보존과 정상 프로필 저장 가드 수정만 적용했다.

다음 구현: 결과 UI 로비 재화 표시, `???` 정보 공개 UI, 퀘스트/필드보스별 로비 보상 입력, 4슬롯 프리셋, 100 숙련 자동승급 수치 계약, 정상 완주·60초 경로 실측. 이번에는 생산 맵/엔진 설정/멀티플레이를 변경하지 않았다.

질문 대기: 중도 종료/재실행은 포기 정산인지, 남은 시간까지 저장한 이어하기인지. 답변 전 종료 정책을 추정 변경하지 않았고 기존 활성 스냅샷 저장은 유지했다. 현재 새 포인트를 영구화하는 정상 경로는 확정된 승리·사망·시간초과다.
