# A안 전투 HUD 글자와 아이덴티티 정리

승인 A안의 슬롯 좌표와 테두리를 유지했다. 실시간 글자는 Slate의 96 DPI 기준에서 2px 줄였고, 아틀라스에 들어 있던 `EXP`, `Alt`, 공격 키 6개와 `Ctrl`의 글자 레이어도 각각 높이 2px를 줄였다. 비어 있는 슬롯의 `HOLD RMB` 표기는 슬롯 내부 폭으로 맞춘 뒤 경계 안에서 그린다. 원형판의 사각형 자국은 이전 문구를 지운 위치의 명암 경계에서 생겼다. 기존 원형 음영을 따라 문구 부분만 보정했다.

기존 `--` 표시는 해당 무기에 표시할 아이덴티티 게이지가 없다는 뜻이었다. 이 경우 무기명은 남기고 숫자는 생략한다. 왼쪽 `Ctrl` 안내는 실제로 수동 발동할 수 있는 너클에서 보인다. 왼쪽 `Ctrl`로 너클의 질풍투기를 발동한다. 대검의 투지 등 공격으로 발동하는 게이지는 수치를 표시한다. 아이덴티티 위에 커서를 올리면 자원명 또는 해당 무기의 안내를 볼 수 있다.

## 실행 검수

- UE 5.8 Editor 컴파일 및 아틀라스 임포트가 성공했다. 실제 StartHub에서 1672×941·1280×720과 기본 카메라 맨손을 확인했다. 검사 63개, 실패 0개다. 대검은 퍼센트만 표시하며 너클의 왼쪽 `Ctrl` 입력으로 질풍투기를 실제 발동해 HUD 갱신을 확인했다. [런타임 결과](evidence/hud-label-polish-20261121/runtime-contract.txt)
- 맨손의 `HOLD RMB` 밝은 글자 픽셀은 x998–1071이고 키 영역은 x994–1073이다. 사각형 이음새와 `--`가 사라진 것을 확인했다. 대검 캡처에서 새 아틀라스와 화면의 비교 대상 55,370픽셀이 일치했다. [기본 카메라 캡처](evidence/hud-label-polish-20261121/unarmed-default-camera.png) · [픽셀 비교](evidence/hud-label-polish-20261121/visual-comparison.txt)
- 사용자 에디터와 별도 물리 체크아웃을 검증에 사용했다. 처음 격리 빌드는 공용 UnrealEditor 실행 파일의 Live Coding 뮤텍스로 지연됐다. 격리 경로에 연결된 에디터가 없음을 확인하고 IDE 핫리로드를 끈 빌드가 성공했다. 임포트와 HUD 검증 구간 오류는 0개이며, `-game`의 기존 Python 초기화 로그 58줄을 별도로 기록했다.
