# 기본 격투가의 자연스러운 움직임 개선

- 날짜: 2026-09-10
- 작업 브랜치: Sprint#4-26-natural-brawler-motion
- 엔진: UE 5.8.2
- 상태: 구현·빌드·Editor 적용·최종 실게임·회귀·독립 소스/시각 검증 완료. 원본 유튜브 직접 시청은 도구 초기화 오류로 미완료.

## 변경 이유와 동작

이전 모션은 양손이 같은 직선을 왕복하고, 몸·머리가 같은 파형으로 움직이며, 특히 어퍼컷 정점의 화면상 정지가 길었다. 작은 준비 동작 뒤 빠르게 신전하고 정점 직후 팔꿈치를 접어 바깥/아래 곡선으로 회수하도록 바꿨다. 연속 공격은 직전 손 위치에서 시작하며 반대 손 방어와 작은 가드 높이 차이를 추가했다.

몸통 선행과 머리 후행을 분리하고, 실제 평가된 머리 변화만 표시용 카메라에 전달한다. Unarmed의 카메라는 속도를 유지하는 임계감쇠로 추종한다. 새 임의 흔들림이나 조준용 CameraComponent/ControlRotation 변경은 없다. 기존 Knuckle 경로는 보존한다.

처음에는 기존 피해 시점을 유지했으나 실게임 시각 검토에서 어퍼컷 해제 후 준비가 길게 느껴져 두 어퍼컷의 AnimationPlayRate를 1.5로 조정했다. 몽타주·포즈·첫 타격 지연이 동일한 속도를 사용하므로 실제 타격 시점은 약 0.633→0.422초로 함께 이동한다. 차징 0.85초, 피해량·비용·쿨다운은 보존한다. 자산 변경은 Editor 스크립트로 적용한다.

## 구현과 튜닝

- FistAnimInstance: 마지막 0.14 정규화 구간에서 빠른 신전, 정점 이후 0.30 구간에서 곡선 회수. 주먹 정점 0.34, 어퍼컷 정점 0.38.
- 기본 주먹: 신전 약 0.14초, 회수 약 0.30초. 어퍼컷 1.5배 템포: 신전 약 0.156초, 회수 약 0.333초.
- 상체 선행 0.04, 머리 후행 0.035는 각 동작 시간에 대한 비율이다. 고정 밀리초가 아니다.
- Camera: BasicCameraMotionResponse 32, 위치/회전/속도 상한과 비정상 DeltaTime 처리. 명시 비활성은 전부 초기화하며 자연 종료는 0으로 부드럽게 복귀한다.
- 기존 어퍼컷 높이, 팔 길이 94% 도달 제한, 목 숨김과 손목 방향을 유지한다.

## 검증 근거

기획 1·개발 2·검증 2 역할로 진행했다. 독립 코드 검토에서 현재 변경 범위의 즉시 수정이 필요한 중대/중간 결함은 발견하지 못했다. 첫 시각 검토에서는 긴 정점 정지 감소, 다른 회수 경로, 비대칭 가드와 반대 손 반응, 정상 팔 실루엣 및 점프 복귀를 확인했다.

- Editor 빌드 성공 40.23초.
- 1차 실게임 RESULT=BASIC_BRAWLER_PASSED frames=480 failures=0.
- 실제 조준 불변, 좌우 수락/피해/취소, 점프·착지, 손의 유한값/과도한 프레임 간 이동 검사.
- 기본 Unarmed 카메라의 DeltaTime 0, 1초 hitch, NaN, 강도 0 직접 실행 검사.
- 30Hz 시뮬레이션과 30fps 실제 300장 촬영. 자연스러움은 수치 통과만으로 단정하지 않고 연속 프레임을 별도로 검토한다.

## 원본 영상 접근

사용자가 지정한 컴퓨터 플러그인의 @oai/sky 초기화를 직접 실행했다. 첫 호출은 trusted Node process exited unexpectedly, 복구 재시도는 windows sandbox failed: apply deny-read ACLs로 실패했다. 브라우저 창을 선택하거나 영상 프레임을 읽기 전에 실패했으므로 두 유튜브 영상을 시청했다고 주장하지 않는다. 이번 개선은 현재 게임의 실제 연속 화면과 코드 분석에 근거한다.

## 최종 결과

- RESULT=BASIC_BRAWLER_ASSETS_PASSED. Editor에서 두 어퍼컷 rate1.5와 강화 차징0.85를 실제로 읽어 확인했다.
- RESULT=BASIC_BRAWLER_PASSED frames=480 failures=0. 카메라 0dt/강도0/hitch/NaN 검사 포함.
- RESULT=FIST_PRESENTATION_PASSED frames=120 failures=0, VIEW_AUDIT completed=3. 기존 너클의 시야·무기/사망/강도0 복원 회귀 통과.
- 최종 시각 검증: 탭78→91/강화156→169에 정점(약0.43초), 94/172에서 회수 시작, 98/176에서 가드 근처. 긴 정점 정지가 줄고 상승/회수 궤적이 구분된다. 새 메시 찢김·손목 뒤집힘·양팔 교차는 발견하지 못했다.
- 30fps 실제 촬영 300장→10초 GIF(800×450), 길이/프레임 수 검증 완료. images/natural-brawler-20260910/natural-brawler.gif.

평가 범위는 현재 기본 공속·Manny 테스트 맵의 실제 비교다. 흰 전완이 크게 보이는 기존 메시 특성은 남아 있다. 극단적인 공속/낮은 프레임율이나 유튜브 원본과의 일치 여부까지 검증했다고 확대하지 않는다. 커밋·푸시는 하지 않았다.
