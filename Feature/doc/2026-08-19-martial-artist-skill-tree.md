# 권사 무협 스킬트리 구현 결과

## 결과

권갑(`Knuckle`)을 장착하면 `권사` 전용 프로필이 활성화되고, 입문부터 문파 최종 오의까지 이어지는 4경지 10무공 트리를 표시한다. 시작 무공은 `연환권` 하나이며, 이후 무공은 선행 무공과 기술 사용 횟수 또는 특정 몬스터 처치 조건을 충족하면 자동으로 해금된다.

## 무공 구성

| 경지 | 무공 | 전수 조건 | 해금 효과 |
| --- | --- | --- | --- |
| 입문 | 연환권 | 기본 전수 | 권사 기본 공격 |
| 초식 | 붕권 | 연환권 20회 수련 | 단일 대상 경력 집중 |
| 초식 | 파진각 | 철갑사 5명 토벌 | 부채꼴 제압 |
| 초식 | 철산고 | 연환권 50회 수련 + 철갑대장 1명 토벌 | 높은 충격력 |
| 절기 | 유운수 | 붕권 30회 수련 | 빠른 연계 시동 |
| 절기 | 금강쇄 | 사막마적 8명 토벌 | 방어선 분쇄 |
| 절기 | 백열난무 | 철산고 40회 수련 | 6연속 타격 |
| 심법 | 금강불괴 | 유운수·금강쇄 전수 + 가시문주 1명 토벌 | 받는 피해 15% 감소 |
| 심법 | 태산압정 | 금강쇄 전수 + 독무노파 1명 토벌 | 착지 원형 충격 |
| 심법 | 무극패왕권 | 백열난무·금강불괴·태산압정 전수 + 백열난무 100회 수련 + 심연마군 1명 토벌 | 권사 최종 오의 |

## 진행 시스템

- `ARogue10mPlayerState`가 무공별 실제 사용 횟수와 몬스터 타입별 처치 횟수를 기록한다.
- 공격은 자원과 재사용 대기시간 검사를 통과해 실제 실행된 경우에만 수련 횟수를 올린다.
- 몬스터는 권한이 있는 사망 처리에서 마지막 피해 플레이어의 진행도에 `MonsterId`를 기록한다.
- `URogue10mCombatComponent`는 진행도 변경 이벤트를 받으면 선행 조건을 포함해 고정점 방식으로 연쇄 해금을 평가한다.
- 해금된 공격 무공만 하단 HUD 입력 슬롯으로 드래그할 수 있고, `금강불괴`는 슬롯 없이 상시 적용된다.
- 무기 교체 시 활성 트리도 해당 무기 프로필로 전환되므로 권사 트리는 권갑 장착 중에만 표시된다.

## UI 적용

- `WBP_SkillTreeWindow`: 좌측 권맥 경지, 중앙 경맥형 분기 트리, 우측 무공 비급 상세 패널로 재구성했다.
- `WBP_SkillTreeEntry`: 경지, 아이콘, 무공명, 수련 진행률, 잠금·해금 상태를 표시한다.
- 잠긴 노드도 선택해 선행 무공, 수련/토벌 현재값, 해금 효과를 확인할 수 있다.
- 활성 연결선은 옥빛, 잠긴 연결선은 묵동색으로 구분한다.
- 실제 배경 프레임 Texture2D는 `/Game/UI/MartialArts/T_UI_MartialArtsSkillTreeFrame`에 배치했다.
- 재현 가능한 생성·UMG 조립·검증 스크립트를 `Scripts/Editor`에 추가했다.
