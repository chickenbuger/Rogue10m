# 머리 카메라 기본 시선 30도 조정

- 날짜:2026-09-22
- 브랜치:Sprint#4-37-forward-head-framing
- 상태:구현·빌드·실행·독립 검토 완료.

사용자가 선호한 Boxing 원본의 아래40도 구도를 기준으로 시선을10도 올려 아래30도로 조정했다. 실제 게임에서는 수평 스폰의 첫 로컬 시선에만 -30도를 적용한다. 이후 마우스 조작과 무기 교체에서 사용자의 방향을 보존한다. 명시적으로 지정된 비수평 시작 방향은 변경하지 않는다.

## 구현

PlayerController::UpdateRotation에서 Super 호출 전에 Presentation의 ApplyInitialFullBodyViewPitchOnce를 호출한다. 엔진 GameMode가 최종 스폰 회전을 지정한 이후에 적용되며 Super가 같은 프레임의 마우스 입력을 이어 처리한다. 초기화 여부는 Pawn이 소유한 Presentation 컴포넌트의 bool로 기록하고 무기 교체·Refresh/Restore에서 초기화하지 않는다. 새 Pawn은 새 초기 상태를 갖는다.

설정은 bEnableInitialFullBodyViewPitch=true, InitialFullBodyViewPitch=-30이며 [-60,0] 범위를 사용한다. 초기 피치가 수평0.01도 이내일 때만 적용하고 yaw/roll을 보존한다. 비활성·팔 전용·비정상 설정·명시적 시선에서도 첫 기회를 소비해 나중에 갑자기 시선이 바뀌지 않게 했다.

최종 화면에만 회전을 더하는 대신 기존 ControlRotation을 사용하므로 카메라와 공격 조준 방향의 관계를 유지한다. 카메라 위치·FOV·머리 추종 강도·전신·Idle·공격·HUD는 변경하지 않았다. 기본값은 아래를 조준하는 시작 방향이며 시선을 고정하거나 자동으로 복귀시키지 않는다.

## 비교 자료

BoxingDirectPreview에 -RogueBoxingForwardView 옵션을 추가해 기존40도 옵션을 보존하고 새30도 장면을 별도 촬영한다. 비교는 같은 리타깃 원본과 눈 위치·머리 추종 설정에서 각도만 바꾼다. 원본 비교의 눈 위치 보정은 촬영용이므로 일반 게임의 카메라 위치까지 동일하다고 설명하지 않는다. 비교 영상의 UI 제외는 촬영 옵션이며 실제 HUD를 숨기지 않는다.

전용 초기 시선 테스트는 프리뷰가 방향을 바꾸기 전의 실제 -30도와 후속 시선 변경·무기 교체·반복 초기화 호출에서 사용자 시선이 유지되는지를 확인한다. 기본 게임 스크린샷도 따로 보존한다.

## 검증과 근거

최종 UE 5.8.2 Editor 빌드 11.22초 성공. 첫 빌드에서 부모 Controller::Character와 지역 변수 이름이 충돌한 C4458은 ControlledCharacter로 바꿔 해결했다.

전용 초기 시선 검사 90프레임, 실패 0. 새 게임의 Control/CameraComponent/렌더 시선 모두 -30도였다. 명시적으로 바꾼 (-12,17) 시선에서 프로그램 회전 입력을 실제 virtual UpdateRotation으로 처리하여 (-19.5,22)로 바뀌고 다음 틱·무기 교체·Refresh 이후에도 유지됐다. 카메라 전방과 Control 방향의 내적 >0.99999를 확인했다. 첫 fixture 실행은 입력 주입 뒤 ignore를 복원해 엔진 PostProcessInput에서 입력이 지워지는 오류로 1건 실패했으며, fixture의 입력 소비 순서만 수정했다. OS 물리 마우스 조작 전체 경로를 자동화한 검사는 아니다.

30도 Boxing 원본 미리보기 278프레임, 실패 0. 머리 추종 오차 0cm/최대0.000002도, 제한 도달 0프레임. 최대 머리 이동67.494cm·yaw13.954도이며 원본 움직임을 유지했다. 독립 화면 검토에서 전방 표적 상체와 공간이 더 보이고 왼손 타격이 하단에 유지되는 것을 확인했다. 낮은 원본 가드와 손 내린 일반 Idle은 여전히 화면 하단 밖으로 나갈 수 있다.

비교 영상은 왼쪽 기존40도/오른쪽 새30도, 1920×540·30fps·248프레임(8.27초)이다. 원본 속도와0.5배속을 포함하며, 기존 영상 끝의 가드 복귀와 현재 Idle 복귀 차이가 각도 비교에 섞이지 않도록 마지막30프레임은 비교에서 제외했다. 전체 새30도 영상은278프레임(9.27초)으로 별도 보존했다.

공용 자산4파일의 SHA256 보존, 생성 경로 검사와 git diff --check를 통과했다. 엔진 실험용 Toolset Python의 기존 초기화 오류는 실행 로그에 남지만 이번 런타임 검사와 촬영은 완료됐다. 독립 소스 검토는 evidence/head-framing-20260922/source-review.md에 기록했다. 멀티플레이 RPC 순서나 임의의 메뉴 Pawn 확장은 검증 범위에 포함하지 않는다. 커밋·푸시는 하지 않았다.
