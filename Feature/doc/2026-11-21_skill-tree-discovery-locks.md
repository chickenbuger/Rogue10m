# 스킬트리 잠금과 미발견 표시

[설계](../architect/2026-11-21_skill-tree-discovery-locks.md) · [ImageGen 시안](evidence/skill-tree-discovery-locks-20261121/state-concept.png)

- 현재 배운 능력은 이름과 메달을 표시한다. 과거에 배웠지만 현재 잠긴 능력은 이름과 메달을 표시하고 오른쪽 아래에 황동 자물쇠를 붙인다.
- 한 번도 배우지 않은 능력은 물음표 메달과 미발견 이름표를 표시한다. 상세 카드와 툴팁에서 효과와 기술 이름을 가린다. 미발견 선행 능력에도 같은 이름표를 사용한다. 전수 조건과 비용은 확인할 수 있고 조건을 갖춘 노드는 전수할 수 있다.
- 시작점과 기본기, 능력치 노드는 연결 경로를 읽을 수 있도록 이름을 표시한다. 공통·너클·검은 같은 형태의 자물쇠와 물음표를 사용한다.
- 첫 습득 시 기존 프로필 발견 기록을 갱신한다. 같은 프로필의 탐험을 정산하거나 투자 상태를 초기화해도 알아낸 이름을 표시한다. 기존 저장에서 불러온 투자 기록도 발견에 포함한다.
- 물음표와 자물쇠를 Slate에서 그린다. 기존 메달 이미지와 프레임을 재사용한다.

## 확인 결과

- 실제 StartHub 게임 창에서 공통·너클·검의 노드 상태와 전수·상세·장착 조작을 프로그램 입력으로 검증했다. 실행 중 342개, 같은 프로필로 게임을 종료하고 다시 실행해 111개 검사를 통과했다.
- 처음 배우기 전에는 이름과 메달이 가려지고, 조건을 갖추면 전수가 가능했다. 전수 직후 이름과 메달이 표시됐다. 저장 지연 중에 투자를 되돌려도 발견 기록이 남았고 재실행 후 현재 전수 상태와 별도로 복원됐다.
- [720p 대표 화면](../../DevLog/20261121_SkillTreeDiscovery/discovery-states-720p.png)과 [1080p 화면](evidence/skill-tree-discovery-locks-20261121/discovery-states-1080p.png)을 확인했다. 대검 화면에는 습득한 회전참, 다시 잠긴 대지파쇄, 아직 배우지 않은 스킬이 동시에 표시된다.
- 두 렌더 세션에서 하드웨어 Direct3D 11 초기화 오류 `887A0004`를 각각 한 번 기록했다. 소프트웨어 렌더러로 화면과 입력을 검증했고 두 세션에 다른 오류가 없었다. 최초 검증에서 잘못 표시된 흰색 배지 배경과 이전 테스트 바이너리의 가격 표시 비교 오류는 최종 빌드에서 수정과 재검증을 마쳤다.
- [검증 기록](evidence/skill-tree-discovery-locks-20261121/verification.json)에 렌더 검증, 재실행 복원 및 통합 테스트 결과를 보관했다.
- 아린 대화 전환과 아자토르 보행 변경을 포함한 통합 후보에서 UE 5.8 Editor 빌드 및 스킬트리·공격 자원·성장 요건 자동화 13개를 통과했다. 자동화 세션의 새 Unreal 오류는 0개였다.
