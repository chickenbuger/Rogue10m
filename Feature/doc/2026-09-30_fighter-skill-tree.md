# 격투가 스킬트리와 테스트 해금·키 설정

브랜치: `Sprint#5-4-fighter-skill-tree`

## 적용 기능

맨손과 너클 모두 K 스킬트리 창에 같은 격투가14노드를 표시한다. 맨손 기본4와 기존 무공10(공격9·상시심법1)을 재사용했다. 총13개 공격과 받는 피해15% 감소의 금강불괴 심법이다. 기존 전용 애니메이션, 피해·자원·차징·연타 설정과 수련·토벌 조건은 보존했다.

테스트 전체 해금 버튼은 현재 세션에서14노드를 즉시 연다. 수련·몬스터 토벌 카운터를 수정하지 않는다. 새 세션의 테스트는 다시 버튼을 누른다. Shipping에서는 버튼과 테스트 API를 제공하지 않는다.

## 사용 방법

1. 맨손 또는 너클 상태에서 **K**를 눌러 스킬트리를 연다.
2. **테스트 · 현재 트리 전체 해금**을 눌러 모든 공격과 패시브를 연다.
3. 사용할 공격 노드를 선택하고 오른쪽 **키 지정**을 눌러 키보드 키 하나를 입력한다. Esc는 선택을 취소한다.
4. 창을 닫고 지정한 키로 사용한다. 차징 공격은 안내된 시간 이상 누른 뒤 놓고, 태산압정은 공중에서 사용한다.
5. **지정 키 해제**로 해당 스킬의 키를 지울 수 있다.

키 설정은 로컬 플레이어 SaveGame `Rogue10mSkillKeys_<컨트롤러 번호>`에 저장해 재실행 후 복원한다. 테스트 해금 상태는 저장하지 않는다. 현재 트리 안의 중복 키, 이동·점프·회피·메뉴·소비품1~5·마우스·보조키 조합은 거부하고 이유를 표시한다. 잠긴 스킬과 패시브에는 실행 키를 지정할 수 없다.

기존 좌/우 클릭, 차징 입력과 HUD 드래그 장착은 유지된다. 새 키는 특정 스킬을 직접 선택하는 별도 단축 입력이며 기존 GAS·쿨다운·자원 검사를 거친다. 메뉴, 사망, 일시정지, 다른 무기의 스킬은 실행하지 않는다. 메뉴·무기교체·키 변경·일시정지가 차징을 취소한다.

## 구조와 보존

- `URogue10mCombatComponent`: 현재 트리의 테스트 해금과 검증된 스킬 실행·차징 정책.
- `URogue10mSkillBindingComponent`: 컨트롤러 소유, Enhanced Input 컨텍스트·키 저장·충돌 검사·소유 입력 정리.
- 기존 SkillTree Window/Entry: 선택 스킬의 키 설정, 실제 오류 안내, 전체 해금 UI.
- Unreal Editor 구성기: 두 프로필과 기본기 위치 메타데이터만 변경하며14개 기술의 전투 필드를 전후 비교한다.

명시 초기 해금 배열은 유지했다. 공용 트리의 무조건 기본 전수 규칙 때문에 정상 시작은 기본기4와 연환권의5개이며 나머지9개는 기존 수련/토벌 조건을 따른다. 기존 dirty 작업은 보존하고 이번 변경만 추가했다.

첫 통합 실행은 점프 후 테스트 위치 복원 누락 때문에 뒤따른 지상 차징 스킬이 거부되었다. fixture를 원위치·속도·중력까지 복구하도록 보완하고, 다음 지상 상태를 검사한 최종 실행에서13개 공격이 모두 통과했다. 독립 리뷰에서 발견한 QA 저장 슬롯 보호와 지연된 입력 재구성 중 이전 자체 Action 오판을 수정했다.

107항목의 모든13개 기술 검증은 키 입력에 따른 실제 실행과 몽타주를 확인한다. 그 시나리오의 명시 실제 피해 assertion은 첫 잽이며, 별도 기존9종 전투 회귀에서14회 실제 체력 감소를 확인했다. 모든13종의 모든 타깃/거리/판정 범위를 검사했다고 주장하지 않는다.

증거: `Feature/doc/evidence/fighter-skill-tree-20260930/`. 검증은 전용 QA SaveGame 슬롯을 사용해 실제 사용자 키 설정을 바꾸지 않는다.

두 담당자가 서로의 변경과 최종 실행 로그·캡처를 독립 검토했다. 위 결과를 확인했으며 검토 범위의 잔여 완료 차단 사항은 없다.

## 범위와 한계

키는 단일 키보드 키만 지원한다. 패시브는 해금 즉시 상시 적용된다. 현재 싱글플레이 로컬 실행을 대상으로 하며 온라인 권한 복제와 캐릭터별 영구 수련 저장은 별도 시스템이다. 기존 미커밋 게임·Studio 변경을 보존했다. 커밋·푸시는 수행하지 않았다.
