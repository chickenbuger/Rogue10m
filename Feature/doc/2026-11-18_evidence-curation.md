# Feature 검증 자료 선별 정리 결과

사용자 요청에 따라 `Feature/doc/evidence`의 반복 사진·중간 JSON을 정리했다. 사진 621장과 JSON 3,293개, 총 **3,914개 / 810,622,927바이트**를 삭제했다. 조사 대상에서 사진 289장·JSON 2,762개를 보존했다.

전체 파일을 날짜별 세 범위로 나누어 검토하고, 삭제 후보 사진은 contact sheet와 원본 비교로 확인했다. 최종 UI·지형 선택 화면·보정 전 결함·손 방향 전후·원본 텍스처·서로 다른 몬스터 외형처럼 후속 대표 자료로 대체되지 않는 파일은 보존으로 돌렸다. 중첩 MCP 응답 독립 검사에서는 Split HUD의 속성/API/dirty 예외 세 건과 초기 MapMaker 통합 테스트 실패 한 건을 추가 보호했다. `job queued` 응답은 완료 결과가 남아 있는 임시 호출 기록으로 분류했다.

스크립트 입력 후보 339개, PCG 재개용 타일 실행 기록, 최종 수치·실패·출처·필수 동작 자료를 보존했다. 활성 자연 경계·동굴 폴더 277개 초기 자료는 전체 보호했다. 나머지 보존 파일은 원본 SHA256과 비교했다. 오래된 형식 오류 JSON 두 건은 고치지 않고 기존 실패/제약으로 남겼다. 이번 작업은 게임 재검증이나 해당 기능 완료 선언이 아니다.

삭제 대상은 내부 절대 경로·일반 파일·확장자·부모 reparse 여부·원본 크기와 해시를 모두 먼저 확인한 뒤 개별 삭제했다. 문서 30개의 링크 76개를 삭제 사실과 보존 목록을 알리는 문구로 바꿨다. 일지의 과거 본문과 보존 JSON 수치·상태는 수정하지 않았다. 로그·영상·패치·Unreal 자산·소스 등 비대상 파일은 남겼다.

검증: 보존 파일 해시, 코드 입력 존재, 삭제 대상 부재, JSON 기존 오류 두 건 외 신규 오류 없음, 정리로 끊기는 Markdown 링크 없음, `Scripts/CheckGeneratedChanges.ps1`, `git diff --cached --check`. 문서/자료 정리이므로 Unreal 빌드·에디터 실행은 하지 않았다.

기존 Git 추적 삭제 2,004개와 관련 문서·정리 manifest만 커밋한다. 미추적 보조 파일 1,910개도 로컬에서 삭제했지만, 보존한 미추적 자료/무관한 맵 변경/비공개 본문은 일괄 stage하지 않는다. 공유 일지에는 이번 추가분만 index에 선별한다. 작업 브랜치 `Sprint#9-32-landscape-world-blockout`에 게시하며 main·develop·test에는 합치지 않는다.
