# 대지파쇄 후속 복귀 검증 자료

StartHub에서 장검을 장착하고 실제 전수한 Q·RMB 기술을 60Hz 프로그램 입력으로 실행했다. 선택한 스킬과 원래 몽타주 인스턴스, 수락 시간, 표시 본을 월드 틱 뒤 읽었다. 정적 상자는 시전자 기준 오른편 대조에서 정면 135cm·오른쪽 129cm 위치에 놓았다. 두 손과 손가락으로 복원한 실제 철제 장검 삼각형을 상자와 대조했다. 그림에 보이는 상자는 같은 크기의 검증용 메시이며 게임 맵에는 들어가지 않는다.

- 오른편 벽의 인간 남성, 드워프 남녀와 오크 남성은 각 8건을 통과했다. 실제 칼 교차는 각각 7·7·8·7개에서 0개로 줄었고, 차징 이후 보정 가중치는 몽타주 1.62초까지 0이 됐다. [오른편 벽 수치](right-wall-runtime.json)
- 드워프 남성이 발동 후 D로 25.21cm 옆걸음한 대조의 칼 삼각형 교차는 8개에서 0개가 됐다. 최종 칼 경계 상자의 한 축 겹침은 실제 삼각형 교차로 이어지지 않았다. [옆걸음 수치](late-strafe-runtime.json)
- 왼편 벽에서 드워프 남성의 교차는 11개에서 0개로 줄었다. 85cm 앞에 놓인 좁은 정면 벽의 인간 남성은 기존과 동일했다. 434개 검·손 표본, 1,110개 액터 표본, 26,640개 본 표본에서 자세와 타이밍 값이 일치했다. [좌우 비교](wall-directions-runtime.json) · [정면 대조](close-front-parity.json)
- 인간 여성과 오크 여성의 프로젝트 리타깃 AnimBP는 기존 보행·장비 전환·구르기 손목 보정 설정을 확인한 뒤 표시 팔을 계산할 수 있는 부모를 사용한다. 부모만 바꾼 비교의 기존 대지파쇄 표시 본 26,640개, 검·손 표본 217개, 뒤 구르기 22프레임 각 924개 본의 위치와 바닥 여유가 일치했다. 두 외형은 최종 통합 빌드에서 오른편 교차가 각각 2개에서 0개로 줄었다. [리타깃 대조](female-retarget-parity.json) · [오른편 벽 비교](female-right-wall-runtime.json)
- 최종 통합 빌드는 `93d0f587`의 코드와 에셋을 사용했다. 인간 여성과 오크 여성의 벽이 없는 프로그램 입력 대조 각각 8/8에서 26,640개 본과 434개 검·손 표본이 일치했다. 차징 중 D도 각각 8/8이며 31.280295cm 이동했다. `AnimFinal93d`의 3인칭 2,792건, 프로그램 마우스 13/13, 상하 시점의 머리·팔 이동 0cm, 기존 저장 28개 해시 보존과 `AnimWeapons93d`의 일반 근접 공격 14/14를 확인했다. 최종 통합 검사 로그의 Unreal 출력 오류는 0건이었다. ## 보존한 실패

첫 후보의 몽타주 1.78초 복귀는 원본이 마지막으로 관측된 1.664904초에 가중치가 남았다. 인간 남성의 최대 검 각 이동은 18.42°였다. 같은 후보의 발동 뒤 D는 가중치를 바로 버려 드워프 남성의 한 프레임 검축이 65.54° 바뀌었다. 정상 복귀는 원본 몽타주 1.62초 안에 마치고, D 입력은 기존 걸음을 시작한 채 이미 적용된 두 팔만 한 번에 이어서 돌려보낸다.

첫 왼편 기본 대조는 공격 8건을 통과했고, 레벨 로드 전 UE Dataflow 클래스 사전 검사에서 `FDataflowToolNodeSnapshot::Date` 진단이 두 줄 찍혔다. 엔진 플러그인에서 해당 값은 `FDateTime::Now()`로 생성된다. 그 실행의 자세와 기하 수치는 남기고 진단을 별도로 표시했다.
