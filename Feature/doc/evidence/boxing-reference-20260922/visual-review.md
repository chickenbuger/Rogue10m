# 권사 복싱 자세 독립 시각 검증

검증 역할: 게임 런타임 구현에 참여하지 않은 검증2. 원본 FBX 분석 도구 작성과는 동일 담당이므로 원본 분석 자체의 독립 검증을 의미하지 않는다.

## 범위와 판정

**대표 게임 프레임 검증 통과.** 세 자세에서 가드, 왼잽, 오른잽, 오른 스트레이트, 차징, 오른 훅, 타격 후 복귀, 점프 착지 후 가드를 눈으로 확인했다. 메시 구멍, 좌우 손 뒤바뀜, 관절 분리, 복귀 시 한 손이 사라진 채 남는 현상은 관찰되지 않았다. 현재 카메라와 HUD 배치에는 아래 프레이밍 한계가 남는다.

검토 원본은 `Saved/Screenshots/WindowsEditor/BoxingStances/{boxing,longguard,rooted}/frame_####.png`이며 각 자세의 12, 27, 39, 88, 150, 169, 181, 235번 프레임을 같은 순서로 비교했다. 축소 시트를 실제 이미지로 열어서 확인했으며 동일 폴더의 `visual-boxing.jpg`, `visual-longguard.jpg`, `visual-rooted.jpg`에 보존했다. 본 검토는 동영상 전체 프레임의 재생 품질이나 모든 전환의 시간 연속성을 보증하지 않는다.

## 제한 및 개선 여지

1. 오른쪽 공격 중 반대 왼가드가 화면 좌상단 약 1/3 가까이를 차지하는 프레임이 있다. 해부학적 손 뒤집힘은 보이지 않지만 주먹이 지나치게 가까운 느낌은 남는다. 이후 게임 플레이 가독성 조정 시 반대손과 카메라 간격을 함께 다듬을 수 있다.
2. 공격 손이 화면 아래로 내려와 HUD와 일부 겹친다. 타격 시 손 전체 형태를 감상하는 데에는 불리하나 표적 중심을 완전히 가리지는 않는다.
3. 이 정면 전투 캡처에서는 플레이어 하체가 보이지 않는다. 지지발 고정, 발 회전, 왼발 전진은 이 자료만으로 시각 검증을 통과했다고 주장할 수 없다. 해당 동작의 관절 길이·수치 검증은 별도 런타임 검사 결과에 따른다.
4. Boxing.fbx 원본은 왼발 전진과 왼손 단타 1회다. 오른손 스트레이트, 훅, 세 가지 가드는 원본 전체를 리타깃해 재생한 결과가 아니라 참고 원칙을 사용해 현재 게임 입력에 맞춘 포즈다.

게임 소스는 본 검증에서 수정하지 않았다.
