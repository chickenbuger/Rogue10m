# 패왕참 준비 자세의 후보와 검증 수정

1. Blender 초기 후보는 양손목을 69.45cm와 72.57cm 당겼다. 기존 발동의 압축 포즈도 준비 구간에서 손과 검을 당기므로 첫 후보를 앞에 붙이면 손이 되감긴다. 대기 자세에 가까운 키로 교체했다.
2. 실제 게임 수치 A의 발 검사에서는 기존 대기 자체의 0.80cm 변위가 절대 0.75cm 기준을 넘었다. 발 검사를 같은 시간의 기존 포즈와 대조하고, 별도로 발의 높이도 확인하도록 보정했다. A 본 표본 SHA-256은 `625e0ae86a2cfc3b8403b2019bfe66b841e3f54aa931f8cbe4cb7267fdf0956d`다.
3. 실제 게임 후보 C를 새 기준으로 다시 계산했다. 완충 구간에서 검 축 방향 왼손목의 추가 이동 7.35cm, 검날의 추가 회전 14.83°, 손목 최대 이동 9.33cm였다. 영상 리타깃과 그립이 적용된 실제 메시의 차이가 Blender 편집 포즈보다 컸다. 동일한 임포트의 런타임 가산 강도를 0.40으로 낮췄다. C 본 표본 SHA-256은 `ecd5b0b79696c4bf9ce0e119e0f8849adc1c39fde4f4857bd027679f00efab28`이며 Unreal 로그는 `5e2537b79a6730150793ac4c26d5c783c083ac17f08a2cc8f534e3ea746112d0`다.

회복 시점과 초기 피해가 일치하는지도 C에서 따로 확인했다. 런타임 보정은 기존 파일과 기록을 보존한 뒤 별도 라벨로 검사했다.

첫 WARP 비교는 엔진 안에서 두 캡처를 저장하고 통과했다. 실행기 종료 코드에는 소프트웨어 어댑터가 선택되기 전 하드웨어 프로브 오류가 남았다. 재실행에서는 전체 오류 기록을 보존하고 WARP 선택 이후의 로그를 따로 검사했다. 두 번째 비교는 같은 시점의 두 장을 저장했고 선택 이후 오류는 0건이었다.
