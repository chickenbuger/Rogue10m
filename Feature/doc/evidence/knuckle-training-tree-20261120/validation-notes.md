# 검증 과정에서 발견한 문제

- 이전 탭 작업의 프로필·입력 검증은 새 캐릭터가 너클을 장착하고 F7/F8을 지정할 수 있다고 가정했다. 격리 프로필에서 실제 인벤토리를 통해 너클을 장착하고, 현재 Q/E/R 입력과 좌우 동시 슬롯의 드롭 조건으로 검증을 갱신했다.
- 위젯 헤더를 바꾼 첫 통합 빌드는 이전 UHT 산출물을 참조해 C4430/C2143이 발생했다. 같은 빌드에서 테스트 지역 변수 이름 중복 C4456도 확인했다. 변수를 구분하고, 프로젝트의 헤더 생성을 UBT에서 다시 실행해 빌드했다.
- 실제 게임 검사 `Knuckle1120B`에서 노드 17개, 기초기 슬롯 조건과 너클 드래그가 통과했다. 대검 패왕참의 피해·범위 공명 검사와 그 검사 뒤 중단된 입력 경로 판정 두 개가 실패했다. 검 기술을 포인트 전수로 전환한 뒤에도 이전 숙련 단계로 공격의 핵심기·최종기 효과를 분류하도록 보정했다. 마나 검사는 현재 최대 마나와 설정된 소모량을 기준으로 확인했다.
- 첫 실제 캡처에서 일부 원형 아이콘이 작고 내부 글자와 겹쳤다. 아이콘 크기와 글자 표시 순서를 조정하고, 연결선 위 이름을 구분할 어두운 배경을 적용했다.
