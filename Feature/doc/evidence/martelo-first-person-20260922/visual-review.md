# Martelo 2 실제 게임 1인칭 미리보기 — 독립 시각 검토

- 검토일: 2026-09-22
- 검토자 역할: 기능 검증 2 / 시각 검토
- 판정: 실제 게임 적용 미리보기로 성립. 완성된 1인칭 공격 연출 품질로는 미완성.
- 범위: 이미지로 확인 가능한 팔 표시, 가드 복귀, 화면 구성. 소스 및 리타깃 설정의 정확성 판정은 별도 검증 담당 범위.

## 확인 자료와 방법

- `Feature/doc/images/martelo-first-person-20260922/review-sheet.jpg`의 12, 30, 38, 45, 52, 60, 69, 199 프레임을 실제 이미지로 확인했다.
- 38, 52, 60 프레임은 960×540 확대 자료로 다시 확인했다.
- 0.5배속의 116, 128, 140, 148 프레임을 추가 확인했다. 검토용 시트는 `tmp/martelo-game/slow-review.jpg`에 있다.
- `tmp/martelo-game/runtime.log`의 `RESULT=MARTELO_PREVIEW_PASSED frames=209 failures=0` 표식을 확인했다. 이는 실행 검증의 결과이며 시각 품질 합격과 같은 뜻은 아니다.
- MP4 전체를 실시간 재생해 본 검토가 아니라, 실제 게임에서 촬영한 시퀀스의 선택 프레임을 통한 검토다.

## 관찰 결과

1. 게임 HUD, 적 캐릭터, 현재 팔 전용 메시가 동일한 게임 배경에서 표시된다. 앞서 검토한 선형 골격 프리뷰와 달리 실제 게임 적용 상태를 보여주는 자료로 성립한다.
2. 12 프레임에서는 양손 가드가 보이며, 199 프레임에서 양손이 같은 기본 가드 위치로 돌아온다. 애니메이션 이후 팔이 계속 사라져 있거나 비정상 자세로 남아 있는 현상은 해당 복귀 프레임에 없다.
3. 재생 중 여러 샘플에서 양손이 화면 밖으로 빠진다. 38 및 느린 재생 116 프레임에서는 한쪽 전완과 주먹이 화면 중앙을 크게 지나 적의 얼굴을 가린다. 52 프레임에서는 팔이 왼쪽 가장자리를 지나고, 60 프레임에서는 팔의 일부가 화면 아래를 가로지른다.
4. 공격하는 발은 나타나지 않는다. 현재 팔 전용 메시로 원본 전신 발차기를 재생하는 조건과 일치한다. 주먹이 주타격 수단인 잽·스트레이트·훅처럼 명확하게 읽히는 동작은 아니다.
5. 확인한 프레임에서 메시가 긴 삼각형으로 찢어지거나 관절이 끊어져 늘어지는 명백한 변형은 발견하지 못했다. 다만 손이 화면 밖에 있는 시간이 많고, 고속 구간에는 모션 블러가 강하며, 느린 구간에도 잔상이 있어 손목·손가락·팔꿈치의 모든 순간을 정상이라고 확정할 수는 없다.
6. 적과 배경의 위치는 샘플 사이에서 유지되어 고정 카메라 조건과 일치한다. 전신의 체중 이동에 따른 카메라 연출이 반영된 최종 타격감 시연으로 해석해서는 안 된다.

## 품질 한계와 사용자 설명

- 이 자료는 원본 FBX를 현재 팔 전용 시야에 적용하면 무엇이 보이는지 판단하기 위한 미리보기다. 완성된 전투 동작으로 권장하는 결과는 아니다.
- 원본의 주요 공격인 발차기가 보이지 않고 균형을 잡는 팔 동작만 남아, 공격 종류와 명중 시점을 알아보기 어렵다.
- 원본 자세와 기본 가드의 전환에 블렌딩이 없다는 촬영 조건을 함께 명시해야 한다. 선택 정지 프레임만으로 전환의 자연스러움을 합격 판정하지 않는다.
- 고정 카메라, 팔 전용 메시, 원본 동작 그대로 재생이라는 세 가지 조건을 시연과 함께 설명하는 것이 적절하다.

## 변경 범위

이 검토는 소스 코드, 게임 에셋, 런타임 설정을 변경하지 않았다. 검토 문서와 임시 확대 이미지만 작성했다.
