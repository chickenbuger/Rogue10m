# 최종 실행 독립 QA — 검증 2

2026-09-28. `tmp/animation-stability/after`의 451개 pose 샘플, 450개 렌더 프레임을 검사했다. before 캡처는 변경하지 않았다. 제품 코드·에셋 변경 없이 분석했다.

## 판정

**수정한 골반 연결·리타깃 발목·Source FootIK 간섭은 실제 실행에서 개선됐고, 이동·점프·착지·1인칭 복귀 검사도 통과했다.** 원본 우클릭 모션의 큰 몸통 회전 자체는 남아 있다. 따라서 “모든 동작이 차분하고 자연스럽다” 또는 “큰 머리 회전이 전부 사라졌다”는 승인은 하지 않는다.

## 원본 클립 → SourceABP 발 회전 보존

보존된 `secondary-stability.json`은 수정 전 원본 MM_Attack_02 / MM_Attack_03을 런타임과 동일한 clip_s에서 읽은 자료다. after의 frame별 clip_s가 같은지 먼저 확인했다. straight는 clip_s 0.30~0.65초의 10개 샘플, hook는 0.25~0.80초의 11개 샘플을 비교했다. 해당 구간에서 native pelvis/head도 수치상 일치해 full-blend 포즈를 확인했다.

| 비교 | 수정 전 native→Source 최대 회전 오차 | 수정 후 |
|---|---:|---:|
| straight 왼발 | 55.740° | 0.000015° |
| straight 오른발 | 81.719° | 0.000053° |
| hook 왼발 | 179.214° | 0.000020° |
| hook 오른발 | 155.959° | 0.000046° |

hook pelvis/head의 수정 후 native 오차도 각각 0.000019° / 0.000024° 미만이다. 기존 FootIK가 공격 발 회전을 다시 바꾸던 동작이 실제로 사라졌다는 근거다. 원본과 블렌딩 중 포즈는 원래 다르므로 전체 attack 프레임에 이 오차 기준을 적용하지 않았다.

정밀 재현 스크립트: `verify_native_runtime.py`.
측정값: `final-independent-runtime-metrics.json`.

- 점프 최고 높이: 89.989 cm.
- 마지막 frame 450: 공격 phase Idle, 누적 공격 serial 4, 1인칭 모드, 낙하 상태 false.
- 이동·점프 구간 frame 330~450에서 Appearance `spine_01`, `thigh_l/r`의 local/reference 길이비는 정확히 1.0.
- 같은 구간의 lowerarm/hand/calf/foot 양측 길이비도 1.0에서 최대 약 0.00000073 이내였다. 골반·척추·사지 연결이 이동/점프 중 다시 늘어나거나 무너지지 않았다.

## Source → Appearance 발 회전

전체 451개 샘플에서 두 스켈레톤의 raw CS 발 quaternion 차이 최대는 왼발 7.118° / 오른발 5.997°다. 서로 다른 reference bone axes/retarget pose가 있는 모델의 raw quaternion이므로 0을 요구하지 않는다. 기존에 한 프레임에서 123~151°가 추가되던 급회전과는 구분해야 한다. 이번 비교로 “두 스켈레톤의 모든 본 회전이 정확히 같다”는 주장은 하지 않는다.

## 이미지 확인

`before-contact.jpg`와 `after-contact.jpg`의 동일 프레임 40/52/58/66/80/95/144/154/251/261/280/305를 직접 비교했다. 잽 구간에서 골반·상체·하지가 서로 분리된 듯 접히거나 다리가 크게 끌려가던 현상이 줄었고, 공격 종료 후 원래 서 있는 자세로 돌아온다. 오른잽 때 반대 가드 방향으로 하체까지 전환되던 모습도 사라졌다. 우클릭의 큰 몸통 기울기와 회전은 여전히 눈에 보이며, 위 원본 비교로 모션 자체의 큰 움직임을 구분했다.

`after-locomotion-contact.jpg`의 320/345/360/380/390/396/415/440 프레임도 확인했다. 이동 및 점프 시 시야는 머리 움직임을 따라가며, 착지 이후 원래 시야로 돌아온다. 점프 중 화면 가장자리의 팔은 보이지만 본이 무한히 늘어나거나 화면 전체를 찢는 형태는 해당 샘플에서 보이지 않았다.

한계: 접촉 시트는 선택 프레임 검사다. 경사면·모든 커스터마이징 체형·모든 무기 몽타주의 접지 품질을 실제 플레이로 검증한 것은 아니다. full-blend 공격의 지형 발 보정 제외는 원본 포즈 보존을 위한 현재 설계이며 별도의 경사면 개선 여지가 있다.
