# Boxing 원본과 파생 공격의 안정성 진단

- 검사: `Scripts/Editor/AuditBoxingStability.py`
- 증거: `boxing-stability.json`, `boxing-stability-summary.json`
- 원본 FBX SHA-256은 import metadata와 일치한다.
- 이 기록의 수치는 수정 전 파생 애니메이션을 대상으로 한다. WORLD는 애니메이션 컴포넌트 공간이며 실제 Appearance 리타깃과 몽타주 블렌딩 이후 화면은 별도 검증 대상이다.

## 정상인 구간

원본 FBX를 가져온 클립의 머리 이동은 최초 프레임 대비 최대 66.38cm다. Manny 리타깃은 66.52cm로 거의 동일하다. 머리 회전은 최초 프레임 대비 원본 14.84도, Manny 14.83도이며, 각자 레퍼런스 대비 최대 원본 56.32도, Manny 57.28도다. 따라서 Appearance 화면에서 관측된 152도 회전을 Boxing 원본의 머리 운동으로 설명할 수 없다.

8개 팔·다리 구간은 모든 샘플에서 레퍼런스 길이 비율 1.0000을 유지하고, 로컬 스케일도 1이다. Manny Preview와 gameplay copy는 같은 포즈다. 파생 좌잽도 그 포즈의 시간만 바꾼 것이다. 뼈가 늘어나거나 머리가 152도 돌아가는 문제는 이 검사 단계에 없다.

Idle 첫 프레임과 좌잽 시작의 머리는 13.54cm, 33.96도 차이다. 손은 일반 손 내림에서 복싱 가드로 올라가므로 38~40cm의 차이가 있지만, 이것만으로 손목 뒤틀림이라고 판정할 수는 없다.

## 실제로 수정해야 할 구간

오른 잽은 기존에 전신 MirrorPose로 만들었다. 좌잽의 끝에서 오른 잽의 시작으로 넘어가면 루트 방향이 69.52도, 양발 방향이 각각 약 109.40도 달라진다. 각 발의 위치 차이는 68.70cm다. 왼발 앞 자세에서 오른발 앞 자세로 짧은 콤보 중에 통째로 전환하는 것이므로, 사용자에게 보이는 발 교차와 몸의 급회전에 기여한다.

| 좌잽 몽타주 위치 | 기존 전신 미러 오른잽 시작까지 왼발 거리 | 동일 하체 스탠스를 사용할 때 거리 |
|---|---:|---:|
| 0.600초: 실시간 0.400초, 재생률 1.5 | 102.88cm | 35.87cm |
| 0.750초: 실시간 0.500초 | 77.98cm | 10.01cm |
| 0.825초: 실시간 0.550초 | 75.14cm | 7.75cm |
| 1.000초: 클립 완주 | 68.70cm | 0cm |

초기 콤보 전환에 남는 35.87cm는 원본의 전진 스텝이 아직 복귀하지 않았기 때문이다. 하체 보존만으로 모든 중간 전환 거리가 사라진다고 주장하지 않는다. 기존 몽타주 블렌드와 실제 콤보 취소 시점을 함께 확인해야 한다.

Manny 리타깃은 시작 시 루트 Z=90.77cm, 골반 월드 Z=82.40cm다. 루트의 높은 위치와 골반의 반대 방향 로컬 이동이 상쇄되는 구조다. Idle은 루트 0, 골반 Z=93.79cm이므로 로컬 골반 차이가 102.17cm에 달하지만, 월드 골반 차이는 12.15cm에 그친다. 이 구조는 단독 클립에서 정상 자세를 만들 수 있으나 다른 리타깃 단계가 골반을 루트에 다시 복사하면 보존되지 않는다. Appearance 리타깃의 root-motion 연산을 별도로 검사해야 한다.

## 수정 구현과 아직 필요한 검증

원본 FBX, Preview Manny, gameplay 원본 시퀀스를 보존한다. 좌잽의 포즈도 그대로 둔다. 오른 잽 작성 시 엔진 미러링 뒤 root/pelvis/양다리 및 foot IK를 원본 값으로 복원한다. hand IK는 최종 오른 잽 손 포즈를 기준으로 다시 작성한다. 상체의 spine/neck/head는 최초 프레임 로컬 회전을 원본 중앙 자세에 맞추는 고정 쿼터니언 오프셋을 적용하고, 이후 미러된 회전 변화는 유지한다. 팔과 손가락은 엔진의 기준 축 보정 미러링을 사용한다.

작성 스크립트에 하체 로컬·월드 포즈 동일성, 첫 머리 자세 동일성, 팔 길이, 타격 시점의 오른손 전진 방향 검사를 추가했다. 해당 검사를 통과한 다음에 생성 에셋을 저장한다. 실제 타격 방향, 허리의 새로운 비틀림 여부, 중간 콤보 전환은 게임 실행과 영상 검증을 통과해야 최종 완료로 판단한다.


### Hand IK 동기화 보완

상체만 미러하고 root 아래 모든 IK를 원본에 고정하면, 손 목표는 왼 잽의 손을 가리키는 불일치가 생긴다. 오른 잽에만 최종 component-space hand_l/hand_r 포즈를 구한 뒤 ik_hand_l/ik_hand_r를 해당 손과 일치시키고 ik_hand_gun은 hand_r에 맞춘다. 부모 본을 먼저 갱신하고 그 부모의 최종 변환으로 로컬 값을 계산하므로 gun 아래 손 IK 구조도 반영된다. ik_hand_root 및 foot IK는 보존한다. 작성 검증은 121개 샘플에서 손과 IK 위치·회전 오차를 검사한다.


### 공격 방향 검증으로 발견한 추가 문제

첫 상체 미러 수정은 저장 전 방향 검사에서 실패했다. 오른손 어깨 기준 전진량 최대가 몽타주 0.741667초에 30.99cm로 나왔고, 실제 타격 시점 0.341667초에는 18.45cm에 그쳤다. 검사 기준을 낮추거나 실패한 파생 에셋을 저장하지 않았다.

원인은 하체를 원본으로 유지하면서 골반의 시간에 따른 회전까지 보존했으나, 상체는 미러 골반을 전제로 한 로컬 회전을 사용한 것이다. 시작 프레임의 로컬 오프셋만으로는 이 동적 부모 회전 차이를 제거할 수 없었다.

수정안은 원본 가슴 시작 방향과 미러 가슴 시작 방향의 고정 차이를 구하고, 그 차이를 미러 가슴의 컴포넌트 회전에 적용하여 매 프레임 목표를 정한다. 현재 상체 가슴 회전과 목표의 차이를 spine_01에 부모 변환을 고려해 반영한다. 시작 자세와 원본 하체를 유지하면서 오른팔의 어깨 기준 궤적을 보존하는 방식이다. 타격 방향 기준은 변경하지 않으며 재실행 검증이 필요하다.


### 최종 작성 및 실행 검증

재설계안은 Editor 검증을 통과해 저장했다. 121샘플 하체 차이0, 손IK 위치오차0.000098cm 미만/회전0.000122도 미만, 팔 길이오차0.000445cm 미만이다. 전진피크0.333초/52.46cm, 타격기준0.342초/52.37cm로 일치한다. 실제 450프레임 통합 실행과280프레임 V 회귀가 실패0으로 완료됐다. 최종 보고서는 `../../2026-09-28_animation-stability.md`와 이 폴더의 `final-runtime-review.md`를 참고한다.
