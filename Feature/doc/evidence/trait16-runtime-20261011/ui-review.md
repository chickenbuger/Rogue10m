# UI 검사 독립 검토

2026-10-11, UI 담당의 읽기 전용 검토 결과를 root가 기록했다. 코드·에셋은 이 기록에서 변경하지 않았다.

ui03의 카드 내부 좌표 실패 10개는 각 해상도의 스크롤 밖 마지막 행 Effect 4개·불굴 State 1개에 집중됐다. UE5.8 Widget.cpp:924는 Cached Geometry를 TickSpace로 반환하며, SWidget.cpp:1545–1546의 Paint에서 Desktop/AllottedGeometry를 갱신한다. SPanel.cpp:31–34는 cull된 자식의 Paint를 생략한다. 화면에 일부만 보인 Frame과 그 아래 텍스트의 캐시가 다른 프레임을 가리킬 수 있으며 GetCachedGeometry의 공개 계약도 미페인트·이전 프레임 데이터 가능성을 명시한다.

fixture는 ScrollToStart/ScrollToEnd 각각 0.35초 렌더 대기 후 완전히 표시된 카드의 이름·단계·효과·상태 경계를 검사한다. 빈 상태 문구는 제외하고 효과는 실제 한국어 폰트 높이로 두 줄을 검사한다. 양 끝에서 확인한 ID 합집합이 16개여야 성공하며, 기존 버튼 경계·키/마우스·재분배·저장 재시도 검사는 유지한다. 독립 검토에서 차단 결함을 찾지 못했다.

실제 ui04는 260 PASS / 0 FAIL, `RESULT=TRAIT_UI_PASSED failures=0`으로 종료했다. root는 1080p, 720p 마지막 행과 재분배 확인창을 열어 효과·잠금 문구, 모달 중앙 배치와 전체 배경 dim을 확인했다. 프로덕션 카드 높이를 추가로 늘리지 않았다. 각 해상도에서 스크롤 검사는 실제 상단/하단 좌표를 사용한다. 스크린샷 요청과 스크롤 이동이 한 프레임에 처리되어 기본 화면 PNG도 하단을 보여주며, 이는 파일명의 상단/하단 구분을 보장하지 않는다.
