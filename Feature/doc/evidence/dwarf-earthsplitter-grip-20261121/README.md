격리 Editor 빌드와 최종 수치·렌더 로그 및 왼쪽 구르기 로그에서 Unreal 출력 오류 0건을 확인했다. 구르기 전 기존 저장 182개의 SHA-256이 유지됐다. 차징과 검 방향은 실제 표시 본을 월드 틱 후 읽었으며, 바닥 여유는 캡슐 바닥으로부터의 높이다. 정지, 벽, 이동 실행의 첫 피해 시점은 모두 수락 틱이었고 원본 몽타주는 0.010953초였다. 늦은 D부터 놓기까지 표시 검축의 프레임 간 최대 변화는 남성 19.658°, 여성 16.367°였다. [정지 표본 수치](runtime-grip-07.json) · [벽 대조 수치](wall-fallback-paired-07.json)

실제 철제 장검 메시를 표시 손바닥 두 개와 손가락 방향에서 복원하고, 벽의 AABB와 겹치는 표본에서 칼 삼각형을 정적 장애물 상자와 대조했다. 복원한 경계 상자의 최대 차이는 차징에서 0.000669cm였다. 수락 이후 남성 7개, 여성 8개 표본의 벽 교차는 기본 자세와 동일했다. 남성의 48개 차징 표본도 기본 자세와 모두 일치했다. 여성은 새 자세를 풀던 차징 표본에서 상자가 한 차례 −3.433cm 겹쳤으나 삼각형 교차가 없었다. [차징 메시 대조](wall-mesh-07.json)

## 보존한 실패

- 02의 골격 초기화 검사에서 `IsRotationNormalized()` 단언이 발생했다. 입력 자세의 로컬 본을 보존한 상태에서 수정한 팔의 회전을 정규화했다.
- 03의 드워프 남성 회복 검축은 한 프레임에 146.9° 회전했다. 04의 독립 팔 보간에서도 남녀 최대 129.09°와 132.17°를 기록했고, 여성의 검 경계가 캡슐 바닥 아래 0.70cm까지 내려갔다. 두 손의 그립을 함께 계산하는 방식으로 변경했다.
- 05는 남녀 모두 차징 중 검의 삼각형 한 표본이 벽을 통과했다. 06의 경계 변경은 여성의 차징 교차를 해소했다. 남성은 0.516667초, 방향 6.071432°에서 −10.662cm의 경계 겹침과 삼각형 교차를 보였다. 같은 자세의 액터 방향을 0°로 고정해서 계산해도 교차했다. 07은 검이 지나간 오른쪽·정면 영역에 정적 장애물이 있는지 남성의 차징 시작 때 확인한다. [검이 움직인 범위](male-recovery-envelope-06.json)
