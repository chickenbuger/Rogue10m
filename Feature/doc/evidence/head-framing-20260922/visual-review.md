# 전방 시야 30° 시각 검토

## 판정

**기존 아래보기 40°보다 시선을 10° 올린 30° 프리뷰는 전방 가독성을 개선하면서 원본 왼팔 타격을 유지한다.** 실제 캡처의 같은 애니메이션 프레임을 비교해 확인했다. 대표 프레임에서 메시 구멍, 머리 내부가 시야를 덮는 현상, 왼팔이 사라진 채 남는 현상은 보이지 않는다.

검증2는 프리뷰·검증 fixture를 작성했으나 초기 카메라 설정과 머리 추종의 생산 코드는 작성하지 않았다. 시각 판정은 실제 대표 정지 프레임을 이미지로 확인한 결과이며, 영상 전체를 실시간 재생해 검토했다는 뜻은 아니다.

## 원본 복싱 프리뷰 비교

- 기존: `Saved/Screenshots/WindowsEditor/BoxingDirectPreviewLookDown40/frame_####.png`
- 변경: `Saved/Screenshots/WindowsEditor/BoxingDirectPreviewForward30/frame_####.png`
- 직접 비교: 12번 원본 가드, 43번 원속도 타격, 139번 0.5배속 타격.
- 비교 시트: `visual-view-comparison.jpg` (왼쪽 −40°, 오른쪽 −30°).

새 30° 화면은 같은 시점의 표적 상체와 주변 배경이 더 보인다. 43/139에서는 왼팔과 주먹이 화면 아래에서 앞으로 뻗는 원본 동작을 계속 확인할 수 있다. 40° 화면보다 자기 팔·바닥이 차지하는 비중은 줄어든다. 원본의 낮은 가드는 30°에서도 화면 하단 경계에 일부만 보이며, 높은 게임용 가드로 변형된 것은 아니다.

두 비교 영상은 모두 원본 리타깃을 직접 재생하고 UI를 제외했다. 원본 자세를 바꾸지 않고 고정된 시선만 10° 올렸으므로, 새로운 공격 애니메이션을 제작한 결과로 설명하지 않는다.

## 실제 기본 게임 시작 화면

`Saved/Screenshots/WindowsEditor/InitialHeadFraming/frame_0005.png`를 직접 확인했다. 사본은 `visual-initial-game.jpg`다. 초기 30° 시야에서 앞쪽 적과 공간이 보이고 기존 하단 HUD가 유지된다. 손을 내린 일반 대기 상태이므로 플레이어 손은 정면 화면에 보이지 않는다. 이 상태를 팔 렌더링 실패나 높은 가드 자세로 설명하지 않는다.

원본 Boxing 프리뷰는 원본 클립 첫 머리 위치에 맞춘 별도 눈 위치 보정을 사용한다. 실제 기본 게임은 기존 전신 카메라 위치를 유지하면서 초기 방향만 설정한다. 두 장면은 카메라 위치까지 같은 설정이 아니므로, 원본 프리뷰의 화면 구도를 기본 플레이 화면에 그대로 적용했다고 주장하면 안 된다.

## 검증 경계

기본 시작 각도, 후속 입력 보존, 무기 교체·표현 갱신 후 각도 유지의 수치 검증은 `TestInitialHeadFraming` 최종 실행 로그에 따른다. 시각 확인 자체가 초기화가 한 번만 실행됨을 증명하는 것은 아니다. 본 시각 검토는 최종 전달 자료로 사용할 수 있으며 추가 포즈 변경은 필요하지 않다.
