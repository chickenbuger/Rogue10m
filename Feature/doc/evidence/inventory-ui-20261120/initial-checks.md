# 인벤토리 UI 초기 검증 기록

| 단계 | 결과 | 처리 |
| --- | --- | --- |
| 배치 빌드 | 두 호출이 컴파일에 진입하지 못하고 배치 잠금을 기다렸다. | 이번 작업의 래퍼만 종료하고 같은 Editor 타깃을 설치 엔진의 UnrealBuildTool로 실행했다. |
| 전용 체크아웃 첫 UBT 빌드 | 열린 공유 에디터의 Live Coding 뮤텍스에 걸렸다. | 물리적으로 분리된 프로젝트에서 `-NoHotReloadFromIDE -NoEngineChanges`를 사용했다. 29개 작업 빌드가 통과했다. |
| 위젯 작성 | 위젯을 추가할 때 엔진 도구가 미완성 트리를 중간 컴파일해 필수 바인딩 오류를 반복 출력했다. 총 804건 모두 해당 항목이며 commandlet 종료코드는 1이었다. 완성된 네 위젯은 최종 개별 컴파일과 저장 기록을 남겼다. | 저장본을 새 프로세스에서 다시 열었다. 기존 메뉴 바인딩, 텍스처, 동일한 580×580 격자·아이템 레이어와 셀 설정을 검사했다. 재컴파일 종료 0, 로그 오류 0건이다. |
| 첫 1080p 플레이 `Inv1080A` | 프로필 생성 검사 실패. 테스트에 넣은 13자 이름의 허용 범위는 2~12자였다. 독립 게임에서 편집기 전용 Python 초기화 오류를 포함해 로그 오류 59건을 기록했다. | QA 이름을 11자로 수정하고 실패 사유를 보고하도록 했다. 독립 게임 실행에서 `-DisablePython`을 적용했다. 로그 검사기는 UTF-8로 실행한다. |
| 두 번째 1080p 플레이 `Inv1080B` | 22개 중 준비 검사 3건이 실패했다. 이미 장착한 초보 투구를 새 철제 투구로 교체하면서 가방에 들어온 투구 2.4kg이 예시 아이템 배치를 막았다. | 같은 장착품이 있으면 재사용하고, 필요한 경우 장착을 완료한 뒤 테스트 가방을 비운다. 게임의 장착 처리 자체는 그대로 사용한다. |
| 세 번째 1080p 플레이 `Inv1080C` | 예시 6종과 12.8kg 준비를 통과했다. 같은 틱에 누름과 뗌을 전달한 `I` 입력에서 창 열기 확인이 실패했다. | 다른 틱에 뗌을 전달하는 기존 메뉴 입력 검사의 흐름에 맞추고, 창을 찾지 못한 경우 가시성 상태를 기록한다. |
| 네 번째 1080p 플레이 `Inv1080D` | `I` 이후 창 검색·가시성·메뉴 일시정지까지 확인했다. 창의 인벤토리 계약 검사는 실패했다. 시작 시 초기 Pawn을 구독했던 창이 프로필 입장 후 바뀐 Pawn으로 갱신되지 않는 기존 경로를 확인했다. | 소유 Pawn 변경 이벤트에서 가방과 장비창을 현재 인벤토리에 연결한다. |
| Pawn 재연결 첫 빌드 | `AController::Character`와 같은 이름을 쓴 지역 변수에서 C4458이 발생했다. | 지역 변수를 주변 코드와 같은 `RogueCharacter`로 수정했다. |
| 1080p `Inv1080F` | 현재 Pawn과 연결된 `I` 창, 실제 100셀, 6개 점유 영역과 하단 수치를 확인했다. 숨김 실행에서 OS 창 검색이 마우스 경로를 찾지 못했다. | Slate가 렌더에서 작성한 해당 창의 히트 그리드를 직접 검색하고 같은 Slate 이벤트 라우팅으로 검증한다. |
| 1080p `Inv1080G`·`Inv1080H` | 히트 경로가 아이템 중심에서 1px 배경 셀을 찾아냈다. 래퍼의 크기는 맞았지만 실제 셀은 점으로, 실제 아이템은 40px 사각형으로 그려졌다. | 균일 격자 슬롯과 아이템 내부 행·열을 채우고, Slate 위젯을 만들기 전에도 아이콘 브러시가 크기를 갖도록 했다. [수정 전 실제 화면](failed-hover-layout.png) |
| 1080p `Inv1080I` | 실측 격자·점유 영역과 비교 카드를 렌더했다. 분류 줄에 장착품 이름이 붙었다. QA 우클릭 후 마우스 뗌에서 렌더 히트 정보가 없는 경로를 사용해 `FWidgetPath::GetVirtualPointerPosition`이 배열 범위 확인에서 중단됐다. | 분류 줄은 슬롯 타입의 이름을 사용한다. QA는 입력 누름·뗌 모두 렌더에서 얻은 Slate 경로에 전달한다. |
| 720p `Inv720J` | 79개 동작 검사와 실제 셀 크기는 통과했지만, 이전 1px 논리 두께에서 화면의 내부 세로선 9개 중 4개가 사라졌다. | 2px 논리 두께를 적용하고 두 해상도에서 저장한 PNG의 가로·세로 내부선 9개씩을 검사한다. [720p 시각 실패 화면](failed-720-grid-lines.png) |

원래 빌드와 게임 로그, 종료 기록은 전용 체크아웃의 `tmp/InventoryConceptRun`과 `tmp/inventory-ui-qa/Inv1080A`에 남겼다. 이 문서는 실패의 종류와 숫자를 보존하며 같은 바인딩 오류 804줄은 중복해서 보관하지 않는다.
