# 첫 검증과 수정 기록

- `MeleeVfxA`는 통합 기준 `a9746019`의 UE 5.8 720p 실제 3인칭 실행이다. 14개 케이스와 캡처 42장, 로그 오류 0건을 확인했다. 대검과 너클 최상위 기술의 범위 밖 케이스 두 건은 피해 0회·적중 섬광 0회였다.
- 첫 대검 기본기 캡처에서는 셰이더 준비 알림과 함께 일부 VFX가 늦게 표시됐다. 이후 캡처에서 백열난무의 손 잔상과 적중점, 회전 베기의 검날 리본과 범위, 최상위 기술의 명중과 빗나감을 확인했다. 밝은 바닥에서는 범위선이 희게 보였고 일부 검 리본의 끝이 굵었다. 후속 후보에서 밝기와 색 대비를 조정하고 끝을 부드럽게 처리했다.
- 이 실행에서 패왕참은 기존 데이터의 지연 0초로 피해가 들어갔다. `AM_GreatSword_Charged` 시작 프레임의 검날과 대상 캡슐 사이 간격은 47.112771cm였다. 새 검날 효과는 실제 이동이 샘플링된 이후에 표시된다.
- 최초 관리 환경 빌드는 UBA 공용 캐시 쓰기 권한으로 중단했다. 별도 작업 사본을 사용한 승인 빌드는 성공했다. 또 다른 증분 빌드는 타 작업의 전역 빌드 뮤텍스 대기로 중단했고, 엔진 파일 변경을 금지한 로컬 증분 빌드에서 성공을 확인했다.
- 기하 테스트 두 건은 첫 실행에서 성공했다. 같은 세션의 MCP 시작이 공용 포트 8001에서 한 번 실패했다. 확인한 새 오류는 MCP 포트 바인딩 오류 1건이다.
