# 팔 전용 1인칭 시각 검증

- 날짜: 2026-09-12
- 역할: 검증 2. 새 런타임 전환 코드의 개발자와 별도로 실제 촬영 프레임을 검토했다.
- 최종 판정: **대표 화면 14장에서 플레이어 몸통·골반·다리 표면 노출, 어깨 절단면 노출, 새 손목 뒤집힘을 발견하지 못했다.** 최종 재촬영한 정확한 -89도 화면 2장도 직접 확인했다.
- 원본 위치: `Saved/Screenshots/WindowsEditor/ArmsOnlyPreview/`.
- 확인 방법: 실제 PNG를 로컬에서 읽어 원본 비율을 유지한 JPEG 800~960px로 표시하고 직접 확인했다. 동영상 또는 전체 프레임 구간을 시청한 검사가 아니다.

## 그림자와 표면 구분

내려다본 바닥에 보이는 어두운 전신 실루엣은 바닥에 투영된 월드 캐릭터의 그림자다. 팔 메시와 달리 전신 피부·재질 표면이나 입체 관절이 카메라 앞에 표시되는 형태가 아니다. 이번 요청인 플레이어 하체 표면 노출과 구분했다. 수평 시야의 흰색 다른 캐릭터들은 월드 몬스터다.

## 구조 검증과 일치 여부

`tmp/arms-only/asset-result.txt`에서 세 렌더 LOD의 `non_arm_vertices=0`, 뼈 89개, 재질 슬롯 2개 보존을 확인했다. 이는 실제 화면에서 팔 이외 플레이어 표면이 보이지 않는 관찰과 일치한다. 시각 판정의 근거를 자산 검사 값만으로 대신하지 않았다.

## 남은 확인 및 평가 한계

- 첫 촬영의 -89도 표기는 실제 -70도 제한이 적용되어 제외했다. 최종 재촬영한 두 파일을 새로 열어 검토했고, `tmp/arms-only/runtime.log`의 1712·1743행에서 각 해상도의 실제 `pitch=-89.0`, 1752행에서 `RESULT=ARMS_ONLY_PASSED frames=390 failures=0`를 직접 확인했다.
- 검사한 것은 대표 정지 프레임이다. 모든 프레임의 메시 관통·자연스러운 움직임·최종 카메라 동조까지 검증했다는 의미는 아니다. 기존 기본 격투가 실게임 회귀 결과와 함께 판단해야 한다.
- 큰 흰색 전완과 높은 가드의 화면 점유, 어퍼컷 때 전완이 크게 보이는 기존 특성은 남아 있다. 이번 팔 전용 메시 적용의 새 결함으로 분류하지 않았다.
- 고릴라 암즈 원본 영상의 동작을 직접 관찰한 비교가 아니며 원본과 동일하다고 주장하지 않는다.


## 기본 격투가 최종 회귀 화면 추가 검토

- 최종 `BasicBrawlerPreview`에서 28·30·32, 40·42·44, 148·150·152, 167·169·171, 196·198·200번의 실제 PNG 15장을 직접 확인했다. 각 구간은 30fps 촬영의 2프레임 간격이며 전체 300프레임을 모두 검토한 것은 아니다.
- 좌우 신전 구간에서 공격 손이 전방으로 나가고 반대 손 가드가 남는다. 충전 때 오른손을 낮춘 자세, 어퍼컷의 빠른 상승과 정점 이후 회수 시작, 점프 중 가드 유지가 이어진다. 전용 팔 메시 때문에 생긴 새 찢김·절단면·손목 뒤집힘·몸통 표면 노출은 발견하지 못했다.
- 어퍼컷 전후 배경과 손 위치가 함께 작게 변하며 기존 표시용 시점 반응이 남아 있다. 실제 머리→카메라 연동의 판단에는 정지 프레임만 쓰지 않고 최종 `tmp/arms-only/basic-regression.log`도 대조했다: `charge_yaw=7.57`, `head_deg=5.91`, `source_camera_deg=1.27`, `rendered_deg=1.27`, `jump_height=89.99`, `RESULT=BASIC_BRAWLER_PASSED frames=480 failures=0`.
- 기존 큰 전완과 모델의 팔꿈치 경계는 동일하게 남아 있다. 이번 검사에서 고릴라 암즈 영상과 동작이 일치하거나 타격 무게감이 새로 향상됐다고 확대하지 않는다.
