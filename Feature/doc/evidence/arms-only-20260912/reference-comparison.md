# 고릴라 암즈 참고 방향과 현재 격투 비교

날짜: 2026-09-12. 이 문서는 직접 관찰한 현재 프로젝트와 제안하는 표현 방향을 구분한다.

CD PROJEKT RED의 공식 Savage Slugger Solo 글은 Gorilla Arms를 Body 계열 둔기 빌드에 포함하고 강한 근접 마무리 동작을 설명한다. 이를 힘 있는 근접 전투의 방향을 정하는 자료로 사용한다. 이 글은 팔 회전 각도, 카메라 진폭 또는 공격 프레임을 설명하는 애니메이션 기술 자료가 아니다.
출처: https://www.cyberpunk.net/en/news/50023/savage-slugger-solo-build-breakdown (2024-03-29)

## 직접 영상 확인 한계

사용자가 지정한 computer-use 스킬의 업데이트 버전(26.903.71938)을 읽고 @oai/sky 초기화를 시도했다. 첫 호출은 trusted Node process exited unexpectedly, 복구 재시도는 windows sandbox failed: helper_unknown_error: apply deny-read ACLs로 실패했다. 브라우저 선택이나 영상 프레임을 얻기 전의 실패다.

고릴라 암즈 및 기존 YouTube 레퍼런스를 재생·프레임 분석했다고 주장하지 않는다. 위 표의 표현 방향은 공식 글과 현재 프로젝트를 바탕으로 한 설계 제안이며 영상 간 직접 비교의 완료가 아니다. 자동 승인 검토의 거절이 아니라 컴퓨터 도구의 초기화 실패다.
