## Reviewer 결과

초안의 스탯 합계, M 단계와 선행, XP 필요량, 포인트 잔액, 심화OR, 무료 수련·실제 비용 환급, LegacyGranted 정책을 검토했다.

1. 비격투 무기에서도 격투 성장값을 발동 산식에 넣는 것으로 읽히던 부분을 수정했다. 해금은 영구 성장 기록을 읽고, 발동은 격투 무기에서만 그 값을 사용하며 다른 무기에서는0으로 평가한다.
2. 입문 환급 뒤 숙련 심화를 유지하는 것으로 읽히던 부분을 수정했다. 입문을 환급하면 해금 경로와 무관하게 후속 심화·성질·공명을 모두 철회한다. 입문을 유지할 때만 심화를0P 수련 경로로 재전수할 수 있다.

수정 후 독립 재검토 미해결0. 수련/토벌을 새 숙련과 이중AND로 붙이지 않고 대체한다는 정책, 기존 전수 기술 사용을 보존하되 스탯을 소급 지급하지 않는 이전 정책도 문서 내에서 일치한다.

## imagegen 시안 독립 검토

참조 기반 생성1회·상태/글자 교정1회 후 최종1672×941 RGB PNG를 열어 비교했다. 중앙 방사 구조와 정권의 스탯→기술 순서, 내공 심화의2P 또는 숙련 조건·실제 비용0P, 내공만 활성·투지/마나잠김, 궁극의 비활성 표현과 내공 공명 잠금을 확인했다. 공격력+3·스태미나+10·잔액0P·숙련60/65가 설계와 일치하고 무극패왕권·백열난무·태산압정 글자도 읽힌다. 생성 원본과 프로젝트 복사본SHA256은 동일하다.

공명 점선의 전체 끝점이 명확하지 않아 무극패왕권과방출의 정확한 양부모 연결은 검증하지 않았다. 일부 중간 노드를 생략한 대표 화면 시안이므로 전체 카탈로그 일치나 실제 작동 결과를 주장하지 않는다. 후속UMG에서는 해당 선행 이름과 잠금 이유를 명시해야 한다.

## 격투가 두 계열 수정 검토

사용자 확정 이후 canonical 설계의 격투가 표·성질·발동 산식은 내공·투지만 포함한다. 마나는 타 직업 정의로 보존하되 격투가의 구매/활성/장착/공명 허용 목록에서 제외한다. 입문1P·심화2P 또는 숙련·성질2P와 활성계열1개 정책은 유지한다.

v3 이미지를 직접 확인해 마나 가지·마나 라벨·마나 연결선 제거와 내공/투지 두 가지를 확인했다. 기존 숙련 경로·좌측LV4/M12·잔액0P·활성내공과수련0P 표현은 유지된다. 생성 원본과프로젝트복사본SHA256이동일하다. 초기 HTML은 변경 전 기록으로 보존하고 이번에 다시 제시하지 않는다.
