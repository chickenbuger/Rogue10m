# DevLog 검증 기록 정리 결과

DevLog JSON **326개 → 55개**로 정리했다. 불필요한 기록 **271개·8,023,339바이트(약8.02MB)**를 실제 삭제했고, 핵심 기록은 **768,419바이트(약0.77MB)** 남겼다. [핵심 기록 목록](../../DevLog/Records.md)에서 보관 기준과 결과를 확인할 수 있다.

## 보존한 기록

- 기능별 최종 검증과 최근 회귀6개 suite의 세부 결과.
- 중요한 설정·장비·성장 사망/승리·시각 검증 실패와 미완료 원인.
- 팔·NPC의 에셋 생성/리타깃/활성화/재로드, 유일한 기하 분석과 대표 메타데이터.
- 기존 비공개 QA 요약7개는 로컬에만 보관한다. 공개 추적을 강제하지 않는다.

## 삭제한 기록

- 반복 세션·드라이버 파싱 결과·전후 세이브 목록과 비교본.
- 일회성 카메라·촬영 RPC 인자와 응답, 삭제된 보조 사진 목록·해시.
- 후속 최종 결과에 대체된 중간 프리뷰와 정확한 중복.

파일명만으로 지우지 않았다. 이름이 captures.json인 두 파일은 고유한 주요 실패 원인을 담아 남겼다. 남긴 JSON은 다시 쓰지 않았고, 실패나 시각 검토 미완료를 성공으로 바꾸지 않았다.

## 검증과 게시

삭제 전 모든 대상의 DevLog 내부 절대 경로·일반 JSON파일·reparse 여부·SHA256을 확인했다. 폴더 재귀 삭제는 사용하지 않았다. 남은55개의 해시·JSON파싱·정확한 보관 목록, 삭제 파일 부재, 기존 비JSON 파일과 대표 사진35장, Markdown 링크를 검증했다. 게임 데이터·실제 세이브·영상·로그·CSV·DevLog 밖의 canonical 자료는 삭제하지 않았다. Unreal 실행·빌드는 필요하지 않은 파일 정리다.

정리 목록과 실행 결과는 [manifest](evidence/devlog-record-curation-20261118/record-manifest.csv), [삭제 결과](evidence/devlog-record-curation-20261118/deletion-result.json), [검사](evidence/devlog-record-curation-20261118/verification.json)에 있다. 맵 제작의 다른 변경은 제외하고 현재 작업 브랜치에만 commit·push하며 main/develop/test는 유지한다.
