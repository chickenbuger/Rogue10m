# Martelo 2 원본 애니메이션과 1인칭 적용 예상

## 확인 결과

사용자 제공 C:/Users/PC/Downloads/Martelo 2.fbx는1.3초짜리 왼발 높은 발차기 전신 동작이다. 파일 이름만으로 분류하지 않고 설치된 Autodesk FBX SDK2020.2의 Import/EvaluateGlobalTransform으로 실제65개 뼈 위치를 읽었다. 애니메이션 스택은 mixamo.com 하나이며, 캐릭터 표면 메시는 없다. MayaYUp 좌표·cm 단위로 변환해0~1.3초를30Hz로40번 샘플링했다.

오른발은 바닥 근처를 유지하고 왼무릎을 접어 올린 뒤 왼발을 높이 펴서 회수한다. 왼발 높이는14.18~159.47cm, 오른발은8.78~10.75cm다. 약0.3초 준비,0.5초 신전,0.7초 회수가 관찰된다. 양팔은 타격보다 균형을 잡기 위한 큰 동작을 한다. 골반~목 축은 수직 기준 최대약74.8도까지 기운다.

## 현재 게임에 적용하면

현재 팔 전용 메시에는 다리 표면이 없어, 이 원본 전신 움직임을 재생해도 주된 타격인 왼발은 보이지 않는다. 양팔이 크게 이동하는 모습만 남아 발차기보다 몸을 틀거나 균형을 잃는 듯 읽힐 가능성이 있다. 이것은 원본 동작과 표시 구조로부터의 예상이며 현재 게임 캐릭터에 리타깃한 실제 화면 판정은 아니다.

기본 Unarmed는 FistAnimInstance.cpp의 EvaluateBasicPose가 기존 몽타주 결과 대신 자체 손 궤적을 만든다. 따라서 공격 슬롯의 몽타주만 FBX로 교체하면 이 동작이 그대로 보이지 않는다. Mixamo 뼈대를 현재 Manny 뼈대에 맞추는 리타기팅과, 원본 포즈를 통과시키는 별도 재생 경로가 필요하다. 단순 SingleNode 프리뷰에서는 기존 FistAnimInstance 기반 카메라 연동도 자동으로 따라오지 않는다.

주먹 잽·스트레이트·훅을 대체하기보다는 별도 발차기 스킬로 쓰는 방향이 더 잘 맞는다. 그 경우 공격 중에만 발차기 다리를 보여주고, 상체의 큰 기울임은 카메라에 제한적으로 전달해야 공격 동작을 읽으면서 조준 시야를 유지할 수 있다. 실제 적용은 이번에 수행하지 않았다.
