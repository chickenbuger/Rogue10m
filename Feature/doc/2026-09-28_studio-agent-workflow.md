# 스튜디오 즉시 에이전트 작업 흐름

- 브랜치: Sprint#4-47-studio-agent-workflow
- 요청: 예정 등록을 출발점으로 에이전트가 일을 배분하고 진행 중 → 검증 대기 → 완료로 관리한다.
- 구현 상태: 즉시 실행기와 역할별 UI 구현, 통합/브라우저 검증 완료. 이 PC의 실제 무인 실행은 샌드박스 ACL 오류로 확인 필요 상태다. 정상 작업을 끝까지 완료한 실모델 검증은 수행하지 못했다.

## 동작

예약 heartbeat rogue10m은 PAUSED로 전환했다. 저장·재검토·재개·서버 시작 이벤트가 dispatcher를 깨운다. 미래 목표일도 즉시 실행 대상이며 선행 작업 완료 조건은 유지한다. 계획 역할이 구체적인 파일을 배정하고 독립적인 최대 두 구현 작업만 병렬 처리한다. 빌드 검증, 독립 리뷰, 결과 기록, 최종 리뷰가 차례로 이어진다.

실제 Codex CLI 프로세스가 각 역할을 수행한다. 설치된 최신 desktop CLI를 찾으며 모델과 로그인은 기존 설정을 사용한다. 역할별 샌드박스를 유지하고 approval_policy=never로 실행한다. 중단 시 소유한 자식 프로세스의 종료를 기다리고 파일 변경은 보존한다. 스튜디오 실행 잠금은 다른 채팅이나 에디터의 편집을 잠그지 않으므로 동시 파일 작업은 별도로 피해야 한다.

작업 기록에는 담당 역할·세션·요약·검증·산출물이 남는다. CLI 성공 종료만으로 완료하지 않으며 실제 성공 명령 근거, 독립 리뷰, 문서 및 프로젝트 내부 산출물 실재 여부를 확인한다. 실행 도중 저장된 다음 작업도 현재 작업 종료 후 처리한다. 같은 파일이나 선행 관계가 있는 구현은 직렬화한다. 실행 잠금이 남으면 탈취하지 않고 확인 필요로 표시한다.

## 검증 결과

- Node 자동 검증 19건: 병렬/직렬 배분, 검증 근거 누락, 독립 리뷰 실패, 실행 중 후속 등록, 자식 종료 대기, 기존 잠금 보존, 실행 소유권, 중단과 완료 경합, HTTP 즉시 트리거, 기존 데이터 및 보안 경계.
- Edge 실제 브라우저: 5개 화면, CRUD/백업/검색/문서, 상태 읽기 전용, 역할별 표시, 진행→검증→완료, 중단·재시도, 엔진 상태·연결 복구, 390px 모바일 및 글자 200% 확대.
- 실제 CLI 격리 smoke: input.txt 읽기 시 helper_unknown_error: apply deny-read ACLs 발생. planner blocked, 전체 paused, 구현/완료 미진입 확인. 근거는 evidence/studio-agent-workflow-20260928/real-agent-blocked-*.json.
- 설치된 예전 PATH CLI는 현재 모델과 호환되지 않아 desktop 최신 CLI 검색으로 해결했다. 샌드박스 오류에 대한 자동 승인 검토 전환은 자동 심사에서 거절되었고, 사용자가 명시적으로 오류 시 중지를 선택하여 적용하지 않았다.
- npm이 PATH에 없어 Node 직접 구문 검사와 test runner로 검증했다. 게임 코드·에셋 변경이 없어 UE 빌드는 수행하지 않았다.

초기 병렬 테스트는 두 구현의 시작 순서를 고정해 간헐 실패했다. 독립 구현 순서는 집합으로 비교하고 planner/build/review/write 순서는 계속 검사하도록 수정했다. 실패 뒤 엔진 표시가 준비로 덮이지 않도록 확인 필요 상태를 보존한다.

독립 검토에서 검증 명령 부분 일치가 단순 출력과 복합 명령도 성공 근거로 오인할 수 있음을 발견했다. 알려진 PowerShell wrapper만 해제한 명령 전체 일치로 수정하고, 후속 명령이 종료 코드를 가릴 수 있는 복합 명령은 완료 근거에서 제외했다. 해당 재현 회귀를 포함해 19건을 다시 통과했다.

## 사용 및 현재 제한

http://127.0.0.1:4317/#schedule 에서 작업 제목·메모·목표일을 등록한다. 정상 환경에서는 즉시 역할 배분이 시작된다. 이 PC에서는 현재 알려진 샌드박스 오류 때문에 자동 실행을 일시정지하고 엔진 확인 필요 이유를 표시한다. 환경 문제 해결 뒤 사용자가 재개·다시 검토할 수 있다. 완료한 기존 무기별 애니메이션 기획 기록은 보존했다.

원본 요청 범위 외 작업, 커밋·푸시·PR·배포·파괴적 삭제·외부 메시지는 수행하지 않는다. 실제 무인 성공 실행까지 검증한 것으로 표현하지 않는다.
