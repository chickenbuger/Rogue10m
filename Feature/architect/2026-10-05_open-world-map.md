# 완성된 오픈월드 탐험 지도

사용자가 제작된 OpenRunMap의 지도를 요청했다. `Sprint#5-13-open-world-map`에서 저장된 제작 좌표와 지형 높이 데이터를 사용해 한국어 지도 PNG를 만든다. 맵·에셋·C++·설정은 변경하지 않는다.

1. Architect: OpenWorldLayout·creation/reload·PCG 타일 기록을 읽고 독립 검토로 지역/보스/풍차 실제 좌표, 도로 정점, 유한 강과 다리, 별도 StartHub 연결을 확인한다.
2. Implementer: 실제 R16 지형을 음영과 등고선으로 표현하고 기록된 6지역·3길·3교량을 일정 축척에 투영한다. PCG 타일의 숲은 기호로 표현하며 개별 나무 위치라고 주장하지 않는다. 방위와 축척, 범례를 포함한 고해상도 PNG와 재현 스크립트·지도 좌표 JSON을 저장한다.
3. Builder/Reviewer: 좌표→픽셀 투영과 입력 데이터 일치·범위·PNG 크기·글꼴을 검사하고 완성 화면의 라벨 겹침과 실제 배치를 육안 확인한다. 관련 Python AST·diff 검사를 수행한다. 콘텐츠 변경이 없어 Unreal 재빌드/재실행은 생략한다.
4. Doc Writer: 결과·입력 근거·한계를 Feature/doc와 한국어 DevLog에 기록하고 SprintChangeLog를 갱신한다. 커밋·푸시하지 않는다.

완료 조건은 한국어 지역명·길·강·교량·입장·보스를 읽을 수 있고, 1800m 정사각형의 정확한 투영과 실제 방향을 보존한 지도다. 롤백 경계는 새 지도/좌표 기록·재현 스크립트·문서에 한정한다.
