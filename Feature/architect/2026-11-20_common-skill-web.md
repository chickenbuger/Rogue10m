# 공통 이동 스킬트리

K 창의 공통 탭에 승인 시안의 이동 능력 거미줄을 적용한다. 중앙 기초 단련을 무료 시작점으로 두고 공중 제어, 이동 속도 증가, 회피 후 회복 단축에서 세 방향으로 출발한다. 공중 속도 유지, 착지 안정, 회피 후 가속을 거쳐 다른 구역에 도달할 수 있다. 습득 노드와 연결된 능력마다 공용 성장 포인트 1P를 사용한다. 이단 점프 강화, 구르기 재사용 단축, 이동 속도 강화에는 해당 기본 능력도 필요하다. 기존 스킬 창, 성장 포인트, 무기별 이동 설정과 UI 렌더링을 활용한다. Fab 가이드에 따라 프로젝트의 기존 회피 경로와 로컬 애니메이션 후보를 먼저 조사한다. `AM_Dodge_Roll`은 이전 기록에서 이름과 달리 `MM_Dash`를 재생하므로, 실제 구르기와 호환하는 기존 모션이나 프로젝트 제작 동작을 사용하고 출처와 재생 상태를 남긴다. 신규 Fab 구매나 외부 팩 도입은 필요하지 않다.
