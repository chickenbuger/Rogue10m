# 외형별 구르기와 전방 달리기 착지 비교

인간·드워프·오크 남녀 여섯 외형은 같은 숨김 Manny 애니메이션 소스를 사용한다. 대검을 든 인간 남성은 전용 리타깃 그래프를 사용하며, 나머지 외형의 대검은 각자 기존 일반 리타깃 그래프를 사용한다. 현재 구르기와 전방 달리기 착지의 프레임 자료는 인간 남성 기준이다. 드워프 남성의 기준 허벅지·종아리 길이 합은 64.72cm, Manny는 85.56cm, 인간 남성은 90.30cm다. 외형별 지면 접촉을 같은 잣대로 해석하려면 각 외형에서 기존 애니메이션도 함께 실행해야 한다.

- 목표는 실제 선택된 외형이 같은 방향으로 구르고, 달리기 착지 중 바닥 근처에서 발이 미끄러지지 않으며, 기존 달리기 보폭으로 연결되는지 확인하는 것이다.
- 검증 옵션은 격리 프로필에만 적용하고 정상 캐릭터 선택을 통과한다. 인간 여성과 드워프 남성으로 먼저 검증한다. 회귀가 없으면 다른 외형을 같은 방법으로 비교한다.
- 구르기 검증은 기존 장착 및 Ctrl 경로에서 실행한다. 오른손 지지·해제·회복 진행률, 오른팔 아래팔 회전, 머리와 발볼의 바닥 여유, 검의 실제 경계 상자, 회복 그립을 기록한다. 두 본 사이 길이는 같은 외형의 기준 자세에 비해 얼마나 변하는지 확인한다.
- 전방 착지는 610 및 620cm/s, 정지와 우측 이동의 기존 분기를 사용한다. 숨김 Manny와 표시 외형을 같은 프레임에서 기록하고 해당 외형의 기존 `MM_Land`에 비해 발볼의 바닥 근처 수평 이동, 무릎 각도 차이, 두 번째 Jog 오른발 마커가 유지되는지 본다.
- 첫 검증은 `VerifyThirdPersonGameplay.ps1 -ForwardLanding -Appearance <외형> -NullRHI`와 `Rogue10m.TestHybridSkillTree`의 `-RogueHybridRollQA -RogueRollAuditDirection=Back -RogueMotionQAAppearance=<외형>`으로 한다. 착지 기존 상태에는 `-ExpectStockLanding`을 추가한다. 작업 롤백 범위는 테스트 옵션과 격리 실행 결과다.

기존 대검 후방 구르기에서 일반 리타깃 다섯 외형의 검이 진행률 14%에서 바닥을 통과했다. 드워프 남녀는 손을 짚는 구간에도 오른손바닥이 바닥 아래로 내려갔다. 첫 진입 시 매번 두 손을 기준으로 방향을 다시 계산하면 칼이 한 프레임에 최대 129.35° 바뀌었다. 바닥 여유만 맞춘 첫 후보는 회전이 174.59°까지 커져 제외했다.

구르기 시작 직전의 검 방향을 보존해 고정된 시작점에서 칼을 들어 옮긴다. 손잡이는 실제 오른손바닥에 연결한다. 캡슐 아래에 유효한 바닥이 있을 때만 필요한 칼 회전을 제한한다. 드워프의 기존 두 리타깃 그래프는 동일한 스켈레톤과 IKR을 보존하면서 두 본 역운동학을 사용하는 부모로 연결한다. 손바닥이 바닥 아래로 내려가는 활성 구르기에서만 오른팔을 보정한다. 낙하, 일반 이동, 다른 무기, 판정 및 공격 저지는 기존 경로를 따른다.

종료 전 여섯 외형, 드워프 단차 전환과 실제 장비 인벤토리·이동, 전방 달리기 착지를 확인한다. 기존과 고정 시작점의 칼 회전 및 끝점 이동을 같은 진행률에서 비교한다. 지면 경계 상자 수치는 실제 메시의 바닥 여유를 보수적으로 평가하는 데 사용한다.
