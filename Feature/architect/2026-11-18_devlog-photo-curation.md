# DevLog 대표 사진 정리

사용자 요청은 DevLog 사진 중 메인만 남기고 나머지를 삭제하는 것이다. 작업 범위는 DevLog 하위의 실제 이미지 파일이며 다른 폴더의 이미지·영상·로그·JSON·세이브는 포함하지 않는다. 최신 요청은 과거의 실패 사진 전체 보관 규칙보다 우선한다.

1. 전체 1,618장·2,083,312,275바이트를 조사하고 문서·최종 실행 결과와 후보 사진을 대조한다.
2. 콘택트 시트로 대표를 시각 확인한다. 최종 UI·게임 화면과 보스/대검/너클/지팡이의 최소 동작 기록 35장을 선별한다.
3. 나머지 1,583장은 SHA256과 DevLog 내부 절대 경로를 사전 확인한 뒤 파일 단위로 삭제한다. reparse/junction·폴더 재귀 삭제는 허용하지 않는다.
4. 남은 원본 해시·사진 수·기존 비사진 파일 존재를 확인하고 삭제된 Markdown 링크를 정리한다. 이전 수치/JSON/텍스트 실패 기록은 수정하지 않는다.
5. 대표 사진 목록·정리 manifest·한국어 일지와 Sprint 기록을 작성하고 현재 작업 브랜치에만 commit·push한다. main/develop/test 병합은 하지 않는다.

복구 경계는 사진 정리 커밋과 삭제 manifest다. 이미 Git 추적된 사진은 이전 커밋에 남지만 미추적 보조 사진은 사용자 지시에 따라 실제 삭제한다. 별도의 사진 사본을 만들어 삭제 효과를 되돌리지 않는다.
