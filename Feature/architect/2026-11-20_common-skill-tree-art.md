# 공통 스킬트리 시안 반영

공통 탭의 실제 화면을 승인 시안에 맞춘다. 검은 질감의 패널, 가장자리의 얇은 금속 장식, 금빛 활성 탭, 음영이 있는 메달리온과 연결선, 왼쪽의 선택 카드에 시안의 위계를 적용한다. 기존 16개 지점과 연결 21개를 사용한다. [승인 시안](../doc/evidence/common-skill-web-20261120/approved-concept.png) · [이전 실제 화면](../../DevLog/20261120_CommonSkillWeb/common-skill-web.png)

| 작업 단위 | 수정 위치 | 완료 조건 | 검증 | 되돌리는 범위 |
| --- | --- | --- | --- | --- |
| 메달리온과 프레임 | 아트 원본·UE UI 텍스처 | 공중·이동·회피의 아이콘이 서로 구분되고 승인 시안의 조명과 색을 따른다. | Unreal 임포트·경로·알파 확인 | 새 공통 UI 텍스처와 원본 |
| 공통 창과 그래프 | 기존 K 창 위젯 | 화면을 어둡게 정리하고 얇은 금속 장식, 입체 노드, 금색 경로와 선택 링을 적용한다. 실제 탭과 조작을 사용한다. | UE 빌드, StartHub 1080p·720p 화면 및 실제 클릭 | 공통 웹의 표시 코드 |
| 통합 검증 | StartHub·출력 로그 | 공통 선택, 아이덴티티 전환과 기존 무기 탭을 확인한다. | `Rogue10m.HybridSkillTree`, `Rogue10m.TestHybridSkillTree`, `Scripts/CheckUnrealOutputLog.py` | 기능 검증 자료 |

기존 Slate/UMG와 프로젝트 안에서 검증한 UI 텍스처 임포트 설정을 재사용한다. 기존 무공 배경과 스킬 아이콘은 스타일과 표현 대상이 달라 승인 시안의 메달리온·금속 질감을 참고해 공통 전용 아트를 제작한다. 텍스트와 상호작용은 실제 위젯에서 표시한다.
