# 오버워치풍 1인칭 전투 VFX 설계 보정

기존 설계의 실행 중 실제 권사 프로필이 10개 진행형 무공으로 확장된 것을 확인해 다음과 같이 범위를 보정한다.

- Packet 2 적용 대상은 핵심 ClassCombat 공격 50개와 실제 권사 진행 스킬 4개, 총 54개다.
- 권사 진행 스킬은 피해, 타격 수, 해금 조건을 보존하고 Montage와 Niagara presentation 필드만 연결한다.
- Packet 4는 일반 9종의 27회 연계·9회 차징과 권사 기본 권법 1회를 실행한다.
- 최종 완료 조건은 스타일 10종, 캡처 10장, 실패 0건이다.
- 활과 다른 권사 진행 데이터는 수정하지 않는다.
