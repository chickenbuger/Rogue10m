# 시작 마을과 오픈 월드로 맵 운영 통합

`StartHub`와 기존 `/Game/Rogue10m/Maps/OpenRunMap`을 게임의 두 레벨로 운영한다. 시작 화면과 캐릭터 선택은 `StartHub`의 메뉴 실행 모드에서 제공하고, 캐릭터 선택 완료 후 같은 레벨을 플레이 모드로 연다. 현재 오픈 월드의 스폰, 전투, 아자토르 승리와 마을 귀환을 기준으로 게임을 검증한다.

현재 추적되는 레벨 35개 중 33개가 정리 대상이다. 시연 레벨, 이전 전투 템플릿, 제작 후보 네 개와 별도 메뉴 레벨을 포함한다. 후보에 있던 최신 동굴과 지형은 복구 가능한 패키지 원본으로 보관한다. 현재 클리어가 검증된 오픈 월드에 후보 맵 전체를 덮어쓰면 스폰·내비게이션·보스 배치를 함께 바꾸게 되므로, 이후 배치는 기존 `OpenRunMap`에서 기능별로 적용한다.

## Ultrawork 작업 단위

| 작업 | 범위와 완료 조건 | 검증 및 복구 경계 |
| --- | --- | --- |
| 사용처 조사와 백업 | 레벨과 소유 외부 패키지 목록, 맵 전용 보조 데이터, 두 유지 레벨과 코드·설정의 참조를 확인한다. 작업 맵과 기존 사용자 변경의 원본을 보관한다. | 파일 SHA256과 Unreal Asset Registry 경로를 확인한다. 검증된 원본 또는 작업 시작 Git 체크포인트에서 복구한다. |
| 메뉴와 출발 경로 | 동일한 `StartHub`에서 시작 메뉴·캐릭터 선택을 제공한다. 기존 일반 오픈 월드 출발문은 유지하고, 폐기 맵으로 연결된 포탈과 표지를 Unreal Editor에서 정리한다. 패키징 목록도 두 레벨에 맞춘다. | 메뉴 모드 기본 실행, 선택 후 플레이 모드, 액터/포탈 확인과 격리 세이브 재생. `Config`, 대상 스크립트, `StartHub` 외부 패키지를 한정한다. |
| 맵과 전용 요소 정리 | 백업과 참조 대조를 통과한 맵·소유 외부 패키지·맵 전용 데이터만 활성 프로젝트에서 제거한다. 벤더 공용 에셋과 네이티브·설정 경로를 보호한다. | 실제 디스크와 새 Unreal 프로세스에서 레벨 두 개, 삭제 경로로 연결되는 활성 참조, 나머지 변경 범위를 점검한다. |
| 플레이와 배포 점검 | 정상 출발문, 보스 승리, 20분 타이머, 정산과 귀환을 확인한다. `OpenRunMap`을 이후 제작의 기준 맵으로 기록한다. | 격리 프로필로 기존 회귀 도구를 사용한다. 실패나 한계는 결과서에 기록한다. 검증을 마친 범위는 작업 브랜치에 게시한다. |
