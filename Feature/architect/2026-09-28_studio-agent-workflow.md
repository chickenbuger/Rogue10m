# 스튜디오 직접 에이전트 워크플로

작성: 2026-09-28 / Sprint#4-47-studio-agent-workflow

## 요청과 범위

예정에 작업을 등록하면 스튜디오가 직접 AI 에이전트를 실행·분배하고 진행 중 → 검증 대기 → 완료 순으로 관리한다. 이전5분 heartbeat는 중지한다. 실제 프로세스를 실행하지 않고 상태만 바꾸는 동작은 구현 완료로 인정하지 않는다.

## 역할 분배

기획1명이 범위를 쪼갠다. 수정 파일이 겹치지 않는 개발 패킷은 최대2명 병렬, 의존성이 있으면 직렬 실행한다. 빌드/QA 담당은 하나만 실행해 Unreal 출력 경합을 피한다. 독립 검토자가 요구사항과 결과를 확인하고, 통과 후 문서 담당이 기록한다. 공유 DevLog/Sprint/브랜치는 코디네이터만 소유한다. 실제 모델 선택은 사용자의 CLI 기본 설정을 유지한다.

## 실행 경계

프로젝트당 한 작업만 실행한다. 저장·재개·재검토가 즉시 실행 트리거이며 5분 스케줄이 아니다. 서로 다른 스튜디오 프로세스도 같은 파일 claim을 사용한다. 기존 작업·원문·결과를 보존하며 엔진이 재시작됐을 때 남은 active는 실행 중 프로세스를 확인하고 중복 실행하지 않는다. 승인/권한/인증 실패는 실제 이유를 기록하고 중단하며 sandbox를 우회하지 않는다. 커밋·푸시·외부 게시·파괴적 삭제를 자동 실행하지 않는다.

검증 통과가 없으면 완료로 이동하지 않는다. 실제 세션/단계별 결과를 기록하며 결과 JSON이 없거나 모델 출력이 잘못되면 실패다. 계획의 파일 범위·경로·개발 수·결과 크기를 검증한다. 새 Agent가 서버 자체를 수정하는 경우 실행 중인 프로세스와 저장 상태를 보존하고 재시작을 별도 인계한다.

## 근거

설치된 Codex CLI exec 도움말: JSONL, stdin prompt, output-schema, output-last-message, sandbox 옵션 지원. 로그인 상태는 ChatGPT 인증. 공식 비대화형 실행 문서: https://learn.chatgpt.com/docs/non-interactive-mode .
