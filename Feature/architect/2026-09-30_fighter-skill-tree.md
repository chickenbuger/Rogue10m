# 격투가 스킬트리, 테스트 해금, 키 설정

작업 브랜치: `Sprint#5-4-fighter-skill-tree`

## 요구와 현재 구조

기존 너클 프로필의 10무공(공격9·패시브1), 맨손 프로필의 기본 공격4, K 스킬트리 창과 수련/토벌 진행을 재사용한다. 기존 미커밋 애니메이션·카메라·Studio 변경을 보존한다. 다른 활성 로컬 작업과 Studio 실행은 없다.

맨손과 너클 모두 기본4와 기존10무공을 합친 격투가14노드 트리를 표시한다. 무기별 기본 입력과 명시 초기 해금 배열은 유지한다. 기존 무조건 기본 전수 규칙 때문에 공용 트리에서는 기본4와 연환권의5개가 최초 해금되며 나머지9개는 수련·토벌 조건을 따른다. 테스트 버튼은 현재 트리 전체를 세션에서 해금하며 수련/토벌 기록을 위조하지 않는다. Shipping에서는 테스트 해금을 제공하지 않는다.

스킬 상세에서 활성 공격을 키에 지정/해제한다. Enhanced Input의 별도 컨텍스트로 실제 전투 실행에 연결하며 키 설정을 로컬 SaveGame에 저장한다. 현재 트리의 중복 키와 이동·메뉴·소비품 등 기존 입력 충돌은 거부하고 이유를 표시한다. 패시브/잠긴/다른 무기 스킬은 실행할 수 없다. 창 열림·사망·일시정지 시 입력을 막는다. 차징 스킬은 키를 충분히 누른 뒤 놓아야 실행하며 점프 스킬은 공중 조건을 유지한다.

## 역할과 경계

전투 담당은 전투/입력/컨트롤러만, UI 담당은 기존 위젯 소스와 생성기만 수정한다. 통합 담당은 프로필 구성, 테스트, 실제 Editor 에셋 저장과 빌드·런타임, 공통 문서를 소유한다. 검토 단계에서는 담당을 바꾸어 독립적으로 읽는다. 바이너리는 Unreal Editor에서만 저장한다. 커밋·푸시는 하지 않는다.
