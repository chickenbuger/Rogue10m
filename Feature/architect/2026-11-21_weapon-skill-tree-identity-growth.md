# 무기 스킬트리 화면과 아이덴티티 성장

## 목표

사용자가 지정한 두 번째 공통 스킬트리 화면을 기준으로 너클과 검 화면의 패널, 탭, 금속 메달, 이름표, 연결선과 상세 정보를 통일한다. 너클은 하단의 기초 무공 네 개에서 시작하는 수련형 구조를 유지한다. 검은 중심에서 시작하는 거미줄과 투자 경로를 유지한다. 장착 무기 우선 탭과 마법 탭도 유지한다.

별도의 아이덴티티 화면과 공통 성장 포인트 구매를 제거한다. 내공, 투지, 마나는 레벨 2부터 레벨당 각각 1단계 성장한다. 해당 영약 1개를 사용하면 해당 능력만 1단계 추가 성장한다. 기존 저장의 획득 노드와 계열 선택을 보존하고 신규 런의 정산 및 저장 수명을 그대로 따른다.

## 시안과 에셋

- [기준 화면](../doc/evidence/weapon-skill-tree-identity-growth-20261121/common-reference.png)
- [ImageGen 무기 화면 시안](../doc/evidence/weapon-skill-tree-identity-growth-20261121/weapon-concept.png)
- 프로젝트의 기존 공통 Slate 화면, 숯색 질감, 금속 패널을 재사용한다. ImageGen으로 해당 화면과 같은 재질의 무기별 아이콘을 제작한다. 영약은 프로젝트의 기존 물약 아이콘을 재사용한다. 신규 Fab 팩을 반입할 필요가 없다.
- 실제 슬롯 위치와 연결은 기존 런타임 데이터를 사용한다. 시안은 조명, 재질, 계층 및 배치 원칙의 참고로 사용한다.
