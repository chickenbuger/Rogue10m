# 대검 장비 교체 자세 점검

실제 종족·성별 프로필을 만들고 StartHub에서 기존 대검 아이템을 인벤토리로 장착하고 해제한다. 대검의 표시 메시와 애니메이션 클래스가 바뀌는 시점의 양손, 어깨, 팔꿈치, 골반과 발을 60Hz에서 기록한다. 숨은 Manny 소스와 표시 메시를 같은 프레임에 읽어 공통 대검 가드와 종족 리타깃의 차이를 찾는다.

첫 프레임에 본이 갱신되지 않으면 해당 프레임을 별도로 표시한다. 자세 급변이 실제 게임에서 재현될 경우 동일한 준비 입력과 표시 메시에서 보정 전후를 비교한다. 복구 범위는 독립된 검증 모드 및 확인된 전환에 한정한다.

측정한 여섯 프로필 모두 공통 Manny의 대검 가드가 해제 첫 프레임에 맨손 전투 자세로 교체됐다. 기존 가드를 먼저 내려 애니메이션 가중치를 줄인 뒤 다음 시퀀스를 선택한다. 인간 남성은 이와 별도로 같은 스켈레톤을 사용하는 두 리타깃 그래프가 서로 교체될 때도 팔이 튄다. 같은 메시에서 직전에 표시한 자세를 0.18초 동안 새 그래프의 평가 결과에 섞는다. 이동 속도가 증가하면 기존 다리 자세의 영향력을 줄인다.
