# 실제 장착하고 배운 공중 무공의 동작 점검

기준 커밋 678e22c5d56992b2c0473f57d66ae7e6a233516c. 기본 전투 검사 14건에 없는 너클 태산압정 F.MountainSlam을 먼저 확인한다. 실제 시작 마을과 캐릭터 저장 슬롯에서 초급 너클을 장착하고, 정상 숙련 스냅샷으로 자동 전수한 다음 실제 단축키에 연결한다. 공용 공중 제어와 이단 점프는 마을 안내 NPC에 접근해 실제 포인트로 배운다.

60Hz의 실제 컨트롤러 입력 경로에서 지상 사용 거절, Space 한 번 뒤 Q, Space 두 번 뒤 Q를 비교한다. 공중 스킬의 인가 프레임, 몽타주 구간·가중치, 낙하 속도·접지, Manny와 실제 외형의 관절, 일반 표적 피해를 기록한다. 피해를 얻지 못한 경우 사유와 측정한 범위를 적고 인가를 피해 적중으로 보지 않는다.

기존 배포 에셋과 동작 계약을 보존한다. 재현된 동작 문제만 별도로 설계·검증하며, 전수, 판정 시간 및 기존 점프 속도를 유지한다. 기본 검사는 그대로 둔다.
