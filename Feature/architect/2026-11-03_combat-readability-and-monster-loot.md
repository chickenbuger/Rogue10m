# 전투 가독성과 몬스터 전리품

사용자 요청: 보스 공격을 보고 회피할 시간을 확보하고, 초기 시야를 조금 정면으로 조정하며, 1인칭 크로스헤어와 테스트 전용 실제 공격 판정 표시를 제공한다. 몬스터 처치 전리품은 기존 인벤토리와 월드 픽업에 연결한다.

## 작업 단위와 완료 조건

1. 보스: 기존 라이브 DA와 공격 프로필을 읽어 기본 .308초/파동1.1초/원형1.4초를 확인했다. 원본 프로필을 보존한 파생 프로필에서 1.0/1.6/1.9초 후보와 비례 회복 시간을 검증한다. HP·공격력·범위·쿨다운·분노 배율을 보존한다. 기본 공격 경고를 새 프로젝트 소유 decal material로 추가한다. 실제 raw overlap과 좁은 단계 판정을 구분한다. 빌드, geometry automation, 18개 실제 입력 회피/정지 대조, 준비·해결·회복 화면이 완료 조건이다.
2. 시야/HUD: 일반 초기 pitch -20→-10도, weighted0도 유지. 초기화 이후 자유 시점은 보존한다. 로컬 1인칭 HUD 중앙에 크로스헤어를 그리고 메뉴·검사·사망에서 숨긴다. 두 모드/두 해상도의 독립 QA와 실제 PNG 중심 판독을 수행한다.
3. 테스트 표시: 기본 OFF. 실제 공격 object overlap 파라미터와 실제 성공 대상을 기록한다. 테스트 몬스터의 query 활성 단순 collider와 skeletal body shape를 표시하고 미지원 shape는 명시한다. 후보 영역과 실제 최종 피격을 구분하며 OFF/대상 삭제/종료에서 소유한 표시를 정리한다. 일반 플레이에 기존 skill debug가 새지 않는지 확인한다.
4. 전리품: 데이터 표와 사망 1회 guard, authority/Standalone/test/terminal 문맥 제한. 기존 DroppedItem의 원자적 pickup과 inventory 저장 연결을 사용한다. 실제 월드 Slime에만 체력 물약25%×1 임시 예시를 연결한다. 수치·GUID·중복·공간 부족·재시도·실제 저장 재로드를 검증한다. 미획득 월드 actor 저장은 기존 v5 중단 런 포기 정책을 유지한다.

## 보존 및 롤백

Sprint#9-26의 실제 다음 판 검증 체크포인트에서 시작한다. 기존 사용자 저장364개와 Nov1 문서 WIP를 보존한다. 에셋은 UE Python으로만 변경하고 vendor/original profile을 수정하지 않는다. 코드와 에셋 변경을 명시적 목록으로 검토·커밋하며 main 병합은 수행하지 않는다. 기능별 native 소스 및 라이브 DA의 원본 연결로 롤백할 수 있다. Fab 골렘은 무료 기간 종료 후 유료이며 취득하지 않는다. 현재 Fab 로그아웃으로 보유 권한 확인은 미완료다.

## 실제 화면 검토 후 추가 범위

BossRenderC의 실제 18개 회피 시험은 통과했지만, 정면 시야에서 가까운 기본 공격 바닥 경고가 화면 아래로 가려졌다. 기존 HP바가 실제 확인한 보스가 로컬 플레이어를 대상으로 Windup 중일 때만 패턴명·실제 남은 시간·진행 바를 표시한다. 같은 Windup 동안만 확인된 대상을 유지하며 다른 대상 선택·공격 종료·죽음·메뉴·검사 화면에서는 기존 타깃 규칙과 가시성 규칙을 따른다. 새 actor 검색이나 Tick을 추가하지 않고, 기존 크로스헤어 위치를 보존한다. 구현 후 실제 준비·해결·회복 화면과 메뉴·검사 숨김을 확인한다.

SpatialRenderB의 일시 정지 변환 시험은 비동기 스켈레탈 포즈가 비교 중 갱신되는 문제를 드러냈다. 소유한 시험 몬스터만 공개 API로 포즈를 동기화·정지하고, 같은 실제 physics scene 도형을 이동 전후에 비교한다. 제품 판정이나 허용 오차를 바꾸지 않는다.
