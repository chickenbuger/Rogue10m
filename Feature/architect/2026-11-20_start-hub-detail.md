# StartHub 환경 미술과 동선 마감

2026-11-20 · Sprint#14-5-start-hub-detail

기존 60×60m `/Game/Rogue10m/Maps/StartHub`에서 사용자와 만든 상세 조감도를 실제 레벨로 옮긴다. 남쪽 등장, 아린, 지붕 우물과 양쪽 우회로, 북쪽 출발 포탈이 기본 카메라 높이에서 읽혀야 한다. 기존 주택과 길, 포탈과 저장·출발 흐름은 배치의 기준으로 사용한다.

## 자산과 구현

기존 `/Game/Stylized_Village`의 지붕·목재·석재·천막·등불·가구·수목과 프로젝트 소유 시작 마을 재질을 우선 사용한다. 기존 현황은 10/19 Fab 보유 가이드와 실제 로컬 패키지를 함께 대조하고 반입 없이 사용한다. 장비 진열에 로컬 초급 무기 메시를 쓰되 소품 세팅은 실제 지급과 분리한다. 수련장은 허수아비와 공간을 나타내며 진행 상태 조작 없이 아린에 연결된 기존 준비 서비스를 사용한다.

웅장한 아치보다 기존 출발 포탈의 가시성을 유지한다. 그림 속 비례와 기존 맵의 빈 공간이 다르는 곳은 42cm 반경의 플레이어 경로와 아린 상호작용 영역을 우선한다. 배치는 소품별 의도가 정해진 정적 레벨 액터로 저작하고, 일반 장식 충돌은 시선·보행을 방해하지 않도록 필요한 지지물에만 부여한다. 4개 경계 차단과 마을 바닥은 현재 계약을 유지한다.

수련장은 주택 출입구를 피해서 원정 접수소 뒤에 둔다. 기존 등주 남쪽으로 진입하는 디딤돌을 놓고, 다섯 준비·대기 구역의 보이는 돌바닥을 실제 보행면으로 쓴다.
