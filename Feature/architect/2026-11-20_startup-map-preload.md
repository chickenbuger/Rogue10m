# 시작맵과 오픈 월드 사전 로딩

기본 실행은 StartHub를 메뉴 게임 모드로 연다. 캐릭터 선택 뒤 같은 패키지를 게임 플레이 모드로 다시 여는 동작은 월드 재생성, 프로필 적용, 대기 상태 진입에 필요하다. 시작 화면이 로드되면 OpenRunMap의 다음 이동에 필요한 맵 패키지를 낮은 우선순위로 읽는다. 필드에 들어간 뒤에는 복귀할 StartHub를 준비한다.

| 작업 | 변경 범위 | 완료 조건 | 검증 | 되돌리는 범위 |
| --- | --- | --- | --- | --- |
| 사전 로딩 | GameInstance 서브시스템 | 로컬 게임의 알려진 두 맵에서 다음 맵 하나를 비동기로 읽는다. 활성화한 월드와 취소한 요청의 참조를 정리한다. | UE 5.8 Editor 빌드와 실행 로그 | 서브시스템 제거 |
| 이동 및 저장 회귀 | 시작 화면, 필드 포털, 결과 복귀 | 시작 화면의 실제 맵을 확인한다. 기존 경로가 준비된 맵을 재사용하고 프로필, 저장, 탐험 시작·종료 조건을 보존한다. | `VerifyLegacyPortalTravel.ps1`, `ValidateRunCompletion.ps1`, Unreal 출력 로그 검사 | 검증 자료와 기능 기록 |

맵 패키지는 초기화 전의 월드 참조로 보관한다. Unreal의 기존 레벨 이동에서 초기화와 World Partition 셀 스트리밍을 담당한다. 준비 여부가 이동 요청을 막지 않는다. 현재 월드와 같은 패키지로 다시 이동하는 경우에는 엔진의 기존 월드 교체를 사용한다. 패키지 재사용 전후의 이동 시간을 로그에서 별도로 읽는다.
