# 무기별 6슬롯과 Ctrl 아이덴티티 설계 (2026-11-10)

## 사용자 확정
- 무기 미장착은 뉴비이며 좌클릭 주먹 기본공격만 사용한다. 무기 장착이 직업을 결정한다.
- 초반 기초 무기 모두 지급 예정. 지급 시점은 미정이므로 이번 구현에서 임의 신규 지급하지 않는다.
- 무기당 10개 스킬 후보, 최대 6개 장착. Q/E/R/우클릭은 공용4, 좌+우 동시와 우클릭 차징은 각 전용1이다. 전용 스킬은 공용에 넣을 수 없다.
- Ctrl 아이덴티티는 6슬롯과 별도. Shift 달리기, Space 점프, 좌클릭 기본공격, F 상호작용.
- 너클 Ctrl은 일정 시간 공속/이속 증가, 스킬 강화와 소폭 공격력 증가, Post Process 및 주변 오라를 동반한다.
- 마법사는 Ctrl로 주문 입력 상태, Q/E/R 조합 가중치로 마나/공격력/속성을 결정한다. 마나 초과 및 잘못된 마법은 유사 페널티, 이번 판까지만 지속. 다음 판 기본 능력치 손실 금지.

## 구현 packet
1. 데이터: 기존 enum 숫자값 보존, Q/E/R/동시클릭 슬롯을 뒤에 추가. Common/ChordOnly/ChargeOnly/BasicOnly 허용 정책을 DataAsset에 노출한다.
2. 검증: 일반4/전용2 외 장착 금지, 같은 스킬 중복 금지, 현재 무기/해금/패시브 검사. Primary는 프로필 고정 기본공격이며 스킬 장착 수에 포함하지 않는다.
3. 저장: 무기별 durable 장착 프리셋. 무기전환/재접속에 복원하고 미해금 테스트 기술은 저장하지 않는다. 구버전 active bindings는 보존 가능한 슬롯만 이관한다.
4. 입력: Character 담당 작업자가 80ms 동시 판별, 탭/차징 단일 실행, 메뉴/사망/무기교체 취소를 소유한다. 80ms는 조작감 확인용 제안값이다.
5. UI: 실제 BottomHUD를 6슬롯에 연결. 드래그 장착은 서버 로직과 동일한 정책 검사. 기존 자유 단축키는 Q/E/R 장착 UI로 제한해 6개 제한 우회 방지.
6. 아이덴티티: 별도 기간제 컴포넌트. 영구 속성 기본값/저장 수정 없이 일시 배율, 종료/무기교체/사망/런 종료 정리. 너클만 우선 실험 구현하며 대검/미래 직업은 기획 상태를 구분한다.

## 제안값 (확정 밸런스 아님)
너클 지속8초, 재사용30초, 공속1.25배, 이속1.20배, 피해1.08배, 스킬 범위1.10배. 중첩/지속 연장 없음. 오라는 기존 보유 Niagara 후보를 재사용하고 확인된 경로만 지정한다. 예산/자원 요구는 아직 미정이다.

## 검증/rollback
Editor 빌드, 순수 슬롯 정책 automation, durable 프리셋 왕복/중복/무기차이/테스트 잠금, 실제 3인칭 탭/차징/동시 입력 확인. 새 기능 파일과 명시한 공용 파일의 개별 hunk만 rollback 가능. 다른 작업자의 카메라/무기/보스 변경 보존.
