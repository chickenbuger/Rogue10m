# 정산 UI 재화 표시
- 기준7891e1b2, Sprint#9-8-result-lobby-ui. 138개 세이브와 기존132개 증거 파일을 신규 백업/해시 확인.
- 로비 이번 획득량은 첫 RunId 영수증 적용의 실제 증가량(cap 후)을 transient로 기록. 새 저장 버전/레거시 초기화 없이 실패·중복 재시도에서 동일 금액 유지.
- 결과 위젯은 정산 컴포넌트가 소유권을 확인한 경제 요약만 읽고 재화를 지급하지 않음. 이번 획득/정산 후 로비 사용 가능/런 재화 잔액을 구분. 저장 실패는 저장 대기로 표시.
- 검증: 빌드, 기존24개, 격리 정상/실패/재시도/0/cap/프로필일치 UI 텍스트, 실제1280×720 캡처.
- 추가 사용자 답변: 포기 재화는 비용 지불 완료 후 오픈월드 직전 기준으로 복원, 보상 없음. 재화 이외 런 물품·성장/Discovery 정책 확인 대기. 독립 재화 모델·검증부터 진행하고 미확정 종속 동작은 보류.
- 금지: 원격 push/merge, 거절된Discovery초기화 재시도, 실제 사용자 슬롯 실행, 생산 맵 변경.

## 확정 후 최종 범위
사용자가 포기 시 런 물품·성장 초기화/Discovery유지에 동의했다. 별도포기상태와 비용후재화복원·무보상·저장실패gate·새허브중단복구를구현. 구v4프로그램오독방지를위해v5별도슬롯사용. 최신정책질문없음. 기존키보존을위해콘솔2회확인/API진입이며설정버튼은후속.
