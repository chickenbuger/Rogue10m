# 대시와 무기 아이덴티티 키 변경

`Sprint#17-1-combat-key-remap`에서 왼쪽 `Ctrl`을 기존 대시·회피 동작에, `V`를 무기 아이덴티티에 연결한다. 기존 `V`의 외형 확인 카메라는 비어 있는 `C`로 옮긴다. `Alt`에서는 대시를 발동하지 않는다.

| 작업 | 변경 범위 | 완료 기준 |
| --- | --- | --- |
| 입력 | 공통 키 정의, 캐릭터·플레이어 컨트롤러 바인딩, 입력 도움말 | 실제 `Ctrl` 대시, `V` 너클 아이덴티티, `C` 카메라 전환, `Alt` 비발동을 확인한다. |
| 표시 | A안 HUD에서 대시와 고유기 표기만 원본 프레임에 동적으로 그린다. | 원래 슬롯 위치와 기본 카메라 영역에 새 키가 보이고, 고유기를 발동할 수 있는 무기에서만 해당 배지가 나타난다. |
| 검증 | UE 5.8 빌드, 아틀라스 공식 임포트, StartHub 실제 입력 검증과 캡처 | 기존 게임플레이 동작·저장·카메라 모드를 유지하고 출력 로그를 확인한다. |

되돌릴 범위는 이 작업의 공통 키 정의, 표시·아틀라스, 도움말과 검증 코드다. 기존 Q/E/R 스킬 슬롯과 아이덴티티 발동 조건은 그대로 둔다.
