# 대검 구르기 오른팔 지지 해제 계획

## 범위

StartHub 기본 Human Male로 공용 구르기를 배운 상태에서 Ctrl, D+Ctrl, S+Ctrl을 비교한다. 세 입력에서 충돌 캡슐이 요청 방향으로 304.56cm 이동하고, 대검 전체 경계는 바닥 위 1.045cm를 유지한다. 세 방향 모두 구르기 46.7→51.4%에 오른팔뚝의 부모 상대 회전이 한 프레임 동안 153.26° 변하고, 골반 좌표계에서 오른손목이 26.02cm 움직였다. 56.0→60.7%에는 팔뚝 축이 106.45° 움직였다. 같은 변화가 Manny 원본 런타임, Blender 편집본과 재수입 FBX에서 확인됐다.

## 제작과 적용

프로젝트가 이미 사용하는 A_CommonShoulderRoll의 Blender 원본을 별도 사본에서 편집한다. 오른손 지지 구간과 지지 해제 뒤 회복 자세를 이어 주는 오른쪽 위팔·아래팔·손의 키만 조정한다. 기존 60Hz, 25구간, Manny SK_Mannequin, 애니메이션 길이, 제자리 루트를 유지한다. 외부 팩은 기존 참고 기록으로만 남기고 새 반입 없이 현재 프로젝트 파생본을 사용한다. Unreal Editor로 격리된 프로젝트의 기존 Sequence 패키지 한 개를 교체한다.

## 검증과 복구

같은 스킬 트리에서 C.EvadeRecovery, C.Roll, C.EvadeDistance, C.RollCooldown을 배운 뒤 세 방향을 60Hz로 실행한다. 실제 이동이 요청 방향과 일치하고 기존 경과 시간, 이동 거리, 배운 자세와 회피 중 공격 제한을 확인한다. 화면에 표시되는 본과 원본 Manny를 같은 진행도에서 비교하고, 팔뚝 회전, 골반 기준 손목 이동, 무릎 굽힘, 머리·손·발 높이와 대검 경계의 최소 지면 여유를 기록한다. 후방 구르기의 같은 관찰 카메라에서 준비, 지지 해제, 회복을 비교한다. Blender 원본과 저장된 UE 패키지는 각자 보관한다. 후보가 기준을 충족하지 못하면 기존 해당 Sequence 한 개를 기준 커밋으로 복구한다.
