# 3인칭 마우스 스킬 입력 중재

## 사용자 요구와 범위
- 좌클릭은 고정 기본 공격이다. Q/E/R/우클릭은 공용 슬롯, 좌+우 동시클릭과 우클릭 차징은 별도 전용 슬롯이다.
- Ctrl 고유 스킬은 별도이다. 향후 마법사 Ctrl 문자 명령 모드의 확정/취소 정책은 아직 미정이며 이번 마우스 중재가 Ctrl/QER를 가로채지 않는다.
- 뉴비 맨손은 좌클릭 주먹질만 허용한다. 등록 스킬/차징/동시클릭/Ctrl은 실행하지 않는다.

## Ultrawork Packets
1. 입력 컴포넌트: Character의 기존 LMB/RMB delegate를 전용 ActorComponent로 전달한다. 무기 변경·비용·쿨다운·해금은 Combat에 남긴다.
2. 동시클릭 중재: 전용 슬롯이 등록된 경우에만 LMB를 최대 80ms 보류한다. 빠른 단독 클릭은 release 때 즉시 확정한다. 좌→우/우→좌 모두 한 전용 스킬만 실행하고 두 release는 추가 공격을 만들지 않는다.
3. 우클릭 분기: press 시 전용 차징을 준비한다. ChargeSeconds 미만 release는 차징을 취소한 뒤 공용 우클릭 스킬을 실행하고, 이상이면 차징 스킬만 release한다.
4. 경계: 늦게 들어온 반대 버튼은 이미 확정된 기본 공격을 동시클릭으로 바꾸지 않는다. 메뉴/일시정지/죽음/빙의해제/스킬 변경은 보류 입력을 취소한다. 보류 중 무기 변경도 차단한다.
5. QA: 신규 저장 네임스페이스와 일시 스킬/프로필에서 Controller InputKey를 통해 각 경로의 실제 스킬 사용 횟수를 검사한다. 물리 마우스 입력과 구분한다.

## 미확정 가정
- 동시클릭 창 80ms는 사용자가 확정한 밸런스가 아니라 조절 가능한 검증용 가정이다.
- 차징 시간은 현재 Skill Data의 ChargeSeconds를 사용한다.
- 이번 검증용 스킬은 zero-cost/짧은 cooldown/no-montage 일시 객체이다. 실제 무기 연출/타격 판정 검증은 별도 무기 fixture가 담당한다.

## 롤백 경계
- 새 MouseCombatInputComponent와 Character 연결, Combat 취소/보류 상태 hook이 입력 변경 경계이다.
- 실제 Data Asset/맵/기존 저장을 변경하지 않는다.
