# 맵 1차 배포 계획

맵 제작 1차 범위를 닫고 `StartHub`와 `OpenRunMap`을 다음 작업의 기준으로 삼는다. 현재 GitHub의 맵 복구와 캐릭터 선택창·프로젝트 정리 커밋을 기존 배포 이력과 합친다. 오픈 월드의 지형과 동굴은 기존 `OpenRunMap` 패키지와 해당 World Partition 액터에서 이어서 제작한다.

| 작업 | 완료 조건 | 검증과 복구 경계 |
| --- | --- | --- |
| 커밋과 작업 폴더 대조 | 배포 브랜치의 기능과 두 작업 브랜치의 완료 커밋을 통합한다. | 최신 원격과 분기 이력을 확인한다. 기존 체크아웃의 미커밋 파일은 두고 독립 물리 폴더에서 통합한다. |
| 최신 에디터 빌드와 주요 경로 | 두 레벨과 캐릭터 선택, 마을 포탈, 동굴 카메라, 승리 정산 경로를 확인한다. | UE 5.8 Editor 빌드와 격리된 QA 저장을 사용한다. 이전 연속 플레이의 보스 결과와 통합 자동 검증 결과를 각각 기록한다. |
| 배포 및 작업 전환 | 검증한 커밋을 `develop`, `test`, `main` 순서로 반영한다. | 단계마다 원격 커밋을 확인한다. 검증 실패 시 작업 브랜치에서 원인을 해결하고, 보호 중인 체크아웃에는 변경을 가하지 않는다. |
