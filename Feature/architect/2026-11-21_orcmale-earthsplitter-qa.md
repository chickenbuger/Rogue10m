# 오크 남성 대지파쇄 표시 자세 검증

공식 기준은 `9cd829f3`이다. 드워프의 기존 대지파쇄 표시 보정과 같은 차징 시계, 스켈레탈 메시, 검 경계와 양손 IK를 써 오크 남성의 실행을 검증한다. 드워프 05 검증본의 소스 다섯 개를 물리적으로 분리한 작업 사본에 먼저 적용했다. 사람이 함께 쓰는 기본 대검, 0.72초 차징 조건, 기존 피해 시점·범위·입력·캡슐과 원본 오크 자산을 유지한다.

엔진의 오크 남성 리타깃 블루프린트를 검사용으로 하나 복제한다. 같은 스켈레톤과 IKR 및 기존 그래프를 유지하면서 복제 클래스만 검증용 팔 보정을 켠다. 복제 클래스는 기존 네이티브 구르기 지원을 끈다. 이미 네이티브 부모를 사용하는 드워프와 인간 남성의 구르기 옵션 기본값은 유지한다. 임시 QA 스위치를 지정한 StartHub 검사 캐릭터에서 실제 대검 장착 후 복제 클래스를 적용한다.

실제 60Hz 프로그램 우클릭, 늦은 D와 벽 회피, 후방·왼쪽 구르기 기록을 비교한다. 우선 보정 없이 기본 클래스와 복제 클래스를 비교한 후, 보정을 켠 발동과 검날 바닥 여유, 팔·손과 검 손잡이 연결, 회복을 재확인한다. 수치가 통과하면 720p에서 준비, 내려베기, 회복을 확인한다. QA 스위치를 빼면 기존 리타깃으로 즉시 되돌아간다. 검사용 복제본을 기존 외형에 연결하는 변경은 수치와 화면 검증 이후 판단한다.
