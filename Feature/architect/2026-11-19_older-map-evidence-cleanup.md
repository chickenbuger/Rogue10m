# 이전 맵 검증 자료와 복구 사본 정리

`Feature` 아래에 남은 이전 맵 자료를 조사한다. 지금 제작 중인 맵, 복구에 필요한 고유 상태, 검증 결론과 중요한 실패는 보관한다.

## Ultrawork 작업 단위

| 작업 | 범위와 완료 조건 | 검증과 복구 경계 |
| --- | --- | --- |
| 이전 맵 사본 조사 | `Feature/doc/evidence`와 `Feature/implementation`의 이전 맵 자료에서 보관본으로 재현 가능한 사본과 최종 보고서로 대체된 중간 성공 출력만 찾는다. 스크립트 입력, 운영 중인 기록, 고유 실패, 최신 맵 복구 자료의 참조를 확인한다. | Git 추적·무시 상태와 문서·스크립트 참조를 대조한다. 사본은 경로와 SHA-256, 출력은 남은 최종 기록과 체크 결과 일치를 확인한다. |
| 로컬 정리와 검증 | 검토한 미추적 파일만 한정해 삭제하고 위치·보관본·근거를 기록한다. | 실제 경로와 SHA-256을 삭제 직전에 재확인하고 보관본의 해시·삭제 경로의 부재·Git 상태를 재검증한다. 동일 사본은 manifest의 보관본에 의해 복구할 수 있다. |
