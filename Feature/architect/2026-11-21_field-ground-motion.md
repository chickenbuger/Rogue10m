# OpenRunMap 경사 이동 애니메이션 점검

평지에서 검증한 달리기 착지가 실제 OpenRunMap의 Q 동굴 접근로, 내리막과 오르막에서도 자연스럽게 이어지는지 확인한다. 동굴 지형과 캐릭터 이동 설정은 실제 게임 상태를 사용한다. 새 게임 저장 경로에서 테스트 캐릭터를 선택하고, 기존 카메라 검증 좌표를 이용해 검증 구간에 진입한다.

| 작업 | 완료 조건 | 검증 및 되돌리기 범위 |
| --- | --- | --- |
| 현장 계측 | 키 입력으로 달리기와 1단 점프를 재생하고, 실제 충돌면과 Manny 및 표시 메시의 접촉 포즈를 기록 | 독립 OpenRunMap 실행과 착지 프레임별 CSV. 계측은 에디터 빌드의 QA 명령으로 제한 |
| 확인된 문제 수정 | 이상 구간이 재현되면 원인을 기존 애니메이션 전환 또는 클립에서 찾아 보정 | 같은 구간에서 수정 전후 비교. 평지 착지, 지상 이동과 입력 검증 재실행. 클립을 바꾸는 경우 기존 원본을 Blender에서 보정하고 파생 에셋으로 적용 |

기존 `A_CommonForwardRunLanding_L` 달리기 착지와 현재 Manny 및 HumanMale 리타기팅 경로를 평가한다. 현재 동작으로 검증할 수 있어 신규 Fab 또는 Mixamo 클립은 필요 시에만 고려한다. 캐릭터 이동 속도, 점프 규칙, 월드 배치와 캐릭터 저장 형식은 검증의 기존 기준으로 사용한다.

평지 접근로와 오르막에서 접지 14~15프레임 뒤 표시 외형의 오른 발목과 종아리가 갑자기 다른 각도로 바뀌었다. Blender 원본 16~17프레임의 오른발 위치에도 급변이 있었다. 왼발의 지지 위치, 오른발의 Jog 인계 키와 기존 시퀀스 마커를 기준으로 두고, 공중에서 앞으로 나오는 오른쪽 다리만 편집한다.
