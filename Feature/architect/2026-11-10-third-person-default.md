# 3인칭 기본 플레이 전환

## Scope Gate
- 사용자는 캐릭터를 3인칭으로 전환하고 1인칭 기능 개발을 잠시 멈추도록 요청했다.
- 기존 1인칭 소스와 설정은 삭제하지 않는다. 맵 동선과 저장된 레벨은 변경하지 않는다.
- 작업 브랜치: Sprint#9-29-humanoid-boss-npc. 보스·무기 작업과 공유 파일 및 빌드를 조율한다.

## Ultrawork Packets
1. 카메라: 캡슐 부착 320cm 스프링 암, 어깨 오프셋, 마우스 직접 회전, ECC_Camera 구체 충돌. 완료 조건은 기본 3인칭·벽 수축/복귀·유한 POV이다.
2. 표현: 전신과 외형 부품 표시, 1인칭 팔/머리 숨김 정책 중단, 원본 1인칭 코드는 비활성 게이트로 보존. 완료 조건은 전신·머리·장비 표시이다.
3. 전투: 실제 몸 위치에서 공격 범위를 유지하고 화면 중앙 조준점으로 방향을 수렴시킨다. 카메라 뒤쪽에서 근접 공격/투사체가 시작되지 않는다.
4. 검증: 새 opt-in 런타임 검증에서 실제 카메라 캐시, 일시 충돌체, 이동/회피 입력, 메뉴 복귀를 검사하고 렌더링 스크린샷을 남긴다.

## 검증과 롤백
- 빌드: Scripts/BuildEditor.ps1 (공유 빌드 담당자가 실행).
- QA는 별도 신규 저장 네임스페이스에서 수행하고 기존 사용자 저장을 사용하지 않는다.
- 1인칭 QA를 재개하지 않는다. 물리 입력·장시간 수동 전투·전체 런 완료는 별도 미검증으로 구분한다.
- 카메라·표현·전투 변경과 신규 테스트가 롤백 경계이다. 맵/외부 에셋/원본 애니메이션을 수정하지 않는다.
