# 기본맵 기반 시작 마을 제작

## 목표와 범위

`Sprint#5-10-start-village`에서 기존 `/Game/FirstPerson/Lvl_FirstPerson`을 Unreal Editor API로 복제하여 `/Game/Rogue10m/Maps/StartHub`를 제작한다. 보유 `Stylized_Village` 팩을 사용하고 기본 플레이맵·구매 원본·기존 미커밋 전투 작업은 보존한다. 목표 구역은 120m × 120m이며 중앙 광장, 주택, 아이템·특성·난이도·스토리 준비 구역, 플레이어 시작점, 보이는 런 포탈을 구성한다.

현재 NPC는 역할 메타데이터만 있다. 이번 작업은 마을 공간과 안내용 준비 구역을 만들며 아이템 지급/영구 특성/난이도 저장의 새 시스템을 임의로 구현하지 않는다. 포탈 목적지는 실제 존재하는 기본 플레이맵으로 설정한다. 메뉴→마을에서는 타이머를 대기시키고 마을→포탈→기본 전투맵에서 20분 런을 시작한다.

## 조사 결과

- 기본 시작 설정 `L_Menu`는 UI 전용 맵이며 실제 게임플레이 기본맵은 `Lvl_FirstPerson`이다.
- `StartHub`와 `OpenRunMap`은 C++ 메타데이터에 정의되어 있으나 실제 에셋은 없다.
- `ModelContextProtocol`, `AllToolsets`, `EditorToolset`은 활성화되어 있다. 등록된 로컬 서버 포트는 8001이며 현재 에디터는 실행 중이지 않다.
- 메뉴 이동 함수가 `StartRun=1`을 붙인다. 허브 진입에서는 옵션 자체를 생략해야 한다.
- 기존 미커밋 작업을 보존하고 HEAD와 develop이 동일한 상태에서 새 Sprint 작업 브랜치를 만들었다. 커밋은 하지 않는다.

## 실행 및 보존 규칙

라이브 Unreal MCP 호출은 root가 직렬 실행한다. MCP가 이 대화의 네이티브 도구에 노출되지 않아도 공식 로컬 Streamable HTTP 서버에 JSON-RPC로 연결하고 동일한 list/describe/call 절차를 사용한다. HTTP 응답과 내부 success/error를 확인하며 모호한 mutation timeout은 재시도하지 않는다. 공식 MCP에는 임의 Python 실행 도구가 없으므로 조사·맵 로드·렌더 캡처는 MCP로 진행하고, 대량 배치와 실제 PIE 검증은 프로젝트의 기존 `RunEditorRemote.py`를 통한 Epic Python Remote Execution으로 수행한다. 작업을 직렬 실행하고 수정 범위를 신규 맵으로 제한한다. 바이너리는 에디터 API로만 생성·저장한다.

원본 맵·외부 액터 기준선을 저장한다. 기존 맵은 저장하지 않고 템플릿 복제 API로 새 맵을 만든다. 건물 배치·충돌·스폰을 확인한 뒤 저장하고 실제 렌더 화면과 게임 흐름을 검증한다. C++ 변경이 있으므로 관련 Editor 빌드를 수행한다.
