## 안전성과 완료 기준

- 등록된 worktree, 중첩 저장소, 엔진 생성/캐시, 도구·환경·원본/backup/baseline은 후보 탐색 입구에서 제외한다. 제외된 경로와 이유를 보고한다.
- 보존 경로의 스크립트도 외부 tmp 파일을 참조할 수 있다. 후보 제외를 모든 참조 검사 생략으로 오해하지 않는다. 프로젝트 Source/Scripts/Config와 tmp의 작업 스크립트 및 필요한 worktree 저작 스크립트만 확인하고, 보호된 설치 패키지 자체의 내부 파일은 열거하지 않는다.
- 문자 검색0은 삭제 증거가 아니다. 확정 후보의 basename·동적 경로·수동/glob 입력을 추가 검토하고 추적 파일·유일 원본을 보존한다.
- 전체 원본 녹화/소스 이미지, 최종 영상과2026-09-28 재생성 복구 계약을 유지한다. 신규 PNG 프레임 정리는 해당 재생성·최종 영상까지 확인할 수 있을 때만 별도 확정한다.
- `.uasset/.umap`, Content/Fab, Source/Config와 생성/캐시 경로를 수정하지 않는다. C++ 변경이 없어 Editor 전체 빌드가 아닌 감사·무결성·도구 회귀를 검증한다.
- 후보가 없다면 감사 결과를 완료로 기록하며 추가 삭제를 강제로 만들지 않는다. 실패가2회 반복되면 조사/검토로 돌아간다.
- 한국어 DevLog/Sprint와 paired 결과를 남기고 상시 승인된 정상 커밋·develop→test→main·푸시를 수행한다.
