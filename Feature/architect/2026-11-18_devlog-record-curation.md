# DevLog JSON 기록 정리

사용자는 불필요한 기록을 골라 삭제하도록 요청했다. 범위는 DevLog 하위 JSON326개·8,791,758바이트다. 게임 데이터·실제 세이브·로그·영상·대표 사진과 DevLog 밖의 검증 자료는 삭제하지 않는다.

1. 경로·해시·스키마·최종 판정을 조사하고 최종 결과, 중요한 실패, 에셋 출처를 선별한다.
2. 반복 세션과 전후 저장 목록, 카메라/RPC 인자·응답, 삭제한 사진의 캡처 목록, 중간 프리뷰와 정확한 중복은 정리한다. 요약으로 대체되지 않는 근거는 보존한다.
3. 삭제 목록의 절대 경로가 DevLog 안인지, 일반 JSON파일인지와 SHA256을 확인한 뒤 파일 단위로 삭제한다. reparse 경로와 폴더 재귀 삭제는 사용하지 않는다.
4. 보존 JSON의 원본 해시·파싱·문서 링크·비JSON 파일과 대표 사진의 보존을 검사한다. 과거 결과 값을 성공으로 바꾸거나 남긴 JSON을 다시 쓰지 않는다.
5. 정리 목록·주요 결과 목록·한국어 일지와 Sprint 기록을 남기고 작업 브랜치에만 commit·push한다. 다른 맵 변경과 main/develop/test는 포함하지 않는다.

현재 맵 작업이 일지와 Sprint 문서를 함께 수정 중이므로, 게시할 두 파일에는 이 작업의 추가 기록만 index에 선별한다. 실제 작업 파일의 다른 변경은 보존한다.
