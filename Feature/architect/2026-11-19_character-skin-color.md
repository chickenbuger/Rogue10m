# 캐릭터 생성 피부색 지정

캐릭터 생성 화면에서 피부색 견본을 고르거나 직접 지정한다. 얼굴·목·몸·1인칭 팔에는 같은 색을 전달하고, 캐릭터 목록과 게임 접속 후에도 저장된 색을 적용한다. 기존 외형의 피부 인덱스를 계속 읽는다.

| 작업 단위 | 변경 위치 | 완료 조건과 검증 | 복구 경계 |
| --- | --- | --- | --- |
| 생성 UI | 로비 위젯 | 견본, 색상·채도·명도, 6자리 HEX, 기본값 복구. 실제 게임에서 프리뷰와 입력 영역을 확인한다. | 생성 화면 런타임 위젯 코드 |
| 프로필과 재질 적용 | 외형 구조체, 카탈로그, 플레이어 외형 | 현재 프로필로 저장하고 목록·새 세션·시작 마을에서 재현한다. 구형 프로필을 읽는다. | 추가 필드와 공용 재질 적용 코드 |
| 피부 영역과 질감 | 현재 사용 중인 StylizedCharacter 6종 몸체·얼굴, OwnerArms, 오크 문신 | 기존 UV·법선·색조 디테일을 재사용하고 공통 피부색을 적용한다. 에디터에서 재질 파라미터와 원본 소스를 확인하고 실제 화면에서 경계를 본다. | 프로젝트 재질 및 해당 메시의 재질 슬롯 |

기존 프로젝트에 통합된 StylizedCharacter 텍스처와 메시를 사용한다. 새 Fab 상품을 가져오지 않는다. 원본을 백업한 뒤 에디터에서 지정한 자산만 저장하고 새 프로세스에서 이를 검증한다.

빌드는 `Scripts/BuildEditor.ps1`로 확인한다. 렌더와 프로필 흐름은 `Scripts/VerifyCharacterLobbyStyle.ps1`의 새 테스트 슬롯으로 실행한다. 실제 `-AbsLog`를 확인하고 검증에 사용한 기존 저장 파일은 변경 전후 해시를 대조한다.
