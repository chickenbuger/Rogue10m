# 개인 게임 개발 스튜디오 제거 계획

## 요청과 변경 경계

사용자가 개인 게임 개발 스튜디오를 더 이상 사용하지 않으므로 제거하라고 지시했다. 이 채팅의 성장·스킬·인벤토리 저장 예정 등록은 취소하며, 게임 기능 구현은 이 작업에 포함하지 않는다.

제거 대상은 `Studio/` 전체와 `OpenPersonalStudio.bat`, `Scripts/OpenPersonalStudio.ps1`, 스튜디오 전용 Codex heartbeat `rogue10m`이다. 현재 안내 문서 `Docs/UE58MCPSetup.md`의 개인 Studio 설명도 정리한다. 게임 Source·Config·Content와 Unreal/Blender 도구, 과거 Feature·DevLog·Sprint 기록은 보존한다.

다른 두 채팅이 같은 체크아웃에서 아자토르와 NPC·저장 기능을 직접 개발 중이며 스튜디오 제거를 인지했다. 앱 제거 유지보수는 공유 브랜치를 변경하지 않고 현재 브랜치에 한정한 삭제로 처리한다. 새로운 게임 기능 개발·빌드·에셋 수정은 수행하지 않는다. 공통 로그는 기존 내용을 읽고 한국어 기록을 추가한다.

## ULW 패킷

### R1 — 실행 중단, 백업과 앱 제거

- 목표: 스튜디오 서버와 전용 예약을 종료하고 프로젝트에서 앱과 실행기를 제거한다.
- 입력: 서버 PID, 실제 프로세스 명령행·포트 소유권, 실행 대기열 상태와 전용 자동화 설정.
- 수정 위치: `Studio/`, 루트 BAT, PowerShell 실행기, 전용 Codex 예약.
- 완료 조건: 실행 중인 스튜디오 작업 없음, 확인된 서버 종료, 전용 예약 삭제, 삭제 전 전체 앱·로컬 일정·실행 로그의 ZIP 백업 검증, 앱·실행기 경로 부재.
- 검증 명령: 실제 API 실행 상태 조회, `Get-CimInstance Win32_Process`, `Get-NetTCPConnection`, ZIP 항목별 SHA256 비교, `Test-Path`.
- 롤백 경계: Git 제외 `tmp/studio-removal-20261011/`에 원본 앱과 데이터·실행기 보존. 사용자의 새 지시 없이 복원·서버 재시작·예약 재생성하지 않는다.

### R2 — 안내·결과·개발 기록 정리

- 목표: 현재 사용 안내에서 Studio 설명을 제거하고 제거 결과와 검증을 남긴다.
- 수정 위치: `Docs/UE58MCPSetup.md`, 이번 Feature 계획·결과, `DevLog/20261011.txt`, `Docs/SprintChangeLog.md`, 오늘의 백로그 검토 결과에 제거 안내 추가.
- 완료 조건: 과거 기록 보존, 제거와 게임 기능 개발의 범위 구분, 실제 검증 결과와 로컬 백업 경로 기록.
- 검증 명령: 좁은 `rg` 참조 검사, `git diff --check`, `Scripts/CheckGeneratedChanges.ps1`, 독립 제거 리뷰.
- 롤백 경계: 이번 기록과 한 문장 안내 수정만 되돌릴 수 있으며 다른 채팅이 추가한 기록은 건드리지 않는다.

## 검증 기준

제거를 위해 UE 빌드는 필요하지 않다. 기존 미커밋 바이너리 변경은 이번 작업이 만든 변경으로 주장하지 않는다. 앱은 제거하되 과거 무기 애니메이션·전투 검증 문서를 지우지 않는다. 커밋·푸시·다른 채팅 메시지 전송은 하지 않는다.
