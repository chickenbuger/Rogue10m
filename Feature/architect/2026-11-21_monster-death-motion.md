# 필드 몬스터 사망 자세 전환

OpenRunMap에 실제 배치된 초록 점액체, 스포어링, 붉은 점액체, 철갑 등껍질, 가시수호자, 인간형 아자토르만 검수한다. 각 BP와 현재 기본 공격 프로필을 사용하는 격리 개체에 대기, 보행, 공격 준비 중 실제 치명 피해를 준다. 같은 60Hz 표본에서 사망 전후의 표시 본과 실제 클립 재생 시각을 비교한다.

기존 몬스터 팩의 사망 시퀀스와 아자토르용 프로젝트 몽타주를 재사용한다. 정지 상태에서도 생기는 본 급변을 재현한 경로에 한해 마지막 평가 포즈에서 기존 사망 클립으로 연결한다. 공격 중단과 추가 피해 차단, 이동·충돌 중단, 세션 보상 정책, 사망 애셋과 제거 일정을 검증한다. 기본 공격, 피격과 다른 움직임의 프로필 설정은 변경 범위에 넣지 않는다.

`VerifyHumanoidMonsterAI20261110.ps1 -MonsterDeathMotion -Label <새 라벨>`에서 60Hz 수치 자료와 실제 엔진 로그를 확인한다. 롤백 범위는 사망 표시 포즈 연결과 opt-in 검수다.
