# 드워프 대지파쇄의 양손 그립 검증

작업 전 두 드워프는 대지파쇄에서 기본 충전 공격 모션을 사용했다. 같은 Manny 후보의 첫 피해 표본이 표시 외형으로 넘어오면 양손 간격이 각각 80.08cm와 30.08cm가 된다. 두 체형의 실제 표시 어깨와 골격 길이를 기준으로 기존 Blender 궤적의 손목을 동시에 놓을 위치를 탐색했다. 두 팔에 최소 4cm의 신전 여유를 둔 양손 위치가 여섯 표본 모두에 있었다.

| 범위 | 완료 기준 | 복구 범위 |
| --- | --- | --- |
| 실제 표시 드워프 두 팔과 대지파쇄 구간 | 실제 우클릭에서 양손과 검 위치가 맞고 검 전체의 바닥 여유가 양수다. 피해 틱과 이동, 벽 전환, 기존 구르기를 검증한다. | 대지파쇄 표시 시계와 표시 드워프의 두 팔 처리 |

Manny에서 실제 차징 및 수락된 몽타주 시점과 가중치를 전달한다. 드워프의 기존 루트·골반·하체로 화면을 평가한 뒤, 검 손잡이의 방향·두 손 간격·중심을 함께 이어 각 손목을 구한다. 손잡이 중심은 길이를 유지한 두 팔이 모두 닿고 칼날이 바닥에 닿지 않는 위치로 옮긴다. 양손 위치와 바닥을 충족할 수 없는 표본은 기존 리타깃 자세를 쓴다. 검 장착은 본 갱신이 끝난 뒤 기존 양손 좌표를 읽는다.

양쪽 팔을 독립적으로 보간한 후보는 회복 구간에 기존 자세로 바뀌며 검축이 한 평가에 129° 이상 회전했다. 표시 외형의 매 프레임 어깨와 손을 입력으로 손잡이 각도·바닥·도달 반경을 함께 계산했다. 60Hz 표본 및 각 표본 사이 일곱 세부 시점에서 양손 도달과 바닥 여유를 검증했다. 실제 벽 검사는 칼의 삼각형과 실제 대비를 함께 확인한다.

드워프 남성은 벽 쪽으로 돌기 전의 방향을 고정해 비교해도, 새 자세를 풀던 검이 오른쪽 앞 위에 놓인 벽을 한 프레임 통과했다. 관측된 칼 메시의 이동 범위를 캡슐 바닥 기준으로 잡고, 같은 범위에 정적 장애물이 있으면 해당 홀드에 기본 자세를 적용한다. 실제로 장애물이 없는 정면 차징에는 양손 보정이 들어간다. 드워프 여성은 벽 쪽으로 돌 때 새 자세에서 기본 자세로 이어지는 범위를 확인했다.

기존 `Rogue10m.TestWeaponThirdPerson`의 `RogueGreatSwordEarthSplitterAudit`를 60Hz에서 DwarfMale과 DwarfFemale로 실행한다. 기본 동작, 적용 동작, 늦은 D 입력과 벽 방향 전환을 비교한다.
