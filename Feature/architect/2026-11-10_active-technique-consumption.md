# 활성 기술 카탈로그 소비 연결

상태: 격리 사본 제작. 공유 원본·에셋·에디터는 수정하지 않는다. 기준은 제작 중인 Sprint#9-29 워킹트리이며, 패치 사본 브랜치는 Sprint#9-30-catalog-consumer-patch다. 커밋·푸시는 수행하지 않는다.

## 범위와 패킷

1. 선택 정책: 기존 전체 성장트리와 해금/패시브를 유지하고 별도 선택 가능 목록을 제공한다. 명시 카탈로그는 검증된 전체 목록만 노출하고 오류 시 부분 공개/전체트리 우회를 막는다. 비명시 기존 프로필은 기존 선택 가능한 공격을 유지한다. Unarmed는 후보가 없고 Staff에 근접 10개 정책을 강제하지 않는다.
2. 소비: 장착·직접 실행·기본 장착·저장 복원과 UI 드래그/키 선택을 같은 정책에 연결한다. 무기 교체 중 이전 프리셋은 AppliedProfileWeaponType으로 보존한다. 목록에서 제외돼도 기존 해금·숙련·패시브 기록은 지우지 않는다.
3. 검증/전달: 실제 네이티브 Combat 컴포넌트와 임시 DataAsset을 사용하는 자동검사, 격리 Editor 빌드, 패치·기준 SHA256·적용 점검서를 준비한다. 새 모션/밸런스/실제20개 에셋 제작 및 시각 검수는 완료로 간주하지 않는다.

완료 조건: 명시 목록 외 공격이 장착·실행·저장 바인딩으로 유입되지 않고, 전체 성장과 기존 비명시 프로필·뉴비·마법사 예외가 보존된다. 명시 카탈로그의 실제 콘텐츠 연결은 모든 독립 기술이 준비된 후 에디터 담당자가 별도 수행한다.

검증: Scripts/BuildEditor.ps1 -ProjectRoot <격리 사본> -NoHotReload; Rogue10m.SkillLoadout.ActiveTechniqueCatalog 및 CatalogConsumption 자동검사. 바이너리/캐시 출력은 수동 편집하지 않는다.

롤백 경계: 전달 패치의 소스·테스트·독립 문서만 제거한다. 공유 프로젝트에 패치를 직접 적용하지 않는다. 원본 변경과 충돌하는 hunk는 담당자가 재조정한다.
