# 맵 제작 중 Git 작업 체크포인트

사용자 지시: 현재 변경을 정리해 commit·push하고 맵 제작 완료 후 main에 합친다. 기존 자동 승격보다 이 지시를 우선하며 현재 Sprint#9-32 작업 브랜치만 게시한다.

| 패킷 | 목표·영역 | 완료 조건·검증 | 복구 경계 |
| --- | --- | --- | --- |
| G1 | C++·Config·스크립트와 도구 | source dependency를 유지한 고정 목록, 구문·generated·diff 검사, 원격 작업브랜치 push | 코드 체크포인트 |
| G2 | 저장된 Content·무기 원본 | 에디터가 디스크에 기록한 파일만 고정·SHA 확인, binary 직접수정0 | saved asset 체크포인트 |
| G3 | 계획·결과·참조·개발일지 | 캐시·비QA 저장·원본백업 제외, 상태·미완료 명시 | 문서 체크포인트 |

현재 editor PID7684가 자연 경계를 제작 중이다. 에디터 재시작·추가 저장·빌드는 하지 않는다. 저장되지 않은 메모리 상태는 Git에 들어가지 않는다. 작업 중 파일이 달라지면 index 스냅샷과 남은 unstaged 차이를 구분한다. main/develop/test 원격을 전후 대조하고 변경하지 않는다.

이번 목적은 복구 가능한 WIP 게시이며 기능 완성·지형 인수·패키지 완주를 주장하지 않는다. raw 캡처·PDB·큰 백업·개인 저장·캐시는 로컬 보존한다. 독립 테스트는 이전 게시된 결과와 현재 구문검사를 구분한다.
