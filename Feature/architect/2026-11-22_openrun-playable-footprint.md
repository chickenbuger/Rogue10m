# OpenRunMap 플레이 영역 축소

요청 이미지의 자연 절벽을 기준으로 기존 `OpenRunMap`의 Landscape를 자른다. 현재 레벨과 플레이 영역 안의 도로, 마을, 동굴과 보스 구역은 원래 좌표를 사용한다.

| 작업 | 적용 범위 | 완료 조건과 복구 경계 |
| --- | --- | --- |
| Landscape 축소 | 16×16 중 기존 제작 후보와 일치하는 X 5–13, Y 10–14를 유지한다. 범위는 X −33,750–67,500, Y 22,500–78,750cm다. | Unreal의 Landscape Manage/Delete로 외곽 211개를 제거한다. 렌더 및 충돌 각 45개를 다시 로드하고 유지 구역을 검증한다. 원본 커밋 `c1de6097`로 복원할 수 있다. |
| 필드 진입 | 기존 StartHub 포탈을 통해 기획 지점 S로 도착한다. 기존 입구 검의 상대 배치를 옮기고 삭제할 지형에 기대던 레거시 교량, 강, 경계를 점검한다. | 시작 위치·검·중앙로·두 동굴·최종 보스 모두 유효한 지면에 놓이며, 자연 절벽을 넘으면 새 외곽에서 차단한다. |
| 검증 | 기존 맵 경로로 새 에디터 세션을 열고 절벽 안쪽 배치를 확인한다. | 실제 포탈 입장과 보스 처치 후 귀환 자동 검증의 결과를 기록한다. 두 동굴과 경계는 충돌 검사로 연결성을 확인한다. |

원본과 독립된 물리 작업 폴더에 같은 맵을 열어 결과를 검증한 뒤, 현재 브랜치의 정확한 패키지만 갱신한다. 기존 환경 에셋과 동굴 메시를 재사용한다.
