# 중앙 확장형 혼합 성장 스킬트리 설계 계획

- 날짜: 2026-10-18
- 작업 브랜치: `Sprint#5-33-hybrid-skill-tree-design`
- 단계: Pre-production / Architect. 이번 요청의 완료 범위는 설계 문서와 검토용 구조도다.
- 입력: 사용자 첨부 스킬트리 이미지와 중앙 → 아이덴티티·기본기 → 핵심 기술의 성장 요구.

## Scope Gate

중앙에서 바깥으로 성장하는 공용 트리, 기본기 경로의 스탯·기술 교대 배치, 격투가 숙련 해금, 레벨업 포인트로 접근하는 아이덴티티와 숙련 스탯의 간접 영향을 설계한다. 첨부 이미지는 공간 배치·계열 구분의 참고이며, 이미지 안의 숫자·문구는 구현 요구로 간주하지 않는다.

사용자 후속 확정: 격투가의 허용 아이덴티티는 내공·투지 두 계열이며, 마나는 타 직업용 공용 정의로만 유지한다. D5 이미지 시안에서 마나 가지를 제거하고 같은 혼합 성장 규칙을 유지한다. 이전3계열 구조도와v2 PNG는 변경 전 기록으로 보존한다.

이번 변경은 문서·로컬 작업 브랜치·검토용 HTML이다. C++, 설정, Unreal 바이너리, 생산 저장 데이터와 실제 UI는 변경하지 않는다. 기존 미커밋 작업을 유지하고 사용자 지시 없는 커밋·푸시는 수행하지 않는다.

## 기존 구조에서 확인한 사항

- 격투가의 기본기4와 연환권은 처음부터 해금된다. 맨손·너클이 공용14기술을 사용한다.
- 현재 기술 선행·수련/토벌 조건은 AND이며, 공격/패시브 외 중앙·스탯·아이덴티티 노드 정의가 없다.
- `GetWeaponMasteryLevel()`은 맨손·너클1/기타0의 임시 구현이다. 실제 숙련 XP와 숙련 스탯은 신규 설계다.
- 마을 특성은 이미 `레벨 - 1 - 실제 투자 비용`의 포인트를 사용한다. 신규 스킬 비용을 같은 원장에서 차감하도록 설계한다.
- 이미지의 근력·민첩·지능 등6속성은 현재 구현에 없다. 이번 안의 수치는 현재 공격력·HP·스태미나·방어·공속으로 표현한다.

## 역할 라우팅과 검증

Architect는 독립적인 기존 성장 코드 조사와 게임플레이 설계 검토를 받아 노드 규칙을 확정한다. Implementer는 문서와 대표 구조도만 작성한다. Builder는 문서 작업에 해당하는 경로·문법 검사를 수행하고 Editor 빌드는 생략한다. Reviewer는 포인트 중복 지출, 순환 성장, 초기 접근성, 무기별 중복 보너스, 저장 이전과 환급 의존성을 검토한다. Doc Writer는 설계 결과와 실제 구현이 필요한 후속 범위를 기록한다.

최종 산출물의 상세 규칙은 [혼합 성장 설계](../../Docs/HybridSkillTreeDesign.md), 완료 기록은 [설계 결과](../doc/2026-10-18_hybrid-skill-tree-design.md)를 따른다.

## Exit Gate

설계 문서에 사용자 요구·노드 예시·성장 예시·UI 배치·기존 기능 이전 경계를 모두 포함하고 독립 검토를 마치면 설계 작업을 완료한다. 실제 숙련 시스템, 공유 포인트 원장, 노드 Data Asset, 영구 저장과 원형 UMG 구현은 다음 Production 작업으로 명시한다.
