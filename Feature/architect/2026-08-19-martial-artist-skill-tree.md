# 권사 무협식 무공 수련 트리 설계

## 목표

- 권사(Knuckle) 무기 장착 시 무협식 `입문 → 초식 → 절기 → 심법` 4단계 무공 트리를 표시한다.
- 스킬 발동 횟수, 특정 몬스터 토벌 수, 선행 무공을 조합해 무공을 자동 해금한다.
- 해금 진행도는 `PlayerState`가 소유해 캐릭터가 다시 생성되어도 현재 플레이 세션에서 유지한다.
- 기존 스킬 Drag & Drop 장착 흐름과 무기별 활성 스킬트리 전환을 보존한다.

## Ultrawork Packets

### Packet 1 — 무공 데이터와 진행도

- 목표: 무공 단계, 노드 위치, 선행 무공, 수련/토벌 조건을 Data Asset에 정의한다.
- 수정 위치: `Rogue10mAttackSkillData`, `Rogue10mPlayerState`
- 완료 조건: 스킬 사용 횟수와 `MonsterId`별 토벌 횟수를 조회할 수 있다.
- 검증: Editor Target 빌드 및 권사 Data Asset 검증 스크립트
- 롤백 경계: C++ 데이터 스키마와 권사 Data Asset만 되돌릴 수 있다.

### Packet 2 — 자동 해금과 심법 효과

- 목표: 실제 기술 발동과 몬스터 사망에서 진행도를 기록하고 조건 충족 시 자동 해금한다.
- 수정 위치: `Rogue10mCombatComponent`, `Rogue10mBasicMonster`, `Rogue10mCharacter`
- 완료 조건: 조건은 AND로 판정되고, 연쇄 해금과 금강불괴 피해 감소가 동작한다.
- 검증: C++ 빌드, 런타임 자동화/검증 로그
- 롤백 경계: 진행도 기록과 판정 함수 단위로 분리한다.

### Packet 3 — 무협식 스킬트리 UI

- 목표: 흑철·황동·비취 기운 프레임, 4단계 노드, 연결선, 수련/토벌 상세 패널을 구성한다.
- 수정 위치: `Rogue10mMenuWindowWidgets`, `WBP_SkillTreeWindow`, `WBP_SkillTreeEntry`, UI Texture
- 완료 조건: 현재 무기에 맞는 트리가 표시되고 선택 노드의 조건별 진행도를 확인할 수 있다.
- 검증: Widget Blueprint 컴파일, 필수 BindWidget 검사, 렌더 이미지 확인
- 롤백 경계: Widget Blueprint와 권사 전용 배경 Texture를 별도 관리한다.

### Packet 4 — 콘텐츠·통합·문서

- 목표: 권사 무공 10개를 실제 자산에 구성하고 전체 흐름을 검증한다.
- 수정 위치: 권사 Attack Skill/Profile Data Asset, 검증 스크립트, Feature 문서, DevLog
- 완료 조건: 권사 프로필은 연환권만 최초 해금되며 최종 무공까지 조건 사슬이 유효하다.
- 검증: `BuildEditor.ps1`, Unreal 검증 스크립트, `CheckGeneratedChanges.ps1`
- 롤백 경계: 신규 권사 무공 자산과 구성 스크립트를 함께 되돌린다.

## 무공 구성

| 단계 | 무공 | 종류 | 핵심 해금 방식 |
| --- | --- | --- | --- |
| 입문 | 연환권 | 공격 | 최초 해금 |
| 초식 | 붕권 | 공격 | 연환권 수련 |
| 초식 | 파진각 | 공격 | 철갑사 토벌 |
| 초식 | 철산고 | 공격 | 연환권 수련 + 철갑대장 토벌 |
| 절기 | 유운수 | 공격 | 붕권 수련 |
| 절기 | 금강쇄 | 공격 | 파진각 계열 토벌 |
| 절기 | 백열난무 | 공격 | 철산고 수련 |
| 심법 | 금강불괴 | 상시 심법 | 두 갈래 선행 무공 + 중간 보스 토벌 |
| 심법 | 태산압정 | 공격 | 금강쇄 + 중간 보스 토벌 |
| 심법 | 무극패왕권 | 공격 | 세 갈래 완성 + 백열난무 수련 + 최종 보스 토벌 |

## 데이터 소유권과 흐름

```text
AttackSkillData (정적 조건/배치)
    ↓ 실제 발동                         MonsterData.MonsterId
CombatComponent ── RecordSkillUse ─┐          ↓ 사망
                                   ├─ PlayerState 진행도
BasicMonster ─ RecordMonsterDefeat ┘          ↓ 변경 알림
                                      CombatComponent 자동 해금
                                                ↓
                                   SkillTreeWindow 진행도/상세 표시
```

## 판정 규칙

- 한 무공의 선행 무공과 해금 조건은 모두 충족해야 한다.
- 기술 수련은 공격 입력이 아니라 쿨다운·자원 검사를 통과해 실제 실행된 시점에 1회 누적한다.
- 토벌은 서버 권한의 사망 처리에서 한 몬스터당 1회 누적한다.
- 조건 충족 후 자동 해금하며 한 번의 진행도 변경으로 여러 노드가 열릴 수 있어 고정점까지 반복 판정한다.
- 상시 심법은 입력 슬롯에 장착할 수 없다. 금강불괴 해금 시 받는 피해 감소를 적용한다.

## UI 구성

- 왼쪽: 권사 경지, 해금 수, 전체 진척도, 무공 분류 안내
- 중앙: 4단계 세로 경맥, 선행 관계 연결선, 원형/패형 무공 노드
- 오른쪽: 선택 무공 이름, 설명, 상태, 수련·토벌 조건별 현재/목표, 해금 효과
- 색상: 흑철 바탕, 낡은 황동 테두리, 활성 경맥과 완료 조건은 비취 녹색, 최종 절기는 주홍색 포인트

## 비범위

- 세션을 넘어서는 SaveGame 영구 저장
- 신규 애니메이션 원본 제작
- 신규 몬스터 종 추가

기존 권사/석권 애니메이션과 아이콘을 재사용하고, 신규 무공 프레임 Texture와 Data Asset 조합으로 범위를 제한한다.
