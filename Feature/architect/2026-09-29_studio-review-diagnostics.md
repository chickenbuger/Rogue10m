# 스튜디오 검토 중단 원인과 Git 조회 수정

목표: 기획 단계 Git 소유권 오류를 해결하고 검증 미실행과 실제 검증 실패를 구분한다.

수정 범위는 Studio/dispatcher.mjs, 관련 테스트, Studio/EXECUTION.md 및 결과 기록이다. 사용자가 지정한 프로젝트 루트에 한해 Git 명령별 safe.directory를 지정한다. 전역 설정과 샌드박스·승인 정책을 바꾸지 않는다. 루트 경로는 셸 인자 인용을 적용한다. 에이전트에는 저장소 상태를 읽는 명령과 기존 구현을 먼저 확인하는 지침을 전달한다.

에이전트 역할별 종료 시점을 기록해 기획/구현 중단은 검증 미실행, 빌드·리뷰 단계 중단은 해당 검증 미완료로 안내한다. 원인과 기존 실행 로그를 보존하고 완료 조건은 완화하지 않는다.

검증: 단위·통합 테스트, 실제 read-only 에이전트의 동일 저장소 Git status/branch 조회. 기존 맨손·너클 구현은 다른 작업의 결과로 보존하고 중복 제작하지 않도록 재검토한다. 변경 파일만 되돌릴 수 있도록 게임 소스와 에셋은 수정하지 않는다.
