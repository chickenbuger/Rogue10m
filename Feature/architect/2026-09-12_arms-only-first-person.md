- 선행 작업: 기본 Unarmed 좌우 연타·차징 어퍼컷·점프 및 자연스러운 손·상체·머리·카메라 연동

## Scope Gate

사용자는 사이버펑크 2077 고릴라 암즈와 현재 격투 모션을 비교하고, 마우스를 아래로 내릴 때 캐릭터 몸통과 하체가 보이지 않도록 팔만 표시하는 구현을 요청했다. 이번 범위는 1인칭 격투의 표시용 메시를 팔 전용으로 분리하고 기존 입력과 몸 기반 카메라 반응을 유지하는 것이다. 외부 게임의 애셋을 복제하거나 가져오지 않는다. 직접 본 레퍼런스 장면과 자체 개선 제안은 구분해서 기록한다.

기획 1·개발 2·검증 2 역할로 진행한다. 개발 1은 Editor를 통한 팔 전용 geometry 자산 준비, 개발 2는 런타임 표시·복원 연결을 맡는다. 기획 담당은 계획 후 독립 소스 검증 1로 전환하고, 검증 2는 실제 아래보기와 공격 연속 프레임을 확인한다. 통합 담당은 레퍼런스 접근, 빌드·런타임 검사와 결과 문서·DevLog·SprintChangeLog를 소유한다.

## 현재 상태와 원인

Character 생성자는 FirstPersonMesh에 OnlyOwnerSee를, 월드 GetMesh에는 OwnerNoSee를 설정한다. 로컬 시야의 전신 노출 원인은 기본적으로 1인칭 메시 자체의 geometry에 있다. 현재 FirstPersonPresentationComponent는 카메라 아래에 전체 Manny 메시를 붙인 후 neck_01, thigh_l, thigh_r만 숨긴다. 머리와 다리가 숨겨져도 골반과 몸통 geometry는 남는다. 실제 런타임에서 Blueprint 설정과 다른 컴포넌트가 이 규칙을 덮어쓰는지도 확인한다.

pelvis 또는 spine를 HideBoneByName으로 숨기는 방법은 팔까지 연결된 자식 본의 스케일을 함께 지우므로 사용하지 않는다. 메시를 멀리 밀거나 카메라 피치 범위를 제한해 하체를 가리는 방법은 팔 거리·공격 궤적·조준 경험을 바꾸므로 해결로 간주하지 않는다.

## 구현 방안

팔 geometry만 남긴 별도 SkeletalMesh를 Unreal Editor의 지원되는 자산 API로 만든다. 원본 Manny와 전체 reference skeleton, 본 이름·계층, 손가락, 머리·spine와 애니메이션 호환성을 보존한다. 머리와 몸통은 렌더 geometry가 없어도 포즈 평가에 남아야 기존 camera delta 및 상체 힘 전달을 유지할 수 있다. 제거 대상 geometry가 LOD 전환에서 다시 나타나지 않도록 모든 활성 LOD를 확인한다. 어깨 절단면은 기본·차징·타격·아래보기에서 노출되는지 실제로 확인하고 필요하면 자연스러운 팔 끝 처리를 자산 범위에서 보완한다.

런타임 컴포넌트는 팔 메시를 소프트 자산 참조로 노출하고, 적용 전 원본 SkeletalMesh·애니메이션·material override·visibility·attachment·카메라 설정 중 실제 변경되는 상태를 보존한다. 유지되어야 하는 UObject 참조는 UPROPERTY/TObjectPtr로 GC 추적한다. 적용 실패 시 반쯤 바뀐 상태를 남기지 않는다. 동일 무기로 반복 Refresh, Unarmed↔Knuckle, 다른 무기 전환, 종료에서 일관되게 복원한다. 메시 교체 시 원본 전신용 material override의 슬롯이 새로운 팔 자산의 섹션과 맞는지도 확인한다.

기존 손 IK와 실제 머리 기반 POV 코드는 원칙적으로 바꾸지 않는다. 새 자산의 본 구성이나 bounds 때문에 변경이 필요하면 구현 근거와 영향 범위를 기록한다. Tick이나 프레임별 asset load를 추가하지 않는다. 자산 제작은 Editor에서만 수행하며 원본 .uasset 바이너리 직접 편집을 하지 않는다.

## Ultrawork Packets

### P1 — 레퍼런스 비교와 시야 계약

- 목표: 고릴라 암즈와 현재 동작의 비교 기준, 팔만 표시하는 시야 계약 확정.
- 입력: 사용자 요청, 기존 자연스러운 격투 기획·실게임 자료, 실제 접근 가능한 고릴라 암즈 장면.
- 수정 위치: 이 설계 문서와 통합 담당의 비교 기록.
- 완료 조건: 준비·신전·충격·회수·카메라·팔 화면 점유를 구분해 비교하고 관찰하지 못한 내용은 미확인으로 표시.
- 검증: 지정 computer-use의 실제 영상 관찰 기록 및 현재 플레이 화면 확인.

### P2 — 팔 전용 geometry

- 목표: 전신 skeleton을 유지한 팔 전용 SkeletalMesh 확보.
- 수정 위치: Scripts/Editor의 전용 제작 스크립트, 별도 신규 팔 자산.
- 완료 조건: 좌우 팔과 손 geometry만 남고 활성 LOD에 몸통·머리·하체가 없으며 기존 애니메이션·머리 본 평가가 가능함.

- rollback 경계: 새 팔 자산과 제작 스크립트. 원본 Manny·몽타주는 유지.

### P3 — 표시 및 복원

- 목표: 로컬 격투 시야에 팔 자산 적용 및 기존 표시 상태 복원.

## Exit Gate

아래보기 정지 화면 하나만으로 완료를 판정하지 않는다. 수평·실제 최소 피치에서 가드와 차징, 좌우 연타, 어퍼컷과 점프를 연속 관찰해 몸통 노출·어깨 절단면·팔 소실·LOD 팝을 확인한다. 모델 자체의 본 보존 검사와 실제 camera motion 로그를 함께 대조한다. 기존 기본 직업과 너클 회귀, 메시·재질·본 숨김 복원, 빌드 및 변경 문서화를 완료한다. 외부 레퍼런스 접근 실패가 있으면 비교 완료로 표현하지 않는다. 커밋·푸시는 사용자 확인 없이 하지 않는다.
