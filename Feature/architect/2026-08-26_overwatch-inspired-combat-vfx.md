# 오버워치풍 1인칭 전투 VFX 리스타일 설계

## 목표

- 기존 10개 전투 스타일의 애니메이션과 판정은 유지한다.
- 오버워치 계열의 선명한 실루엣, 짧은 색상 신호, 단계가 분명한 타격 피드백을 Rogue10m 공격 파티클에 적용한다.
- 1인칭에서는 조준점과 적 실루엣을 우선하고, 3인칭에서는 직업 판독성을 유지한다.
- Cast, Charge, Impact가 애니메이션의 동작 크기와 공격 단계에 맞춰 서로 다른 강도로 보이게 한다.
- UE 5.8 Niagara Effect Type을 사용해 전투 효과의 성능 예산을 한곳에서 관리할 기반을 만든다.

## 참조 원칙

- Overwatch: 영웅별 색상과 효과 실루엣은 구분하되 전투 정보가 화려함보다 우선한다.
- Overwatch의 1인칭 제작 사례처럼 무기와 효과의 화면 점유가 실제 조작을 방해하지 않아야 한다.
- VALORANT: 조준점은 항상 깨끗하게 유지하고, 1인칭 효과는 기본 공격 형태와 크기를 넘지 않으며 짧게 끝낸다.
- Unreal Niagara: Effect Type을 공통 배정하고 시스템·Emitter 인스턴스 수와 오버드로우를 제한할 수 있게 한다.

## 시각 언어

| 계열 | 주 색상 역할 | 형태 | 시간감 |
| --- | --- | --- | --- |
| 단검·쌍단검 | 청록 | 가는 손목 섬광, 짧은 교차 잔광 | 매우 짧음 |
| 표창 | 밝은 청색 | 작은 점광과 직선 투사 신호 | 짧음 |
| 장검·쌍검 | 은청색 | 날카로운 검광, 얇은 충돌 섬광 | 보통 |
| 대검 | 주황·적색 | 무거운 핵과 넓지만 짧은 충격 | 느린 예고, 빠른 소멸 |
| 방패 | 황금색 | 단단한 원형 충격, 불꽃 파편 | 짧고 명확함 |
| 한손검·작은방패 | 청색+금색 | 검광과 작은 방패 충격의 혼합 | 보통 |
| 마법사 | 보라·청색 | 작은 마력 핵, 룬 계열 예고 | 차징만 길고 방출은 짧음 |
| 권사 | 황금색 | 손 중심의 작은 권압, 타격 핵 | 빠른 펄스 |

## 1인칭 예산

- Cast 실제 스케일: 최대 0.060
- Charge 실제 스케일: 최대 0.026
- Impact 실제 스케일: 최대 0.180
- Cast 실제 방출 시간: 최대 0.060초
- Impact 실제 방출 시간: 최대 0.070초
- 양손 보조 효과: 주손 대비 0.70배
- 효과 위치: 조준점 기준 좌우 14 이상, 아래 11 이상
- 1타 < 2타 < 3타 < 특수/차징 순으로 크기를 올리되 각 상한을 넘지 않는다.
- 화면 전체 왜곡, 장시간 점광원, 불투명 원판, 지속 연기는 사용하지 않는다.

## Ultrawork Packets

### Packet 1 — 데이터 계약과 런타임 예산

- 목표: 양손 보조 효과를 별도로 축소하고 공통 1인칭 예산을 Data Asset으로 조절한다.
- 수정 위치: `Rogue10mAttackSkillData`, `Rogue10mCombatComponent`
- 완료 조건: 1인칭 양손 효과가 주손보다 작고 기존 3인칭 출력은 유지된다.
- 검증: UE 5.8 Editor target 빌드, 런타임 효과 컴포넌트 수 확인
- 롤백 경계: 신규 배율 필드와 적용 계산

### Packet 2 — 오버워치풍 스타일 튜닝

- 목표: 10종 50개 공격 데이터의 단계별 크기·지속시간·속도·오프셋을 리스타일한다.
- 수정 위치: `Scripts/Editor/ApplyReadableClassCombatVFX.py`, ClassCombat Attack Skill Data Assets
- 완료 조건: 콤보 단계와 무기 무게에 따른 계층이 있고 1인칭 상한을 모두 지킨다.
- 검증: 전용 Validator 50개 데이터 검사
- 롤백 경계: 신규 튜닝 스크립트와 해당 Data Asset 속성

### Packet 3 — Niagara 성능 예산

- 목표: 전투 Niagara에 공통 Effect Type을 배정한다.
- 수정 위치: `/Game/Rogue10m/VFX/Character/Combat/NET_CombatReadable`, 요청 10종 Niagara 30개
- 완료 조건: 요청 30개 시스템이 같은 Effect Type을 참조하고 로컬 플레이어 효과는 거리 컬링으로 사라지지 않는다.
- 검증: 전용 Validator의 Effect Type 연결 검사
- 롤백 경계: Effect Type 자산과 Niagara의 참조 속성

### Packet 4 — 직접 실행 QA

- 목표: 10종 연계·차징 공격을 실제 게임에서 실행하고 화면 중앙 점유와 누적을 확인한다.
- 수정 위치: 기존 `Rogue10m.TestClassCombatPresentation` 테스트와 필요 시 테스트 예산 검사
- 완료 조건: 30회 연계, 10회 차징, 캡처 10장, 실패 0건
- 검증: Unreal `-game` 실행과 캡처 육안 검토
- 롤백 경계: 자산 튜닝값

### Packet 5 — 리뷰와 문서화

- 목표: 빌드·자산·수명주기·성능 예산을 검토하고 결과를 기록한다.
- 수정 위치: `Feature/doc`, `DevLog/20260826.txt`, `Docs/SprintChangeLog.md`
- 완료 조건: 빌드, 데이터 검증, 직접 실행 결과와 알려진 한계가 기록된다.
- 검증: `CheckGeneratedChanges.ps1`, `git diff --check`, Python AST 검사
- 롤백 경계: 문서 변경

## 안전 원칙

- 원본 Marketplace Niagara는 수정하지 않는다.
- `.uasset`은 Unreal Editor 스크립트로만 저장한다.
- 상시 Tick을 추가하지 않는다.
- 로컬 플레이어의 공격 효과는 성능 컬링보다 입력 피드백을 우선한다.
- 타인의 기존 작업과 활·권사 스킬트리 자산은 이번 요청 범위에서 수정하지 않는다.
