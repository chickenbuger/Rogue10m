# A안 전투 HUD 글자와 아이덴티티 정리

`Sprint#16-1-hud-label-polish`에서 A안의 슬롯과 계기판 좌표를 유지한다. 사용자 캡처에 보인 `HOLD RMB` 넘침을 없애고, 기준 화면의 고정·실시간 HUD 글자를 각각 2px 줄인다. 맨손처럼 자원이 없는 경우 무기명만 표시하고, 동작이 연결된 무기에서만 `Ctrl`을 표시한다.

| 범위 | 적용 | 완료 기준 |
| --- | --- | --- |
| 네이티브 HUD | Slate 96 DPI에서 2px에 해당하는 크기 적용. 슬롯 라벨은 내부 폭으로 맞추고 경계에서 클리핑한다. `Ctrl`은 너클 질풍투기 활성화 가능 무기에서 표시한다. | Editor 빌드, 기본 카메라 맨손 캡처, 대검·너클 상태 검증 |
| 원본 아트 | 원본 A안 PNG를 보존하고 아틀라스의 고정 글자와 원형판 글자 제거부만 다듬는다. | 추출기 `--check`, 에디터 임포트, 픽셀 및 경계 비교 |
| 검증 | 기존 실행 중 에디터를 보존하고 별도 물리 체크아웃에서 검사한다. | `Scripts/VerifyCombatHudA.ps1`, 실제 출력 로그와 저장 해시 |

원복 범위는 A안 텍스처, 아틀라스 생성기와 전투 HUD 표시 로직이다. 기존 무기 스킬 발동 규칙과 마을·카메라 설정을 유지한다.
