# Feature 검증 자료 선별 정리

사용자는 Feature/doc/evidence의 불필요한 사진과 JSON을 정리하되 최종 결과와 중요한 실패는 남기고, commit·push 후 main에는 합치지 않도록 지시했다.

| 패킷 | 목표·영역 | 완료 조건·검증 | 경계 |
| --- | --- | --- | --- |
| E1 | 전체 파일·참조·활성 작업 조사 | 후보6,965개(사진910/JSON6,055), 원본 해시와 코드 입력 식별 | 읽기 전용 |
| E2 | 과거/중간/맵 담당별 선별 | 최종 결과·중요 실패·출처/원본·필수 입력 보존, 삭제 이유 명시 | 고정 manifest |
| E3 | 사진 시각 확인·삭제 | 일반 파일·내부 절대 경로·해시 확인, 파일별 삭제 | 사진·JSON만 |
| E4 | 문서·검증·게시 | 보존 파일 원본 해시/JSON/링크/비대상 파일 확인 후 작업 브랜치 push | main/develop/test 변경0 |

현재 자연 경계 에디터가 사용하는 landscape-natural-boundary20261117과 진행 중인 caves20261118은 전체 보호한다. generated/Saved/Intermediate/Binaries/DerivedDataCache와 reparse 경로는 대상에서 제외한다. 로그·패치·영상·소스·Unreal 바이너리 자산·실제 세이브는 삭제하지 않는다.

최종 JSON과 중요한 실패의 원본을 다시 쓰거나 성공으로 바꾸지 않는다. 실제 스크립트 입력, 원본 참조/소스 이미지, 핵심 애니메이션 단계와 주요 실패 장면은 보존한다. 중복/반복 RPC·촬영·임시 세션은 후속 결과가 근거를 보존하는지 확인한 뒤 정리한다.

공유 일지·Sprint 문서는 다른 맵 작업의 미커밋 변경을 유지하고 이번 추가분만 index에 선별한다. Git 추적 삭제는 과거 커밋에 남지만 미추적 보조 자료는 실제 삭제하며 별도 원본 사본을 만들지 않는다.
