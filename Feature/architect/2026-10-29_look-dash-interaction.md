# 아래보기·달리기·대시와 NPC 상호작용 점검

기준4676fdad, Sprint#9-13-look-dash-interaction. 기존 세이브238개와 증거509개를 합친747파일을 독립 복사·SHA256 검증한다. 원격 push/병합, 실제 사용자 세이브 초기화, 생산 맵 저장, 신규 에셋 구매는 하지 않는다.

사용자는 아래보기와 달리기의 시야·모션을 Dead by Daylight의 묵직한 인간형 살인마 느낌으로 지정했다. 실제 공식/플레이 자료의 관찰과 구현 제안을 분리하고, 재생하지 못한 영상의 움직임을 봤다고 표현하지 않는다. 고유 능력·대시·무적·강한 shake를 임의로 복제하지 않는다. 기존 공격 판독성·입력·충돌 규칙을 보존한다.

## 실행 묶음

현재 대시는 별도 Dash 클래스가 아니라 E→DoDodge다. 실제 무기 DodgeSkill 또는 fallback의 거리/시간/쿨다운/비용을 사용한다. 정확한 판정을 위해 IsDodging/GetDodgeCooldownRemaining 읽기 API만 우선 추가한다. 현재 CameraManager의 FullBodyViewPitchMin 기본-85도 안에서0/-60/-80/-85도, OFF/ON, 아래보기+달리기, E회피와 아래보기+E 조합을 새 격리 프로필/바닥/벽에서 검증한다. 방향·수평 이동·벽 충돌·자원1회·반복거부·쿨다운후재허용·UI/공중차단을 실제 실행으로 확인한다. configured Distance는 초기 velocity 식의 입력이며 friction영향이 있어 정확 이동거리 보장으로 해석하지 않는다. -89는 별도 stress로 구분하고 제품 시야 제한을 바꾸지 않는다.

카메라/trace 일치·유한변환·머리숨김만으로 클리핑 없음으로 판정하지 않는다. 가까운 손/몸의 투영·near-plane 수치와 실제 viewport PNG를 함께 검토한다. 재현된 문제만 좁게 고치고 같은 시나리오를 재검사한다. 기존 QA통과를 이번 실행 결과로 대신하지 않는다.

NPC F는 실제 BindKey로 확인했고 F 대화하기 안내가 이미 있다. 새 프롬프트를 중복 추가하지 않는다. 실제 proximity/UI/입력으로 안내와 대화열기/닫기를 검증한다. F custom active remap과 legacy 소비의 동시실행 위험은 실행으로 확인한 후 수정 여부를 정한다.

Map Maker는 Editor Window→World Map Maker이며 실제 OpenRunMap 환경물 편집/같은맵+OFPA 저장 도구다. 사용법과 보호 범위는 현재 구현으로 별도 중간 안내하며 이번에는 읽기 전용으로만 확인한다. 맵 편집·저장을 실행하지 않는다.
