# 인벤토리 시안 실제 적용

Sprint#14-4의 기준은 [승인 시안](../doc/evidence/inventory-concept-20261120/inventory-concept.png)과 [정확한 격자](../doc/evidence/inventory-concept-20261120/inventory-grid-guide.png)다. StartHub와 OpenRunMap에서 공통으로 쓰는 `I` 인벤토리에 프레임, 간결한 골드·무게 띠, 고정 크기 아이템과 장착 비교 카드를 적용한다.

| 작업 | 완료 조건 | 검증 | 복구 경계 |
| --- | --- | --- | --- |
| 프레임과 레이아웃 | 실제 네 모서리 장식, 제목과 키 표시, 10×10 정사각형 셀, 하단 정보가 승인 시안과 같은 시각적 위계로 표시된다. 기존 아이콘과 실제 월드를 사용한다. | UE 위젯 컴파일 및 재로드, 1080p·720p 게임 캡처 | 새 텍스처와 변경한 인벤토리 위젯 |
| 호버와 드래그 | 호버하면 연결된 이름·능력치·같은 부위의 현재 장착품을 확인한다. 유효·무효 드래그 대상은 격자 위에서 구분된다. | 실제 Slate 입력과 게임 데이터 확인 | 메뉴 위젯의 인벤토리 표시 부분 |
| 게임 동작 확인 | `I`와 `P` 창, 장착·해제, 유효·무효 이동, 포션 소비와 저장 복원이 기존 데이터에 맞게 동작한다. | 격리된 StartHub 세션, 실제 `-AbsLog` 경계 검사, 최종 캡처 | QA 실행 코드 및 격리 세이브 |

프레임은 승인 시안을 ImageGen으로 편집해 기존 고딕 텍스처에 어울리는 독립 텍스처로 제작한다. 아이콘은 프로젝트에 연결된 Item Data Asset을 다시 사용한다. 기존 가방 크기, 슬롯, 저장 포맷, 월드와 장비 교체 규칙을 기준으로 구현한다. [Fab 에셋 재사용 원칙](../../Docs/FabAssetReuseGuide.md)

작업은 기본 체크아웃과 분리된 물리 체크아웃에서 한다. 기존 WBP의 네이티브 부모와 필수 바인딩을 사용한다. 가방 UI는 두 레벨에 공통으로 적용되며 맵 제작과 독립적으로 검증한다.
