# 철산고의 어깨 주도 동작 계획

현재 실제 격투가 기술 `F.Shoulder`는 `DA_Attack_Knuckle_Charged`로 연결된다. 기존 `A_Knuckle_ShortBlow`는 전방 주먹을 먼저 내민다. 철산고에서는 어깨를 앞으로 가져오고, 팔을 몸 가까이에 접은 채 지지발로 짧게 버틴 뒤 가드로 돌아오게 한다.

프로젝트의 `A_Knuckle_ShortBlow` Manny 가드를 Blender에서 출발점으로 사용한다. 기존 가드의 뼈 계층과 기준 좌표, 실제 타격 구간을 평가하고 접촉 자세를 새로 키프레임한다. 기존 시퀀스와 공유 몽타주를 보존하고 철산고 데이터에만 프로젝트 파생 시퀀스와 몽타주를 연결한다. 기본 캡슐 이동, 타격 범위와 피해 시계, 입력 방식을 유지한다.

실제 StartHub의 격투가 기술 입력에서 기존과 수정본의 첫 피해, 주먹과 어깨의 전방 위치, 앞발과 뒷발 접촉 및 회복을 비교한다. Blender와 새 FBX에서 고정 루트, 관절 길이, 양 끝 가드를 확인하고 실제 720p 화면을 별도로 검토한다. 변경 범위는 철산고 전용 모션, 검증 코드와 기록이다.
