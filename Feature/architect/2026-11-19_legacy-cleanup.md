# GitHub 게시 전 레거시 정리

두 맵으로 통합한 현재 프로젝트에서 쓰이지 않는 코드와 중복·폐기 JSON을 찾는다. 현재 실행 경로, 기존 저장 이행, 맵 제작 기준 자료와 중요한 검증 기록을 보호한다.

## Ultrawork 작업 단위

| 작업 | 범위와 완료 조건 | 검증과 복구 경계 |
| --- | --- | --- |
| C++ 조사 | `Source/Rogue10m`에서 호출이 없는 비반사 코드 또는 폐기된 기능 전용 코드를 선별한다. C++·설정·도구 참조와 Unreal 반사 및 저장 이행 여부를 확인한다. | `rg` 및 `git grep`으로 정의·호출을 확인하고, C++ 변경 시 Editor 빌드로 검증한다. 삭제 범위는 Git에 원본이 있는 코드로 제한한다. |
| 제작 도구 조사 | `Scripts`·`Tools`에서 현행 진입점·테스트·공용 도구가 사용하는 코드를 확인한다. 폐기된 기능만을 위한 잔여 코드와 사용처 없는 내부 구현을 선별한다. | 남은 호출·import·문서 진입점을 확인하고 관련 구문 검사와 실행 가능한 테스트를 수행한다. 파일 단위 원본은 기준 커밋에 보존한다. |
| JSON 조사 | Git 추적 JSON에서 최종 결과에 내용이 남아 있는 중간 기록 또는 폐기된 작업의 사용처 없는 중간 산출물만 선별한다. 제작 입력, 보존 목록의 중요 기록과 작업 중인 자료를 확인한다. | 삭제 경로·보존 근거를 결과서에 기록하고, 남은 실행 입력이나 문서 링크가 삭제 경로를 가리키는지 검사한다. 파일 단위 원본은 기준 커밋에 보존한다. |

기준은 `084865cd`이며 캐릭터 선택 UI의 기존 작업이 있는 `Sprint#9-35-character-select-ui` 작업 트리에서 겹치지 않는 파일만 수정한다. 검증한 레거시 정리를 현재 작업 브랜치에 별도 커밋으로 게시한다.
