# 캐릭터 선택창 외형 호환성 복구

작업 브랜치 `Sprint#9-35-character-select-ui`의 후속 수정이다. 1920×1080 실제 선택창에서 확인된 회색 렌더링과 `/Engine/EngineMeshes/Humanoid` 종속성 오류를 해결한다.

1. 기존 카탈로그의 여섯 종족·성별 조합에서 메시의 실제 재질 슬롯과 머리·몸·눈·장식 재질, 원본 Skeleton과 IK 리타깃 연결을 조사한다. 프로젝트에 이미 설치된 Stylized Character 외형을 사용하고 새 팩을 구입하거나 반입하지 않는다.
2. Editor를 통해 구형 의존성이 제거된 Skeleton으로 활성 외형 연결을 정리한다. 본 계층과 기본 자세, 소켓, 기존 AnimBP와 리타깃 설정을 비교한다. 회색 원인이 된 슬롯에는 기존 종족별 스타일에 맞는 재질을 연결하고 꾸미기 선택을 검증한다.
3. 별도 프로세스로 저장된 자산을 다시 열고 여섯 조합의 의존성·재질과 실제 렌더 선택·생성·접속을 확인한다. 실행 전후 실사용 세이브를 대조하고 실제 `-AbsLog` 전체의 오류 및 재질 경고를 조사한다.

구형 스켈레톤을 참조하는 패키지를 조사한 결과, 1인칭 팔과 전투 애니메이션에서 기존 스켈레톤 경로와 객체 일치 여부를 확인하고 있었다. 복구용 원본을 따로 보존한 뒤 같은 경로의 패키지 6개를 공식 에디터로 다시 저장해 구형 직렬화 종속성만 제거한다. 몸체와 드워프 얼굴의 회색 텍스처는 질감을 살리는 프로젝트 재질로 보정한다. 선택창에 쓰이는 몸체와 1인칭 팔의 디버그 눈 슬롯 및 해당 얼굴 장식 슬롯도 교체한다.

실제 첫 화면에서 편집기 셰이더 준비 중 렌더된 회색 프리뷰가 입력 전까지 남는 경우를 확인했다. 에디터에서 활성 프리뷰의 재질 컴파일이 끝나면 다음 프레임에 다시 캡처하고, 같은 프레임의 여러 알림은 한 번으로 합친다.

수정된 자산 목록과 소스만 별도 커밋으로 게시한다. 현재 진행 중인 다른 소스·맵·문서 변경은 해당 작업의 범위에 둔다. 관련 산출물과 확인 결과는 일일 개발 기록과 Sprint 변경 이력에 남긴다.
