# 기존 오픈 월드에 보관 지형과 동굴 적용

대상은 `/Game/Rogue10m/Maps/OpenRunMap`이다. 보관된 지형과 Q/Z 동굴을 기존 레벨의 World Partition 좌표에 적용한다. 현재 두 게임 맵과 시작 마을 출발문, 캐릭터 저장, 런 정산 경로를 기준으로 삼는다.

회수 지형과 기존 Landscape의 원점과 격자 간격은 같다. 보관 영역은 동서 −33,750~67,500cm, 남북 22,500~78,750cm이며 중앙로 X 15,000cm와 마을 세 곳의 기준 고도는 Z 9,600cm다. 보관 영역의 바깥 경사와 남쪽 연결 구간을 기존 땅에 이어 붙인다. 기존 남쪽 등장 위치, 강과 다리, 보스 바닥과 게임 진행 액터를 실제 좌표에서 대조한다. 북쪽 평탄면을 적용할 때 보스 입구의 충돌과 기존 경사로 계약을 별도로 확인한다.

Q/Z의 연속 바위 셸·경사로·보행 바닥·조명을 옮긴다. 기존 프로젝트의 Stylized Village 메시와 검증한 동굴 V2 제작 자산을 재사용한다. 복구본을 읽을 때는 독립 물리 사본을 사용하고, 실제 프로젝트에 과거 레벨을 추가하지 않는다. 카메라 스프링 암과 캐릭터 크기는 현재 게임 설정을 사용한다.
