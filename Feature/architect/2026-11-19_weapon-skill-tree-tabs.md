# 무기별 스킬트리 탭

기존 K 스킬 창을 무기별로 나눈다. 공통 → 너클 → 검 → 마법 순서를 기준으로 장착한 무기의 탭을 맨 앞으로 옮겨 열 때 선택한다. 탭을 직접 둘러보는 동안에는 장비가 바뀔 때만 기본 탭을 다시 적용한다. 마법은 준비 화면만 제공한다.

## 작업 단위

| 목표 | 수정 위치 | 완료 조건 | 검증 | 되돌리는 범위 |
| --- | --- | --- | --- | --- |
| 네 탭 및 장착 무기 연동 | 기존 HybridSkillTreeWidget | 무기별 기본 탭과 순서, 탭 전환 및 다시 열기, 마법 준비 화면 | Editor 빌드, K 창 런타임 검증 | 위젯 탭 및 패널 코드 |
| 너클 수련 사다리와 검 거미줄 | 기존 그래프 렌더링 및 스킬 카탈로그 | 기존 실전 숙련으로 너클 기술 전수, 검의 선택 경로와 실제 기술 투자, 공통 노드 접근 | HybridSkillTree 자동화 및 K 창 런타임 | 그래프 배치 및 검 해금 규칙 |
| 저장 및 입력 호환성 | 기존 진행·UI 자동화 | 기존 해금과 키/드래그 API 유지, 새 검 투자 경로 검증 | 로그 경계 검사 및 기존 자동화 | 새 회귀 검증과 저장 호환 규칙 |

예시 이미지를 먼저 제시했다. 이미지 속 스킬명은 화면 배치 예시이며 구현은 기존 카탈로그와 공격 에셋을 사용한다. 검의 기존 자동 전수 기록은 같은 노드 ID와 기존 선행·숙련 기준으로 읽는다.

## 화면 예시

기본 ImageGen에서 Rogue10m 전투 HUD 템플릿의 황동 테두리와 어두운 색감을 참고했다. 프롬프트는 공통의 분기, 너클의 기초기술과 상승 사다리, 검의 중심에서 넓어지는 연결망, 마법의 빈 준비 화면을 2×2로 배치하도록 지정했다. [네 탭 예시](../doc/evidence/weapon-skill-tree-tabs-20261119/concept.png)
