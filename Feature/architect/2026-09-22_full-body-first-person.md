# 전신 1인칭 표시 전환 계획

## 목표와 범위

사용자의 최신 요청은 팔뿐 아니라 다리와 몸통이 보이도록 실제 게임 표시를 바꾸는 것이다. 이전 팔 전용 요구는 이 요청으로 변경된다. 현재 Unarmed/Knuckle의 1인칭 표현을 전신 Manny 기반으로 전환하고, 아래를 보면 몸통·골반·다리가 보이며 Martelo 시연에서는 실제 발차기 다리가 나타나게 한다. 기존 좌·우클릭 공격 종류, 피해·쿨타임·자원 소모는 유지한다. Martelo는 이번에도 독립 프리뷰이며 정식 공격 슬롯 변경은 별도 범위다.

## 변경 전 코드에서 확인한 제약

`Rogue10mFirstPersonPresentationComponent`는 SK_FirstPersonArms로 메시를 교체하고 neck_01 및 양쪽 thigh를 숨긴다. FirstPersonMesh는 Camera 자식이므로 시선을 내리면 메시 전체가 카메라 pitch를 따라 돈다. 따라서 전신 메시를 넣고 thigh 가림만 풀어서는 아래보기 요구를 만족하지 못한다.

`Rogue10mFistAnimInstance`의 손 목표·팔꿈치 목표는 현재 메시 컴포넌트 공간에 작성되어 있으며, `MeshToCamera`는 GetComponentRelativeTransform의 회전으로 가정한다. 카메라와 메시 부모를 분리하면 이 가정이 바뀐다. 전신을 수직으로 유지하면서 손이 조준을 따라가려면 상체 조준 또는 손 목표 좌표를 명시적으로 보정해야 한다. 기본 EvaluateBasicPose는 Idle 기반 하체를 유지하고 상체·손 궤적을 생성한다. 하체를 표시한다고 별도 보행 애니메이션 시스템이 자동 완성되는 것은 아니다.

## 구현 방향

전신 전용 표현은 기존 full Manny 또는 같은 기준 뼈대의 전신 메시를 사용한다. 카메라는 현재처럼 capsule 기준 위치와 조준 회전을 유지하고, 전신 메시도 capsule 기준으로 부착해 카메라 pitch와 분리한다. 메시 yaw는 캐릭터 방향을 따르고 몸의 수직축은 시선 상하 이동과 무관하게 유지한다. 기존 camera-relative 위치를 단순 복사하지 않고 capsule 위치로 환산한다. 현재 수치의 시작점은 카메라 Z64 + 메시 Z-158 = capsule 기준 Z-94이며, 실제 발과 바닥 정렬을 보고 조정한다. 위치·FOV·머리 가림은 조정 가능한 속성으로 둔다.

원본 월드 캐릭터 GetMesh는 계속 소유자 시야에서 숨겨 중복 몸체를 막는다. FirstPersonMesh 하나가 보이는 팔·몸통·다리를 담당하는 구성을 우선한다. 목/머리 내부가 카메라를 가리지 않도록 neck_01 이하만 숨긴다. pelvis/spine은 팔·몸통의 부모이므로 숨기지 않는다. thigh 가림은 제거하고, 과거 팔 전용 마스크가 남을 수 있는 재활성화·메시 전환에서도 다리 표시를 명시적으로 확인한다.

FistAnimInstance는 게임 스레드 PreUpdate에서 캐릭터 조준 pitch와 전신 표현 설정을 snapshot으로 가져온다. 병렬 Evaluate에서 UObject를 조회하지 않는다. 상체 조준은 pelvis/다리를 회전시키지 않는 범위에 적용하고, 팔 손목·손 목표와 팔꿈치 목표를 같은 좌표 변환으로 처리해 관절 뒤집힘을 막는다. 카메라 표현용 머리 변화는 조준 보정 자체를 타격 흔들림으로 오인하지 않도록 기준 포즈 대비 공격 변화와 구분한다. 스케일 0·NaN·무기 전환의 기존 카메라 초기화 및 이동·회전 한도는 유지한다.

Martelo SingleNode 프리뷰는 전신 메시·capsule 부착 상태를 그대로 사용한다. 원본 애니메이션의 하체가 재생되며 아래보기와 발차기 순간을 실제 게임 화면으로 찍는다. 캡슐 충돌·루트 이동·피해 판정은 추가하지 않는다. 이번 목표는 몸과 다리를 보이게 하는 것이므로 카메라를 원본 머리의 큰 회전에 직접 고정하지 않는다.

## 역할과 Ultrawork Packets

### Packet 1 — 전신 표시와 복구 (개발 1)

- 목표: 전신 Manny, capsule 기준 메시, 머리만 가리는 표시 경로를 만든다.
- 수정 위치: FirstPersonPresentationComponent 및 필요한 기본 설정.
- 완료 조건: 정면에서 팔, 아래보기에서 몸통·다리가 보이고 시선 pitch에 몸 전체가 같이 기울지 않는다.
- 검증: BuildEditor, 실제 아래보기·무기 전환 실행 검증.
- 복구 경계: 전신 표시 설정/부착/가림 변경만 되돌릴 수 있어야 한다. 이전 부모·소켓·변환·메시·재질·애니메이션·명시적 가림·소유자 표시·카메라 상태 복구를 유지한다.

### Packet 2 — 상체 조준과 Martelo 연계 (개발 2)

- 목표: 수직 전신에서 기존 주먹의 조준을 유지하고 Martelo 전체 포즈를 보여준다.
- 수정 위치: FistAnimInstance와 담당이 합의한 프리뷰 파일.
- 완료 조건: pitch 변화에 손이 사라지거나 비틀리지 않으며, pelvis와 발은 시선만으로 뒤집히지 않는다. Martelo 왼발 신전이 화면에서 확인된다.
- 검증: 기존 Boxing/Fist 테스트 중 의미 있는 회귀 검사, 전신 전용 시연 명령.
- 복구 경계: 입력·스킬 Data Asset·공격 판정은 변경하지 않는다. 프리뷰 종료 후 기본 AnimBP를 되돌린다.

### Packet 3 — 통합 검증과 실제 영상 (주 담당 + 검증 2명)

- 목표: 구조적 검증과 실제 화면 검증을 따로 수행한다.
- 수정 위치: Tests, Feature/doc, DevLog, SprintChangeLog, 증거 영상.
- 완료 조건: 소스 검토 1명 및 렌더 프레임 검토 1명이 아래 검증을 완료하고 실제 게임 영상을 제공한다.
- 검증: BuildEditor, 런타임 PASSED 마커, 대표 이미지/영상 확인, git diff --check 및 CheckGeneratedChanges.
- 복구 경계: 새 전신 테스트와 시연 산출물을 분리한다. 기존 팔 전용 테스트는 폐기하지 말고 요구 변경에 맞춘 명시적 legacy 경로나 전신 검증으로 갱신한다.

## 최소 검증과 수용 기준

- 기본 Unarmed와 Knuckle에서 전신 메시가 사용되고 양쪽 thigh/foot이 숨겨지지 않는다. 목/머리는 소유자 시야에 나타나지 않는다.
- 정면, -35도, -70도, +70도에서 캐릭터 몸의 수직축과 발 높이가 조준 pitch에 따라 통째로 돌아가지 않는다. 전신 아래보기 제한은 -85도이며, 팔 전용은 기존 -70도를 유지한다. 실제 확인한 각도는 결과 문서에 구분해 기록한다.
- 정면 가드가 중앙 시야를 과도하게 가리지 않고, -85도에서는 몸통과 양쪽 다리·발이 실제 화면에 보인다. 카메라가 가슴 안쪽을 보거나 메시가 바닥 아래에 박히는 경우 수정한다.
- 기존 좌클릭 왼잽→오른잽, 우클릭 짧게 스트레이트/길게 놓기 훅을 실행한다. 주먹 좌우가 바뀌거나 손목이 뒤집히지 않고, 조준 CameraComponent/ControlRotation 및 실제 피해 타이밍은 기존 계약을 따른다.
- Martelo 정면 또는 약간 아래보기 시연에서 왼무릎 준비→왼발 신전→회수가 나타난다. 원본 애니메이션 전체를 재생하고 발이 보이도록 임의 타격을 합성하지 않는다.
- 월드 GetMesh와 FirstPersonMesh가 겹친 두 몸처럼 보이지 않는다. 목 절단면·복부 내부면·다리 내부 관통은 실제 대표 프레임으로 판정한다.
- 무기 전환, 표시 비활성화/재활성화, 사망/월드 종료, SingleNode 프리뷰 종료에서 상태가 정상 복원된다. 반복 전환 후 다리 가림이 남지 않는다.
- 16:9 및 울트라와이드에서 몸과 HUD가 겹치는 정도를 확인한다. 기존 HUD 배치는 이번 작업의 독립 변경 대상으로 삼지 않는다.

## 주요 위험과 판단

전신은 팔 전용 때보다 카메라 가까운 표면이 많다. 머리를 숨겨도 가슴·어깨 내부가 화면을 덮을 수 있으므로, 카메라 전방 오프셋과 상체 조준 범위를 실제 화면으로 조정해야 한다. 시야를 극단적으로 넓혀 문제를 감추지 않는다.

기존 팔 전용 모델은 신체의 바닥 정렬을 요구하지 않았다. 전신 첫 시연에서 기존 FirstPerson 렌더링을 유지하자 재질의 시점 가림과 보정 때문에 표면이 띠처럼 잘려 보였다. 최종 전신은 표준 월드 투영을 사용하고, FirstPersonScale 0.6/팔 FOV80은 legacy 팔 전용에서만 활성화한다. 수치만으로 통과시키지 않는다.

상체 보정 회전을 카메라 흔들림 신호에 포함하면 마우스를 움직일 때 흔들림이 추가되는 회귀가 생긴다. 조준 보정과 공격 기반 머리 신호를 분리하는 것이 핵심이다. 단순 메시 교체만으로 완료 판정하지 않는다.
## 실제 화면 및 공격 회귀에 따른 생산 설정

- 전신 카메라: capsule 기준 **(20, 0, 76)cm**.
- 전신 메시: capsule 기준 **(-5, 0, -94)cm**, 기존 Manny 기준 yaw 유지.
- 손·팔꿈치 목표 보정: 메시 공간 **(0, 12, 18)cm**, 유한성 검사 후 벡터 길이 최대 **40cm**.
- 전신 맨손(Unarmed) 가드 전용 보정: **FullBodyGuardPullback=14cm**, **FullBodyGuardInward=8cm**. 각각 유한성을 검사하고 0~25cm, 0~15cm로 제한한다. 공격 정점 및 훅 제어점에는 가드 보정을 더하지 않는다. Knuckle은 원래 가드를 유지하고 이 보정을 적용하지 않는다. 기본 복싱은 기존 기준으로 480프레임·실패 0을 확인했고, 나머지 회귀·시야 확인은 통합 기록에 남긴다.
- 전신 투영: **FirstPersonPrimitiveType=None**, 카메라 FirstPerson FOV/scale 활성화 **false**. 월드 FOV **90도**.
- legacy 팔 전용: 기존 FirstPerson primitive, 전용 FOV/scale 및 기존 부착 방식 유지.
- 전신 아래보기: **-85도**, legacy 아래보기 **-70도**. 위보기 제한은 기존 설정 유지.
- 조준 상체 분배: **FullBodySpinePitchShare=0**, 팔은 clavicle에서 조준을 따르며 조준 보정 한도는 **75도**.

초기 시연은 상태 검증을 통과했지만 실제 화면에서 전신 표면이 리본처럼 끊겼다. 같은 포즈의 표준 렌더링 대조에서는 몸통·팔 표면이 연속적으로 나타나, 기존 Manny 재질의 1인칭 가림·FOV/scale 보정 경로를 전신에 사용한 것이 원인으로 확인됐다. 원본 재질을 변경하는 대신 전신 표현만 표준 월드 투영으로 바꾼다.

시야를 아래로 내릴 때 spine까지 굽히면 가슴이 하체를 덮는다. 따라서 **마우스 조준에 따른 몸통 굽힘만 0으로 두며, 잽·스트레이트·훅·차징·점프의 기존 공격/행동 기반 spine·pelvis 움직임과 카메라 연동은 유지한다.** 손 목표는 전방 12cm·상향 18cm로 보정한다. 이 공통 보정만으로도 가드가 팔 길이 제한에 걸려 실제 스트레이트 전진량이 7.364cm로 기존 기준 8cm에 미달했다. 고정된 카메라 위치는 가드와 정점의 차이를 구할 때 상쇄되므로, 원인은 카메라 위치 자체가 아니라 어깨에서 손까지의 도달 한계였다. 실제 관절 좌표로 계산한 가드 목표 거리는 63.832cm, 도달 제한은 51.721cm다. 가드만 14cm 후퇴하면 51.115cm로 제한 안에 들어간다. 여기에 맨손 가드만 중앙으로 8cm 접어 화면 가장자리 이탈을 줄인다. 이 작은 가드를 Knuckle에도 적용하면 손이 지나치게 가깝고 위보기에서 사라지는 문제가 있어, 보정 적용을 기본 맨손으로 한정한다. 전신 카메라는 전방 20cm로 조정해 몸 아래보기와 너클 시야를 함께 확보한다. 가드에서 파생되는 준비·차징 진입·회수·연속 잽 경로는 함께 따라가고 절대 공격 정점은 유지한다. 이 구조의 최종 값은 기존 임계값을 유지한 실행과 실제 가드 화면으로 검증한다.

카메라 매니저의 LimitViewPitch만 재정의해 전신의 현재 로컬 1인칭 view target에서만 -85도를 허용한다. 전역 ViewPitchMin을 덮어쓰지 않으며 별도 카메라·전환 중·legacy에서는 기존 제한을 사용한다. 실제 ProcessViewRotation에서 전신 -85도와 팔 전용 -70도, 전신 모드 복귀를 검증한다.

최종 수용 판단은 임시 진단 옵션 없이 위 기본값으로 찍은 실제 화면을 사용한다. 아래보기에서 자신의 몸통·양쪽 다리·발이 연속적으로 보이고, Martelo의 왼발 신전이 확인되어야 한다. 빌드 및 기본 복싱·Knuckle 시야·legacy 팔 전용 회귀 결과는 최종 기록에 각각 구분한다.


시연 표적은 플레이어 전방 210cm에 둬 Martelo 발과 표적 표면이 겹쳐 보이는 것을 줄인다. 이 거리는 프리뷰 배치이며 생산 공격 거리·피해 판정의 변경이 아니다. 기존 복싱 테스트의 스트레이트 전진량 기준은 낮추지 않고 최종 손 목표로 다시 검증한다.
