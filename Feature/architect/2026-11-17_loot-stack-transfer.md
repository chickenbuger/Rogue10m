# 전리품 스택 수량 계산 독립 게시 계획

2026-11-17.

## 범위와 계약

자동 입고의 수량 계산만 독립 검증 가능한 패킷으로 분리한다. `Rogue10mLootStackTransfer.h`와 이를 직접 사용하는 C++ 검사·PowerShell 실행기, 본 문서와 결과·증거가 대상이다. 인벤토리·몬스터·드롭·월드 서브시스템과 자산을 추가하지 않는다.

호출자는 호환되는 기존 스택과 실제 빈 공간 여부를 전달한다. 계산기는 유효한 입력을 기존 스택 순서대로 합치고, 공간이 있으면 잔량을 새 항목에 배정한다. 수량이 최대 스택을 넘는 입력은 거절하고 잘못된 기존 수량은 그대로 둔다. 실제 인벤토리 변경, GUID 소유권, 드롭 생성과 재시도는 호출자의 책임이다.

## 인수 조건

clang++ C++17·`-Wall -Wextra -Werror -pedantic -O2`로 실제 헤더를 검사한다. 독립된 64비트 용량 계산을 oracle로 사용해 합산·수량 보존·새 항목·잔량을 대조한다. 이 패킷은 엔진 타입이나 UHT를 사용하지 않으므로 UE 빌드가 필요하지 않다.

완료한 계산 기반만 게시하며, 자동 입고의 게임 연결이나 월드·충돌·저장 검증 완료로 확대하지 않는다. 나머지 전리품 구현은 원래 checkout에 유지한다. 일지·Sprint 기록과 commit·push는 게시 담당자가 수행한다.
