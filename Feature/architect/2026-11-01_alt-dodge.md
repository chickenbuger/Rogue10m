# Alt 회피·대시 입력 분리

사용자 확정: 회피·대시는 Alt, Space 점프 유지. E를 회피 예약에서 해제하여 액티브 스킬 입력과 충돌하지 않게 한다. 공통 InputKeys 헤더를 Character/HUD/SkillBinding과 관련 QA에서 참조한다. enum 순서·저장 스키마·기술 비용·쿨다운·이동 수치는 바꾸지 않는다. Ctrl/Q/E/R4슬롯과 무기별 프리셋은 이번 최소 입력 전환과 구분한다.

LeftAlt 독립 계약, 실제 pawn legacy binding, Alt 회피1회/반복 입력, E 실제 활성 기술/회피0회, NPC F consumed 보호를 검사한다. 과거 고정 출력 QA는 덮어쓰지 않고 새 evidence label과3개 저장 override를 사용한다. OS Alt 메뉴·포커스와 HUD 라벨은 실제 화면에서 별도 확인한다. 코드 빌드/프로그램 입력/네이티브 입력/일반 필드 완주는 분리한다.

기준66607612의 실제 저장폴더304개를 새 manifest/복사로 보존하고 현재 byte SHA가 검토한 초안 원본과 일치할 때만 적용한다. 원본 맵·에셋·사용자 세이브·다른 작업 무변경, 원격 push/병합 없음.


## 오래된 Hybrid QA fixture 현행화

AltInput1101A는 E 검사 진입 전 런포인트로 영구 Trait을 구매하던 가정 때문에4실패했다. 실패 출력은 보존한다. 런4P/로비0에서 Trait 구매 거부·잔액/원장 불변을 강하게 검사하고 Identity 결제/환불의 정확한 델타를 유지한다. SaveNow 산출물의 옛v3 기대는 독립v5/RunId/분리예산 검사로 바꾸며, 의도적인 레거시 마이그레이션 검사를 제거하는 변경은 아니다. 직접 GreatSword 변수만 바꾸던 fixture는 실제 기존 아이템의 QA 인벤 획득·장착과 GUID 정합으로 교체한다. 제품코드·저장 스키마·가짜 로비 재화 주입은 바꾸지 않는다.
