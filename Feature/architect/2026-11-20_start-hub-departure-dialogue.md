# 시작 마을 북쪽 관문과 아린 대화 설계

2026-11-20 · Sprint#14-3 · UE 5.8

## 출발 동선

중앙 우물에서 북쪽 길을 따라 기존 석조 관문으로 접근한다. 가까이 가면 `F 대화하기`가 보인다. 관문 대화에서 `관문을 넘으면 20분 탐험이 시작됩니다.`를 읽고 `마을에 남기` 또는 `탐험 출발`을 선택한다. 첫 포커스는 `마을에 남기`에 놓는다. 방향키와 Enter/Space 또는 클릭으로 선택한다. Esc와 다시 누른 F는 닫기다. 겹침·대화 시작·닫기에서 저장과 런 상태는 바뀌지 않는다.

출발을 확인할 때 유효한 로컬 플레이어, 관문 범위, 현재 대화 소유권을 재확인한다. 기존 입장 재화 기준 저장, 시작 보급 이관, `OpenRunMap?StartRun=1` 순서를 따른다. 저장 실패는 대화에 표시하고 선택을 다시 허용한다. `StartHub`에서 시계는 대기하고 `OpenRunMap`이 로드되면 기존 규칙으로 시작한다.

## 자산과 범위

`Docs/WorldMapProductionGuide.md`와 배치·획득 카탈로그를 기준으로 StartHub 북쪽 출발 위치를 유지한다. 아린은 남쪽 길잡이 역할, 기존 출발 보급 조건과 서비스를 유지한다. 관문은 현재 프로젝트에서 쓰는 석조 아치, 바닥과 접근로를 재사용한다. 이 패킷은 라이브러리에서 새 자산을 반입하거나 활성화할 필요가 없다. 기존 배치 외에 목조 지붕, 문지기, 얕은 안개는 ImageGen이 제안한 연출이다. 실제 배치와 경계·충돌 검증이 필요한 별도 제작 항목으로 본다.
