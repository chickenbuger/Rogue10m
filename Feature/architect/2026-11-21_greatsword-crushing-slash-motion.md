# 대검 분쇄참의 양손 내려베기

`af9ffb60`의 실제 전수·장착 Q 실행에서 분쇄참은 맨손 `MM_ChargedAttack`을 재생했다. 표시 외형의 양 손목 간격은 최대 98.43cm였고, 골반 기준 오른손목이 몽타주 1.119359→1.132079초 사이 22.72cm 움직였다. 같은 범위 안·밖의 입력과 캡슐, 무기 부착 상태를 기준으로 삼는다.

G01 설계에 맞춰 기존 대검 가드에서 양손을 어깨 위로 들고, 전방 사선으로 내리며, 낮아진 검을 짧게 끌어 돌아온다. 프로젝트의 Mixamo 기반 `A_GreatSword_Primary01`과 `A_GreatSword_Primary02`를 비교한다. `Primary01`은 손 간격이 안정적이나 주요 낮은 스윙이 정면을 벗어난다. `Primary02`의 올림과 전방 내려치기를 우선 검토하며, 지나치게 낮은 원본 회복 구간을 편집하고 바닥 여유를 확인한다. Manny 골격을 Unreal에서 추출해 Blender로 편집하고, 신규 프로젝트 시퀀스와 몽타주를 분쇄참 데이터에만 연결한다.

기존 몽타주 슬롯·길이·블렌드와 입력 수락, 즉시 피해 1회, 전방 판정 범위, 캡슐 이동을 대조한다. 60Hz에서 Manny와 표시 외형의 손 간격, 오른손목 최대 변화, 실제 검 중심축의 3D 각도와 정면 표적 캡슐 거리를 측정한다. 같은 대검 기술 8건을 회귀 실행한다. 적합한 후보의 루트와 바닥 여유, 준비와 회복을 프로그램 입력과 실제 렌더에서 확인한다. 이전 몽타주 참조를 복구하면 분쇄참 변경만 되돌릴 수 있다.
