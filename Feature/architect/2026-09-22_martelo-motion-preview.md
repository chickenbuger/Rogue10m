# Martelo 2 원본 동작 미리보기 계획

- 날짜:2026-09-22 / 브랜치:Sprint#4-30-martelo-motion-preview
- 요청:사용자가 제공한 Martelo 2.fbx를 현재 게임에 적용했을 때 어떻게 보이는지 확인한다.
- 범위:원본 동작 검사·골격 미리보기·현재 1인칭 구조와 비교. 기존 공격 입력이나 게임 자산을 교체하지 않는다.
- 작업1:설치된 Autodesk FBX SDK로 원본 뼈·스택·시간·전역 관절 변환을 읽는다. 완료 조건은 실제 동작의 주도 관절 식별이다.
- 작업2:원본 관절 변환을 고정 카메라 두 각도로 재생하고 발끝까지 표시되는지 확인한다. 게임 메시/리타깃 결과로 표시하지 않는다.
- 작업3:현행 절차형 포즈·카메라 코드와 독립 대조하고 적용 시 보이는 부분과 필요한 작업을 기록한다.
- 검증:SDK Import/EvaluateGlobalTransform 성공,40프레임 원본 좌표 검사, 대표6프레임 육안 확인, 서브에이전트 독립 수치/코드 검토.
- 복구 경계:이번 문서와 미리보기·분석 파일만 제거 가능. 런타임 소스/Content 변경 없음.
