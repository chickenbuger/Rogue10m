# 무기 교체의 상태·아이템 경계

- 목표: 장착/해제/제거 전에 사망·공격 상태를 검사하고, 거부 시 인벤토리/장비/능력치/자원/현재 프로필에 변경이나 알림을 남기지 않는다.
- 입력: 7f60c5da 체크포인트, 최신 사용자 교체 규칙, Sprint#9-5 브랜치 유지 지시.
- 변경 위치: Character 상태 질의, Combat 공격 행동 시간, Inventory 공통 사전 검사 및 성공 후 실제 아이템 교체 알림, 전용 격리 테스트.
- 완료 기준: 대기/걷기/달리기 허용, 사망/실제 공격 중6개 변경 경로 거부, 같은 타입 다른 GUID 교체 하한, 반복 입력/동일 GUID 중복 거부, 자원 콜백 재진입 거부, 무적 없음. 기존16개 회귀 유지.
- 검증: UE5.8.3 Editor 빌드, NullRHI 자동화 및 가능한 실제 공격 경로. 실제 렌더링·입력 검증과 구분한다.
- 롤백: 본 소스·테스트 묶음만 되돌릴 수 있다. 원본/세이브/맵/저장 스키마와 기존 커밋은 보존한다. merge/push/PR 없음.

후속 승인: 사용자가 큰 기능 완료 후 GitHub commit/push를 승인했다. main 병합/강제 push/삭제/PR은 승인하지 않았다. 로컬 선행 원시 로그에 기기 식별자가 있어 원래 작업 이력을 재작성하거나 그대로 공개하지 않는다. 별도 공개용 브랜치에 기능별 코드·문서와 식별자 없는 검증 요약을 담고 일반 push 후 원격 SHA를 확인한다. 원본 증거는 로컬 작업 브랜치에 보존한다.

공격 중 여부를 긴 재사용 대기시간으로 대신하지 않는다. 공격 수락 중 재진입과 차지 입력을 차단하고, 수락한 몽타주 길이와 지연/다단 판정 시각의 최댓값을 행동 경계로 사용한다. 발사 후 비행 시간은 시전자 행동 시간에 더하지 않는다. 이동은 Walking/NavWalking에 한정하고 회피 및 재생 중 몽타주는 보수적으로 차단한다. 일반 피격/시전 전용 상태 머신은 아직 없으므로 존재한다고 주장하지 않는다.

기존 프로토타입 BeginPlay 장착과 저장 복원은 명시적인 초기화 문맥을 유지한다. 게임플레이 인벤토리 명령은 별도 우회 플래그를 노출하지 않는다. 기존 저수준 Character 타입 setter는 QA/프로필 설정용으로 유지하며 소유 아이템을 장착하는 사용자 명령으로 사용하지 않는다.

아이템 InstanceId가 동일한 복제 참조는 거부해 중복 장착 효과를 막는다. GUID가 없는 레거시 임시 아이템은 성공 시에만 GUID를 부여한다. 기존 세이브 파일을 수정하거나 버전을 바꾸지 않는다. 교체 트랜잭션 중 중첩 장착과 공격 수락을 막아 알림 재진입으로 반쯤 갱신된 상태를 소비하지 않게 한다.

Ctrl/Q/E/R 4슬롯 프리셋은 이 상태 경계를 통과한 후 별도 묶음으로 분리할 수 있다. 물리 키/E 회피 충돌, HUD, 독립 스킬 쿨타임, 메뉴 정지는 이번 수용 조건이 아니다.
