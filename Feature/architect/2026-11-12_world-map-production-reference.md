# 월드맵 실제 제작 참조 통합 계획

2026-11-12 한국 시간. 작업 브랜치 `Sprint#9-31-world-map-production-reference`. 목표는 이 채팅의 최신 결정과 생성 지도를 실제 맵 제작자가 놓치지 않고 참조하도록 문서·계획 데이터를 연결하는 것이다.

## Scope Gate

- 변경: 문서, 생성 PNG의 프로젝트 내 보존, 계획 JSON, 제작 진입 안내.
- 보존: 기존 dirty Source/Config/Content/세이브와 과거 기록. 이번 작업에서 `.uasset`/`.umap`·런타임·에디터·빌드 설정은 수정하지 않는다.
- 실제 맵 제작/몬스터 AI/비급 시스템 구현은 다음 패킷 범위다. 문서 작업 완료를 게임 기능 완료로 표현하지 않는다.
- 현재 shared checkout의 기존 변경을 보존하고 별도 작업 브랜치로 전환했다. 무관한 파일을 스테이징하거나 통합 승격하지 않는다.

## 최신 결정의 반영 범위

큰 마을3+전문초소5+사냥터5, 일반15종과 중간4/최종1 분리, 중앙 직행60초/선택 성장15분 입구/20분 상한, 시작 마을과 필드 분리, 무기별 선택적인 동시·차징 기술, Ctrl→첫Q부터 고정시간→QQQ 자동 마력미사일, 하위 비급만 직접 수련 보상·중상위 비급은 현장 발견, 런 성장/영구 정보 분리를 통합한다.

## 이번 검증 계획

JSON 구문과 참조 무결성, 일반15/중간4/최종1의 독립 집계와 로스터ID,21개 노드·29개 양방향 연결·경로 연결·거리·숨은 평면 교차,20근접+3마법 비급과 직접 보상의 하위 한정,새 PNG 원본 해시와 로컬 링크를 확인한다. 기존 dirty 파일은 의도한 로그 외 해시 보존을 확인한다. 실제 엔진·물리 입력·전체 런 검증은 P1 이후로 남긴다.

## Exit Gate

- 참조 묶음과 제작자 진입 경로가 실제 파일에 반영됨.
- 검사 결과와 범위·남은 미정 사항을 짝 결과에 기록.
- DevLog와 Sprint 기록 갱신.
- 완료된 문서만 scoped commit 대상으로 검토. 기존 미검증 gameplay/WIP를 포함하는 승격은 하지 않으며, remote 확인 후 통합 장애가 있으면 기록.
