# 전투 HUD A안 실제 적용

승인 기준은 1672×941 [A안 원본](../doc/evidence/main-combat-hud-concept-20261121/layout-a-single-row.png)이다. 좌측 상단 체력·스태미나·레벨·경험치와 하단 왼쪽부터 회피·공격 6칸·대검 원형 게이지, 공격 아래 잠금 4칸을 맞춘다. 검게 처리된 금속 프레임, 청동 테두리와 대검 아이콘은 사용자 승인 PNG에서 분리해 사용한다. 원본의 104/135, 64/100, LV 8, 72%는 시각 QA를 위한 예시 상태다. 게임에서는 현재 값·장비·해금·쿨다운·회피를 표시한다.

작업 브랜치는 `Sprint#15-1-combat-hud-a`다. 기존 게임 코드, 저장, 맵 변경을 새 작업에 포함하지 않는다. 현 작업 폴더의 로컬 수정은 보존하며 게시할 변경은 최신 통합 브랜치와 비교한다.

| 작업 | 범위 | 완료 조건과 검증 | 되돌릴 범위 |
| --- | --- | --- | --- |
| A안 아트 | 승인 PNG, SourceArt, Unreal 텍스처 | 원본 프레임과 아이콘을 알파 아틀라스로 분리한다. 추출기를 다시 실행한 해시와 공식 Unreal Editor 임포트 결과를 확인한다. | 새 SourceArt, 추출기, 아틀라스 패키지 |
| 실제 HUD | Main HUD, A안 네이티브 표시 | 기존 Main에서 사용하고 뷰포트가 바뀌어도 좌측 상단과 하단 앵커가 유지된다. 실시간 HUD 뷰, 장비별 그림과 입력 상태를 연결한다. `Scripts/BuildEditor.ps1 -NoHotReload`로 빌드한다. | Main의 A안 옵션과 새 네이티브 위젯 |
| 런타임 QA | 전용 런타임 검증, 자동 캡처, 출력 로그 | 1672×941에서 원본 좌표를 대조하고 1280×720 축소를 확인한다. 실제 캐릭터 상태를 바꿔 패널 갱신을 검사하고, 새 로그의 오류와 기존 저장 해시를 확인한다. | 전용 검증 코드와 이번 증거 |

기존 HUD 슬롯과 수치 API를 재사용한다. 관련 Fab 가이드와 기존 HUD 아트 위치를 확인했으며, 이번 A안 프레임은 사용자가 선택한 프로젝트의 ImageGen 시안을 원본으로 삼는다. 별도 Fab 에셋 도입 없이 기존 직업 아이콘을 사용한다. 게임 화면 캡처는 실제 카메라·맵·캐릭터 상태로 검증하고, 픽셀 기준 비교는 같은 해상도에서 HUD 마스크와 요소 경계에 맞춘다.
