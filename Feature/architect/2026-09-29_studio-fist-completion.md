# 스튜디오 맨손·너클 작업 인계와 완료 검증

브랜치: Sprint#5-3-studio-task-completion
등록 작업: 85585afd-1a57-490f-a52f-95e22987fa2c

사용자가 확인 필요를 스스로 해결하고 완료까지 진행하도록 요청했다. 원 작업 채팅의 완료 결과와 현재 다른 활성 작업 없음, 같은 제목·범위의 기존 소스·자산·문서를 확인했다. 기존 미커밋 구현은 이 요청의 기준 구현으로 인계받고 보존한다. 확인 필요의 원인이었던 인계 판단을 coordinator가 확정하며 중복 제작하지 않는다.

패킷 A: 기존 파일·원본/최종 SHA·문서 검토. 두 독립 검토자가 제작 소스 및 검증 증거를 분리 검토한다. 완료 조건은 현재 구현과 근거가 연결되고 알려진 중대 결함이 없다는 것이다.

패킷 B: 통합 담당자 한 명이 BuildEditor.ps1, 실제 FistCombat의 9종 공격·14회 피해·840프레임, ThirdPersonInspection·AppearanceCamera 회귀를 순차 실행한다. 새 출력 label로 기존 증거를 보존한다. 필요하면 실패 원인만 수정하고 같은 실패를 무조건 반복하지 않는다.

패킷 C: 실제 최신 자세 CSV에서 유한값·본 길이·카메라 상한을 재집계하고 기존 6체형 검증 및 시각 자료와 대조한다. 최종 결과와 한계를 문서화한 후 queue progress/finish로 검증 대기에서 완료로 이동한다.

롤백 경계는 이번 검증 결과·스튜디오 진행 기록·완료 문서다. 기존 게임 소스/애셋/미커밋 변경을 정리하거나 되돌리지 않는다. 커밋·푸시·배포·승인 정책 확장은 하지 않는다. 사용자가 중단하면 진행을 멈춘다.
