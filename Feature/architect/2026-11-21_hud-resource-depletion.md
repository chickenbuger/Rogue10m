# 전투 HUD 자원 소모 애니메이션

`Sprint#17-2-hud-resource-depletion`은 통합 기준 `a9746019`의 전투 HUD A안에서 큰 폭의 자원 소모를 읽기 쉽게 표시한다. 기존 1280×720 게임 화면을 참고해 내장 ImageGen으로 스태미나 83 → 61 → 38의 세 장면을 먼저 구성했다. [시각 초안](../doc/evidence/hud-resource-depletion-20261121/imagegen-draft.png)의 목표 지점과 줄어드는 채움 사이 색 차이를 기존 HUD 아틀라스에 적용한다. 기존 프레임, 채움 텍스처와 원형 링을 재사용한다.

체력과 표시 중인 스태미나·마나, 스킬 발동에 소모되는 아이덴티티 게이지에 적용한다. 한 번의 갱신에서 최대치의 10% 이상 감소하면 현재 표시 위치부터 목표까지 약 0.4초 동안 끝에서 감속하며 줄인다. 숫자도 표시 위치에 맞춰 내려간다. 목표 지점부터 현재 표시 끝까지의 소모 구간은 기존 색보다 조금 어둡게 칠하며, 목표 지점에 가까울수록 짙다. 원형 아이덴티티는 같은 방식으로 목표 각도부터 움직이는 끝까지 표시한다. 질풍투기의 지속·재사용 대기시간, 경험치와 A안 이전 레이아웃은 범위에서 제외한다.

| 작업 | 범위 | 완료 조건과 검증 | 되돌릴 범위 |
| --- | --- | --- | --- |
| 자원 표시 상태 | 전투 HUD A, Main HUD의 기존 갱신 흐름 | 최초 값은 즉시 표시한다. 연속 소모는 움직이고 있던 위치에서 새 목표로 이어지고, 표시 끝 아래의 작은 회복은 애니메이션을 끊지 않는다. 자원 종류·최대치·표시 대상 변경 시 현재 값부터 다시 표시한다. 실제 게임의 자원 값과 소모 판정은 기존 경로를 따른다. | 표시 상태, 갱신과 페인트 코드 |
| 색상과 숫자 | 기존 직선 채움과 원형 링 | 남는 구간과 소모 구간을 구분하고 목표 지점에 닿으면 어두운 구간을 없앤다. 숫자와 끝 위치가 함께 목표에 수렴한다. | 페인트의 색상·끝 위치·숫자 계산 |
| 빌드와 게임 검증 | 독립 작업 트리의 Editor 빌드, StartHub 런타임 QA | 해당 작업 트리에서 `Scripts/BuildEditor.ps1 -ProjectRoot (Get-Location).Path -NoHotReload`와 `Scripts/VerifyCombatHudA.ps1`을 실행한다. 격리된 프로필에서 초기값, 큰 소모, 연속 소모, 회복, 최종값, 자원 전환을 측정하고 1672×941·1280×720 게임 화면에서 변화와 대비를 확인한다. 실제 `-AbsLog` 경로의 로그와 기존 저장 해시를 확인한다. | 검증 코드와 이번 증거 |

애니메이션 시점은 자원 변화 감지, 진행 중, 최종 수렴으로 기록한다. 테스트의 프로그램 입력과 실제 렌더링 여부를 구분하고, 측정값과 실제 화면의 색상 판정을 함께 남긴다.
