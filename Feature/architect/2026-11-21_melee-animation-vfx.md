# 너클·대검 공격 VFX 설계

기본 3인칭 전투에서 준비, 손·검날의 움직임, 판정 범위, 적중 순간을 알아볼 수 있게 한다. 일반 잽과 베기는 짧은 선으로 읽히게 하고 상위 무공은 흐름을 유지하면서 잔상 층과 분진을 추가한다.

## 작업 패킷

| 작업 | 수정 위치 | 완료 및 검증 | 되돌리기 경계 |
| --- | --- | --- | --- |
| 시각 초안 | 기능 증거의 ImageGen 시트와 프롬프트 | 너클과 대검을 기본·숙련·최상위에서 비교 | 초안과 프롬프트 두 파일 |
| 실제 전투 연결 | CombatComponent와 공격 판정 시각화 보조 코드 | 기존 공격 단계와 애니메이션을 사용한다. 피해가 발생한 표면에 짧은 섬광이 뜨고 빗나가면 섬광이 뜨지 않는다. 순수 기하 자동화 검사와 실제 전투 런타임 검사 | 전투 연결과 신규 VFX 코드 |
| 효과 제작 및 QA | 궤적 컴포넌트와 프로젝트 재질 | UE 5.8 빌드, 에디터 재질 저장과 다시 로드, 기본·상위·빗나감 렌더와 출력 로그 검사 | 신규 재질, 렌더링 코드, 검증 도구 |

## 자산과 연출

10월 19일 Fab 보유 조사에 기록된 Slash Trail FX Elemental은 이번 작업 사본과 로컬 VaultCache에서 확인되지 않았다. 현재 코드에는 프로젝트 소유의 시전·적중 Niagara 원본이 연결되어 있다. 검토한 궤적 후보는 한 장의 스프라이트를 사용한다. 검날과 손을 매 프레임 따라가는 잔상에는 별도의 재질과 런타임 메시가 필요하다. 기존 Niagara 시전·충전·적중 참조와 편집값은 유지하고, 근접 적중용 Niagara와 신규 섬광에 같은 표면 좌표를 준다.

기본 단계는 가볍게 시작하고 상위 단계는 카탈로그에 설정된 숙련 요구를 따른다. 캐릭터의 현재 숙련으로 기본 공격이 화려해지는 일은 없다. 주황·금색은 너클, 청색·청록은 대검에 적용한다. 근접 피해 판정은 오버랩과 각도 필터를 사용한다. 범위선은 판정에 쓰인 도형을 수평으로 투영한 윤곽이며, 타격점은 피해 전 무기 포즈와 대상 충돌 표면을 이용한 시각화 좌표다. 실제 대미지, 판정 타이밍, 자원과 입력은 유지한다.
