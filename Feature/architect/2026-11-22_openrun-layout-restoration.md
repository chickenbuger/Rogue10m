# OpenRunMap 기존 배치 복구와 외곽 정리

사진의 수렵촌, 장터, 기록 마을과 둘레 능선은 보관된 `WorldLayoutCompactCrop20261114A`에서 확인했다. 작업 브랜치 `Sprint#17-1-combat-key-remap`에는 지형과 동굴을 옮겼던 `5d23f12e`의 맵 패키지 80개가 아직 들어오지 않았다. 활성 레벨은 `/Game/Rogue10m/Maps/OpenRunMap`이다.

| 작업 | 작업 범위와 완료 조건 | 검증과 복구 경계 |
| --- | --- | --- |
| 지형과 동굴 | 검증된 복구 커밋의 Landscape 및 Q/Z 동굴, 도로와 마을 바닥 패키지를 복원한다. | 대상 80개의 Git 객체 해시를 대조하고 Unreal에서 다시 로드한다. 배치 재작업 전 이 상태를 기준으로 둔다. |
| 마을 배치 | 보존된 H/M/T 건물, 울타리와 주변 장식을 같은 좌표로 옮긴다. 보관본의 프로젝트 자산과 기존 `Stylized_Village`를 재사용한다. | 로드한 액터와 배치 수를 대조하고 뷰포트에서 갈색 바닥, 출입구, 연결로를 확인한다. 복구된 액터 패키지가 변경 경계다. |
| 외곽 정리 | 남쪽 도착 지점, 서쪽 다리, 중앙로, 두 동굴과 북쪽 보스 구역에 필요한 지면과 충돌을 유지한다. 활성 경로 바깥의 경계와 남은 제작용 구조를 검토한다. | 손대는 범위를 액터와 좌표로 확인하고 시작·교량·보스 쪽을 검증한다. Landscape를 조정할 경우 복구된 컴포넌트와 대조한다. |

보관 후보의 45개 컴포넌트 경계는 활성 맵의 남쪽 포탈 도착과 기존 다리를 포함하지 않는다. 배치 판단은 기존 월드 제작 가이드와 지형·획득 카탈로그, 자연 경계 및 동굴 제작 기록을 따르며 패키지는 Unreal Editor에서 저장한다.
