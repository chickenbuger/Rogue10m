# Rogue10m 인벤토리 UI 기획

`I`로 가방을 열면 아이템이 차지하는 공간, 비어 있는 칸, 현재 장착품과의 차이가 한눈에 보여야 한다. 기존 고딕 프레임의 검게 그을린 금속과 황동 테두리를 살리고, 그리드와 툴팁을 읽는 데 필요한 대비를 높인다.

## 화면 설계

| 영역 | 제안 |
| --- | --- |
| 제목 바 | 왼쪽의 독립 창에 **인벤토리** 제목과 작은 `I` 키 안내를 둔다. 제목 바를 잡아 옮기고, 창을 누르면 앞으로 올라오는 기존 조작을 사용한다. |
| 그리드 | **10열 × 10행**을 한 화면에 표시한다. 기본 44px 셀, 440×440 논리 크기의 그리드와 아이템 캔버스를 같은 좌표에 둔다. 빈 칸은 짙은 무채색과 가는 선, 점유 칸은 아이템 하나당 하나의 연속 배경으로 표현한다. |
| 아이템 | 등급색은 낮은 채도의 아이템 배경과 이름에 사용한다. 호버는 밝은 상아색 외곽선으로 구분한다. 포션 수량은 셀 오른쪽 아래에 표시한다. |
| 하단 정보 | 골드는 왼쪽, 가방 무게와 기준값은 오른쪽에 배치한다. 액자 안쪽에 충분한 여백을 둔다. 현행 무게는 가방 속 각 아이템의 단위 무게 × 수량의 합이며, 기본 기준값은 100kg이다. |
| 호버 툴팁 | 아이템 이름과 행동 안내를 먼저 읽게 한다. 설명, 무게, 능력치를 기존 데이터로 출력한다. 같은 부위에 장비가 있을 때 현재 장착품과 증감 행을 함께 표시한다. 화면 오른쪽 공간이 부족할 때는 왼쪽 또는 위쪽으로 옮겨 그리드를 가리지 않게 한다. |
| 장비창 | `P` 장비창을 독립적으로 열고 `I`와 함께 사용할 수 있게 한다. 능력치, 캐릭터 프리뷰와 7개 부위(투구·목걸이·갑옷·장갑·무기·신발·반지) 배열을 따른다. |

## 조작과 상태

| 상황 | 기존 동작과 표시 제안 |
| --- | --- |
| 아이템 위치 이동 | 좌클릭 드래그는 잡은 칸을 기준으로 움직인다. 놓을 수 있는 위치는 녹색 테두리와 체크, 겹침·경계 밖은 붉은 테두리와 금지 표식으로 구분한다. 유효한 위치에서 놓을 때만 이동한다. |
| 장비 장착·교체 | 가방에서 장비를 우클릭하거나 맞는 장비 슬롯에 드래그한다. 교체되는 장비는 새 장비가 있던 위치부터 맞는 공간을 찾는다. 들어갈 자리가 없으면 두 아이템을 원래 위치에 두고, 구현 시 공간 부족을 짧게 알려준다. |
| 장비 해제 | 장비 슬롯을 우클릭한 뒤 **장착 해제**를 선택하거나, 슬롯에서 가방의 유효한 위치로 직접 끌어온다. |
| 회복 포션 | 가방에서 우클릭한다. 실제 회복에 성공했을 때 수량을 1 줄인다. 최대 체력이라면 수량을 유지한다. |
| 창 열기와 닫기 | `I`와 `P`는 각각 토글한다. 독립 실행의 안전 구간에서는 기존 메뉴 일시정지를 적용한다. 필드에서는 기존 진행 상태에서 창을 사용한다. |

기존 조작을 제목 바와 해당 아이템의 툴팁에서 안내한다. `I` 키 안내, 상아색 호버 테두리, 배치 가능 여부를 나타내는 보조 표식, 화면 가장자리에서의 툴팁 이동과 공간 부족 안내는 이번 기획에서 제안한 표시다.

## 시안 데이터와 에셋

| 아이템 | 점유 크기(가로 × 세로) | 예시 수량 |
| --- | --- | --- |
| 철제 장검 | 1×3 | 1 |
| 수호자의 투구 | 2×2 | 1 |
| 가죽 갑옷 | 2×3 | 1 |
| 회복 포션 | 1×1 | 4 |
| 초심자의 반지 | 1×1 | 1 |
| 가죽 장화 | 2×2 | 1 |

수호자의 투구에 마우스를 올리고 현재 장착 중인 철제 투구를 비교하는 장면을 대표 상태로 선택했다. 방어력은 +10과 +5, 최대 체력은 +20과 +10이다. 가방 속 예시 무게의 합은 12.8kg이며 골드 120은 표시용 수치다.

후속 UMG 작업은 프로젝트의 [고딕 프레임](../../Content/UI/HUD/Gothic/T_UI_GothicInventoryFrame.png)과 기존 Item Data Asset의 아이콘을 먼저 사용한다. ImageGen의 마을과 아이콘은 화면 배치와 분위기를 보여 주는 예시다. 적용 시 런타임 창의 타입과 기존 현지화 텍스트를 사용한다. [Fab 에셋 재사용 가이드](../../Docs/FabAssetReuseGuide.md)

## 작업 범위와 적용 검증

- **이번 작업**은 기존 동작 조사, 시안 1장, 정확한 격자 배치 기준, 생성 프롬프트와 기획 기록이다. 완료 기준은 PNG 디코딩과 한글·격자·점유 형태의 시각 검토다. 되돌릴 때는 이번 문서·이미지와 추가한 일지 항목만 제거한다.
- **후속 적용**은 `WBP_InventoryWindow`, `WBP_InventoryCell`, `WBP_InventoryItem`, `WBP_InventoryItemTooltip`의 표시부터 다룬다. `UI_InventoryGrid`와 `UI_InventoryItemCanvas`의 원점·크기 및 필수 바인딩을 유지하고, 이동·장착·소비는 기존 `URogue10mInventoryComponent` 경로를 사용한다. [UMG 생성 스크립트](../../Scripts/Editor/BuildMenuDesignerLayouts.py) · [메뉴 위젯 C++](../../Source/Rogue10m/UI/Widgets/Rogue10mMenuWindowWidgets.cpp)
- **후속 검증**에서는 1920×1080과 1280×720의 실제 게임에서 격자 100칸, `I`·`P` 동시 열기와 닫기, 제목 드래그, 툴팁 비교 및 화면 가장자리, 1×3 위치 이동과 2×3 경계 충돌, 가방 여유가 없는 장비 교체, 최대 체력에서 포션 수량 유지, 저장 후 배치 복원을 확인한다. 에디터를 사용할 때는 해당 세션의 실제 출력 로그를 확인한다. [출력 로그 검사 절차](../../Docs/OutputLogErrorWorkflow.md)
