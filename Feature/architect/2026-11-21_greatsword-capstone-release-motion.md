# 패왕참 발동의 양손 베기

배포 기준 `55ab2ddc`의 패왕참은 실제 우클릭을 뗀 뒤 맨손 `MM_ChargedAttack`을 재생한다. 실제 720p 실행에서 손목 간격이 최대 98.44cm였고 306개 공격 표본 중 292개가 33cm를 넘었다. 기존 Blender 차징 준비 자세와 그 가중치는 그대로 사용한다. 목표는 준비와 발동의 첫 프레임을 잇고 손잡이를 양손으로 따라가며 한 번 크게 벤 뒤 기존 가드로 돌아오게 하는 것이다.

프로젝트에 있는 Mixamo 기반 `A_GreatSword_Charged`와 현재 대검 `A_GreatSword_Idle`을 Manny 골격 FBX로 내보낸다. Blender에서 차징과 이어지는 시작 자세, 정면을 향하는 한 번의 베기, 회복만 편집한다. 발·골반을 포함하는 자세는 캡슐의 루트를 기준으로 반입한다. 작업용 FBX와 .blend는 로컬에 둔다. 새 시퀀스와 기존 몽타주의 설정을 이은 파생본을 패왕참 데이터 한 건에 연결한다.

실제 RMB 기준을 먼저 저장하고, 같은 60Hz 실행에서 홀드의 마지막 프레임, 발동의 첫 표시와 최초 피해, 전체 검 궤적, 실제 캡슐 교차와 회복을 비교한다. 0.72초 차징, 입력 수락과 같은 틱의 단발 피해, 360cm 부채꼴 범위, 스킬 배속 0.62, 1.833333초 몽타주, 기존 노티파이와 루트 설정을 대조한다. 짧은 떼기, 취소, 기존 대검·너클 공격을 회귀 실행한다. 대기·발동·회복의 전체 실루엣을 720p로 확인한다. 이전 패왕참 몽타주 연결을 복구하면 이번 발동 동작만 되돌릴 수 있다.
