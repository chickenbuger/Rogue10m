# 스킬별 모션·VFX 상세 제작 설계안

작성: 2026-11-10. 상태: **100개 활성 후보의 사전 제작 기획**. 이 문서는 신규 동작·효과의 구현 완료 보고가 아니다. 기존 몽타주, HitStartDelaySeconds, 타수, 피해, 자원, 밸런스, 입력 및 안전 카메라 정책은 이 작업에서 변경하지 않았다.

## 1. 읽는 법과 확정 범위

- 기준 목록은 [WeaponClassDesign.md](WeaponClassDesign.md)의 너클·대검·미래 8무기 각 10개다. 이름과 공용6/좌우동시2/우차징2 분배, 이하 동작·타수·형태·색·강화는 **제안**이다. 후보10개를 모두 동시에 쓰는 것이 아니다.
- 사용자 확정 구조는 무기당 최대6개: Q/E/R/짧은 RMB 공용4, 좌+우 동시 전용1, RMB차징 전용1. 기본공격·패시브·Ctrl은 별도이며 전용기술의 공용슬롯 교차장착은 금지다. 무기 미장착 뉴비는 좌클릭 주먹질만 사용한다.
- 본문의 `공용`, `동시`, `차징`은 후보 허용 슬롯이다. 공용6개 중4개, 각 전용후보2개 중1개를 선택하는 구성안이다. 특정 기술을 Q/E/R로 영구 고정하지 않는다.
- 너클은 **체술 공통 설계**로 작성했다. 내공/투지/마나 계열 구분, 자원명·허용 계열과 계열 전용 강화는 사용자 결정 전 보류한다. 흰 궤적·금색 접점은 시각 제안이지 속성·자원 확정이 아니다.
- 대검은 일반 / 투지→광전사 / 마나→화염 방향을 구분한다. 활성 방향·자원은 하나이며 광전사와 화염을 겹치지 않는다. 일반의 새 Ctrl 기능, 일반기술 MP 소모, 소모량·계수는 미정이다.
- 너클 Ctrl의 기간제 공속·이속·스킬강화·소폭 공격력, 주변 오라와 PP는 사용자 확정 방향이다. 8초/30초쿨/공속25%/이속20%/피해8%/범위10%는 현재 실험 가정이지 확정 밸런스가 아니다. 본문의 고유 강화는 모두 후속 제안으로 현재 공통 범위 보정을 넘어서는 내용이다.
- 미래8무기의 이름·Ctrl·자원은 모두 후보다. 마법사는 별도 명령 체계이므로 이 100개나 근접10/6틀에 포함하지 않는다.


### 최신 제작 순서와 원본 후보 보완

사용자의 최신 우선순위는 **Fab/Mixamo에서 실제 사용할 애니메이션을 먼저 선택하고, 그 동작에 다양하고 판타지다운 VFX를 연결해 구현**하는 것이다. 아래 목표 포즈를 억지로 맞추기보다 확보한 원본의 무게중심·접촉·회복에 맞춰 기획을 조정한다. 이미지와 이 문서는 구현 완료 증거가 아니다. 현재 1인칭 작업/검증은 일시 중단 상태이며 아래 1인칭 시인성 권고는 후속 범위다.

로컬 원본 조사에서 CloseCombatAnimSet의 `Animations/InPlace/Attacks/NinjaRightUppercut`, `NinjaLeftHook`, `NinjaLowRightThaiKick`, `NinjaStraightKick` 에셋과 `UE4_Mannequin_Skeleton`이 확인되었다. 이는 현재 계정의 Fab 소유·라이선스·UE5.8 호환·Manny 리타겟·실제 접촉 검증 완료를 뜻하지 않는다.

- 금강쇄의 현행 안전 구현이 마무리 단발이라는 사실은 유지한다. 어퍼컷 목표에는 NinjaRightUppercut **로컬 원본 후보가 확보**되었으며, 선정·리타겟·접촉 검증은 아직 남았다.
- 유운수의 현행 훅과 패리 판정 미구현을 구분한다. 훅 동작 후보가 있어도 방어/성공 판정은 C++ 기능을 별도로 구현해야 한다.
- 파진각의 킥에는 NinjaLowRightThaiKick/NinjaStraightKick 후보가 있다. 후보 존재와 실제3인칭 적용·타격 프레임 검증을 분리한다.
- 태산압정의 도약 슬램과 철산고의 어깨 충돌은 이 조사에서 적합한 원본을 확보하지 못했다. 해당 새동작을 완료로 표시하지 않는다.

## 2. 공통 모션·판정·연출 계약

### 2.1 준비 → 접촉 → 회복

1. **준비**: 손·무기·체중의 방향으로 다음 공격 영역을 먼저 읽게 한다. 목표 방향을 바꾸는 허용 구간과 확정 시점을 후속 구현 데이터로 분리한다. 준비 전체가 자동 무적/슈퍼아머인 것은 아니다.
2. **접촉**: 첫 피해 때 실제 주먹·검날·화살 또는 승인된 충격파가 판정 지점에 도달해야 한다. 긴 빛 꼬리의 끝까지 피해를 늘리지 않는다. 허공에는 명중 폭발을 재생하지 않는다.
3. **회복**: 팔·무기를 억지 순간이동시키지 않고 제동→체중 회수→가드로 이어간다. 강한 기술은 회복 자세로 빈틈을 보이고, 그 뒤에만 다음 공격 연결을 연다. 세부 취소 창은 미정이며 기존 창을 임의 덮어쓰지 않는다.

아래는 초 단위로 강제하지 않은 포즈 설계다. 스토리보드의 세 장은 같은 길이의 시간 구간을 뜻하지 않는다. 실제 제작 때 현재 몽타주 시간, 재생률, 공속과 HitDelay를 먼저 기록하고 기존 접촉을 보존한 파생본을 평가한다. 회전·도약·킥은 목표 콘셉트일 뿐 기존 안전모션 정책을 해제하거나 즉시 원복하는 지시가 아니다.

### 2.2 판정과 중복 방지 제안

- 단발은 승인된 실행 하나당 대상 하나에1회. 연타는 실행ID+의도된 타격번호+대상으로 중복 방지한다. 여러 프레임/여러 뼈/겹친 볼륨에 닿아도 그 타격번호에서는1회다. 기존 ExecutionId 경로를 존중하며 새 Notify에서 피해를 중복 호출하지 않는다.
- 여러 투사체가 같은 대상을 치는 산개형은 별도로 지정한 상한을 따른다. 투사체 개수와 피해 횟수는 같다고 가정하지 않는다. 반사·왕복·지속영역은 횟수/주기/동일대상 상한을 명시한 뒤 구현한다.
- 밀기·띄우기·다운·경직은 대상의 질량/면역에 따른다. 보스는 강제 이동 대신 자세 누적 등의 대안이 필요하며, 그 수치는 미정이다. 벽 관통, 적 캡슐 통과, 지형 밖 도약을 그림만으로 승인하지 않는다.
- 반격의 성공 판정과 시각 불꽃을 분리한다. 방어 가능 방향/시간/공격유형, 실패 회복, 반격 발동 횟수, 성공 후 재입력 여부를 구현 전에 확정한다. 본문의 반격은 자동무적 승인안이 아니다.
- 차징은 준비 표시→완료 표시→방출→회복으로 구분한다. 완충이 자동 발사라는 뜻은 아니다. 부족 차지/중단/메뉴/사망/무기교체 때 기존 입력·취소 계약을 우선하고 VFX가 남지 않게 한다.

### 2.3 시각 언어와 접근성

- 준비는 작은 점/얇은 선, 실제 접촉은 짧고 선명한 형태, 회복은 빠르게 사라지는 잔광으로 구분한다. 위력은 화면 전체 백색 플래시보다 접점의 형태·입자 운동·짧은 음향 정지감으로 전달한다.
- 기본 물리는 회백 궤적+재질별 파편. 너클은 짧은 압축 링, 대검은 넓고 무거운 초승달, 단검은 바늘/절개, 쌍검은 엇갈린 이중 호, 활은 직선 화살, 표창은 회전 궤적, 쌍단검은 짧은 갈고리, 장검은 단정한 한 줄, 대방패는 판/지면 균열, 버클러는 점 불꽃으로 읽는다.
- 색은 보조 단서다. 광전사는 적갈색 톱니 충격, 화염은 주황 외곽·황백 접점과 위로 타는 입자를 쓰되 서로 배타적이다. 적의 공격 예고와 플레이어 잔상은 채움/테두리/움직임으로도 구별한다.
- 1인칭 손/무기, 3인칭 캐릭터 전체, 다수 적, 벽 옆, 밝고 어두운 배경에서 따로 검사한다. 손 앞 불투명 원판·전면 장막·과한 카메라 회전·강한 색수차·지속 섬광을 피한다. PP 강도와 화면 흔들기는 접근성 옵션으로 줄일 수 있는 후속안이다.
- 이동 궤적은 실제 경로만 따른다. 금속 불꽃은 금속 접촉에, 흙먼지는 지면에만 낸다. 혈흔은 비고어 상태표식으로 대체 가능하게 하며 캐릭터 외형과 적 실루엣을 가리지 않는다.
- VFX는 피해를 결정하지 않는다. 실행 승인/실제 명중/종료 이벤트를 각각 구독하는 표현층으로 제작한다. 종료·취소·사망·무기교체 때 루프·디칼·사운드를 정리하고 성능 제한은 실제 프로파일 결과로 확정한다.

## 3. 우선 제작: 너클 10개

모든 너클 강화는 Ctrl 공통 상태에 대한 **스킬별 미래 후보**다. 주변 오라는 낮은 불투명도의 몸 윤곽 흐름과 발 부근의 짧은 상승 입자로 제안한다. 너클 손의 접촉 실루엣을 가리는 커다란 구체는 쓰지 않는다. PP는 상태 진입·유지·종료를 읽히게 하되 영구 화면 착색을 피한다.

### K01 연환권 · 공용
- **콘셉트/의도**: 가드를 크게 풀지 않는 짧은 3연타. 기본 좌클릭 연계 사이의 확실한 빈틈을 소화하되 기본공격과 독립된 활성기술로 읽힌다.
- **동작**: 준비는 왼 어깨를 좁히고 앞발에 체중을 싣는다. 접촉은 왼 잽→오른 직선→짧은 왼 훅, 매번 반대손은 턱을 지킨다. 회복은 마지막 훅을 가슴 앞으로 접어 양손 가드로 복귀한다.
- **범위/히트**: 근거리 정면의 작은 주먹 스윕3회 제안. 각 타격번호별 대상1회, 몸 전체 큰 구형판정으로 옆·뒤를 치지 않는다. 추적은 준비 중 방향 보정만 허용하는 안이다.
- **VFX**: 시작에 전완의 짧은 회백 선, 접촉마다 작은 평평한 금색 링3개, 마지막 링만 조금 두껍게. 회복에는 손을 따라 잔선이 끊기며 사라진다. 허공 타격에는 링 대신 짧은 바람만 남긴다.
- **위험/강화**: 사거리가 짧아 빗나가면 마지막 훅 회수가 노출된다. Ctrl 후보는 마지막 접점의 충격 강조이며 추가 피해 펄스는 별도 승인 전 넣지 않는다.
- **원본/차이**: 10/2 기록은 AM_Knuckle_Jab 단발 연결. Primary01과 좌클릭이 같은 원본을 쓰던 문제를 별도 활성로 이중 집계하지 않는다. 독립 3연타·타수·강화는 새 제안이다.

### K02 붕권 · 공용
- **콘셉트/의도**: 발→골반→어깨→주먹의 한 줄로 힘을 모으는 전진 정권. 짧은 접근과 좁은 방향의 강타를 결합한다.
- **동작**: 준비는 뒷주먹을 허리 옆으로 당기고 앞발을 낮춘다. 접촉은 한 걸음과 동시에 골반을 열며 정권을 뻗는다. 회복은 팔꿈치를 접고 앞발에 실린 체중을 중립으로 돌린다.
- **범위/히트**: 전방 짧은 캡슐 스윕1회. 이동 경로를 무한 판정하지 않고 접촉 구간만 활성화한다. 충돌한 벽 앞에서 멈추며 동일대상1회다.
- **VFX**: 시작은 주먹 뒤쪽으로 모이는 얇은 바람선, 접촉은 전방으로 눌린 흰 원뿔과 금색 핵점, 종료는 옆으로 퍼지는 두 줄의 먼지. 원뿔은 실제 사거리 안에서 닫는다.
- **위험/강화**: 큰 정권 실루엣이 방향을 예고하고 비껴간 적에게 옆구리를 노출한다. Ctrl 후보는 접촉 중심 경직/관통 폭 강화이며 수치와 보스 면역 대응은 미정이다.
- **원본/차이**: AM_Knuckle_BodyStraight 재사용 후보. 현재 지연·root 이동은 보존하며 전진 거리/관통 증가는 별도 콘텐츠·충돌 검증이 필요한 제안이다.

### K03 금강쇄 · 공용
- **콘셉트/의도**: 아래에서 위로 자세를 무너뜨려 후속 연계를 여는 올려치기. 너클의 낮은 자세와 수직 추진을 읽히게 한다.
- **동작**: 준비는 무릎을 굽혀 오른 주먹을 낮춘다. 접촉은 발을 펴며 짧은 어퍼컷으로 턱 아래 방향을 친다. 회복은 팔을 위에 남기지 않고 몸 안으로 접고 낮은 가드로 돌아온다.
- **범위/히트**: 정면 좁은 수직 호1회. 가벼운 적은 작은 띄움, 보스는 자세 누적 대안. 띄운 적 재접촉은 같은 실행에서 추가 피해를 만들지 않는다.
- **VFX**: 시작은 손 아래 작은 압축선, 접촉은 위로 접히는 흰 쐐기와 짧은 금색 수직 파편, 종료는 상승 잔광이 빨리 끊긴다. 화면 중앙을 덮는 기둥은 피한다.
- **위험/강화**: 낮게 앉는 준비와 노출된 회복을 감수한다. Ctrl 후속 내려찍기는 별도 입력/타격이 필요한 후보이며 기본 상태에 자동 추가하지 않는다.
- **원본/차이**: 현재 기록의 AM_Fighter_IronChain_TwoPunch는 두 권 중 마무리 단발이며 어퍼컷이 아니다. 10/5 팔 동작 보강 이력도 보존한다. 올려치기·띄움·후속타 모두 미구현 목표다.

### K04 유운수 · 공용

- **범위/히트**: 전방 작은 부채꼴1회. 체력피해와 자세 누적은 한 접점에서 발생하고 깨짐 상태를 여러 볼륨마다 중복 적용하지 않는다. 보스 누적량/방어유형은 미정이다.
- **VFX**: 시작은 검날 끝의 짧은 떨림, 접촉은 안쪽으로 갈라지는 각진 금속 조각, 종료는 균열 표식이 짧게 닫힌다. 표식 지속과 실제 디버프 지속은 일치시킨다.
- **위험/강화**: 방어한 적에게 무조건 제어를 보장하지 않는다. 광전사=자세 누적, 화염=화상 또는 화염취약 중 선택 후보이며 둘 다 자동 부여하지 않는다.
- **원본/차이**: 기존 파생 DA의 실제 공격은 보존한다. 자세붕괴·화상·취약의 고유 룰과 상태 VFX는 후속 제작 범위다.

### G04 돌진참 · 공용 · 신규
- **콘셉트/의도**: 검을 옆에 붙인 짧은 접근 뒤 종점에서 한 번 베어낸다. 장거리 순간이동 대신 무게 있는 간격 줄이기다.
- **동작**: 준비는 상체를 낮추고 검을 바깥 허리 뒤로 둔다. 이동은 두세 걸음의 낮은 전진, 접촉은 종점 횡베기. 회복은 바깥발로 미끄러짐을 끊고 검을 앞에 세운다.

### G05 반격참 · 공용 · 신규
- **콘셉트/의도**: 두 손 검을 사선으로 세워 받아낸 뒤 무게를 되돌린다. 빠른 버클러 방어와 달리 좁은 기회를 크게 되베는 대검형 반격이다.

- **원본/차이**: 신규 방어/성공/실패 분기와 검 교차 접점이 필요하다. 기존 공격 에셋 이름 변경만으로 반격이 완성되지 않는다.

- **원본/차이**: 신규 후보. 적합한 상향 클립·손잡이 양손 고정·소형 적의 착지 안전을 검증해야 한다.

### G07 대지파쇄 · 동시 전용
- **콘셉트/의도**: 검을 땅에 내리쳐 전방으로 낮은 충격을 보낸다. 원형 포위해제와 다르게 한 방향의 적 줄을 무너뜨린다.

- **원본/차이**: 기존 파생 DA 이름을 보존한다. 실제 지면파·지형 대응·균열 Niagara는 현재 적용으로 간주하지 않는다.

### G08 섬멸연참 · 동시 전용 · 신규

### G09 패왕참 · 차징 전용
- **콘셉트/의도**: 검을 머리 뒤로 오래 모았다가 한 번 크게 가르는 최고 위험 단발. 대검의 준비와 보상을 가장 명확히 보여준다.

- **원본/차이**: 기존 차징 파생 DA와 타이밍을 보존한다. 완충 표시·중심보상·새 화염파는 미구현 제안이다.

### G10 단공참 · 차징 전용 · 신규
- **콘셉트/의도**: 검을 몸 옆에 모았다가 좁은 선으로 돌파하며 베는 기술. 패왕참의 넓은 정지 강타와 달리 위치 변화 자체가 보상과 위험이다.
- **동작**: 준비/차징은 검을 허리 옆으로 낮추고 몸을 옆으로 틀어 길게 모은다. 접촉은 낮은 한 번의 전진과 직선 베기, 회복은 끝지점에서 검을 가로로 들며 길게 제동한다.

- **원본/차이**: 신규 이동공격. 순간이동·적 통과·루트모션·화염 지속영역 어느 것도 현 구현으로 주장하지 않는다.

## 5. 미래 제작: 단검 10개

한 손의 정확한 일격·짧은 이탈이 중심이다. 회백의 가는 절개선과 작은 청록 접점은 시각 후보이며 독/마나 속성을 의미하지 않는다. 후방 조건이 불가능한 보스에도 정면 기본 성능을 남긴다. 급소간파/기회는 미래 Ctrl/단일자원 후보이며 아래 기술에 자동 추가하지 않는다.

### D01 그림자찌르기 · 공용
- **콘셉트/의도**: 짧은 발걸음으로 적 가드 틈에 정확히 들어가는 시작기.
- **동작**: 준비는 검을 옆구리 가까이 숨기고 앞어깨를 좁힘 → 접촉은 앞발과 함께 짧은 찌르기 → 회복은 팔꿈치를 접고 뒷발로 거리를 고정한다.
- **범위/히트**: 실제 접근 끝의 좁은 정면 캡슐1회. 접근선 전체 피해/순간이동 없음, 동일대상1회.
- **VFX**: 시작은 발 뒤 얇은 먼지, 접촉은 바늘 같은 회백선과 청록 점, 종료는 손 회수와 함께 선이 끊어진다.
- **위험/차이**: 좁은 방향이라 측면으로 빗나가면 짧은 회복에 노출. 신규 미래안이며 전용 찌르기/접근 에셋 연결 미확인, 뒤잡기 자동화는 포함하지 않는다.

### D02 흘려베기 · 공용
- **콘셉트/의도**: 정면 압박을 옆으로 넘기며 작은 피해와 위치 이득을 얻는다.
- **동작**: 준비는 바깥발을 열고 칼을 안으로 접음 → 접촉은 짧은 측면 스텝과 안쪽→바깥 절개 → 회복은 적을 향해 골반을 돌리며 발을 모은다.
- **범위/히트**: 스텝 옆의 짧은 호1회, 경로 충돌을 존중한다. 피해회피/무적은 동작만으로 부여하지 않는다.
- **VFX**: 시작은 발 방향선, 접촉은 낮고 가는 초승달/청록 점, 종료는 옆으로 흘러가는 잔선이 사라진다.
- **위험/차이**: 이동 종점·반대편 공격에 취약. 신규 미래안으로 실제 측면클립·벽 대응 검증 필요, 유운수 같은 성공 반격기와 구별한다.

### D03 약점노출 · 공용
- **콘셉트/의도**: 짧은 견제 절개로 다음 정확한 일격의 기회를 만든다. 자체 피해보다 후속 선택을 유도한다.
- **동작**: 준비는 칼끝으로 가드를 유도 → 접촉은 손목을 틀어 한 번 짧게 긋기 → 회복은 검끝을 상대에 둔 채 팔만 회수한다.
- **범위/히트**: 작은 전방 호1회+대상별 표식1개 제안. 표식 갱신/소비자는 구현 전 결정하며 겹친 판정으로 여러 중첩을 쌓지 않는다.
- **VFX**: 시작은 칼끝 점, 접촉은 끊어진 작은 마름모, 종료는 실제 표식 시간 동안 외곽선만 남다가 닫힌다.
- **위험/차이**: 첫 피해가 약하고 후속을 놓치면 이득이 줄어든다. 신규 표식/소비기능 미구현, 머리·등 뼈 위치를 강제하는 약점 시스템으로 확정하지 않는다.

### D04 매복걸음 · 공용

### T09 십자단멸 · 차징 전용
- **콘셉트/의도**: 양검을 모아 준비한 뒤 큰 X한 번으로 전방을 가른다.
- **동작**: 준비/차징은 검을 바깥어깨에 들어 힘 모음 → 접촉은 동시에 교차하는 큰 사선 → 회복은 낮아진 두 검을 몸 양옆으로 회수한다.
- **범위/히트**: 전방 X쐐기 단발1회. 두 검/교차점/잔광은 하나의 타격번호를 공유한다.
- **VFX**: 시작은 두 칼끝 수렴점, 완충은 작은 X표식, 접촉은 굵은 이중강철선, 종료는 교차 중심이 빠르게 갈라져 사라진다.
- **위험/차이**: 높이 든 준비와 낮은 회복이 길다. 신규 차지단발 미구현, 교차베기2타와 분명히 다른 타수/포즈가 필요하다.

### T10 쌍월참 · 차징 전용
- **콘셉트/의도**: 준비한 무게를 두 번의 넓은 반달베기에 나눠 전방을 정리한다.
- **동작**: 준비/차징은 두 검을 한쪽 아래로 모음 → 접촉은 큰 첫 횡호 뒤 발을 바꿔 반대 횡호 → 회복은 두 번째 검을 넓게 제동한다.
- **범위/히트**: 넓은 전방2타, 각 타격당1회. 두 타 사이 방향 변경 한도를 후속 확정한다.
- **VFX**: 시작은 평행 검등선, 완충은 두 짧은 반달, 접촉은 시간차 큰 강철호, 종료는 마지막 호만 빠르게 옅어진다.
- **위험/차이**: 첫 타 뒤 역회전 준비와 종결회복이 빈틈. 신규2타 미구현이며 십자단멸의 동시 X단발과 혼용하지 않는다.

## 7. 미래 제작: 활 10개

거리·조준·사격위치가 중심이다. 실제 화살과 가는 회백 궤적, 작은 황록 접점으로 제안한다. 매의눈/집중은 정밀·관통 강화 후보이며 전역 시간감속·자동명중은 기본안에 없다. 조준 UI와 적의 공격예고를 색 외의 모양으로 구분한다.

### B01 연속사격 · 공용
- **콘셉트/의도**: 짧은 빈틈을 두 발의 빠른 사격으로 소화한다.
- **동작**: 준비는 활을 들고 첫 화살을 짧게 당김 → 접촉은 첫 발 방출·재장전·두 번째 방출 → 회복은 시선을 목표에 둔 채 활을 조금 낮춘다.
- **범위/히트**: 순차 투사체2개, 투사체마다 대상1회. 각 발의 발사 시점 조준을 쓰며 발사 뒤 궤도를 자동 보정하지 않는다.
- **VFX**: 시작은 시위 근처 작은 선, 방출에 짧은 깃바람, 접촉은 실제 화살 도착점의 황록 점, 종료는 각 궤적이 따로 사라진다.
- **위험/차이**: 두 번째 장전 중 근접 압박에 취약. 신규 연사·투사체 타이밍 미구현, 한 번의 활 당김을 두 피해로 위장하지 않는다.

### B02 퇴각사격 · 공용
- **콘셉트/의도**: 뒤로 물러나면서 한 발 쏘아 사격거리를 복구한다.
- **동작**: 준비는 앞발을 밀고 활을 당김 → 접촉은 후퇴 중 균형이 잡힌 순간 방출 → 회복은 뒷발을 딛고 다음 자세를 잡는다.
- **범위/히트**: 실제 화살1개/대상1회. 후방 충돌·절벽을 확인해 이동을 줄이되 가상의 원래 종점에서 발사하지 않는다.
- **VFX**: 시작은 뒷방향 발먼지, 방출은 가는 직선, 명중은 작은 재질별 파편, 종료는 후퇴 먼지가 가라앉는다.
- **위험/차이**: 뒤 공간을 확인하지 않으면 짧게 멈추거나 불리한 종점. 신규 이동사격 미구현, 점프무적·자동 거리확보는 아니다.

### B03 견제시 · 공용
- **콘셉트/의도**: 빠르게 한 발 쏘아 접근의 박자를 끊는 짧은 견제.
- **동작**: 준비는 활을 몸 가까이 두고 짧게 당김 → 접촉은 빠른 방출 → 회복은 팔꿈치를 낮춰 재장전 준비한다.
- **범위/히트**: 직선 투사체1개/대상1회. 경직은 대상 면역을 따르며 보스 행동을 항상 끊지 않는다.
- **VFX**: 시작은 짧은 시위 진동, 방출은 가는 회백 꼬리, 접촉은 작고 각진 황록 점, 종료는 잔광을 즉시 줄인다.
- **위험/차이**: 준비가 짧은 대신 큰 위력·관통은 기본안에 없다. 신규 견제효과 미구현, 활 기본단발과 별도 역할/소모를 검토해야 한다.

### B04 도약사격 · 공용
- **콘셉트/의도**: 낮은 사선도약으로 위치를 바꾼 뒤 한 발을 안정적으로 쏜다.
- **동작**: 준비는 무릎을 굽히고 활을 몸 가까이 둠 → 접촉은 낮은 도약 정점 또는 착지 직전 방출 → 회복은 착지하며 활을 세운다.
- **범위/히트**: 실제 방출위치의 화살1개/대상1회. 도약체 피해 없음, 천장·벽·착지점 제한 필요.
- **VFX**: 시작은 작은 발먼지, 이동은 짧은 바람호, 방출/명중은 가는 선/점, 종료는 착지 먼지로 마무리한다.
- **위험/차이**: 착지 때 노출되며 공중 조준 흔들림을 UI로 과장하지 않는다. 신규 공중사격 미구현, 사격 순간과 카메라 안정화 검증 필요.

### B05 고정사격 · 공용
- **콘셉트/의도**: 짧게 발을 멈추고 조준 정밀도를 얻는 사격. 우차징보다 빠른 고정 준비다.
- **동작**: 준비는 양발을 넓혀 세우고 어깨선을 고정 → 접촉은 한 번 깊게 당겨 방출 → 회복은 시위를 따라 팔을 내리며 다시 이동한다.
- **범위/히트**: 정면 투사체1개/대상1회. 정밀보너스 조건은 미정, 화면 조준점과 실제 출발점이 벽에 막힐 때 별도 표시한다.
- **VFX**: 시작은 조준선이 좁아지는 짧은 표식, 방출은 곧은 가는 꼬리, 접촉은 단단한 황록 핵점, 종료는 고정 표식을 지운다.
- **위험/차이**: 발 고정 자체가 대가. 신규 정밀효과 미구현이며 RMB차징과 다른 준비/입력시간을 후속 정의해야 한다.

### B06 올가미화살 · 공용
- **콘셉트/의도**: 명중한 적의 이동을 잠깐 방해해 다음 사격의 거리를 만든다.
- **동작**: 준비는 특수 화살을 꺼내 시위에 얹음 → 접촉은 한 발 방출 후 명중 → 회복은 활을 아래로 돌려 다음 화살을 집는다.
- **범위/히트**: 투사체1개/대상1회+이동방해 후보. 지면 광역함정과 혼용하지 않으며 면역 보스 대안은 미정이다.
- **VFX**: 시작은 화살촉의 작은 매듭, 명중은 적 발밑의 끊긴 얇은 고리, 종료는 상태 종료와 함께 고리가 풀린다.
- **위험/차이**: 빗나가면 거리이득 없음, 즉시 공중적 고정 불가안. 신규 이동상태/특수화살 미구현, 영구 속박으로 해석하지 않는다.

### B07 부채사격 · 동시 전용
- **콘셉트/의도**: 근중거리 전방 여러 방향을 한 번에 견제한다.
- **동작**: 준비는 화살 묶음을 넓게 걸고 활을 세움 → 접촉은 한 번의 방출로 부채꼴 산개 → 회복은 앞팔을 아래로 낮춰 제동한다.
- **범위/히트**:5발 산개 제안, 전체 실행에서 동일대상 최대1회 기본안. 근접 산탄5배 피해는 자동 허용하지 않는다.
- **VFX**: 시작은5개 작은 화살촉, 방출은 분리된 가는5선, 명중점은 독립 표시, 종료는 각 선을 즉시 줄인다. 넓은 광선면은 없다.
- **위험/차이**: 퍼진 방향으로 원거리 단일 효율 감소. 신규 다중발사/대상상한 미구현, 상한을 바꾸려면 명시적 밸런스 설계가 필요하다.

### B08 화살비 · 동시 전용
- **콘셉트/의도**: 지정 지점을 여러 발로 압박해 적 움직임을 제한한다.
- **동작**: 준비는 활을 높이 들어 조준지점을 표시 → 접촉은 위로 방출한 뒤 지역에 순차 낙하 → 회복은 활을 내리고 바로 주변을 확인한다.
- **범위/히트**: 지정 원 안3회 낙하펄스 제안, 펄스당 대상1회. 장식 화살 수와 피해 횟수 분리, 천장/시야/도달 조건은 후속 정의한다.
- **VFX**: 시작은 속 빈 조준원, 낙하 직전 얇은 점선, 접촉은 작은 지면 파편, 종료는 원 테두리가 끊겨 사라진다.
- **위험/차이**: 예고 후 적이 벗어날 수 있고 지점이 자동 추적하지 않는다. 신규 영역공격 미구현, 그림만 보고 벽 뒤 공격을 승인하지 않는다.

### B09 관통시 · 차징 전용
- **콘셉트/의도**: 긴 직선으로 정렬된 적을 한 발로 관통한다.
- **동작**: 준비/차징은 활을 완전히 당기고 몸을 옆으로 세움 → 접촉은 시위가 풀리며 한 발 직진 → 회복은 당긴 손을 귀 뒤에서 낮추고 활의 반동을 받는다.
- **범위/히트**: 제한 관통 투사체1개, 같은 대상1회. 최대관통수·거리·감쇠는 미정, 벽에서는 멈추는 기본안.
- **VFX**: 시작은 화살축의 수렴선, 완충은 화살촉 짧은 링, 명중마다 작은 점을 남긴 긴 가는 꼬리, 종료는 종점에서 닫힌다.
- **위험/차이**: 긴 조준고정과 좁은 선이 대가. 신규 차지/관통 미구현, 전체화면 레이저처럼 폭을 과장하지 않는다.

### B10 낙성시 · 차징 전용
- **콘셉트/의도**: 미리 예고한 한 지점에 강한 한 발을 떨어뜨린다. 화살비의 여러 펄스와 구별되는 단발이다.
- **동작**: 준비/차징은 활을 높게 당기며 목표원 축소 → 접촉은 방출 후 한 번 큰 낙하 명중 → 회복은 활을 내리고 앞발 고정을 푼다.
- **범위/히트**: 지정 작은 원1회. 직격과 지면폭발이 같은 타격번호를 공유하며 낙하 후 남는 불빛은 피해 없음.
- **VFX**: 시작은 속 빈 원/중앙점, 완충은 중심선 정렬, 접촉은 짧은 수직 흰 꼬리와 황록 링, 종료는 낮은 먼지만 남는다.
- **위험/차이**: 긴 예고와 고정지점 때문에 빗나갈 수 있다. 신규 낙하단발 미구현, 천장·높은 단차·시야 조건을 먼저 검증해야 한다.

## 8. 미래 제작: 표창 10개

투척·회전·귀환 궤적이 중심이다. 은빛의 짧은 반복 점선과 청백 회전테두리를 사용한다. 회수진/순환은 귀환경로·다음 투척의 미래 보상 후보다. 반사/귀환 횟수와 동일대상 상한은 각각 제한하며 새 자원 두 개를 만들지 않는다.

### S01 반월투척 · 공용
- **콘셉트/의도**: 완만한 곡선으로 전방의 옆각을 견제하는 투척.
- **동작**: 준비는 손목을 몸 옆으로 당김 → 접촉은 옆으로 펼친 팔에서 표창을 놓아 곡선 비행 → 회복은 손을 가슴앞으로 돌린다.
- **범위/히트**: 지정 곡선투사체1개/대상1회. 장애물 옆으로 실제 지나갈 수 있으나 벽을 관통하지 않는다.
- **VFX**: 시작은 손끝 짧은 회전선, 비행은 가는 점선반달, 명중은 금속 작은 별, 종료는 종점에서 점선이 사라진다.
- **위험/차이**: 직선보다 도달 지연/가까운 중앙 사각이 있을 수 있다. 신규 곡선투사체 미구현, 벽 뒤 자동 유도를 뜻하지 않는다.

### S02 도약투척 · 공용
- **콘셉트/의도**: 짧게 위치를 바꾸며 한 발을 빠르게 던진다.
- **동작**: 준비는 표창을 귀 옆에 들고 낮게 도약 → 접촉은 공중의 안정 구간에서 던짐 → 회복은 착지하며 손을 몸 안으로 접는다.
- **범위/히트**: 실제 방출 위치의 직선표창1개/대상1회. 도약 경로에 피해/무적 없음, 착지 충돌검사 필요.
- **VFX**: 시작은 발먼지, 투척은 짧은 청백 회전점선, 명중은 작은 접점, 종료는 착지먼지와 궤적을 따로 정리한다.
- **위험/차이**: 낮은 천장과 착지 종점에 취약. 신규 이동투척 미구현, 활 도약사격과 다른 한손 손목 방출이 필요하다.

### S03 반사표창 · 공용
- **콘셉트/의도**: 가까운 적 사이를 제한 횟수 연결해 다수 압박한다.
- **동작**: 준비는 표창을 세워 쥠 → 접촉은 첫 표적에 던진 뒤 명중마다 다음 적으로 튕김 → 회복은 손을 가슴앞으로 회수한다.
- **범위/히트**: 최대3대상 제안, 대상당 실행1회. 다음 대상 거리/시야 제한, 이미 맞은 대상을 다시 선택하지 않는다.
- **VFX**: 시작은 은빛 손끝점, 비행은 직선점선, 반사 접점에서 짧은 각진 청백 불꽃, 종료는 마지막 접점에서 소멸한다.
- **위험/차이**: 주변 표적이 없으면 추가 보상 없음. 신규 반사선정/방문목록 미구현, 무한 반사·벽 관통은 배제한다.

### S04 귀환베기 · 공용
- **콘셉트/의도**: 돌아오는 경로를 적 뒤에 걸쳐 위치를 보상하는 왕복투척.
- **동작**: 준비는 팔을 길게 뻗을 공간 확보 → 접촉은 바깥투척 뒤 손을 당겨 귀환 지시 → 회복은 실제 귀환 또는 종료 후 손을 접는다.

- **VFX**: 출발은 짧은 은색점선, 귀환은 더 촘촘한 청백점선/안쪽 화살모양, 명중은 작은 별, 종료는 손에서 짧게 닫힌다.
- **위험/차이**: 귀환선을 만들 위치선택이 필요하고 벽에 걸릴 수 있다. 신규 왕복/경로검증 미구현, 등뒤 보너스를 무조건 부여하지 않는다.

### S05 연속투척 · 공용
- **콘셉트/의도**: 좁은 전방에 두 발을 빠르게 잇는 압박.
- **동작**: 준비는 두 표창을 손 안에 포갬 → 접촉은 손목을 두 번 튕겨 순차 방출 → 회복은 두 번째 방출팔을 짧게 회수한다.

### S06 제압표창 · 공용
- **콘셉트/의도**: 가까워지는 적에게 무거운 한 발로 접근박자를 끊는다.

- **VFX**: 시작은 두꺼운 회전테두리, 비행은 짧고 굵은 은색꼬리, 명중은 납작한 청백별, 종료는 파편이 빠르게 떨어진다.
- **위험/차이**: 준비가 보이고 빗나가면 근접에 취약. 신규 경직/중량표창 미구현, 반사표창처럼 다수를 튕기지 않는다.

### S07 팔방산개 · 동시 전용
- **콘셉트/의도**: 주변 여러 방향으로 표창을 흩어 포위를 느슨하게 만든다.
- **동작**: 준비는 양손을 몸앞으로 모음 → 접촉은 몸을 낮춰 바깥으로 동시에 펼쳐 투척 → 회복은 손을 회수하며 정면 가드를 잡는다.
- **범위/히트**:8방향 투사체 제안, 전체 실행당 동일대상1회 기본안. 가까운 큰 적의 다중접촉을 상한으로 제한한다.
- **VFX**: 시작은 손끝 여러 점, 방출은8개 분리 점선, 명중은 개별 작은 별, 종료는 각 선이 멀어지며 끊긴다.
- **위험/차이**: 방향 사이 빈틈과 짧은 사거리 효율이 위험. 신규 다중투척 미구현, 화면 전체 원판폭발로 표현하지 않는다.

### S08 회전결계 · 동시 전용
- **콘셉트/의도**: 잠시 주변을 도는 표창으로 근접 접근을 견제한다.
- **동작**: 준비는 표창을 몸옆에서 짧게 돌림 → 접촉은 낮은 원궤도를 유지하는 방출 → 회복은 손을 모아 회수 또는 종료한다.
- **범위/히트**: 고정된 짧은 유지시간의 원형영역, 총3펄스 제안/펄스당1회. 표창 공전 횟수·프레임과 피해를 분리한다.
- **VFX**: 시작은 끊긴 원테두리, 유지에는 실제 표창과 짧은 청백 꼬리만, 명중은 작은 별, 종료는 원이 손 방향으로 풀린다.
- **위험/차이**: 결계는 방어막/투사체삭제가 아니며 원 밖 원거리 공격에 노출. 신규 지속영역·정리 이벤트 미구현이다.

### S09 나선수리검 · 차징 전용
- **콘셉트/의도**: 큰 회전표창을 직선으로 던져 적 줄을 압박한다.
- **동작**: 준비/차징은 양손 앞에서 표창 회전 가속 → 접촉은 허리 회전으로 전방 방출 → 회복은 양손을 낮추며 발을 제동한다.
- **범위/히트**: 큰 직선투사체1개/대상1회, 관통 상한 미정. 회전날 여러 개가 닿아도 반복피해하지 않는다.
- **VFX**: 시작은 커지는 청백 얇은 테두리, 완충은 테두리 끊김 정렬, 비행은 나선점선, 명중은 금속별, 종료는 회전이 짧게 풀린다.
- **위험/차이**: 준비 중 전면 노출과 넓은 장애물 충돌. 신규 대형표창/차지 미구현, 크기가 무한히 커지는 완충효과는 아니다.

### S10 천공표창 · 차징 전용
- **콘셉트/의도**: 먼 직선 목표를 작은 표창의 집중속도로 노린다.
- **동작**: 준비/차징은 표창을 귀옆으로 당기고 반대팔로 방향 고정 → 접촉은 전신을 써서 한 번 곧게 투척 → 회복은 던진 팔을 몸앞으로 회수한다.

- **VFX**: 시작은 칼끝에 모이는 얇은 선, 완충은 작은 원, 비행은 짧은 압축 흰꼬리, 명중은 작고 강한 청백점, 종료는 즉시 소멸한다.
- **위험/차이**: 긴 차지·좁은 조준·장애물에 취약. 신규 장거리단발 미구현, 이름이 하늘 낙하공격을 뜻하지 않도록 직선안을 유지한다.

## 9. 미래 제작: 쌍단검 10개

적 곁을 돌며 짧은 연타와 출혈 상태를 활용한다. 회백 갈고리 궤적과 작은 진홍 점/적갈색 외곽표식으로 제안한다. 출혈은 적 상태이상이지 플레이어의 두 번째 자원이 아니다. 혈무/연격은 미래 Ctrl/단일자원 후보다. 피 분출 없이도 표식과 실루엣으로 읽히게 한다.

### A01 교차할퀴기 · 공용
- **콘셉트/의도**: 가까운 적에게 두 손으로 빠르게 압박을 시작한다.
- **동작**: 준비는 팔꿈치를 접고 칼을 가슴옆에 둠 → 접촉은 짧은 좌우사선2회 → 회복은 손을 얼굴 아래로 회수한다.
- **범위/히트**: 짧은 정면2호, 타격번호당1회. 출혈 부여 여부/중첩은 별도 제한하며 여러 뼈접촉으로 증가하지 않는다.

- **위험/차이**: 사거리가 매우 짧고 마지막 손 회수가 빈틈. 신규2타 미구현, 긴 쌍검의 큰 X호와 다른 근접폭을 유지한다.

### A02 측면쇄도 · 공용
- **콘셉트/의도**: 적 옆을 스치며 연타를 이어갈 자리를 잡는다.
- **동작**: 준비는 바깥발을 열고 앞손칼을 낮춤 → 접촉은 짧은 측면 이동에 두 손 절개를 순차 결합 → 회복은 이동끝에서 적을 다시 향한다.
- **범위/히트**: 실제 이동선 옆2타, 각 대상1회. 적 뒤 자동배치/충돌관통 없이 정지점에 맞춰 종료한다.
- **VFX**: 시작은 발먼지, 접촉은 낮은 짧은 갈고리2개, 종료는 이동선 뒤쪽부터 잔상이 끊긴다.
- **위험/차이**: 벽 가까이선 경로가 짧아지고 종점이 노출. 신규 이동연타 미구현이며 화면회전으로 적을 강제로 중앙에 고정하지 않는다.

### A03 핏빛칼춤 · 공용
- **콘셉트/의도**: 가까운 곳에 머무르며 짧은 연타로 출혈을 누적한다.
- **동작**: 준비는 양칼을 가슴앞에 겹침 → 접촉은 손목 중심 짧은 베기4회 → 회복은 마지막 손을 몸밖으로 열었다가 가드한다.
- **범위/히트**: 좁은 정면4타, 타격번호당1회. 출혈 상한/갱신/초당피해는 미정, 타수마다 무제한 중첩하지 않는다.
- **VFX**: 시작은 두 손 작은 점, 접촉은 짧은 회백선과 진홍 점, 실제 출혈상태는 얇은 적갈 외곽표식, 종료는 상태와 함께 정리한다.
- **위험/차이**: 긴 근접체류가 대가. 신규4타/출혈 미구현, 피폭발·고어 대신 상태가독성을 우선한다.

### A04 낮은베기 · 공용
- **콘셉트/의도**: 추격하는 적 발밑을 두 번 견제해 다음 위치전환을 준비한다.
- **동작**: 준비는 무릎을 낮추고 양칼을 바깥으로 둠 → 접촉은 낮은 좌우 횡베기2회 → 회복은 낮은 자세에서 몸을 펴며 반걸음 물러난다.
- **범위/히트**: 전방 낮은2호/타격당1회. 이동방해 후보는 대형·공중 면역 대안 필요, 발뼈 정밀충돌만 요구하지 않는다.
- **VFX**: 시작은 낮은 발먼지, 접촉은 얇은 두 갈고리, 종료는 실제 둔화가 있을 때만 끊긴 발고리를 남긴다.
- **위험/차이**: 상체가 낮아져도 무적 아님, 회복 때 정면 노출. 신규2타/둔화 미구현이며 단검 발목베기보다 연속압박에 초점을 둔다.

### A05 잔상회피 · 공용
- **콘셉트/의도**: 공격을 멈추고 짧게 옆으로 빠지는 명확한 방어 선택.
- **동작**: 준비는 두 칼을 몸 가까이 접음 → 접촉 대신 낮은 측면 스텝 → 회복은 바깥발을 딛고 바로 적 방향 가드한다.
- **범위/히트**: 피해 없음, 유효 거리/충돌/취소창은 후속 결정. 잔상이 적을 공격하거나 대신 피해를 받지 않는다.
- **VFX**: 시작은 몸윤곽 가는 선, 이동 중 반투명 윤곽1개만 짧게 남기고, 종료는 발먼지와 함께 완전히 소멸한다.
- **위험/차이**: 종료위치와 연속사용 제한이 중요. 신규 회피 미구현이며 자동무적·표적해제·공격강제취소는 승인된 사실이 아니다.

### A06 추적찌르기 · 공용
- **콘셉트/의도**: 조금 멀어진 적에게 짧게 다시 붙는 한 번의 찌르기.
- **동작**: 준비는 앞칼을 정면에 두고 뒷발에 힘 모음 → 접촉은 한 걸음과 한손 찌르기 → 회복은 반대칼로 가드하며 발을 따라붙인다.
- **범위/히트**: 실제 접근 종점의 좁은 캡슐1회. 준비 중 제한 방향보정만, 도망간 적을 무한추적하지 않는다.
- **VFX**: 시작은 앞칼끝 점, 이동은 짧은 발선, 접촉은 바늘/진홍점, 종료는 팔 회수와 함께 끊긴다.
- **위험/차이**: 거리 밖/벽/방향변경에 실패 가능. 신규 접근찌르기 미구현, 잠금대상 순간이동을 기본으로 두지 않는다.

### A07 칼날폭풍 · 동시 전용
- **콘셉트/의도**: 가까운 주변을 짧게 여러 번 휩쓸어 포위를 풀어낸다.
- **동작**: 준비는 낮게 앉아 두 칼을 안으로 모음 → 접촉은 짧은 회전절개3회 → 회복은 발을 정면으로 돌리며 손을 가드로 모은다.
- **범위/히트**: 좁은 주변3펄스/펄스당1회. 시각회전/프레임 수와 타수 분리, 적을 자동 흡인하지 않는다.
- **VFX**: 시작은 작은 열린 원, 접촉은 짧은 갈고리가 순차 나타났다 삭제, 종료는 마지막 테두리만 풀린다.
- **위험/차이**: 유지 중 원거리/끝나자마자 공격에 취약. 신규 회전연타 미구현, 현재 카메라 안전정책과 양손 궤적 검증 필요.

### A08 혈흔추격 · 동시 전용
- **콘셉트/의도**: 출혈 중인 적의 열린 틈을 전방 연격으로 활용한다.
- **동작**: 준비는 목표 방향에 앞칼을 낮게 둠 → 접촉은 짧은 진입베기→반대 베기→마무리 찌르기 → 회복은 양손을 몸 안으로 접고 멈춘다.
- **범위/히트**: 전방3타/타격당1회. 출혈은 선택 보상조건 후보, 비출혈 대상의 기본기능/소비 여부는 별도 결정한다.
- **VFX**: 시작은 유효상태 목표에 작은 끊긴 표식, 접촉은3개의 짧은 갈고리/점, 종료는 보상표식만 닫힌다. 멀리 적을 관통하는 연결선은 없다.
- **위험/차이**: 목표상태/위치가 달라지면 이득 감소. 신규 상태연계 미구현이며 출혈을 새로운 플레이어 게이지로 바꾸지 않는다.

### A09 쌍아관통 · 차징 전용
- **콘셉트/의도**: 두 칼끝을 가까이 모아 낮게 파고드는 집중 찌르기.
- **동작**: 준비/차징은 두 손을 갈비뼈옆에 당기고 무릎을 굽힘 → 접촉은 짧은 낮은 전진과 양손 찌르기 → 회복은 칼을 뽑아 몸쪽으로 회수한다.
- **범위/히트**: 좁은 전방1타, 양칼 볼륨이 타격번호 공유. 제한 관통 여부 미정, 두 칼이라2배피해하지 않는다.
- **VFX**: 시작은 두 칼끝 수렴점, 완충은 나란한 작은 두 쐐기, 접촉은 이중 바늘선/한 접점, 종료는 선이 빠르게 수축한다.
- **위험/차이**: 긴 낮은 준비와 좁은 진입각. 신규 차지단발 미구현, 적 뒤까지 통과시키는 이동은 별도 검토한다.

### A10 회전쇄도 · 차징 전용
- **콘셉트/의도**: 좁은 적 무리를 향해 짧게 회전 진입한다. 칼날폭풍의 제자리 연타와 위치보상을 구분한다.
- **동작**: 준비/차징은 두 칼을 바깥으로 열고 발을 모음 → 접촉은 낮은 회전전진 중 두 번 절개 → 회복은 종점 바깥발로 강하게 제동한다.
- **범위/히트**: 실제 짧은 이동선의2펄스/각 대상1회. 벽/대형적에서 중단하는 기본안, 무한 적통과 없음.
- **VFX**: 시작은 발앞 작은 나선, 접촉은 이동방향의 짧은 이중갈고리, 종료는 종점 낮은 먼지와 함께 끊긴다.
- **위험/차이**: 차지 중·진입종점에서 포위될 수 있다. 신규 이동회전 미구현, 루트/카메라/캡슐충돌을 함께 검증해야 한다.

## 10. 미래 제작: 장검 10개

적정거리·한 번의 절제된 베기·정확한 반격이 중심이다. 은회색의 단정한 선, 담청 접점으로 제안한다. 검심/기세는 거리와 성공 반격을 보상하는 미래 후보이며 대검의 경직저항·무거운 연격과 구별한다.

### L01 사선베기 · 공용
- **콘셉트/의도**: 반걸음과 한 번의 사선으로 적정거리를 잡는 시작기.
- **동작**: 준비는 검을 어깨옆에 가볍게 둠 → 접촉은 앞발과 함께 오른위→왼아래 사선 → 회복은 검끝을 정면으로 되돌린다.
- **범위/히트**: 정면 사선호1회/대상1회. 검 전체 스윕을 합쳐 처리하고 발 이동 자체에 피해 없음.
- **VFX**: 시작은 검등 얇은 선, 접촉은 한 줄 강철호/담청점, 종료는 회수 방향으로 잔광이 끊긴다.
- **위험/차이**: 너무 가까우면 거리보상 없음, 헛치면 짧은 회수 노출. 신규 미래안이며 대검 분쇄참보다 짧은 준비/절제된 무게가 필요하다.

### L02 받아치기 · 공용
- **콘셉트/의도**: 정확한 검 접점으로 받아낸 뒤 같은 선을 되돌린다.
- **동작**: 준비는 검을 정면 사선에 세움 → 성공 접촉은 손목을 틀어 흘린 뒤 짧은 되베기 → 회복은 성공 시 검을 정면으로 회수, 실패 시 검을 낮춰 가드 복귀한다.
- **범위/히트**: 전면 제한 방어창+반격1타. 실행당 성공토큰1개, 여러 히트가 맞아도 한 번만 반격한다.
- **VFX**: 시작은 검날 가는 선, 성공은 작은 별/담청 반사선, 반격은 단일 은빛호, 종료는 두 선이 짧게 사라진다.
- **위험/차이**: 정확한 시간/각도 실패가 빈틈. 신규 방어분기 미구현, 지속가드나 전면무적을 기본에 넣지 않는다.

### L03 정면찌르기 · 공용
- **콘셉트/의도**: 장검 끝으로 적정거리를 유지하는 좁은 직선공격.
- **동작**: 준비는 손잡이를 가슴옆에 붙여 검끝 정렬 → 접촉은 팔과 앞발을 짧게 뻗음 → 회복은 검을 같은 선으로 회수한다.
- **범위/히트**: 좁은 정면 캡슐1회. 검끝/검신 접촉이 겹쳐도1회, 광역부채 없음.
- **VFX**: 시작은 검끝 작은 점, 접촉은 얇은 은빛 직선/담청점, 종료는 선이 손쪽으로 수축한다.
- **위험/차이**: 옆으로 비킨 적에게 약하고 뻗은 팔 회수 노출. 신규 찌르기 미구현, 관통일섬의 깊은 이동/차지와 구별한다.

### L04 후퇴베기 · 공용
- **콘셉트/의도**: 물러나면서 한 번 베어 적과 거리를 다시 만든다.
- **동작**: 준비는 앞발 체중을 뒤로 옮김 → 접촉은 후퇴와 짧은 횡베기 동시 → 회복은 뒷발을 딛고 검을 앞에 세운다.
- **범위/히트**: 실제 검궤적 호1회/대상1회. 후퇴 경로 충돌을 존중하고 멀어진 원래 자리에서 피해를 생성하지 않는다.
- **VFX**: 시작은 뒷발먼지, 접촉은 얇은 횡선, 종료는 검잔광보다 발먼지가 조금 늦게 가라앉는다.
- **위험/차이**: 뒤 장애물/절벽과 짧은 후퇴가 위험. 신규 이동베기 미구현, 후퇴 자체 회피무적을 확정하지 않는다.

### L05 견제격 · 공용
- **콘셉트/의도**: 큰 스윙 없이 적의 준비를 짧게 건드리는 박자 견제.
- **동작**: 준비는 검끝을 정면에 둠 → 접촉은 손목으로 짧게 사선 절개 → 회복은 팔만 접어 기존 가드로 돌아온다.
- **범위/히트**: 작은 정면호1회, 경직 여부는 대상 규칙 따름. 보스 준비를 항상 취소시키지 않는다.
- **VFX**: 시작은 작은 칼끝떨림, 접촉은 짧은 반직선/담청점, 종료는 즉시 사라져 기본공격 시야를 비운다.
- **위험/차이**: 짧은 거리와 낮은 보상이 한계. 신규 견제효과 미구현, 사선베기와 동작/사거리/소모를 명확히 구별해야 한다.

### L06 올려치기 · 공용
- **콘셉트/의도**: 낮은 검끝으로 적의 중심을 올려 다음 일격의 기회를 만든다.
- **동작**: 준비는 검을 몸옆 낮게 둠 → 접촉은 무릎을 펴며 짧은 상향검격 → 회복은 검을 가슴앞 사선으로 내린다.
- **범위/히트**: 전방 좁은 수직호1회. 소형적 작은 띄움/대형 자세대안, 재접촉 추가타 없음.
- **VFX**: 시작은 낮은 검끝선, 접촉은 가는 상향쐐기/담청점, 종료는 위쪽 잔광이 먼저 지워진다.
- **위험/차이**: 검을 낮춘 준비와 올라간 팔이 빈틈. 신규 상향/제어 미구현, 대검 올려베기의 무거운 회복과 차별화한다.

### L07 일섬연계 · 동시 전용
- **콘셉트/의도**: 좁은 찌르기로 틈을 낸 뒤 넓은 횡베기로 끝내는2단 연결.
- **동작**: 준비는 검끝 정렬 → 접촉은 정면찌르기 뒤 팔을 회수하며 횡베기 → 회복은 검을 반대어깨 아래에 두고 정면가드한다.
- **범위/히트**: 직선1타+전방호1타, 타격번호당1회. 찌르기 잔광과 후속 호가 겹쳐도 해당 번호 외 추가피해 없음.
- **VFX**: 시작은 작은 검끝점, 접촉은 직선→횡선 순서, 종료는 두 번째 선 끝만 짧게 남는다.
- **위험/차이**: 첫 타 후 방향고정/팔 회수의 틈. 신규2단 미구현, 기본연계를 활성기술 수로 다시 세지 않는다.

### L08 만월참 · 동시 전용
- **콘셉트/의도**: 정확한 한 번의 원호로 가까운 포위를 정리한다.
- **동작**: 준비는 검을 허리옆으로 모아 축발고정 → 접촉은 한 번의 수평회전 → 회복은 앞발을 다시 정면에 놓고 검을 멈춘다.
- **범위/히트**: 주변 원호1타, 시작/끝에 걸친 대상도 실행당1회. 실제 검길이와 벽 충돌을 존중한다.
- **VFX**: 시작은 열린 발고리, 접촉은 가는 은색 원테두리, 종료는 지나간 뒤쪽부터 끊어진다. 채워진 빛원판 없음.
- **위험/차이**: 회전종료 제동이 빈틈. 신규 회전기 미구현, 대검의 무거운 밀기보다 절제된 타이밍을 강조한다.

### L09 발도참 · 차징 전용
- **콘셉트/의도**: 검을 거두는 정적 준비와 빠른 단일 베기의 대비를 보상한다.
- **동작**: 준비/차징은 검을 칼집 위치에 모아 몸을 닫음 → 접촉은 한 번의 빠른 수평발도 → 회복은 뻗은 검을 천천히 가드로 회수한다.
- **범위/히트**: 긴 전방 횡호1회. 보이지 않는 원거리 검기/벽 관통은 별도 제안 없으면 제외한다.
- **VFX**: 시작은 손잡이 가까운 얇은 점, 완충은 조용한 짧은 선, 접촉은 단일 은빛절개, 종료는 선이 양끝부터 사라진다.
- **위험/차이**: 긴 정적 준비와 느린 회복. 신규 발도모션/칼집 미구현, 실제 칼집이 없으면 가짜 관통 없이 저위 가드 대안을 제작해야 한다.

### L10 관통일섬 · 차징 전용
- **콘셉트/의도**: 좁은 방향으로 깊게 파고드는 차지찌르기.
- **동작**: 준비는 검끝을 정면에 두고 뒷발로 힘 모음 → 접촉은 한 걸음 깊게 전진하며 찌르기 → 회복은 앞발 제동 뒤 검을 똑바로 회수한다.
- **범위/히트**: 실제 짧은 이동선 직선1타/대상1회. 제한 관통 후보, 벽/대형 적에서 경로를 중단한다.
- **VFX**: 시작은 평행 가는 선, 완충은 검끝 작은 고리, 접촉은 긴 은빛 바늘, 종료는 종점 담청점만 잠시 남는다.
- **위험/차이**: 좁은 조준과 끝지점 긴 회수. 신규 차지이동 미구현, 단공참의 대검 가로절단과 다른 찌르기 실루엣이 필요하다.

## 11. 미래 제작: 대방패 10개

전면 버팀·밀기·적 위치 제어가 중심이다. 넓은 금속판, 낮은 흙먼지, 옅은 황토 접점으로 제안한다. 수호태세/수호는 미래 후보이며 방어방향·시간·막을 수 없는 공격을 표시해야 한다. 방패가 보인다는 이유로 전신 무적이나 모든 투사체 차단을 부여하지 않는다.

### H01 방패밀치기 · 공용
- **콘셉트/의도**: 넓은 전면으로 가까운 적을 밀어 안전한 발판을 만든다.
- **동작**: 준비는 방패를 가슴에 당기고 뒷발고정 → 접촉은 짧은 앞걸음과 수평밀기 → 회복은 팔꿈치를 접어 방패를 다시 몸에 붙인다.
- **범위/히트**: 전면 넓은 상자/캡슐1타, 대상당1회. 밀림은 질량/면역과 벽을 따르며 벽에 낀 적을 반복타격하지 않는다.
- **VFX**: 시작은 발먼지, 접촉은 납작한 황토 압력판/재질별 작은 파편, 종료는 먼지가 바깥으로 낮게 흐른다.
- **위험/차이**: 팔을 뻗은 동안 측후방이 열림. 신규 방패충돌/밀기 미구현, 방패판 전체를 무적영역으로 해석하지 않는다.

### H02 응징타 · 공용
- **콘셉트/의도**: 유효한 방어 성공 뒤 방패 모서리로 강하게 되친다.
- **동작**: 준비는 전면 방패를 몸에 붙임 → 접촉은 성공 신호 뒤 모서리 짧은 사선타격 → 회복은 방패를 가슴앞으로 바로 세운다.
- **범위/히트**: 선행 방어성공 토큰1개 소비+전면1타. 유효기간/입력조건은 미정, 같은 성공을 여러 응징타에 재사용하지 않는다.
- **VFX**: 시작은 성공 때만 방패테두리 작은 황토점, 접촉은 각진 금속별, 종료는 테두리 빛이 꺼진다.
- **위험/차이**: 성공조건 없이 쓰는 경우의 동작/실패비용 미정. 신규 성공연계 미구현, 이름만으로 즉시 자동반격을 확정하지 않는다.

### H03 엄폐이동 · 공용
- **콘셉트/의도**: 정해진 방패 방향을 유지하며 짧게 전진한다.
- **동작**: 준비는 방패를 얼굴앞까지 올림 → 접촉 대신 짧고 낮은 전진걸음 → 회복은 발을 딛고 방패를 정상높이로 낮춘다.
- **범위/히트**: 피해 없음. 유효 전면각·방어가능 유형·유지시간은 후속 정의, 측후방/지면공격은 별도 위험이다.
- **VFX**: 시작은 방패 바깥에 얇은 사각테두리, 실제 방어접촉에만 작은 금속불꽃, 종료는 테두리가 위에서 아래로 꺼진다.
- **위험/차이**: 낮은 이동성과 방향고정이 대가. 신규 이동방어 미구현, 모든 피해를 무효화하는 전방 장막은 아니다.

### H04 발구르기 · 공용
- **콘셉트/의도**: 방패를 유지한 채 가까운 적의 균형을 낮은 발구름으로 흔든다.
- **동작**: 준비는 한 발을 짧게 듦 → 접촉은 발뒤꿈치를 땅에 찍기 → 회복은 두 발로 중심을 낮게 정리한다.
- **범위/히트**: 발앞 작은 지면원1타. 공중/대형 면역은 별도, 발·충격파가 겹쳐도1회.
- **VFX**: 시작은 든 발 아래 작은 그림자, 접촉은 낮은 황토링/지면파편, 종료는 바깥먼지만 남고 중심은 즉시 비운다.
- **위험/차이**: 짧은 범위와 한발 준비 중 균형노출. 신규 발구름/자세효과 미구현, 방패가 있더라도 해당 순간의 방어는 별도 정의한다.

### H05 수호각 · 공용
- **콘셉트/의도**: 특정 전면을 선택해 짧게 버틸 준비를 한다.
- **동작**: 준비는 바깥발을 벌려 방패각 확정 → 접촉은 유효 공격을 받아 몸과 방패를 짧게 후퇴시킴 → 회복은 방패를 내려 정상 가드로 돌아온다.
- **범위/히트**: 피해 없음, 제한 방향/시간의 방어영역. 동일 공격의 중복접촉 비용/반응은1회, 광역·관통 방어 여부 미정.
- **VFX**: 시작은 속 빈 짧은 전면부채, 성공접촉은 방패판 안쪽 금속별, 종료는 부채 테두리가 닫힌다.
- **위험/차이**: 방향을 틀지 못하는 동안 측후방 취약. 신규 방향방어 미구현이며 수호태세 Ctrl과 같은 기술로 중복 집계하지 않는다.

### H06 돌려치기 · 공용
- **콘셉트/의도**: 옆에서 파고드는 적에게 방패 모서리를 한 번 돌려친다.
- **동작**: 준비는 방패를 몸 안으로 당김 → 접촉은 허리회전으로 한쪽 측면 횡타 → 회복은 돌아간 방패를 정면으로 세운다.
- **범위/히트**: 선택한 측전방 호1회. 반대쪽/등뒤 자동피해 없음, 대상당1회.
- **VFX**: 시작은 방패모서리 짧은 선, 접촉은 둔탁한 황토호와 금속파편, 종료는 옆으로 흐르는 먼지다.
- **위험/차이**: 방패가 옆을 향한 동안 정면이 열린다. 신규 방패횡타 미구현, 회전윤무처럼 전방위 기술로 만들지 않는다.

### H07 진형붕괴 · 동시 전용
- **콘셉트/의도**: 방패를 낮게 찍어 주변 가까운 적의 자세를 무너뜨린다.
- **동작**: 준비는 양손으로 방패를 높이 짧게 들기 → 접촉은 방패 하단을 지면에 내려찍기 → 회복은 무릎을 펴며 방패를 가슴까지 회수한다.
- **범위/히트**: 근거리 원1타. 다운 가능 적/보스 자세대안 분리, 방패와 지면파의 중복피해 없음.
- **VFX**: 시작은 방패 아래 모이는 먼지, 접촉은 낮은 다각형 황토링, 종료는 균열 테두리가 바깥부터 닫힌다.
- **위험/차이**: 방패를 든 준비와 회수 동안 전면보호 공백. 신규 주변제어 미구현, 대지진압보다 짧고 가까운 범위로 구별한다.

### H08 성벽반격 · 동시 전용
- **콘셉트/의도**: 짧은 전면 방어로 받은 압박을 한 번의 전방 충격으로 반환한다.
- **동작**: 준비는 방패를 깊게 몸에 붙이고 버팀 → 성공 접촉은 몸을 펴며 방패를 밀어 충격방출 → 회복은 성공 시 방패를 몸에 당겨 가드, 실패 시 방패를 낮추고 천천히 자세를 되찾는다.
- **범위/히트**: 제한 방어창+전방충격1타. 받은 공격수/피해를 무한 누적하지 않고 성공토큰/보상상한을 둔다.
- **VFX**: 시작은 방패 얇은 판테두리, 방어성공은 안쪽 수렴선, 반격은 낮은 황토 압력부채, 종료는 판과 먼지가 해제된다.
- **위험/차이**: 성공 없으면 큰 보상 없음, 측후방은 노출. 신규 누적/반환 룰 미구현, 성벽반격 유지 중 상시무적은 아니다.

### H09 성벽돌파 · 차징 전용
- **콘셉트/의도**: 방패로 길을 만든 뒤 짧게 전면 돌진한다.
- **동작**: 준비/차징은 몸을 방패뒤로 낮추고 뒷발에 힘 모음 → 접촉은 방패를 세운 낮은 돌진 → 회복은 두 발로 강하게 제동하며 방패를 회수한다.
- **범위/히트**: 실제 이동선 앞쪽1타/대상1회. 벽/대형적에 중단, 밀린 적과 계속 닿아도 추가타 없음.
- **VFX**: 시작은 발밑 짧은 직선준비표식, 완충은 방패테두리 닫힘, 접촉은 전면 압력판/낮은 먼지, 종료는 종점 먼지만 남는다.
- **위험/차이**: 방향고정·종점 긴 제동·측후방 위험. 신규 차지돌진 미구현, 돌진 중 방어가능 공격과 비용은 미정이다.

### H10 대지진압 · 차징 전용
- **콘셉트/의도**: 오래 준비해 방패 전체 무게로 밀집지역을 누르는 한 번의 지면타격.
- **동작**: 준비/차징은 방패를 두 손으로 높여 전신 힘 모음 → 접촉은 낮게 앉으며 넓은 판을 지면에 찍음 → 회복은 방패를 들어 올리고 몸을 세운다.
- **범위/히트**: 중간 크기 지면원1타. 중심접촉/바깥충격 중복 없음, 높이차/공중적 대응과 제어면역 별도 정의.
- **VFX**: 시작은 발아래 닫히는 다각형, 접촉은 낮고 두꺼운 황토링/재질파편, 종료는 중앙부터 비우고 테두리만 빠르게 가라앉힌다.
- **위험/차이**: 큰 준비와 긴 낮은 회복이 분명. 신규 대형차지타격 미구현, 진형붕괴와 차지보상/범위를 별도 검증한다.

## 12. 미래 제작: 검버클러 10개

작은 방패의 정확한 타이밍과 검의 빠른 전환이 중심이다. 버클러는 작은 금속점/호박색 별, 검은 가는 강철선으로 구분한다. 공방일체/박자는 정밀방어 후 연결을 보상하는 미래 후보이며 대방패처럼 오래 유지하는 방어가 아니다.

### C01 버클러튕기기 · 공용
- **콘셉트/의도**: 짧은 순간 방패중앙으로 공격을 튕겨 다음 행동을 연다.
- **동작**: 준비는 버클러를 몸 가까이 둠 → 접촉은 공격선에 손목을 짧게 내밀기 → 회복은 버클러를 바로 가슴앞에 회수한다.
- **범위/히트**: 제한 전면 파리창, 기본 피해 없음. 성공토큰1개/실행, 연타 접촉마다 여러 다음공격 보너스 생성 금지.
- **VFX**: 시작은 버클러 중심 작은 점, 성공 때만 호박색 금속별/짧은 원테두리, 종료는 바로 소멸한다.
- **위험/차이**: 짧은 창 실패와 작은 방향범위가 위험. 신규 파리 미구현, 방패를 들고 있는 전체 시간 방어를 유지하지 않는다.

### C02 틈새찌르기 · 공용
- **콘셉트/의도**: 열린 가드에 검끝을 빠르게 넣는 짧은 공격.
- **동작**: 준비는 버클러를 가슴에 붙이고 검끝 정렬 → 접촉은 검팔만 짧게 뻗음 → 회복은 같은 선으로 검을 회수하며 방패를 전면에 둔다.
- **범위/히트**: 정면 좁은 캡슐1회/대상1회. 정밀방어 후 보상 여부는 미래 연계규칙, 방패에도 공격판정 없음.
- **VFX**: 시작은 검끝 점, 접촉은 가는 은빛바늘/작은 금속점, 종료는 선이 손으로 수축한다.
- **위험/차이**: 좁은 조준과 짧은 거리. 신규 찌르기 미구현, 방패포즈만으로 공격 중 자동가드를 가정하지 않는다.

### C03 스텝베기 · 공용
- **콘셉트/의도**: 짧은 한 걸음으로 각도를 바꾸며 베는 공방전환.
- **동작**: 준비는 버클러를 앞에 두고 바깥발 개방 → 접촉은 스텝 뒤 한 번 사선베기 → 회복은 두 손을 몸앞으로 모아 발을 정리한다.
- **범위/히트**: 실제 종점 검호1회/대상1회. 이동 중 몸/버클러 피해 없음, 벽과 캡슐통과 금지안.
- **VFX**: 시작은 발먼지, 접촉은 짧은 강철사선, 종료는 발뒤 작은 먼지와 함께 끊긴다.
- **위험/차이**: 이동끝에서 검팔이 노출. 신규 스텝연계 미구현, 이동 방향은 준비 중 결정하고 자동뒤잡기는 하지 않는다.

### C04 쓸어베기 · 공용
- **콘셉트/의도**: 작은 방패로 몸을 정리하며 검으로 전방 여러 적을 견제한다.
- **동작**: 준비는 검을 몸옆에 낮게 둠 → 접촉은 한 번의 짧은 허리높이 횡베기 → 회복은 검끝을 앞으로 세우고 가드한다.
- **범위/히트**: 가까운 전방 부채1회/대상1회. 후면 원형피해 없음, 버클러 충돌은 공격에 더하지 않는다.
- **VFX**: 시작은 칼끝 얇은 선, 접촉은 낮은 강철반달/금속점, 종료는 반달 끝부터 지워진다.
- **위험/차이**: 베기 방향 바깥쪽과 회복에 빈틈. 신규 전방베기 미구현, 대검 회전참처럼 긴 회전·큰 밀기를 기본으로 넣지 않는다.

### C05 방패두드리기 · 공용
- **콘셉트/의도**: 버클러의 작은 타격으로 적 준비를 건드려 검의 기회를 만든다.
- **동작**: 준비는 방패손을 안으로 당김 → 접촉은 짧은 전면 손목 밀치기 → 회복은 방패를 가슴에 회수하며 검끝을 세운다.
- **범위/히트**: 작은 전방판1회, 경직/자세는 면역을 따른다. 버클러 테두리 여러점 접촉도1회.
- **VFX**: 시작은 중심 작은 점, 접촉은 호박색 금속별/납작한 짧은 링, 종료는 즉시 사라진다.
- **위험/차이**: 아주 짧은 거리와 뻗은 방패손 노출. 신규 견제타격 미구현, 대방패 밀치기처럼 큰 이동제어는 별도 제안 없으면 없다.

### C06 맞받아베기 · 공용
- **콘셉트/의도**: 방패로 공격선을 흘리는 순간 검으로 반대쪽을 친다.
- **동작**: 준비는 버클러를 안쪽에 두고 검을 어깨옆에 둠 → 성공 접촉은 방패를 밖으로 튕기며 검으로 짧게 되베기 → 회복은 성공 시 검을 정면으로 회수하고 방패를 세움, 실패 시 양손을 몸안으로 접는다.
- **범위/히트**: 제한 전면 성공창+검호1타, 실행당 성공1개. 방패접촉과 검피해를 같은 피해원으로 중복 계산하지 않는다.
- **VFX**: 시작은 작은 방패점, 성공은 호박별, 검은 한 강철호, 종료는 둘을 순서대로 지운다.
- **위험/차이**: 타이밍/방향을 놓치면 검반격 없음. 신규 성공/실패분기 미구현, 버클러튕기기와 별도 자동2연계로 확정하지 않는다.

### C07 방패검격 · 동시 전용
- **콘셉트/의도**: 방패타격과 검의 후속베기를 두 박자로 이어간다.
- **동작**: 준비는 양손을 몸앞에 가까이 둠 → 접촉은 버클러 짧은 밀치기 뒤 검 사선베기 → 회복은 검을 가슴옆에 회수하고 방패를 앞에 세운다.
- **범위/히트**: 전면판1타+전방검호1타, 타격번호별1회. 첫 타의 제어가 면역이어도 둘째 타는 별도 접촉 검증한다.
- **VFX**: 시작은 방패점, 첫 접촉은 호박별, 둘째는 강철사선, 종료는 검 끝의 작은 잔광만 남긴다.
- **위험/차이**: 두 타 사이와 마지막 회수가 빈틈. 신규2타 미구현, 두 손의 역할을 같은 X형 궤적으로 섞지 않는다.

### C08 결투연무 · 동시 전용
- **콘셉트/의도**: 한 방향에서 짧은 검격·가드전환·마무리를 묶은 공방연계.
- **동작**: 준비는 방패앞 검뒤 자세 → 접촉은 검베기→짧은 방패 재정렬→검찌르기2타 → 회복은 두 손을 중립으로 모은다.
- **범위/히트**: 전방호1타+좁은선1타, 타격별1회. 중간 방패자세는 자동 방어판정이 아니며 별도 창을 설계해야 한다.
- **VFX**: 시작은 검/방패 작은점, 접촉은 강철호→잠깐 소등→직선, 종료는 한 접점만 남긴다.
- **위험/차이**: 방향고정과 중간 재정렬에 공격이 들어올 수 있다. 신규 복합연계 미구현, 전체기간 가드·무적을 부여하지 않는다.

### C09 결투일격 · 차징 전용
- **콘셉트/의도**: 작은 방패뒤에서 준비하고 한 번 강하게 찌르는 집중기.
- **동작**: 준비/차징은 버클러를 얼굴앞에 세우고 검을 갈비뼈옆으로 당김 → 접촉은 방패옆으로 검을 길게 뻗음 → 회복은 검을 빼고 방패를 정상높이로 내린다.
- **범위/히트**: 좁은 정면1타/대상1회. 차징 중 방어 여부·방향·비용은 미정, 시각적 엄폐를 무적승인으로 쓰지 않는다.
- **VFX**: 시작은 검끝 얇은 수렴선, 완충은 버클러 뒤 작은 점, 접촉은 강철바늘/호박핵점, 종료는 즉시 수축한다.
- **위험/차이**: 차지 중 측후방과 긴 팔 회수 노출. 신규 차지찌르기 미구현, 방패가 조준/적 실루엣을 가리지 않게 검증한다.

### C10 파고들기 · 차징 전용
- **콘셉트/의도**: 짧은 방어 준비 뒤 간격을 좁혀 베는 기동 단발.
- **동작**: 준비/차징은 버클러를 비스듬히 세우고 뒷발고정 → 접촉은 짧은 앞걸음 뒤 옆사선 검격 → 회복은 종점에서 방패를 다시 전면으로 돌린다.
- **범위/히트**: 종점 전방호1타/대상1회, 이동선 피해 없음. 준비 방어창/소모는 후속 확정, 벽/대형적에서 이동을 줄인다.
- **VFX**: 시작은 방패짧은 테두리, 이동은 발먼지, 접촉은 강철사선과 작은 호박점, 종료는 테두리와 이동흔적을 함께 정리한다.
- **위험/차이**: 준비각과 끝지점이 위험. 신규 이동차지 미구현, 대방패 성벽돌파의 전면 몸통돌진/지속버팀과 구별한다.

## 13. 마법사 별도 기획·입력·표현 계약

이 절은 미래 마법사 설계다. 위 100개 후보의 무기별10/6슬롯 규칙을 마법사에 강제하지 않으며 Native 코드·에디터·실행 검증을 수행한 결과가 아니다.

### 13.1 확정과 미정 분리

- **사용자 확정**: Ctrl로 주문명령 입력상태에 진입, Q/E/R 순서조합, 조합 가중치에 따른 마나소모·공격력·속성 변화, 리듬게임 등 다양한 미니게임으로 해금, 마법서클 개념, 숙련이 높거나 약2단계 하위마법의 일반 Q/E/R 즉발.
- **사용자 확정**: 현재 마나를 초과한 주문과 잘못된 주문은 최대마나·체력 손실 페널티를 유발한다. 페널티는 이번 런만 적용하고 다음 런 초기화한다. 프로필 기본능력치를 영구 손상시키는 내용이 아니다.
- **미정**: Ctrl hold/toggle, 주문문자열 길이, 완료·취소 입력, 시간제한, 오조합 판정시점, 초과량 계산/상한, 체력손실의 현재/최대 구분, 미니게임 실패조건, 서클의 정확한 뜻, 즉발의 OR/AND 및2단계 비교기준, 해금/숙련의 영구보존범위.
- **제안**: 런 페널티는 무기교체/주문모드 해제로 제거하지 않고 같은 런 중단·재개에서 유지한다. 저장방식과 영구해금 보존은 사용자 결정 이후 설계한다.

### 13.2 모션·VFX 콘셉트

- **모드 진입**: 한 손은 정면에 펼치고 다른 손은 가슴 가까이 둔다. 손 사이에 속 빈 작은 문양틀을 열되 화면 중앙 조준점을 가리지 않는다. 틀은 명령 입력 가능 상태를 의미하고 방어/무적을 의미하지 않는다.
- **Q/E/R 입력**: 각 입력이 틀의 서로 다른 모양/위치에 쌓이고 순서가 줄로 남는다. 색뿐 아니라 획/점/각을 다르게 해 구별한다. 동일 키 반복도 화면에서 분리해 보여준다. 입력마다 큰 팔회전 대신 손목·손가락의 작은 비트로 반응한다.
- **유효 주문 준비**: 현재 문자열, 예상 마나, 속성, 초과위험을 읽기 쉬운 HUD로 표시하는 안. 주문 성립 전 불꽃/얼음이 실제 공격처럼 앞에 나가지 않는다. 완료 입력을 아직 Enter/키해제로 확정하지 않는다.
- **실제 방출**: 주문 확정과 자원승인이 끝난 뒤 손을 앞으로 짧게 밀어 투사체/파동을 방출한다. 충돌위치에만 명중효과를 재생하고 준비 문양은 회복 중 닫는다. 즉발 Q/E/R은 같은 주문의 짧은 준비형으로 읽히되 명령문자를 입력하지 않는다.
- **대표 화염탄 후보**: 손 사이 작은 주황 구체→한 번 밀어 방출→손 회수. 실제 투사체1개와 접점 소형폭발을 같은 타격번호로 묶는 안. 원형 불꽃/상승 입자/짧은 잔불로 표현하며 잔불 지속피해는 미정.
- **대표 냉기파 후보**: 손을 가슴앞에 펼침→앞으로 낮게 쓸어 부채형 파동→팔 회수. 전방1펄스/대상1회와 이동제어 후보. 흰서리 쐐기/육각 외곽선/낮은 얼음가루를 사용하고 완전빙결·보스정지는 확정하지 않는다.
- **오조합/초과위험**: 확정 전에 문자 틀의 끊긴 선, 경고아이콘, 예상 손실 문구로 예고한다. 실제 실패 시 손이 짧게 움츠러들고 문양이 안쪽으로 접히는 연출안. 경고만으로 실제 피해를 먼저 적용하거나 과한 화면번쩍임으로 감춘 상태를 만들지 않는다.
- **런 페널티 표현**: 최대마나 바의 잠긴 구간과 명확한 지속범위 문구로 이번 런 보정을 표시하는 안. 실제 체력손실 종류가 확정되기 전 최대체력 바까지 줄이는 시안을 확정하지 않는다. 사망/무기교체/취소는 모드/VFX 정리와 런 페널티 보존을 서로 분리한다.
- **미니게임/서클**: 리듬 입력은 성취·실패 피드백을 전투 주문피해와 분리한다. 서클은 동심선 단계 표시 후보만 제시하며 주문등급/레벨/세계관 어느 의미로 확정하지 않는다.

### 13.3 UE 5.8 입력 분리 후보와 검증 목록

Enhanced Input의 별도 Mapping Context 우선순위·입력 소비 설정은 **구현 후보**다. 현재 Character의 Q/E/R 고정슬롯에는 Native BindKey 경로도 있으므로 Mapping Context 우선순위/소비만으로 일반즉발이 차단됐다고 가정하지 않는다. 아래는 미래 구현안이며 현재 마법사 입력기능이나 실기 검증을 마쳤다는 뜻이 아니다.

- 모든 Q/E/R 실행 요청을 단일 입력라우터 또는 명시적인 현재직업·현재모드 gate로 통과시키는 안을 우선 검토한다. 일반 즉발/주문문자 경로는 한 물리입력에 정확히 하나만 소비하고, 구 Native BindKey 경로도 같은 gate를 따르게 한다.
- 모드 전환 때 입력 epoch를 갱신하고, 전환 전부터 누른 Q/E/R은 실제 release까지 새모드에서 무시하는 안이다. 입력 버퍼·반복트리거·지연 콜백이 이전 모드로 승인되지 않게 실행 시점의 모드도 검증한다.
- Ctrl 종료·사망·무기교체·런종료·메뉴취소는 주문대기/미완료입력/루프VFX를 강제로 취소하는 후보 계약이다. 이미 승인된 투사체나 런 페널티의 수명을 미완료 주문과 섞지 않는다.
- 강제취소를 오주문 페널티로 칠지는 미정이다. 시스템상태 변화로 취소된 주문에 자동으로 실패벌점을 부과하지 않는 안을 권장한다. 사용자 확정 전 구현하지 않는다.
- Ctrl을 누르고 유지하는지, 한 번 눌러 전환하는지는 미정 그대로 둔다. release 무시/epoch 규칙은 선택된 hold/toggle 계약에 맞춰 별도 시험한다.

| 시험 | 관찰해야 할 결과 | 아직 확정할 항목 |
|---|---|---|
| 일반상태 Q/E/R | 장착 즉발주문만1회 승인, 명령문자 추가 없음 | 즉발 허용/숙련 조건 |
| 주문모드 진입 후 Q/E/R | 문자열만 순서대로 변경, Native BindKey 포함 일반 즉발0회 | 진입 hold/toggle |
| Q/E/R 누른 채 모드 진입/종료 | 같은 press가 새모드에서 재사용되지 않음, 놓았다 다시 누른 입력을 구분 | release·trigger 소비규칙 |
| Ctrl 누른 채 사망/무기교체 | 모드/문양/입력대기 정리, 예전 키가 새 무기에서 재발동하지 않음 | hold/toggle별 재진입 규칙 |
| 매우 빠른 QER/반복키 | 실제 순서 보존, 프레임별 중복입력 없음 | 주문길이·입력시간 제한 |
| 유효조합 완료 | 승인1회·마나차감1회·주문실행1회 | 완료키/오버랩 처리 |
| 잘못된 조합 | 명확한 경고/실패표시, 페널티 적용이 중복되지 않음 | 오주문 판정시점·수치 |
| 마나와 동일/조금초과/크게초과 | 예상값과 실제 비용/이번런 페널티 일치 | 초과공식·최대/현재체력 구분 |
| 취소/메뉴/포커스변경 | 대기 입력·루프VFX·차지표시가 남지 않음, 이전 epoch 콜백 재승인 없음 | 취소입력·비용·오주문 페널티 여부 |
| 런내 무기교체/재개 | 제안대로라면 런 페널티 유지, 임시모드/VFX 복원 안 함 | 실제 런 저장계약 |
| 새 런 시작 | 이전 런 페널티 제거, 기본능력치 영구손상 없음 | 영구해금/숙련 보존범위 |

오조합·마나초과 시험에서는 실제 체력감소와 HUD 표시를 따로 기록하고, 실패 원인이 아직 정해지지 않은 주문을 임의로 정상/오류 판정하지 않는다.

## 14. 제작 소스·이미지·검증의 연결

### 14.1 현재 확인한 근거와 한계

- [격투 팔동작 보강](../Feature/doc/2026-10-05_fighter-arm-swing.md), [혼합 스킬트리 런타임](../Feature/doc/2026-10-20_hybrid-skill-tree-runtime.md): 기존 파생본/대검5개 재사용 이력. 과거의 맨손-너클공유·혼합자원 전제는 최신 사용자 방향을 덮어쓰지 않는다.

- 이번 문서에서 외부팩 구매·다운로드·반입·원본변형·몽타주교체·소스/바이너리변경·빌드·에디터 실행을 하지 않았다. 각 후보의 에셋 경로가 적혀 있지 않으면 실제 확보를 확인한 것이 아니다.

### 14.2 후속 제작 단위

1. **포즈 확정**: 기술별 준비/접촉/회복3포즈와 실제 판정모양을 함께 검토한다. 보기 좋은 포즈와 실제 검끝·손 도달 위치가 다르면 접촉을 기준으로 다시 그린다.
2. **소스 평가**: 기존 원본의 리타기팅·구간·재생률·양손접점·발접지·머리회전을 먼저 확인한다. 적합한 프로젝트 소유 파생본으로만 수정하고 vendor 원본을 보존한다. 부족한 태산압정 등의 소스는 확보 전 미완료다.
3. **타이밍 표**: 준비 시작, 첫 실제접촉, 각 후속타, 회복 시작/끝, 취소가능 구간의 authored와 observed 시간을 각각 기록한다. 새 연출을 이유로 기존 HitDelay/타수/피해를 바꾸지 않는다.
4. **VFX 이벤트**: 준비루프, 방출, 실제명중, 종료/취소를 분리한다. 허공명중·중복피해·끝나지 않는 루프·메뉴뒤 잔광을 검사한다. 이름만 다른 같은 효과를100개 제작완료로 세지 않는다.
5. **입력/슬롯 확인**: 공용4+전용2와 실제 해금, 비허용교차 거부, RMB탭/차지/좌우동시 분기, 메뉴취소, 뉴비 맨손제한을 확인한다. 숫자 단위테스트와 물리키 입력시험을 따로 기록한다.
6. **실제 화면 확인**: 1인칭·3인칭 준비/접촉/회복 캡처, 손/무기궤적, 동일타깃 체력변화, 공속변화 후 타이밍, 밝기/벽/다수적 상황을 확인한다. 임시 너클 Ctrl 전후의 오라/PP·종료/사망/무기교체도 별도 비교한다.
7. **완료표시**: 기획완료, 이미지완료, 소스확보, 연결완료, 수치검증, 실화면검증을 독립 상태로 기록한다. 한 단계 통과를 나머지 통과로 쓰지 않는다.

### 14.3 이미지 스토리보드 지시

- K01~K10, G01~G10의 기술ID/이름을 설명파일과 동일하게 매핑한다. 원칙은 준비→접촉→회복3패널, 단일 접촉시트라면 접촉 장면만 있는 것으로 표시한다.
- 실제 스크린샷이 아닌 생성 콘셉트이미지는 **미래 모션/VFX 목표**임을 표시한다. 준비에 큰 명중폭발을 넣지 않고 회복에 아직 유효한 공격판정을 그리지 않는다.
- 키포즈별 발 위치·칼/주먹 진행방향·피해범위 윤곽을 함께 보여준다. 범위 윤곽은 설명용이며 게임 상시HUD를 확정한 것이 아니다.
- 너클의 마나/투지/내공 분류가 미정인 동안 속성명·자원 UI를 확정하지 않는다. 공통 앰버/시안 등의 이미지 팔레트 차이는 자원판정 근거가 아니다. 문서의 흰/금색안과 이미지안 중 실제 팔레트는 후속 검토한다.
- 대검 일반/광전사/화염은 같은 동작의 대안 패널로 분리한다. 하나의 캐릭터가 두 계열자원·강화를 동시에 쓰는 그림으로 합치지 않는다.
- 태산압정의 도약/착지, 금강쇄의 어퍼컷, 유운수의 성공방어, 무극패왕권의 동시슬롯은 현 원본과 다른 미구현목표를 명시한다.
- 미래80개도 동일ID를 쓰되 이미지가 실제 생성·검수·전달되지 않았다면 이 문서의100개 기획완료와 이미지100개 완료를 혼동하지 않는다.

### 14.4 최소 승인/실기 체크리스트

- [ ] 기술명·슬롯·역할이 기준100개와 일치하고 기본공격/패시브/Ctrl 중복 없음.
- [ ] 실제몽타주와 목표포즈의 차이, 소스미확보, 미구현상태를 숨기지 않음.
- [ ] 준비/접촉/회복과 각 판정의 위치·타이밍을 실제 화면에서 대응 확인.
- [ ] 동일대상·다중뼈·지면/검 중첩·왕복·반사·산개에서 의도한 타수 상한 유지.
- [ ] 실패반격, 허공공격, 부족차징, 벽/절벽/천장, 메뉴/사망/교체에서 안전 종료.
- [ ] 너클계열 미정, 대검활성자원택1, 마법사전용입력/런페널티 미정항목을 유지.
- [ ] 일반/강화 전후 시야·성능·가독성·멀미/섬광 접근성을 별도 확인.
- [ ] 새100개 동작/VFX·밸런스가 구현완료라는 문구를 사용하지 않음.

## 15. 문서 완결 범위

너클 K01~K10, 대검 G01~G10, 단검 D01~D10, 쌍검 T01~T10, 활 B01~B10, 표창 S01~S10, 쌍단검 A01~A10, 장검 L01~L10, 대방패 H01~H10, 검버클러 C01~C10의 **100개 후보 상세기획**을 수록했다. 각 항목은 콘셉트/의도, 준비·접촉·회복, 범위·타수·중복방지, 시작·접촉·종료VFX, 빈틈, 원본/미구현 차이를 포함한다. 마법사는 별도 절로 분리했다. 이미지 생성물과 실제게임 QA의 결과는 별도 전달물/증거를 확인해야 하며 이 문서만으로 완료를 대신하지 않는다.
