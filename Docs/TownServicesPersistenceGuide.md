# 마을 NPC 서비스와 진행 저장 사용 가이드

선택한 캐릭터의 성장, 스킬 진행, 인벤토리와 마을 서비스 결과를 저장한다. 기존 StartHub 안내 NPC 아린의 대화창에서 물약 구매, 장비 강화, 특성 강화창과 다음 탐험 난이도 선택을 이용할 수 있다. 특성 강화창은 전투·생존·기동·탐험의 16종 투자와 무료 재분배를 제공한다.

인벤토리·스킬·성장은 각각 독립된 UI와 상태 영역으로 유지한다. 여러 영역을 같은 프로필 진행 파일에 저장해도 특성 창에 해당 관리 화면을 합치지 않는다. 특성별 수치와 세부 조건은 [특성 강화 가이드](TraitEnhancementGuide.md)를 참고한다.

현재 지원 범위는 로컬 단일 플레이(NM_Standalone)다. 선택 프로필 없이 에디터에서 맵을 직접 실행하면 기존 세션 보급 정책을 사용하며 캐릭터 진행을 디스크에 저장하지 않는다.

## 조작과 이용 조건

| 조작 | 동작 |
| --- | --- |
| 아린 근처에서 F | 대화 열기 |
| 대화 중 ↑ / ↓ | 서비스 항목 선택 |
| Enter | 선택한 서비스 실행 |
| Esc | 대화 닫기 |
| 보급을 아직 받지 않은 대화에서 F | 최초 출발 보급 받기 |
| 보급 수령 이후 F | 대화 닫기 |
| I | 인벤토리 정리 |

아린의 대화에서 `특성 강화창`을 선택하고 Enter를 누르면 전용 창을 연다. 특성 창에서는 방향키/WASD로 선택, Enter/Space로 강화, Tab으로 분류 순환, 1~5로 전체·전투·생존·기동·탐험 선택, R로 재분배 확인, Esc로 취소·닫기를 수행한다.

서비스는 StartHub에서 살아 있는 캐릭터가 NPC 대화 범위 안에 있고 런 상태가 WaitingToStart일 때 이용할 수 있다. 기본 대화 범위는 320cm다. 멀어지거나 캐릭터 상태가 바뀌면 대화와 전용 서비스 입력이 해제된다.

저장할 캐릭터를 선택한 경우에는 해당 프로필의 복원이 끝나야 보급과 서비스를 이용할 수 있다. 실패 사유, 골드, 특성 포인트, 강화 단계와 선택 난이도는 대화창에 표시된다. 검증된 현재 프로필의 쓰기 실패 이후에는 특성 창을 열어 저장을 재시도할 수 있지만, 저장이 준비되기 전에는 추가 투자·재분배를 할 수 없다.

## 기본 서비스 수치

대화 메뉴는 다음 7개 항목을 표시한다. 기존 활력·힘 개별 항목은 특성 전용 창의 강인한 육체·날카로운 일격으로 이어진다.

| 순서 | 서비스 | 기본 비용 | 기본 효과 / 상한 |
| --- | --- | --- | --- |
| 1 | 회복 물약 1개 구매 | 10골드 | TutorialData.StartingItem에 지정한 소모품 1개 |
| 2 | 장착 주무기 강화 | 25 × 다음 강화 단계 골드 | 단계마다 공격 +2, 최대 +5 |
| 3 | 장착 몸통 방어구 강화 | 25 × 다음 강화 단계 골드 | 단계마다 방어 +2, 최대 +5 |
| 4 | 특성 강화창 | 창 열기 무료 | 16종 투자; 일반 특성 단계당 1포인트, 불굴은 LV 20·3포인트; 무료 재분배 |
| 5 | 다음 탐험: 쉬움 | 없음 | 아래 난이도 배율 선택 |
| 6 | 다음 탐험: 보통 | 없음 | 아래 난이도 배율 선택 |
| 7 | 다음 탐험: 어려움 | 없음 | 아래 난이도 배율 선택 |

장비 강화에는 실제 Item Data Asset이 연결된 장착 아이템이 필요하다. 이름만 가진 기존 자리 표시자 장비는 강화할 수 없다. 강화 비용은 +1부터 순서대로 25, 50, 75, 100, 125골드다. 최대 단계에 도달하거나 골드가 부족하면 상태와 재화가 바뀌지 않는다. 물약을 넣을 공간이 부족한 경우에도 골드를 차감하지 않는다.

캐릭터 레벨이 오를 때 특성 포인트 1을 얻는다. 사용 가능한 포인트는 `max(0, 레벨 - 1 - 실제 사용 포인트 합계)`로 계산하며, 포인트 지갑을 별도로 중복 저장하지 않는다. 특성별 단계·구매 당시 비용·누적 효과를 기록하므로 불굴의 3포인트 비용과 커스텀 비용도 계산에 반영한다.

무료 재분배는 특성 투자만 초기화하고 실제 사용한 비용을 전부 환급한다. 성장·스킬·인벤토리·아이템 강화는 유지한다. 투자나 재분배 후 현재 HP·스태미나는 절대값을 유지하고 새 최대값을 넘는 부분만 줄인다. 최대치를 내렸다가 다시 투자해 무료 회복을 얻을 수 없다.

경험치 보상이 있는 몬스터의 기본 금화는 난이도로 보정된 실제 경험치 보상의 10분의 1을 정수로 내림한 값이며 최소 1이다. 경험치 보상이 0이면 금화도 지급하지 않는다. 전리품 감각은 그 기본 금화에만 최대 +15%를 추가하고 경험치를 늘리지 않는다. 소수 금화 보너스는 현재 탐험에서 누적해 정수 금화로 지급한다.

| 난이도 | 몬스터 최대 HP | 몬스터 피해 | 경험치 보상 |
| --- | --- | --- | --- |
| 쉬움 | ×0.75 | ×0.75 | ×0.75 |
| 보통 | ×1 | ×1 | ×1 |
| 어려움 | ×1.5 | ×1.25 | ×1.5 |

선택 수치는 포탈 이후 새로 생성되는 몬스터에 적용된다. 경험치 보상이 바뀌면 그 보상에서 계산하는 골드도 함께 달라질 수 있다. 이미 진행 중인 런의 난이도는 마을 서비스에서 바꿀 수 없다.

## 저장되는 데이터

| 영역 | 저장 내용 |
| --- | --- |
| 성장 | 레벨, 현재 경험치, 다음 레벨 필요 경험치, 장착 무기 타입 |
| 스킬 진행 | 기술별 사용 횟수, 몬스터별 처치 횟수, 해금 스킬, 공격 입력 슬롯 배치 |
| 인벤토리 | 좌우 장비 슬롯, 기존 아이템 슬롯, 그리드 위치/수량, 아이템 GUID, 추가 가방, 골드/크리스탈, 소모품 퀵슬롯 배치 |
| 아이템 강화 | 개별 강화 단계, 누적 공격/방어 보너스 |
| 마을 진행 | 16종 특성의 ID·단계·실제 사용 포인트·누적 보너스, 다음 탐험 난이도와 선택 당시 배율 |
| 최초 보급 | 보급 RewardId의 프로필별 수령 기록 |

아이템과 스킬 에셋은 소프트 에셋 경로로 기록한다. 강화 수치는 장착 해제, 장비 교체, 그리드 이동, 드롭과 재획득을 거쳐 같은 아이템 인스턴스에 보존된다. 드롭 아이템은 근처에서 충돌 범위에 들어가면 재획득하며, 가방에 공간이 없으면 월드에 남는다.

공격 입력 슬롯에 어떤 스킬을 배치했는지는 캐릭터별 진행 데이터다. 물리 키를 어떤 키로 바꿨는지는 기존 `Rogue10mSkillKeys_<로컬 컨트롤러 ID>` 설정을 사용하며 캐릭터 공통이다.

현재 런의 남은 시간, 몬스터 위치/상태, 캐릭터의 현재 HP/스태미나/마나, 전투 쿨다운과 월드에 드롭된 아이템 액터는 저장하지 않는다. 연격 대상·적중 수·버프, 회피 반격 기회·재사용 시간, 처치 회복 재사용 시간, 불굴 사용 여부와 미지급 소수 금화도 탐험 중 임시 상태이며 새 탐험 시작·새 Pawn 생성에서 초기화한다. 드롭한 뒤 재획득하지 않고 종료한 아이템은 인벤토리에 다시 생기지 않는다. 소모품 퀵슬롯의 사용 쿨다운은 복원 시 초기화한다.

## 저장 시점과 프로필 구분

진행 슬롯 이름은 `Rogue10mProgression_<ProfileGuid의 32자리 숫자/문자>`다. 일반적인 로컬 저장 위치는 프로젝트의 `Saved/SaveGames/`다. 캐릭터 이름을 바꿔도 프로필 GUID가 같으면 같은 진행을 사용하며, 새 프로필 GUID는 새 진행으로 시작한다.

Pawn이 준비된 뒤 성장 → 인벤토리 → 특성 → 스킬 → 파생 능력치 순서로 복원한다. 새 프로필은 기존 Controller의 PlayerState가 재사용돼도 이전 캐릭터의 성장과 특성을 물려받지 않는다. 신규 진행의 무기 타입과 스킬 배치는 실제 장착 주무기에 맞춘다.

변경 이벤트가 발생하면 1초 뒤 자동 저장한다. 지속적으로 공격해도 최초 예약을 계속 미루지 않는다. 특성 창의 투자·재분배 완료, 포탈 이동 직전과 Pawn의 장착 해제/종료 시에는 즉시 저장한다. 포탈 저장이 실패하면 이동을 중단한다. 운영체제 강제 종료나 프로세스 강제 종료는 마지막 저장 이후의 변경을 남기지 못할 수 있다.

기존 파일을 읽지 못하거나 지원하지 않는 저장 버전/프로필이거나 필요한 에셋과 인벤토리 배치를 복원할 수 없으면 기존 파일을 덮어쓰지 않는다. 대화창에 저장 오류를 표시하고 보급과 서비스를 막는다. 쓰기 실패 후에도 검증된 현재 상태를 유지한다. 특성 창의 오류 상태에서 `저장 재시도` 버튼으로 `URogue10mProgressionSubsystem::SaveNow()`를 호출할 수 있다. 재시도는 현재 프로필의 모든 진행 영역을 함께 저장하며, 읽기·검증 실패 파일을 덮어쓰는 복구 동작은 제공하지 않는다.

프로필 저장이 활성화된 경우 보급품도 전체 인벤토리에 포함된다. 기존 보급 전용 포탈 운반을 함께 실행하지 않으므로, 수령한 물약이 포탈 이동 때 복제되지 않는다. 수령 기록은 해당 프로필에만 속한다.

## 저장 버전 1 → 2 전환

현재 진행 저장 버전은 2이며 버전 1 파일도 읽는다. 버전 1의 활력·힘 단계와 실제 누적 보너스를 새 특성 투자 기록으로 옮기고, 각 단계에 사용했던 1포인트 비용을 기록한다. 새로 추가된 14종은 미투자 상태로 시작한다. 기존 NPC에서 조정했던 활력·힘 보너스를 현재 기본 수치로 다시 계산하지 않는다.

파일과 모든 진행 영역의 검증·복원이 끝난 뒤에만 버전 2 저장을 요청한다. 복원에 실패한 기존 파일은 보존한다. 버전 2에도 기존 활력·힘 필드를 호환용으로 함께 기록하며 새 투자 기록과 일치하는지 검증한다. 지원 범위를 벗어난 버전, 중복 특성 ID, 잘못된 단계·비용·효과와 획득 포인트보다 큰 사용량은 거절한다.

## 서비스 데이터 조정

`URogue10mTownServiceDataAsset`을 만들어 NPC의 `ServiceData`에 연결하면 물약·장비 강화 비용, 최대 장비 강화 단계, 기존 활력·힘의 최대 단계·증가량과 난이도 배율을 조정할 수 있다. `ServiceData`가 비어 있으면 C++ 클래스 기본 객체(CDO)를 사용하므로 기존 안내 NPC도 별도 바이너리 에셋 수정 없이 서비스를 표시한다. 판매 물약과 최초 보급은 기존 `TutorialData`를 사용한다.

16종 정의는 `URogue10mTraitCatalogDataAsset`이 담당한다. 에셋을 만들면 사용 중인 PlayerState의 `URogue10mTownProgressionComponent.TraitCatalog`에 연결한다. 비어 있으면 카탈로그 CDO를 사용한다. 카탈로그는 이름·분류·비용·해금 레벨·효과·상한·시간 조건을 제공하고, NPC ServiceData의 활력·힘 증가량과 상한은 계속 우선 적용한다. 두 특성의 최종 상한은 카탈로그와 NPC 상한 중 작은 값이며 나머지 14종은 카탈로그를 사용한다.

강화와 특성은 구매 당시 실제로 적용한 보너스를 아이템/캐릭터에 저장한다. 특성은 실제 사용한 비용도 보존해 재분배 때 그 비용을 환급한다. 난이도도 선택 당시의 배율을 저장하므로 커스텀 ServiceData의 효과가 재접속 후 유지된다. 이후 Data Asset 수치를 바꿔도 이미 구매한 보너스가 자동 재계산되지는 않는다. 추가 투자에는 새 증가량을 적용하며, 특성의 시간·적중 조건은 현재 카탈로그를 사용한다.

비용은 양수여야 한다. 장비 강화·기존 활력·힘 상한은 1~5, 난이도 배율은 유한한 0.1~10 범위에서 검증한다. 특성 카탈로그에는 16개 ID가 중복 없이 있어야 하며 활력·힘 최대 5단계, 불굴 최대 1단계, 나머지 최대 3단계를 지원한다. 불굴은 비용 3 이상·해금 LV 20 이상이며, 다른 값도 특성별 허용 범위를 검증한다. 잘못된 설정은 대화창에서 이용을 거절한다. 세부 필드와 튜닝 주의점은 특성 강화 가이드에 정리했다.

2026-10-11 기능 구현과 네이티브 검증을 완료했고, 최신 작업 폴더 및 원본 통합 Editor 빌드는 성공했다. 원본 `integrated01` Write 60개/Read 25개 검사로 서비스, 성장/아이템/스킬 재시작 복원, 방어구 강화, 물약 퀵슬롯 이동과 프로필 격리를 확인했다. 원본 `integratedrun01` Write 42개/Read 15개 검사는 실제 포탈 이동, 보급 중복 방지, 강화 아이템 드롭/재획득과 어려움 몬스터 보상·재시작 복원을 확인했다. 분리 작업 폴더에서도 같은 서비스/런 검사가 통과했다. `failure01`의 27개 검사는 맞지 않는 버전과 누락 에셋 파일을 거절하고 기존 저장 바이트를 보존하는 것을 확인했다. 1280×720 / 1920×1080 화면·입력 검사는 각각 9개가 통과했고 원본 생성 출력 검사도 통과했다. 최신 F8 입력과 함께 사용하는 원본 720p 화면·서비스 입력 검사 9개도 모두 통과했다.

## 현재 16종 검증과 후속 작업

이번 확장의 최종 Editor 빌드는 성공했다. 실제 전투 효과 100개, 저장 Write 125개·Read 227개, 특성 창 1080p·720p 화면·입력·무료 재분배·저장 재시도 260개가 모두 통과했다. 현재 통합 코드에서 기존 마을 서비스 Write 60개·Read 25개와 포탈/런 Write 42개·Read 15개도 다시 통과했다. 버전 1의 맞춤 보너스 보존, 16종 재시작 복원, 실제 비용 환급, 프로필 격리, 21개 잘못된 저장의 원본 바이트 보존과 실제 쓰기 실패 후 재시도를 검증했다. [이번 적용 결과](../Feature/doc/2026-10-11_trait16-runtime.md)에 명령과 증거 경로를 기록했다.

저장 버전 1 → 2 전환과 특성 창의 쓰기 실패 재시도는 이번 구현에 포함했다. 남은 후속 작업은 저장 백업·복구 UI, 모든 화면에서 접근할 수 있는 일반 수동 저장 UI, 멀티플레이어 서버 저장 정책, 신규 아이템/서비스 카탈로그와 실제 플레이 기반 재화·특성·강화 밸런스 조정이다. 향후 특성 추가나 이미 구매한 보너스의 변경에는 별도 저장 전환·환급 정책이 필요하다.
