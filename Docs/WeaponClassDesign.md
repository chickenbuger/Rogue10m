# 무기 직업 전투 설계 제안

작성: 2026-11-10. 이 문서에서 **확정**은 사용자의 최신 지시, **제안**은 구체화한 설계안이다. 이름·효과·분배·수치는 별도 표시가 없으면 제안이다. 실제 우선 개발은 너클·대검이며 나머지는 미래 기획이다.

## 1. 확정 규칙
- 무기 미장착은 뉴비. 좌클릭 주먹질만 사용한다. 장착한 무기에 따라 직업을 얻는다.
- 초반 기초 무기 모두 지급 예정. 구체 지급 시점은 미정이다.
- 무기별 기술10개 후보 중 최대6개 장착. Q/E/R/짧은 우클릭은 공용4개, 좌+우 동시와 우클릭 차징은 각 전용1개다. 전용기술은 공용슬롯에 넣을 수 없다.
- 좌클릭 기본공격, Ctrl 아이덴티티는 장착6개와 별도다. Shift달리기, Space점프, F상호작용.
- 아이덴티티/자원은 현재 선택 계열 하나만 활성. 비활성 무기/계열의 성장은 보존한다.
- 마법사는 아래 전용 명령 규칙을 우선한다. 근접10후보/6장착을 마법사에도 그대로 적용할지는 미정이다.

## 2. 너클: 짧은 빈틈에 들어가는 연속 타격
### 확정 아이덴티티
Ctrl로 일정 시간 공속·이속 증가, 스킬 강화 및 소폭 공격력 증가. Post Process와 캐릭터 주변 오라 사용. 지속시간·증가율·소모자원은 미정이다.

### 성장 세 방향
- **일반**: 기본공격·기술숙련·범위·재사용 중심. 새 자원이나 Ctrl 기능을 임의 확정하지 않는다.
- **투지→광전사**: 활성 자원 투지 하나. Ctrl 광전사 상태 후보. 너클의 공속복제가 아니라 경직저항·자세붕괴·마무리를 중심으로 제안.
- **마나→화염계**: 활성 자원 마나 하나. 물리동작에 화염효과를 더하는 Ctrl 화염무장 후보. 일반기술의 MP소모 여부는 미정.
- 광전사와 화염을 동시에 활성하지 않는다. 비활성 방향 투자기록은 보존하지만 그 효과까지 동시에 적용하지 않는다.

## 4. 마법사: 최신 사용자 확정
- Ctrl로 명령 입력 상태에 진입한다. Q/E/R 순서조합을 사용한다.
- 조합 가중치가 마나소모·공격력·속성 등을 가감한다.
- 현재 마나보다 큰 마법은 최대마나·체력 손실을 발생시킨다. 잘못된 마법도 유사 페널티를 받는다.
- 페널티는 **이번 판까지만** 지속하고 다음판 초기화한다. 사용자 프로필 기본 능력치의 영구손상으로 구현하지 않는다.
- 리듬게임 등 다양한 미니게임으로 마법을 해금한다.
- 마법서클 개념을 도입한다.
- 일반상태 Q/E/R에는 숙련이 높은 마법 또는 약2단계 하위마법을 설정해 즉발할 수 있다.

### 제안과 미정
일반상태의 QER 즉발과 Ctrl 명령상태의 조합입력은 서로 소비처를 분리한다. 현재 문자열·예상 마나·속성·초과위험을 표시하는 안을 제안한다. 서클은 복잡도/단계 후보로 해석할 수 있지만 사용자가 의미를 아직 특정하지 않았다.

주문길이·완료/취소·시간제한·오주문 판정·페널티수치·체력손실의 현재/최대 구분·즉발 OR/AND 및2단계 비교기준·해금/숙련의 영구보존범위는 미정이다. 실제 구현으로 확정하지 않는다.

런 페널티는 버프와 별도 보정이며 무기교체·Ctrl 해제로 없어지지 않는다. 같은 런 중단/재개에서는 유지하는 안을 권장한다. 새 런에서는 제거한다. 화염탄(단일폭발)·냉기파(제어)는 대표 주문후보이며 근접 동시/차징 슬롯은 아직 배정하지 않는다.

## 6. 구현 상태와 안전
6슬롯/전용정책/뉴비제한/프리셋/너클 기간제 기반을 우선 구현한다. 열거한 모든 기술과 강화효과의 콘텐츠 제작·애니메이션·개별밸런스까지 완료한 상태가 아니다.

너클 실험값은8초/30초쿨다운/공속25%/이속20%/피해8%/스킬범위10%로 **임시 제안**이다. 고유 스킬별 강화 대신 범위공통강화를 실험한다. 효과는 중첩하지 않고 종료·무기교체·사망·런종료에 정리한다. 기본 GAS 속성은 수정하지 않으므로 다른 성장/장비변경을 옛값으로 덮어쓰지 않는다. 버프시간·효과객체·차징상태는 durable 저장에서 제외한다.
