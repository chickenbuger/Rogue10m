# 중앙 확장형 혼합 성장 스킬트리

2026-10-18 기획 초안. [사용자 참조 이미지](../Feature/doc/evidence/hybrid-skill-tree-20261018/reference.png)의 중앙에서 바깥으로 뻗는 배치를 참고한다. 아래 수치와 새로운 해금 규칙은 제안이며 실제 게임에 적용되지 않았다.

같은 날 사용자 확정 사항: **격투가의 사용 가능 아이덴티티는 내공·투지 두 계열이다.** 마나는 다른 직업의 공용 계열로 남기며 격투가 트리의 해금·활성·기술 변형·공명에는 포함하지 않는다. 기존3계열 구조도와v2 이미지 시안은 변경 전 기록이다.

현재 격투가 화면 시안은 [내공·투지 v3 PNG](../Feature/doc/evidence/hybrid-skill-tree-20261018/imagegen-mockup-v3.png)를 따른다.

## 1. 설계의 중심

**기본기를 반복해 숙련과 영구 스탯을 얻고, 그 사이에서 기술을 하나씩 배운다. 레벨업 포인트는 아이덴티티를 일찍 선택하거나 성질을 바꾸는 데 사용한다. 숙련으로 단련한 몸은 선택한 아이덴티티의 효과와 일부 심화 해금에 영향을 준다.**

중앙 노드는 캐릭터의 시작점이다. 안쪽에서는 기본기와 아이덴티티로 갈라지고, 바깥에서는 핵심 기술과 아이덴티티가 만나는 공명 노드를 만든다. 일반 핵심 기술은 아이덴티티 없이도 사용할 수 있다.

~~~mermaid
flowchart BT
    R["중앙 · 캐릭터 시작"] --> B["격투 기본기4 + 연환권 · 무료"]
    R --> I["아이덴티티 입문 · 1P"]
    B --> S1["M3 · 공격력 +1"]
    S1 --> T1["M5 · 붕권"]
    T1 --> S2["M8 · 공격력 +2"]
    S2 --> T2["M12 · 금강쇄"]
    T2 --> S3["M16 · 공격력 +2"]
    S3 --> T3["M20 · 무극패왕권"]
    I --> I2["심화 · 2P 또는 숙련+영구 성장"]
    I2 --> I3["성질 선택 · 2P"]
    T3 --> X["핵심기 공명 · 양쪽 선행 필요"]
    I3 --> X
~~~

`M`은 격투 숙련 레벨, `P`는 레벨업으로 얻는 공용 성장 포인트다. 위 그림은 정권 계열의 대표 경로이며 다른 수련 경로도 존재한다.

## 2. 노드 역할과 공간 배치

|영역|노드|하는 일|주요 해금 방식|
|---|---|---|---|
|중앙|시작점|직업·무기 계열 연결, 기본 전투 제공|무료|
|안쪽|기본기|잽·스트레이트·훅·어퍼컷과 연환권|격투가 초기 전수|
|안쪽|아이덴티티 입문|격투가는 내공·투지 중 사용 성향 선택|1P, 숙련 조건 없음|
|중간|스탯|수련 경로의 작은 영구 성장|숙련 단계, 무료|
|중간|기술|직전 스탯·기술을 이어 순차 전수|숙련 + 선행, 무료|
|바깥|핵심 기술·심법|운용을 바꾸는 강한 기술·상시 효과|숙련 + 선행|
|연결부|아이덴티티 심화|자원·효율·발동 효과 강화|포인트 또는 숙련 성장|
|끝점|성질·공명|선택한 아이덴티티로 핵심기를 변형|성질은 포인트, 공명은 양부모 선행|

실제 화면에서는 중앙 주위 첫 링을 아이덴티티, 두 번째 링을 무기별 기본기 입구, 바깥 링들을 스탯→기술→스탯→핵심기로 배치한다. 진행 방향은 중심에서 외곽이다. 좌우 직업 부채꼴과 아래쪽 공용 아이덴티티 영역을 사용해 참고 이미지의 읽는 순서를 유지한다. 현재 무기 경로를 먼저 보여주고 다른 직업은 접어서 혼잡을 줄인다.

작은 원은 스탯, 큰 원은 기술, 마름모는 아이덴티티, 이중 표식은 공명으로 구분한다. 계열 색과 함께 이름·모양을 사용한다. 실선은 필수 선행, 점선은 선택한 아이덴티티의 공명 연결이며 포인트/숙련 대안은 연결선 대신 조건 패널에서 `또는`으로 보여준다. 융합의 두 선행은 모두 만족해야 한다.

## 3. 포인트와 숙련의 역할

### 공용 성장 포인트

신규 캐릭터는 레벨1에서0P로 시작하고 레벨이 오를 때마다1P의 사용 권리를 얻는다. 기존 마을 특성 포인트와 같은 원장을 사용한다.

```text
누적 획득 P = max(0, 캐릭터 레벨 - 1)
사용 가능 P = 누적 획득 P - 특성 실제 투자 비용 합 - 스킬트리 실제 투자 비용 합
```

구매 전에 잔액을 검사하고 한 거래에서 비용과 NodeId를 함께 기록한다. 유효 원장에서 잔액은 음수가 될 수 없다. 비용 합이 획득량을 초과한 저장은 오류로 처리하며0으로 감춰 다시 지급하지 않는다. 이 설계는 포인트를 하나 더 지급하는 방식이 아니다.

특성 화면과 스킬트리 화면은 분리하되 같은 잔액을 표시한다. 레벨2에서 특성에1P를 먼저 투자했다면 아이덴티티 입문에 쓸 잔액은0P다. 기존 무료 특성 재분배로1P를 돌려받아 입문할 수 있다. 스킬트리 재분배는 스킬트리 투자만, 특성 재분배는 특성 투자만 환급한다.

### 격투 숙련

맨손과 너클은 하나의 `Brawler` 숙련을 공유한다. 무기를 갈아 끼워 같은 보상을 두 번 얻을 수 없다. 숙련 XP는 소비 재화가 아니며, 노드가 요구하는 숙련 레벨에 도달하면 유지된다.

숙련 스탯 노드는 숙련 단계 보상의 표시이자 선행 지점이다. 별도로 '숙련 레벨당 스탯'을 또 지급하지 않는다. 현재 안에서는 모든 수련 경로를 함께 배울 수 있으며, M과 선행을 만족한 무료 노드는 순서대로 자동 전수한다. 빌드 선택은 장착 기술·아이덴티티·포인트 투자에서 생긴다.

유효 적중을 낸 공격 실행1회당 숙련 XP1을 기준으로 잡고, 같은 실행의 다단히트·여러 대상은 합쳐1회만 인정한다. 죽은 대상·허공·무적 대상·훈련 표적은 지급하지 않는다. 가드/회피는 실제 공격을 막거나 피한 판정이 있을 때만 동일한 수련 성과로 인정하며, 공격1회 ID 또는 피한 적 공격 ID별로 중복을 막는다. 그 판정이 아직 없는 행동에는 XP를 지급하지 않는다.

초안의 다음 M 필요 XP는 `10 + 5 × (현재 M - 1)`이다. M1에서 M5까지70XP, M12까지385XP, M20까지1,045XP다. 일반 캐릭터 경험치와 분리하며 실제 전투 빈도·런 길이·장기 유지 여부를 측정한 뒤 속도를 조정한다. 숙련은 프로필에 영구 유지하고 새 탐험에서 초기화하지 않는다.

## 4. 격투가 노드 예시

기존 기본기4와 연환권은 초기 전수로 유지한다. 여기서 '하나씩 해금'은 초기 기본기를 사용할 수 있는 상태에서 이후 무공을 경로의 선행 순서대로 얻는다는 뜻이다. 회피도 시작부터 제공한다.

아래는 기존9개 잠금 무공을 새 숙련 경로로 재배치하는 제안이다. 공격 Data Asset의 피해·비용·쿨다운·모션을 새로 정의하지 않고 해금·배치만 설계한다. 모든 행의 비용은0P다.

|경로|노드 ID|M|선행|보상|
|---|---|---:|---|---|
|공통|`F.Basic`|1|중앙|기본기4 + 연환권|
|정권|`F.Power.1`|3|F.Basic|영구 공격력 +1|
|정권|`F.Bengquan`|5|F.Power.1|붕권|
|정권|`F.Power.2`|8|F.Bengquan|영구 공격력 +2|
|정권|`F.DiamondStrike`|12|F.Power.2|금강쇄|
|정권|`F.Power.3`|16|F.DiamondStrike|영구 공격력 +2|
|호흡·연계|`F.Breath.1`|4|F.Basic|영구 최대 스태미나 +5|
|호흡·연계|`F.CloudHands`|6|F.Breath.1|유운수|
|호흡·연계|`F.Breath.2`|9|F.CloudHands|영구 최대 스태미나 +5|
|호흡·연계|`F.HundredFists`|13|F.Breath.2|백열난무|
|호흡·연계|`F.Flow.3`|17|F.HundredFists|공격 속도 배율 +0.02|
|체술·방어|`F.Body.1`|4|F.Basic|영구 최대 HP +5|
|체술·방어|`F.Shoulder`|7|F.Body.1|철산고|
|체술·방어|`F.Body.2`|9|F.Shoulder|영구 방어력 +1|
|체술·방어|`F.BreakingKick`|10|F.Body.2|파진각|
|체술·방어|`F.Body.3`|14|F.BreakingKick|영구 최대 HP +5|

무극패왕권의 선행은 `(F.Power.3 AND F.DiamondStrike) OR (F.Flow.3 AND F.HundredFists) OR (F.Body.3 AND F.MountainSlam)`이다. 하나의 길을 마친 플레이어가 다른 모든 길의 완주를 강요받지 않게 한다. 공용 숙련을 올리면 다른 길도 자동 전수할 수 있지만 최종 노드의 정의는 단일 경로 완주로 성립한다.

표의 영구 스탯 총합은 공격력+5, 최대 스태미나+10, 최대 HP+10, 방어력+1, 공격 속도 배율+0.02다. 각 NodeId의 보상은 한 번만 반영한다. 금강불괴는 별도 기존 패시브이며 이 합계에 피해감소를 재차 더하지 않는다.

기존 기술 명칭이 요구하는 회전·공중 동작을 이 설계 때문에 복원하지 않는다. 파진각 등의 실제 모션은 현재 안전 모션 정책을 유지하고, 이름과 실제 연출의 일치 검토는 후속 콘텐츠 작업으로 분리한다.

## 5. 아이덴티티 혼합 해금

격투가의 아이덴티티는 내공·투지다. 현재 런타임의 돌주먹·기력·마력·집중·분노 타입과 동일한 enum으로 가정하지 않는다. 특히 기존 돌주먹의 기본 전투를 새 포인트 입문 뒤로 잠그지 않는다. 마나는 다른 직업용 공용 정의로 보존하되 격투가의 허용 목록에 넣지 않는다.

두 계열의 입문→심화→성질 선택 순서는 같다. 내공과 투지를 모두 배울 수 있으나 활성 아이덴티티는 둘 중1개다. 다른 계열의 효과·게이지·공명은 동시에 적용하지 않는다.

|계열|입문|심화: 입문 이후|성질 선택: 심화 이후|지향점|
|---|---|---|---|---|
|내공|1P, M 조건 없음|2P **또는** M12 + 숙련 스태미나 성장10|2P|꾸준한 연계·효율|
|투지|1P, M 조건 없음|2P **또는** M12 + 숙련 공격력 성장3|2P|강타·순간 폭발|

심화의 숙련 대안은 격투로 단련한 몸이 내공/투지에 직접 연결되는 통로다. 내공은 호흡·연계와 자원 효율, 투지는 강타·순간 폭발을 중심으로 차이를 만든다. 포인트로 일찍 배우거나 숙련 성장으로 심화하는 혼합 해금 규칙은 두 계열에 동일하게 유지한다.

심화 조건의 스탯은 **해당 격투 숙련 스탯 노드에서 얻은 영구 증가량**이다. 장비·버프·특성 투자·아이덴티티 보너스는 조건에 넣지 않는다. 숙련과 스탯은 대안 내부에서 AND, 포인트 경로와 숙련 경로 사이는 OR다.

```text
투지 심화 해금 가능 = 투지 입문 전수 AND
    (사용 가능 P >= 2 OR (격투 M >= 12 AND 격투 숙련 공격력 증가량 >= 3))
```

해금 가능 상태에서 플레이어가 경로를 확인하고 선택한다. 숙련 대안을 만족하면 기본 제안은0P 수련 경로다. 포인트로 먼저 연 심화도 숙련 조건에 도달했다고 보상을 두 번 지급하지 않는다. 지불한 P는 자동 환급하지 않고, 재분배 시 실제 비용만 돌려준다. 그때 숙련 조건이 충족되면0P 경로로 다시 선택할 수 있다.

성질 선택에서는 계열별 두 효과 중 하나를 고른다. 동일 선택 노드의 다른 성질로 바꾸려면 마을에서 재분배한다. 비용2P는 선택 노드 하나의 비용이며 양쪽을 동시에 구매하지 않는다.

|계열|성질 A|성질 B|
|---|---|---|
|내공|순환: 아이덴티티 발동 후 다음 연계 자원 소모 감소|방출: 모은 내공을 핵심기의 범위 효과로 사용|
|투지|폭발: 완충 게이지를 단일 강타에 집중|집중: 폭발량을 낮추고 공격 후 빈틈 감소|

게이지 발동·소모·재사용 시간·정확한 피해 계수는 후속 전투 밸런스 Data Asset에서 튜닝한다. 입문 시 무상 영구 자원을 무한 제공하지 않으며, 활성 내공 또는 투지의 자원 규칙만 사용한다. 격투가는 마력 추격·확산 성질이나 마나 공명을 선택할 수 없다.

## 6. 숙련 스탯이 아이덴티티에 미치는 영향

숙련이 포인트를 대신하는 일부 심화 통로 외에도, 같은 아이덴티티를 선택한 두 캐릭터는 숙련 성장에 따라 발동 효과가 달라진다. 아래는 **유료 심화를 강제하지 않는 입문 효과의 예시 산식**이다. 평타마다 무조건 붙는 보너스가 아니라, 자원·쿨다운 조건을 만족한 아이덴티티 발동에 적용한다.

`GAtk`은 격투 숙련 공격력 증가량, `GStam`은 격투 숙련 최대 스태미나 증가량이다. 해금 조건은 장착과 무관한 영구 기록을 읽는다. 아래 발동 산식은 현재 무기가 격투 계열일 때만 그 값을 읽고, 비격투 무기에서는 격투 출처의 GAtk/GStam을0으로 평가해 기본 계수만 남긴다. 현재 스탯 전체나 장비 수치를 대신 넣지 않는다. 다른 무기 숙련을 연동하려면 그 계열의 별도 출처와 계수를 정의해야 한다.

|계열|발동 효과의 기획 예시|M12의 성장값을 넣은 예시|
|---|---|---|
|내공|추가 피해 배율 `0.08 + 0.002 × GStam`|GStam10 → 기본 피해의10% 추가|
|투지|강타 추가 피해 배율 `0.10 + 0.01 × GAtk`|GAtk3 → 기본 피해의13% 추가|

M1도 기본 계수가 있어 포인트로 아이덴티티를 일찍 배운 의미가 있다. M20의 숙련 값으로는 내공10%, 투지15%가 된다. 계수는 초안이며 실제 능력의 공통 피해 처리와 특성 보너스는 후속 구현에서 각각 한 번만 적용한다.

스탯의 원본은 `기본값 + 숙련 노드 보상 + 특성/포인트 노드 보상 + 장비 보상`을 출처별로 합산한다. 임시 버프는 전투 적용 단계에서 따로 처리한다. 아이덴티티는 필요한 성장값을 읽어 발동 효과를 계산하며 같은 스탯을 다시 만들어 되먹임하지 않는다.

## 7. 성장·포인트 예시

|상태|포인트와 전수|플레이 느낌|
|---|---|---|
|LV1 / M1|0P, 기본기4·연환권·회피|시작부터 기본 전투 가능|
|LV2 / M1|획득1P → 내공 입문1P, 잔액0P|숙련이 낮아도 아이덴티티 사용 가능|
|LV3 / M5|누적2P, 내공 투자1P, 잔액1P. 공격력+1·붕권|전투 수련으로 다음 기술 전수|
|LV4 / M12|누적3P, 내공 입문1P, 내공 심화 수련0P, 잔액2P|스태미나+10으로 심화 대안 충족|
|LV4 / M12 / 성질 투자|남은2P로 내공 방출 선택, 잔액0P|같은 숙련에서도 포인트 배분으로 성향 결정|
|LV6 / M1|누적5P → 입문1+심화2+성질2, 잔액0P|레벨 성장으로 정체성을 먼저 완성, 핵심기 전수는 수련 진행|
|LV6 / M20|위 내공 투자 총3P라면 잔액2P. 무극패왕권 전수와 방출 공명 활성|핵심기와 아이덴티티가 마지막에 결합|

위 표는 각 상태를 독립적으로 비교하는 예시이며 특정 LV에 특정 M이 강제되지 않는다. 기존 특성 투자가 있으면 그 실제 비용만큼 잔액이 줄어든다. 포인트가 많은 저숙련 캐릭터가 아이덴티티는 완성할 수 있지만 격투 핵심기를 구매해 숙련 경로를 건너뛸 수는 없다.

공명은 `핵심 기술 전수 AND 해당 아이덴티티 성질 선택`의 양부모 노드다. 추가 비용0P이며 기존 핵심기를 선택 성질에 맞춰 변형한다. 동일 공격을 별도 스킬로 중복 지급하거나 모든 아이덴티티의 공명을 함께 발동하지 않는다.

## 8. UI·재분배·영구 상태

왼쪽에는 캐릭터 레벨·공용 P 잔액·실제 격투 숙련 XP·다음 스탯/기술·활성 아이덴티티를 표시한다. 노드 상세에는 효과, 필수 선행, 대안별 조건, 실제 비용을 표시한다. 예: `내공 입문 완료 / 포인트2P 또는 격투M12·숙련 스태미나+10 / 수련 전수0P 가능`.

노드 상태는 잠김·조건 충족·전수 완료·장착 중으로 구분한다. 자동 숙련 전수는 영구 기록이며, 포인트/성질 노드는 선택 확정이 필요하다. 슬롯 장착은 해금과 별도다. 배운 패시브에는 공격 키를 배정하지 않는다.

아이덴티티 변경과 포인트 재분배는 기존 마을 서비스의 생존·위치·탐험 출발 전 조건을 따른다. 현재 HP·스태미나·MP는 절대값을 유지하고 새 최대값을 넘는 부분만 제한한다. 새 계열 게이지는0으로 시작하고, 교체로 재사용 시간을 초기화하거나 자원을 채우지 않는다. 재분배로 제거하는 효과와 후속 노드·공명·키/슬롯을 함께 정리한다.

무료 숙련 기술·성장·XP는 포인트 재분배로 제거하지 않는다. 입문1P를 환급하면 그 계열의 심화·성질·공명은 수련/포인트 전수 경로와 무관하게 모두 철회하고 하위 유료 비용도 환급한다. 입문이 남아 있고 유료 심화2P만 환급할 때에 한해, 심화 수련 조건이 충족되면0P 경로를 확인해 다시 전수할 수 있다. 기존 성질 선택과 공명은 심화 철회 시 함께 정리하고 필요하면 다시 구매·활성화한다. 환급은 구매 당시 실제 비용을 사용한다. 카탈로그 비용 변경으로 이익을 얻지 않는다.

공용 아이덴티티 전수는 다른 무기로 유지할 수 있으나, 사용 효과는 현재 무기의 허용 계열과 전수 기술에 맞춘다. 허용하지 않는 무기로 바꾸면 배운 상태와 선택 기억을 유지하고 효과만 비활성화한다. 격투 숙련 스탯 보상은 격투 계열 적용값이며 다른 무기 숙련 보상과 전역 누적하지 않는다. 장착/교체 시 재계산하고 유효 선행의 성장값은 무기 장착과 무관한 저장 사실로 확인한다.

## 9. 기존 구현에서 후속 개발로 이어지는 경계

|현재 확인한 사실|후속 구현 제안|
|---|---|
|`Rogue10mPlayerState.cpp`의 무기 숙련은 임시 상수|실제 Brawler 숙련 XP·레벨을 PlayerState 소유 성장 컴포넌트로 분리|
|`Rogue10mAttackSkillData.h`는 공격/상시심법과 사용·토벌 조건|별도 SkillTreeNode Data Asset으로 중앙·스탯·아이덴티티·공명과 AND/OR 그룹 표현|
|`Rogue10mTownProgressionComponent.cpp`에서 특성 잔액 계산|공용 포인트 원장을 한 곳에서 계산하고 특성/스킬 창 모두 조회|
|현재 전투 컴포넌트가 기술 해금과 실행을 담당|새 성장 판정은 전용 컴포넌트, 공격 실행은 기존 Combat/GAS 유지|
|SaveGame 현재 버전2|숙련XP·NodeId·실제 비용·선택 성질·활성 계열과 원장 검증을 포함한 새 버전 계획|
|이미지의6기초속성은 미구현|현재 스탯으로 먼저 설계. 6속성 도입 시 별도 데이터·변환·밸런스 작업|
|현재 K 창은 기존14기술 트리|독립 노드 모델을 읽는 원형 Canvas UI로 Production에서 구현|

노드 정의는 `NodeId`, 노드 종류, 선행 그룹, 포인트/수련 대안, 보상 출처 ID, 전투 스킬 참조, 계열, 링·좌표를 가진다. 기술 노드만 기존 AttackSkill Data Asset을 참조한다. 빈 공격 에셋으로 스탯·아이덴티티를 흉내 내지 않는다. C++에서 성장 규칙을 처리하고 Blueprint/Data Asset은 수치·배치·에셋을 설정한다. 갱신은 경험치·구매·장착·저장 복원 이벤트를 사용하며 Tick은 필요하지 않다.

직업별 허용 아이덴티티 목록을 Data Asset에 정의한다. 격투가 목록은 `{내공, 투지}`이며 UI 표시뿐 아니라 구매·활성화·기술 바인딩·공명 실행에서도 같은 목록을 검증한다. 다른 직업에서 배운 공용 마나 기록이 있어도 격투가로는 사용할 수 없다. 해당 기록은 다른 직업의 상태로 보존하고 직업/무기 전환 시 격투가의 유효한 선택으로 복원하거나 미활성 처리한다.

기존 사용/토벌 조건은 새 숙련 조건으로 **대체**하는 방향이다. 둘을 일괄 AND로 붙여 이중 수련을 요구하지 않는다. 토벌은 이후 선택 수련 보상/도전 기록으로 유지하고 일반 핵심기 해금의 필수 병목에서 제외한다. 기존 `SkillUses`/`MonsterDefeats` 기록은 삭제하지 않는다.

저장 이전은 기존 전수 공격·바인딩·특성 투자 비용을 보존한다. 과거 허공 사용 카운터를 유효 숙련 XP로 바꾸지 않는다. 새 숙련은M1에서 시작하고, 이전 전수 기술은 `LegacyGranted`로 유지하여 사용할 수 있다. 다만 그 기록이 아직 하지 않은 숙련 스탯 보상을 지급하거나 수련 대안을 만족시키지는 않는다. 기존 전수 노드와 새 선행 관계가 어긋나면 legacy 예외만 적용하고 선행 스탯을 소급 지급하지 않는다. 파생 스탯 합계는 저장 원본이 아닌 고유 보상 출처에서 재계산한다.

현재 자동 전수·임시 숙련 UI와 이 설계의 새 시스템은 아직 연결되지 않았다. 실제 개발 시 초기 기본 바인딩과 이전 전수 기술을 보존하고 이후 잠금 후보만 새 판정에 맡겨야 한다.

## 10. 설계 검증 기준

1. LV2/M1 캐릭터가 잔액1P로 입문할 수 있다. 특성에 이미 지출했으면 같은 P를 또 쓸 수 없다.
2. M 성장 시 스탯→기술 순서와 기존 초기5기술을 유지한다. M12에 공격력+3·스태미나+10, M20에 전체 표의 합계를 확인한다.
3. 내공/투지 심화는 포인트 **또는** 지정한 숙련+영구 성장으로 열린다. 장비·버프·특성만으로0P 대안을 만족시킬 수 없다.
4. 같은 노드의 포인트/숙련 경로, 저장 재로드, 맨손/너클 교체가 보상을 재지급하지 않는다.
5. 아이덴티티 활성은1개이고 양부모 공명은 둘 중 하나만 배웠을 때 발동하지 않는다. 비활성 계열·미전수 핵심기의 공명은 적용하지 않는다.
6. 재분배·무기교체·저장 복원에서 포인트·선행·효과·게이지·바인딩이 일치하고 무료 회복을 얻지 않는다.
7. 기본 공격·일반 핵심기를 아이덴티티 구매로 잠그지 않는다. 다단히트·복수 대상·허공으로 숙련 XP를 부풀리지 않는다.
8. Production 검증은 별도 QA 저장 접두사를 사용해 기존 생산 저장을 보호한다. 이번 설계 검증은 실제 런타임 구현/플레이 밸런스 검증을 대신하지 않는다.
9. 격투가 화면에는 내공·투지만 표시한다. 공용 마나 전수 기록이 있어도 격투가의 마나 구매·활성·기술 장착·공명 요청은 거부한다. 다른 직업용 마나 정의는 삭제하지 않는다.
