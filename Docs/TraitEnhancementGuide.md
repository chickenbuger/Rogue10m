# 특성 강화 사용·튜닝 가이드

특성 강화는 캐릭터 프로필에 영구 저장하는 패시브 투자다. 전투·생존·기동·탐험의 4개 분류에 16종을 제공하며, 인벤토리·스킬·성장은 각각 독립된 UI와 상태 영역으로 유지한다. 특성 창에서는 특성 투자와 무료 재분배만 다룬다.

현재 지원 범위는 로컬 단일 플레이(`NM_Standalone`)다. StartHub에서 살아 있는 캐릭터가 아린의 대화 범위 안에 있고 탐험 출발 전(`WaitingToStart`)이어야 이용할 수 있다. 기본 대화 범위는 320cm다. 선택한 프로필이 있으면 진행 복원이 끝나야 투자할 수 있으며, 프로필 없이 맵을 직접 실행한 에디터 세션에서는 디스크에 저장하지 않는다.

## 창 열기와 조작

아린 근처에서 **F → 특성 강화창 선택 → Enter**로 연다. 카드에서 단계와 효과를 확인하고, 선택한 특성의 상세 영역에서 현재·다음 단계 효과, 비용, 해금 조건을 확인한다. 상단에는 사용 가능 포인트를 표시하고, 재분배 확인 창에서 사용한 포인트와 환급량을 확인한다.

| 조작 | 동작 |
| --- | --- |
| 방향키 / WASD | 특성 카드 선택 이동 |
| Enter / Space | 선택한 특성 1단계 강화; 재분배 확인 창에서는 확정 |
| Tab | 전체 → 전투 → 생존 → 기동 → 탐험 순서로 분류 전환 |
| 1 / 2 / 3 / 4 / 5 | 전체 / 전투 / 생존 / 기동 / 탐험 바로 선택 |
| R | 무료 재분배 확인 창 열기 |
| Esc | 재분배 확인 취소; 일반 상태에서는 특성 창 닫기 |
| 마우스 | 카드·분류 선택, 강화·재분배·저장 재시도 버튼 클릭 |

최대 단계, 해금 레벨 미달, 포인트 부족과 이용 조건 변경은 창에 사유를 표시하고 투자를 거절한다. NPC에게서 멀어지거나 캐릭터가 사망하거나 탐험 상태가 바뀌면 전용 창과 입력을 해제한다.

## 기본 특성 16종

아래는 C++ 기본 카탈로그 수치다. 비용은 **단계당 특성 포인트**이며, 불굴 외에는 LV 1부터 투자할 수 있다. 기존 NPC의 `ServiceData`가 지정한 활력·힘 수치는 아래 기본값보다 우선한다.

| 분류 | 특성 / 코드 ID | 단계당 효과 | 최대 단계 / 누적 효과 | 비용 | 발동 조건·제한 |
| --- | --- | --- | --- | --- | --- |
| 전투 | 날카로운 일격 / `Power` | 공격력 +2 | 5 / +10 | 1 | 기존 힘 강화와 같은 투자 |
| 전투 | 약점 간파 / `CriticalChance` | 치명 확률 +2%p | 3 / +6%p | 1 | 최종 치명 확률 상한 100% |
| 전투 | 정밀 타격 / `CriticalDamage` | 치명 피해 배율 +0.10 | 3 / +0.30 | 1 | 치명타에 적용; 기본 1.5배라면 1단계에서 1.6배 |
| 전투 | 연격의 달인 / `Combo` | 발동 중 피해 +4% | 3 / +12% | 1 | 같은 적에게 3초 안에 서로 다른 공격 실행 3회 적중, 버프 3초; 중첩 불가 |
| 생존 | 강인한 육체 / `Vitality` | 최대 HP +10 | 5 / +50 | 1 | 기존 활력 강화와 같은 투자; 현재 HP 충전 없음 |
| 생존 | 철벽 방어 / `Defense` | 방어력 +2 | 3 / +6 | 1 | 고정 피해 감산; 방어 계산의 최소 피해는 1 |
| 생존 | 사냥꾼의 회복 / `KillRecovery` | 직접 처치 시 HP +2 | 3 / +6 | 1 | 처치 회복 공통 재사용 2초; 최대 HP 초과 불가 |
| 생존 | 불굴 / `LastStand` | 치명적인 전투 피해에서 최대 HP의 25%로 생존 | 1 / 25% | 3 | LV 20 해금, 탐험당 1회; 시간 종료·강제 사망 제외 |
| 기동 | 기민한 발걸음 / `MoveSpeed` | 이동 속도 +3% | 3 / +9% | 1 | 걷기·질주 속도 모두 적용 |
| 기동 | 깊은 호흡 / `MaxStamina` | 최대 스태미나 +10 | 3 / +30 | 1 | 현재 스태미나 충전 없음 |
| 기동 | 절약의 보법 / `DodgeEfficiency` | 회피 스태미나 소모 −5% | 3 / −15% | 1 | 회피 가능 여부와 실제 소모량에 같은 할인 적용 |
| 기동 | 회피 반격 / `DodgeCounter` | 회피 후 첫 공격 피해 +6% | 3 / +18% | 1 | 성공적으로 회피를 시작한 뒤 2초 안에 시작한 첫 공격 실행; 재사용 8초 |
| 탐험 | 전리품 감각 / `GoldFind` | 몬스터 금화 보상 +5% | 3 / +15% | 1 | 기본 금화 보상에 적용, 경험치 유지; 소수 금화는 탐험 중 누적 |
| 탐험 | 빠른 재충전 / `StaminaRecovery` | 스태미나 회복 +1/초 | 3 / +3/초 | 1 | 살아 있는 동안 기존 재생량에 추가 |
| 탐험 | 치유의 숙련 / `PotionMastery` | 물약 HP 회복량 +5% | 3 / +15% | 1 | 그리드 물약·기존 퀵슬롯 물약에 적용; 처치 회복·자연 재생·불굴 제외 |
| 탐험 | 보스 사냥꾼 / `BossHunter` | 보스 대상 피해 +4% | 3 / +12% | 1 | `MidBoss`·`FinalBoss` 등급만 적용 |

연격은 한 공격의 다단 적중을 1회로 센다. 빗나간 공격과 대상 변경은 연속 적중을 초기화하며, 지연된 공격 결과도 실제 결과가 확정된 순서로 처리한다. 세 번째 적중으로 버프가 시작되므로 이후 피해부터 보너스를 받는다. 버프가 유지되는 동안 적중으로 지속 시간을 연장하거나 중첩하지 않는다.

회피 반격은 회피 입력이 실제 실행된 경우에만 준비된다. 스태미나 부족 등으로 회피가 거절되면 준비되지 않는다. 유효 시간 안에 시작한 첫 공격 실행이 기회를 소비하며, 그 공격의 다단 피해 전체에 같은 보너스를 적용한다. 공격 실행 자체가 거절되면 소비하지 않고, 실제 시작한 공격이 빗나가도 기회는 소비한다. 이 특성은 회피 무적 판정을 추가하지 않는다.

전리품 감각은 경험치에 배율을 곱하지 않는다. 기존 난이도로 보정된 경험치에서 계산한 기본 금화를 유지하고 그 금화에만 보너스를 붙인다. 경험치 보상이 없는 몬스터는 기본 금화도 지급하지 않는다. 소수 보너스를 모아 정수 금화로 지급하므로 작은 보상의 증가분도 탐험 중 누적된다.

## 포인트와 무료 재분배

획득 포인트는 `max(0, 캐릭터 레벨 - 1)`이며, 사용 가능 포인트는 `max(0, 캐릭터 레벨 - 1 - 실제 사용 포인트 합계)`다. 별도 포인트 지갑을 중복 저장하지 않는다. 기본값으로 16종을 모두 최대 단계까지 투자하는 데 52포인트가 필요하다.

무료 재분배 확인 창에서 환급량과 재분배 후 포인트를 확인하고 확정한다. 모든 특성 투자만 초기화하며, 구매 당시 실제로 사용한 비용을 전부 돌려준다. 이후 카탈로그 비용이 변경돼도 현재 비용으로 환급액을 다시 계산하지 않는다. 성장 레벨, 스킬 진행, 장비 강화와 인벤토리는 재분배 대상에 포함하지 않는다.

투자·재분배 시 현재 HP와 스태미나는 절대값을 유지하고 새 최대값을 초과하는 부분만 잘라낸다. 예를 들어 현재 HP 80에서 최대 HP가 150 → 100 → 150으로 바뀌어도 현재 HP는 80이다. 최대 HP나 최대 스태미나를 내렸다가 다시 투자해 무료 회복을 얻을 수 없다. 새 캐릭터 생성과 진행 복원에서 기존에 실행하던 생명력 초기화 경로는 별도로 유지한다.

## 저장과 재시도

영구 투자에는 특성 ID, 단계(`Rank`), 실제 사용 포인트(`SpentPoints`), 구매한 누적 효과(`Bonus`)를 기록한다. 현재 HP·스태미나, 연격 대상·적중 수·버프, 회피 반격 기회·재사용 시간, 처치 회복 재사용 시간, 불굴 사용 여부와 미지급 소수 금화는 저장하지 않는다. 이 임시 상태는 새 탐험 시작과 새 Pawn 생성에서 초기화된다.

특성 창에서 투자나 재분배를 마치면 즉시 저장을 요청한다. 쓰기에 실패해도 현재 세션에 적용한 투자 결과는 유지하며 오류와 저장 재시도 버튼을 표시한다. 저장이 준비되지 않은 동안 추가 투자·재분배는 막고, 검증된 현재 프로필의 쓰기 실패는 창에서 재시도할 수 있다. **저장 재시도는 특성만이 아니라 현재 프로필의 성장·인벤토리·스킬·마을 진행 전체를 저장한다.**

기존 파일 읽기·검증·복원에 실패한 상태는 검증된 쓰기 실패와 구분한다. 복원하지 못한 파일을 현재 상태로 덮어쓰는 복구 기능은 제공하지 않는다. 저장 버전 전환과 프로필별 복원 순서는 [마을 서비스·저장 가이드](TownServicesPersistenceGuide.md)를 참고한다.

## 카탈로그와 기존 NPC 튜닝

특성 정의는 `URogue10mTraitCatalogDataAsset`에서 관리한다. 별도 에셋을 연결하지 않으면 C++ 클래스 기본 객체(CDO)의 16종 정의를 사용한다. 기본 동작을 위해 기존 NPC 바이너리 에셋을 수정할 필요는 없다.

커스텀 설정은 Unreal Editor에서 해당 클래스의 Data Asset을 만들고, 사용 중인 PlayerState 클래스의 `URogue10mTownProgressionComponent.TraitCatalog`에 연결한다. 투자 상태는 PlayerState의 Town 컴포넌트가 소유하고, 캐릭터의 `URogue10mTraitRuntimeComponent`는 탐험 중 임시 효과를 관리한다. NPC의 `ServiceData`에 TraitCatalog를 연결하는 구조가 아니다.

| 정의 필드 | 조정 대상 |
| --- | --- |
| `Trait`, `Category` | 특성 ID와 전투·생존·기동·탐험 분류 |
| `DisplayName`, `Description`, `EffectSummary` | 카드·상세 영역에 표시하는 이름과 설명 |
| `MaxRank`, `PointCost`, `UnlockLevel` | 투자 상한, 단계당 비용, 해금 레벨 |
| `ValuePerRank` | 단계당 효과; 확률·비율은 0.02처럼 소수 단위 |
| `DurationSeconds`, `CooldownSeconds`, `RequiredHits` | 연격·회피 반격의 시간, 처치 회복 재사용 시간과 연격 적중 조건 |

카탈로그에는 16개 ID가 중복 없이 모두 있어야 한다. 활력·힘 상한은 5, 불굴은 1, 나머지는 3까지 지원한다. 활력·힘 비용은 1이며, 불굴은 비용 3 이상·해금 LV 20 이상·양수 효과여야 한다. 모든 수치의 유한성·허용 범위를 검증하며, 잘못된 카탈로그는 투자를 거절한다. 단계 상한 확대나 새 ID 추가는 카탈로그 값만 수정하지 말고 저장 검증·런타임 효과·UI도 함께 변경해야 한다.

기존 `URogue10mTownServiceDataAsset`의 활력(`VitalityHealthPerLevel`)·힘(`PowerAttackPerLevel`) 증가량은 해당 NPC에서 계속 적용한다. 두 특성의 상한은 카탈로그와 NPC `MaximumTraitLevel` 중 작은 값이다. 나머지 14종은 TraitCatalog를 사용한다. 물약 비용, 장비 강화와 난이도는 기존 NPC ServiceData, 판매 물약과 최초 보급은 기존 TutorialData를 유지한다.

구매한 보너스와 실제 비용은 당시 값을 저장한다. 이후 Data Asset 수치를 바꿔도 이미 투자한 보너스를 현재 단계 수에 곱해 다시 계산하지 않는다. 추가 투자에는 변경된 단계당 값이 적용되며, 재분배 후 다시 투자하면 새 정의를 사용한다. 시간·적중 조건은 현재 카탈로그에서 읽으므로 변경하면 기존 투자자에게도 적용된다. `Description`·`EffectSummary`는 작성한 텍스트이므로 효과를 조정할 때 함께 수정한다.

## 검증 상태와 후속 작업

2026-10-11 최종 Editor 빌드가 성공했다. 격리된 실제 게임 프로세스에서 16종 효과 100개, 저장 Write 125개·Read 227개, 1080p·720p 화면/입력/재분배/저장 재시도 260개와 기존 서비스·포탈 회귀 142개가 모두 통과했다. 스크롤 상단·하단을 렌더한 후 16개 카드 전체의 글자 경계와 두 줄 표기를 검사했다. 저장·효과 및 UI 검사에 대한 독립 검토를 완료했다. [적용 결과와 실행 증거](../Feature/doc/2026-10-11_trait16-runtime.md)를 참고한다. 이전 2종 서비스의 검증 이력은 마을 서비스·저장 가이드에 보존한다.

후속 작업은 실제 플레이에 따른 특성·재화 밸런스 조정, 저장 백업·복구 UI, 멀티플레이어 서버 저장 정책과 향후 특성 추가에 대한 저장 전환 정책이다. 구매 당시 누적 효과와 현재 카탈로그가 다른 경우의 표시·보정 정책도 별도로 검토한다.
