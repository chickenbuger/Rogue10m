## 생성 프롬프트 요구 요약

이 절은 원본 프롬프트의 **요구 요약**이며 축약 없는 호출 원문이라고 표현하지 않는다. 원문은 이 채팅의 이미지 생성 호출에 있다.

고해상도 가로3:2 판타지 월드 지도. 제목은 “Rogue10m 전체 월드 배치안”, 부제는 “탐험 · 수련 · 무기와 비급 발견”. 손으로 그린 스타일라이즈드 지형·작은 마을 건축·읽기 쉬운 한글 지명. 북쪽이 위.

남쪽 필드 진입에서 북쪽 인간형 아자토르의 최종 보스 입구까지 마을·필수 적·관문을 지나지 않는 중앙 직행로와 세 교차로를 표시한다. “보스 직행 · 목표60초”를 표시하고 StartHub는 왼쪽 아래 별도 포털 연결 인셋으로 둔다.

큰 마을은 서쪽 낙엽 수렵촌(서린), 남동 풍차장터(도윤), 북쪽 중앙의 동쪽 기록촌 마탑(유하)3곳. 전문 거점은 산림초소(윤결/활), 돌샘 수련초소(무건/너클), 수비초소(도겸/대검), 잔불 대장간(라온/장비), 옛 관측초소(세란/마법)5곳.

사냥터는 뿌리 숲·운송길·돌샘 채석사면·폐서고/유적·제련로 잔해. 별도 곁가지에 포자 군락의 어미·가시 성채의 수문장·심연을 보는 눈·황금 포식자4종을 로마 숫자Ⅰ~Ⅳ로 표시한다. 최종보스는1종만 둔다.

서쪽 수렵/너클, 동쪽 장비/대검, 북동 마법/기록의 선택 고리를 실제 도로를 따라 표시한다. 책·무기 아이콘은 현장 발견 지점에 둔다. 범례는 큰 마을3·전문 거점5·일반 몬스터15종·중간보스4종·최종보스1종과 “기획 지도 · 실제 배치 전”을 포함한다. 추가 대형 마을·필수 열쇠·비급 보상 선택창을 만들지 않는다.

## 사용 시 주의

지도는 환경 분위기·상대 배치의 시각 참조다. 정확한 도로29연결, 로컬 좌표, 학습/입력 규칙과 획득처는 [제작 기준](../../WorldMapProductionGuide.md) 및 두 JSON을 따른다. 생성 텍스트 오기·장식 마름모·스케일 차이를 실제 규칙으로 채택하지 않는다.
