# Rogue10m 현재 개발판 실행·조작 안내

2026-11-01 초안. 필드 학습과 입구 대검은 새 빌드/프로그램 QA를 통과했지만, 실제 입력으로 정상 한 판을 완주한 상태는 아직 확인하지 않았다. 부모가 남은 관찰 결과와 최종 커밋을 반영한 뒤 제공한다.

## 실행

프로젝트는 `D:\Project\Rogue10m\Rogue10m.uproject`, 엔진은 UE5.8이다. 정상 시작 맵은 `L_Menu`이며 메인 메뉴에서 시작→캐릭터 선택/생성→입장하면 StartHub로 간다. 캐릭터 이름은2~12자다. 마을에 들어간 시점에는20분 타이머가 시작되지 않는다.

기존 사용자 저장과 분리해서 플레이를 확인하려면 프로젝트 PowerShell에서 다음처럼 새QA세션을 연다. 다른 UE/게임 프로세스가 있으면 실행기가 중복 시작을 거부한다.

```powershell
.\Scripts\StartBasicPlayQA.ps1 -Label Play1101A -Visible
```

`Label`은 매번 새 값으로 정한다. 이 실행기는 QA 저장3개namespace와 사전 세이브 해시 목록을 분리하고 관찰을 시작한다. 자동 캐릭터 생성·이동·보상 지급이나 자동 종료를 수행하지 않는다. 메뉴와 게임은 직접 조작한다. 실행 결과가 불확실하면 같은 명령을 다시 누르기 전에 PID/로그를 확인한다. 이번 신규 관찰기의 실제 실행 결과는 아직 대기 중이다.

## 현재 조작

| 동작 | 현재 입력 |
|---|---|
| 이동 / 시야 | W/A/S/D / 마우스 |
| 달리기 / 점프 | 왼쪽Shift 유지 / Space |
| 회피·대시 | E |
| 기본 공격 / 특수 공격 | 좌클릭 / 우클릭 |
| 인벤토리 / 장비 / 스킬트리 | I / P / K |
| 설정·포기 메뉴 | O / Esc / F10 |
| NPC 대화 | 가까이에서 F |
| NPC 서비스 선택 / 실행 / 닫기 | 위·아래 / Enter / Esc |
| 소모품 | 1~5 |
| 결과 화면 귀환 | 버튼 또는 Enter/Space |

Ctrl/Q/E/R4슬롯은 확정 설계지만 전체 연결 완료로 안내하지 않는다. **현재E는회피**다. Alt 변경도 다음 별도 작업으로, 이 가이드 시점에는 적용 완료가 아니다. 키를 재설정할 때 화면의 허용/충돌 안내를 따른다.

## 마을에서 필드로

시작 전투 계열은 너클이며 외형은 맨손이다. 앞으로 획득한 너클의 실제 외형을 붙이는 방향과 구분한다. NPC 근처에서 F 안내를 보고 대화한다. 대화 후 위·아래/Enter로 포션·장비강화·영구특성·난이도 서비스를 고른다. 영구 강화에 쓴 로비 예산과 이번 판 성장 포인트는 별개다.

준비를 마치면 마을의 필드 입구에 걸어 들어간다. F로 여는 포털이 아니라 overlap 이동이다. 입장 직전 재화 기준선을 저장하고 OpenRunMap으로 이동하면20분 런이 시작된다. 저장 실패 시 이동이 막히므로 표시된 오류를 확인한다.

## 필드에서 성장·대검 얻기

입구 인근 고정 위치에 기존 대검이 한 번 배치된다. 설정 기준은 `(600,-62600,3000)`이며 지형을 확인해 실제 높이를 맞춘다. 가까이 걸어 닿으면 기존 드롭 아이템의 pickup으로 인벤토리에 들어간다. 공간이 없으면 아이템이 남는다. 획득만으로 너클 장착이 자동 변경되지는 않으므로 I/P에서 장착한다.

적을 때려 숙련을 쌓고 처치로 캐릭터XP·이번 판 재화를 얻는다. K에서 현재 무기 트랙을 고르고 조건과 포인트/숙련 경로를 확인한다. 진행 중인 정상 런에서도 수동 학습이 가능하며 저장 오류·요구조건 미달·다른 트랙·부족한 포인트는 거부된다. 최초 Identity를 배우면 기존 방식대로 자동 활성화하지만 두 번째 습득이 현재 Identity를 자동 교체하지 않는다. 환불·수동Identity전환·마을영구강화는 필드 학습과 별도 제한을 유지한다.

숙련 게이지0..100은 현재XP비율 표시다. 이번 변경이 모든 레벨의 실제 필요 숙련을100으로 바꾸지는 않았다. 필드 메뉴를 열어도 월드와 타이머가 계속된다. 안전지대 메뉴 pause가 전체 경로에서 검증됐다고 가정하지 않는다.

## 종료·포기·다음 판

최종 보스 승리·사망·시간초과는 결과 화면과 정산으로 이어진다. 저장에 실패하면 귀환이 막히고 결과 UI에서 재시도한다. 저장 성공 후 마을로 돌아와 다음 판을 준비한다. 정상 보스전 난이도와 전체 입력 완주는 아직 검증 중이다.

포기는 설정 메뉴의 포기 버튼→정책 확인→확정으로 진행한다. 이번 판 장비·아이템·숙련·배운 기술은 초기화된다. 이미 공개된 기술 정보는 유지되며 다음 판 자동 습득을 뜻하지 않는다. 재화는 **마을 준비 비용을 지불한 뒤 필드 입장 직전** 상태로 복원한다. 준비 비용은 환불하지 않으며 포기 보상은 없다.

기존1인칭과 설정의 무게감 조절은 유지한다. 새OwnerArms/ViewFraming은 기본OFF이며 이번 가이드가 켜도록 요구하지 않는다. 이동·시야가 안 되면 열린 메뉴를 닫고 게임 창을 활성화한 뒤 키를 놓고 다시 누른다. 지속되면 위치·화면·로그를 남기고 저장 삭제나 강제 초기화로 해결하지 않는다.
