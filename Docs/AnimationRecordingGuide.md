# 애니메이션 개발 기록

사용자의 2026-10-31 요청에 따라 앞으로 제작하거나 수정하는 애니메이션과, 해당 작업에서 검증한 기존 애니메이션을 기능별 DevLog에 남긴다. 프로젝트 전체의 미검증 에셋을 일괄 검증한 것처럼 기록하지 않는다.

## 저장 위치와 필수 항목

`DevLog/YYYYMMDD_<기능명>/`의 README 또는 AnimationRecord.md에 다음을 기록한다.

- 작업 사본, 브랜치, 커밋 또는 미커밋 상태, 검증 일시와 재현 절차.
- 기존/신규/프로젝트 파생/수정 여부, 실제 로드된 DataAsset·Montage·Sequence·Skeleton 경로와 출처.
- 준비, 접촉 또는 최초 피해 관측, 회복 자세의 실제 게임 사진. 공격 수락 사진을 접촉 순간으로 부르지 않는다.
- 손·무기의 궤적을 기록했다면 기준 좌표계, 단위, 실제 프레임·월드 시간, 촬영 요청/완료 지연을 함께 기록한다.
- 원본 길이·구간·재생률·블렌드·게임플레이 히트 지연 등 실제 변경 항목과 유지한 계약. 자산 수치와 실측 타이밍을 구분한다.
- 자동 단위 테스트, 프로그램 입력을 사용하는 실제 렌더링, 물리 키보드/마우스 입력, 일반 필드 완주를 구분한다.
- 수치 검사 통과와 시각 판정을 별도로 적고 실패한 후보·캡처·로그도 보존한다.

사진과 영상은 실제 검증 실행에서 생성한 것만 사용한다. 원본 캡처를 연출·보정해 성공 증거로 만들지 않는다. 기존 파일을 덮어쓰지 않고 새로운 label/폴더를 사용한다. 실제 세이브나 개인정보, 토큰, 관계없는 앱 화면을 포함하지 않는다. 대형 미디어는 로컬 증거 보존과 Git 추적을 별도로 판단한다.
