# 스킬 제작 단계 및 구현 추적

갱신: 2026-11-10. 이 기록은 **기획/이미지와 실제 구현을 구분**한다. 완료 표시는 모든 단계의 증거가 있을 때만 사용한다. 현재 새100개 기술 가운데 전체 파이프라인 완료로 표시한 항목은0개다. 기존 안전 기본공격과 일부 실제 기술은 보존했지만 새100개 제작 완료로 중복 집계하지 않는다.

## 2. 공통 기반과 별도 기능 상태

- 6슬롯 정책·전용 교차차단·고정기본공격 분리·무기별 프리셋·불량저장 원자검증·뉴비Unarmed→None은 D빌드에 반영. 슬롯2+기존성장3 자동테스트가 경고0/오류0 통과했다.
- 실제 production 뉴비 LeftJab와 원래 GAS를 사용한 Controller InputKey 검사는 LMB사용증가1, Q/E/R/RMB/Ctrl 무기능력 미실행을 확인했다. 13개 마우스 시나리오 통과. 물리 키보드·세이브 재시작·풀런은 별도다.
- 새100개 기술의 실제 후보10개 카탈로그/새모션/VFX/고유기능을 모두 도입한 상태는 아니다. 기존 tree와 기본공격을 보존한 기반 구현이다.
- 카탈로그 소비 기반(2026-11-11 확인): ActiveTechniqueCatalog의 안정적 TechniqueId+Skill 선택목록을 전체 성장트리와 분리한다. 정확10·고유ID/참조·고정기본/패시브제외·전체트리소속·명시정책 검증과 Combat/UI/장착/실행/프리셋 소비 방어는 공유 소스에 반영됐고 CatalogSharedA 전체6개가 경고0/오류0 통과했다. 빈목록은 기존동작 유지, 잘못된 명시목록은 부분 공개하지 않는다. Unarmed/Staff에 근접10개를 강제하지 않는다. 실제20개 독립 기술 데이터·신규 성장노드/선택UI·저장ID 이관과 카탈로그 활성화는 별도 미완료다. 보존 readback은 두 프로필0개이며 오늘 live 에디터 조회는 수행하지 않았다.
- 너클 Ctrl 프로토타입: Identity_E1(E2 DLL) 54 checks/0 failures·8개 실제3P 캡처·기존396 세이브 해시 보존. Ctrl 활성과 유지·만료/교체/Die/직접 런종료 핸들러 정리, MaxWalk620→744→620·공속1.04→1.30→1.04·기본GAS불변 통과. 8초/30초/25%/20%/8%/10%는 제안값이다. 차용NS_Knuckle_Charge의 큰 검푸른 바닥 소용돌이가 발·하체를 가리므로 최종 오라 시각품질은 미완료, PP 단독 체감 A/B·교체 직후 잔상·실제 풀런 정산·저장재시작은 별도 검증한다.
- 마법사: 사용자 확정 주문조합·가중치·런 한정 페널티·미니게임해금·서클·숙련/하위 즉발 기획. 모드 hold/toggle, 길이·확정·취소·판정과 수치는 미정. 명령입력 구현 완료로 표시하지 않는다.

## 3. 공통 블로커/선행 작업

- B01: 기본공격과 별도 활성기술 데이터 분리, 무기별 정확한10후보, 전용정책·현재해금·기존저장 이관 계약.
- B02: 선정원본의 UE5.8 리타겟, root XY/Z/회전·pelvis·지지발·손잡이와 원본 RateScale 검증. 원본은 보존하고 프로젝트 파생본을 사용.
- B03: 패리/방어붕괴/돌진/착지슬램은 모션과 별개 C++ 기능. 성공·실패·벽·높이·보스면역·종료정리 계약.
- B04: 준비/명중/회복 VFX를 실제 모션에 연결. Combat Magic 팩에 포함되지 않은 마법진/재질/효과는 신규 제작. 이미지 자체를 엔진 효과로 셈하지 않음.
- B05: HitDelay/재생률/공속을 실측하고 비균등 연타라면 일정 HitInterval로 억지 맞추지 않음. 피해는 현재 실행ID 경로 하나만 소유.
- B06: 실제3P 시각 검수 및 저장·메뉴·중단·사망/교체 회귀. 물리입력/풀런은 수행한 경우에만 명시.
