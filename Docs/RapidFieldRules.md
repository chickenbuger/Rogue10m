# 빠른 보스 접근·성장·조합의 최신 요구사항

2026-10-26 사용자 직접 답변과 초기 지시를 정리한 현재 요구사항이다. 기존 상세설계의 추천과 충돌하면 이 문서의 확정 방향이 우선한다. 아래 규칙을 문서에 기록한 것이 구현·플레이 검증을 뜻하지 않는다.

## 확정 방향

- 시작부터 보스 입구까지 비전투 기본 이동 약60초. 600cm/s에서 360m는 출발 가정이며 실제 속도·경사·충돌로 보정한다. 직행로 주변 여러 방향의 전투/중간보스/아이템/장비/퀘스트는 선택 기회다. 5개 지점은 밀도 검증 예시이고 필수 선형 코스가 아니다.
- 20분 초과는 게임 오버다. 해당 런에서 오른 숙련/능력치는 초기화하고 로비용 재화를 정산한다. 로비 재화로 구매한 캐릭터 영구 강화 수치는 보존한다. 게임 마무리 후 재화로 영구 강화한다. 상세설계의 ‘숙련 영구 성장’ 추천은 폐기한다.
- 한 캐릭터가 여러 무기를 배울 수 있다. 초기 조건 예시는 검 숙련3+마법 계열2의 마력 인챈트, 검 숙련3+격투 숙련3의 내공 검술이다. 현재 첫 검 트랙은 기존 GreatSword를 활용하는 검증 범위다.
- 조합별 호환성으로 표현한다. 마나+내공 동시 사용 불가, 내공+투지 허용 예시가 있다. 모든 검술 변형을 한 슬롯만 활성화한다는 기존 추천은 폐기한다.
- 무기별 사전 스킬 세팅은 비전투 중 편집한다. 전투 중 무기를 교체하면 연결된 세팅으로 전환된다. 무기 교체는 무적을 부여하지 않는다. 전투 중 교체 자체를 전면 금지하지 않는다.
- 초반 직행 보스 승리는 현실적으로 매우 어렵지만 불가능하지 않으며 여러 기믹/기술 대응이 필요하다. 20분 대기나 필수 퀘스트/중간보스 열쇠를 추가한 방향이 아니다.

## 아직 결정하지 않은 세부사항

사망/승리 시 성장·정산 처리, 장비/기술 해금 지속성, 재화 종류/산정식/중복 방지·저장 시점, 자원 보유/동시 축적/전환 잔량, 조합 호환성 전체 표, 무기 교체 시간/공격 취소/쿨다운 공유는 아직 확정하지 않는다. 기본0 MageRank 평가 입력을 신규 영구 성장 모델로 해석하지 않는다.

## 현재 구현 경계

R11은 기존 공격 비용 합산·원자적 결제 수정이다. R02/R03는 수명 중립적인 조건 입력과 기존 UI backend/구매/자동 해금의 공통 AND gate 기반이다. 이 packet들은 런 초기화/로비 영구 강화/정산/새 호환성 표/무기 세팅 전환 정책을 구현하지 않았다. 기존 legacy 저장·아이덴티티·자원·입력 동작은 호환 기준선으로 유지하며, 새 규칙 구현 완료라고 주장하지 않는다.
