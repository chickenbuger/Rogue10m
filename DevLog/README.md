장면1/2/3은 각 실행의 준비·피해/동작·회복 순서다. 지팡이 action 사진은 접촉 판정 증거가 아니다. 최초 피해 사진 역시 실제 접촉점이나 모든 애니메이션의 완성도를 뜻하지 않는다.
