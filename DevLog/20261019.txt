설치된 Unreal MCP 스킬과 Epic 최신 원본을 비교하고 빠진 내용을 Codex에 맞게 반영했다.

[진행 내용]
1. 2026-10-19 확인한 Epic 3.1.1의 a6aa73ada02a9fb1f5415bec491f9942c519b297 커밋을 비교 기준으로 고정했다.
2. AllToolsets/개별 provider 활성화, 프록시 캐시·복구, 의존 호출 순차/독립 호출 병렬, 도구 작성과 Agent Skill 저장 절차를 보완했다.
3. 본문과 참조 Markdown 총 9개를 개인 설치 경로에 반영했다. 기존 8001 endpoint·자동 호출 정책·스크립트 8개·MIT 고지는 유지했다.
4. 한국어 프로젝트 규칙에 맞게 Saved 직접 편집과 무승인 커밋을 피하도록 지침을 명확히 했다.

[검증 결과]
공식 스킬 구조 검사, 설치 전용 검사, 로컬 참조 15개·예제 구문 3개·스크립트 AST·YAML·MIT 대조를 통과했다. 독립 가상 시나리오 6개를 검토했고 timeout 시 공유 에디터/프록시 종료로 읽힐 수 있던 문구 1건을 수정했다. 실제 설치본 20파일의 SHA256과 구조 검사도 통과했다. 생성 경로 검사는 통과했고 기존 에셋 변경 경고는 작업 전 상태로 보존했다.

[완료 범위와 한계]
개인 설치 스킬과 프로젝트 기록 보완 완료. 게임 소스·설정·에셋·실제 MCP 연결 설정은 수정하지 않았다. 로컬 엔진에는 선택형 프록시가 없어 프록시 실행과 실제 MCP·빌드·PIE·품질 향상은 검증하지 않았다. 커밋·푸시는 하지 않았다.

제목: Unreal MCP 플러그인 직접 설정과 재시작 연결 검증
날짜: 2026년 10월 19일
작업 브랜치: Sprint#5-35-unreal-plugin-setup
============================================================

[작업 목표]
스킬이 실제 에디터 도구를 사용할 수 있도록 프로젝트 플러그인과 관련 설정을 직접 확인·보완했다.

[주요 변경]
기존 MCP·AllToolsets와 8001 자동 시작은 이미 설정되어 있었다. 현재 엔진의 AllToolsets에 포함되지 않은 LiveCodingToolset을 Editor 대상으로 추가했다. Live Coding 기능값은 공식 에디터 설정 API로 켰으며, 재시작 지속성을 위해 tracked 프로젝트 기본 설정에 LiveCoding bEnabled=True를 추가했다. Saved 파일은 직접 편집하지 않았다.

[실제 검증]
엔진 기본 Entry 맵에서 에디터를 시작했다. 명시적인 MCP 시작이나 포트 override 없이 127.0.0.1:8001 자동 시작, meta-tool 3개와 toolset 53개, CompileLiveCoding 스키마를 확인했다. 필수 플러그인 3개 활성·기존 AIAssistant 비활성, 실제 MCP 설정 4개, PIE 종료 상태를 조회했다.
API 저장이 False override만 제거하는 점을 독립 검토에서 발견해 프로젝트 기본값을 보완했다. 이 작업이 시작한 에디터를 정상 종료·재기동한 뒤에도 Live Coding=True와 기존 MCP 설정이 유지됐다. 최종 PID42032가 loopback 리스너를 소유했다.

[검토와 범위]
의존성·DLL·엔진 BuildId·Editor 대상 제한·기존 설정 보존을 독립 검토했다. 실제 연결과 재시작 지속성은 확인했으며 Live Coding 컴파일·빌드·PIE·패키징은 실행하지 않았다. 현재 채팅의 native 도구 노출과 공식 서버 직접 호출 검증을 구분해 문서에 기록했다. 기존 미커밋 작업과 게임 소스·에셋을 보존했고 커밋·푸시는 하지 않았다.

제목: Fab 보유 에셋 우선 재사용 개발 원칙 반영

[작업 목표]
사용자 요청에 따라 앞으로 콘텐츠 개발에서 이미 가진 Fab 에셋과 프로젝트 자원을 우선 활용하도록 지침과 후보 목록을 정리했다.

[실제 확인]
Epic Games Launcher의 Fab 내 라이브러리와 해당 범위 Combat/Monster 검색에서 카드 30개를 확인했다. 전체 계정 목록을 조사한 것은 아니다. Close Combat Animset, Combat Magic Animations, Monster for Survival Game PBR Polyart, Stylized Village, Slash Trail FX Elemental, 몬스터 음성 팩 등을 확인했다.
프로젝트 폴더·문서·소스/제작 참조에서 기존 주요 팩 8개와 사용 흔적을 독립 조사했다. Fab 보유 확인, 로컬 존재, 과거 적용 기록, 실제 현재 실행 검증을 구분했다.

[반영 내용]
AGENTS.md에 보유 에셋 우선 평가 규칙을 추가했다. Docs/FabAssetReuseGuide.md에 격투·마법·몬스터·환경·외형·시청각 후보와 기능별 반입/검증 절차를 기록했다. 기존 C++ 전투·성장·인벤토리·저장과 머리 카메라 안정화 및 화면 방향을 보존하며 필요한 자산부터 선별한다.

[검증과 한계]
문서/JSON·출처/상태 구분·기존 변경 보존·생성 경로를 검사하고 독립 검토했다. 실제 다운로드·설치·구매·에셋 import·빌드·PIE는 수행하지 않았다. 라이선스·버전·개별 자산 내부는 실제 적용 전에 해당 제품에서 확인한다. 런처 사용자 입력 신호 후에는 상태만 재조회하고 추가 조작을 멈췄다. 커밋·푸시는 하지 않았다.

제목: 기본 애니메이션과 VFX의 보유 에셋 편집 우선 원칙
날짜: 2026년 10월 19일
작업 브랜치: Sprint#5-36-fab-owned-asset-reuse
============================================================

[사용자 후속 요청과 반영]
기본적인 애니메이션 구성과 VFX는 가진 에셋을 수정·편집하는 방식으로 진행하도록 재사용 규칙을 구체화했다. vendor 원본은 보존하고 프로젝트 파생본에서 편집한다. 애니메이션은 리타깃·구간·재생률·블렌딩·몽타주/Notify, VFX는 파라미터·재질·색·크기·수명·방출·타이밍·부착을 우선 조정한다.

[검증과 범위]
적합한 보유 원본이 없거나 편집으로 요구를 충족하기 어렵거나 사용자가 새 제작을 명시한 경우에는 이유를 기록하고 새 제작할 수 있도록 했다. 기존 카메라·타격·root motion 계약과 원본을 보존한다. AGENTS·활용 가이드·계획/결과와 개발 이력을 보완했으며 이번 후속에서 실제 게임 에셋·코드·설정은 변경하지 않았다. 문서 검토·경로/공백 검사를 수행하고 빌드·PIE는 실행하지 않았다. 커밋·푸시 없음.
