
2026-10-24 개발 일지

[작업] Sprint#8-1 — 월드 맵 메이커 제작

현재 플레이맵 OpenRunMap을 조사하니 이미 World Partition RuntimeHashSet을 사용하고 있었다. 런타임 셀 256m, 로딩 범위 700m와 1.8km 정사각 Landscape 구조를 유지하고, 별도 청크 시스템 대신 에디터 편집 격자를 제공하기로 했다.

전용 Rogue10mEditor 모듈에 구역 로드·시점 이동·환경물 선택/이동·기존 메시 지형 배치·외부 액터 저장 패널을 구현했다. 보스·게임플레이·경계·이동 잠금 액터는 자동 편집에서 보호한다. 계획 M1~M5 패킷과 사용 가이드를 작성했고 빌드/임시 WP 맵 자동화 검증을 진행한다.

기준 브랜치를 공개 main 973678bc로 fast-forward했다. 작업 시작 때 남아 있던 보스 Save v3 코드와 검증 자료는 이미 main에 포함되어 있었으며 기존 원본도 명시 경로 stash에 보존했다. 현재 작업은 신규 에디터 코드·등록·테스트·문서로 한정한다.

[검토 보완]
첫 빌드의 Slate WrapBox API 차이는 UE5.8 UseAllottedSize로 수정했다. 독립 리뷰에서 이동 잠금 보호 누락과 PIE 정리 이전 상태 갱신 문제를 확인하여 이동 잠금 거부와 ShutdownPIE 갱신으로 보완했다. 검증 완료 수치는 실행 후 추가한다.

[Notion 요약 후보]
주제: World Partition을 유지한 Rogue10m 월드 맵 메이커
핵심: 청크 런타임을 새로 만들지 않고 256m 편집 작업 영역, 소유 로더, 환경물 배치와 네이티브 Landscape 도구를 연결한다.
상태: 구현 후 빌드·자동화·시각 확인 진행 중.

[최종 검증]
UE5.8 프로젝트 파일 생성과 최종 Editor 빌드(18.62초)가 통과했다. 맵 메이커 자동화 3개가 최종 42.39초에 모두 성공했고 실패·미실행·진행 중은 0이다. 지형 배치, 배치/이동 실행 취소·다시 실행, 보호 선택, OFPA 저장 후 맵을 닫고 재로드한 상태를 확인했다. 패널 생성과 레이아웃 계산도 통과했다.

원본 OpenRunMap과 외부 패키지 1,260개 파일의 SHA256은 최종까지 변경 0이었다. 실제 플레이맵을 저장 없이 로드해 World Partition RuntimeHashSet, 1.8km 크기, 지형/충돌 컴포넌트 256개와 공간 프록시 16개를 다시 확인했다.

첫 지형 배치 실패는 일반 컴포넌트 trace의 overlap 결과를 blocking으로만 검사한 데서 발생했다. 엔진 Landscape 편집기와 같은 complex visibility-object query로 수정한 뒤 통과했다. 임시 맵 삭제 뒤 남던 HLOD와 외부 액터/객체도 정확한 fixture GUID 경계에서 Unreal Editor/ObjectTools API로 정리하고 잔여 파일 0을 검사한다.

최종 보고서의 네이티브 경고 4개(참조 수집 fallback 및 삭제 임시 에셋의 레지스트리 갱신)는 보존한다. 실제 패널 렌더/마우스 사용성, 생산맵 편집·저장, 전체 20분 런·cook/Shipping은 이번 검증에 포함하지 않았다. 사용법은 Docs/WorldMapMakerGuide.md에 정리했다.

[Notion 요약 후보 — 완료 검증]
기존 World Partition을 유지한 에디터 맵 메이커를 구현하고 빌드·3개 자동화·생산맵 읽기·독립 리뷰를 완료했다. 256m 구역별 환경물 배치/이동과 네이티브 지형 도구를 지원하며, 원본 맵 1,260파일은 그대로다. 상시 승인에 따른 커밋·승격·공개 게시를 마무리한다.
