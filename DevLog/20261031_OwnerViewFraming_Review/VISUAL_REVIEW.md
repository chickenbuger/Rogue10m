# 실제 사진의 검토 범위

수치 검사를 시각 통과로 대체하지 않았다. 원본 GameViewport PNG를 view_image로 열어 검토했다. 모든 모션/외형/픽셀의 무가림을 보장하는 검토는 아니다.

1. Before의04/05/06 극하향 및10/11/12 실제E를 비교했다. mode0 정상과mode2 몸체그림자OFF에는 검은돌출이남고,mode1 팔만뷰제외에는사라졌다. 이 재현형상은 팔메시의근접투영에관련된다.
2. After의04 극하향·13벽E회복에서상부팔절단면돌출이재현되지않고손이하단에들어왔다. 화면내상완render-index경계중점은일반5장모두0이었다. 실제near교차삼각형은36~48개남으므로전체교차0/전부프러스텀밖이라고쓰지않는다.
3. Weighted의16/19 실제피해관측·08벽회복에서중간후보의양손중앙겹침을보정한후분리된손위치를직접확인했다. Original의04/08/19도같은검토에포함한다. 손중심간격만으로메시전체비겹침을증명하지않는다.
4. 이동·대시의모션블러는사진에남아있다. 무정지60fps나성능개선을측정/주장하지않는다. 일반필드완주나물리입력의체감평가가아니다.
