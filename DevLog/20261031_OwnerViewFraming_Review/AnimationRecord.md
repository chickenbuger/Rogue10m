# 소유자 팔 프레이밍: 진단·통합 애니메이션 기록

실제 Git HEAD 표시는 `ref: refs/heads/Sprint#9-15-owner-view-framing`이다. 기준 로컬 커밋은 root 보고의 7958b62이며 제품 기본값은 OFF다.

## 변경 경계

기존 Montage/Sequence 에셋과 게임플레이 애니메이션 시계는 유지했다. 이번 후보는 소유자에게만 보이는 표현 포즈의 팔 회전 4개/IK와 component framing을 변경한다. 원본 에셋과 기존 여섯 파생 팔 메시는 수정하지 않았다.

Build G의 새 raw metadata는 소유자 팔 회전4개/component framing 변경을 정확히 기록한다. 이전 Candidate A/Full F의 구식 문구와 사진은 수정하지 않고 중간 후보 증거로 보존한다.

## 소스 몸체와 소유자 표현 궤적의 구분

`animationframes.csv`는 source/body 손의 월드 좌표와 CalcCamera 기준 상대 좌표다. `presentationframes.csv`는 실제 소유자 proxy 손의 월드 좌표와 PlayerCameraManager의 cached camera 기준 상대 좌표다. 두 상대 좌표를 같은 카메라 기준이라고 가정하지 않는다. cached camera 시각과 world 시각 차이를 각 stage별로 기록했다. inspection 등 framing이 꺼진 표본은 활성 proxy 궤적 집계에서 제외하고 별도로 셌다.

전체 stage별 world/camera-relative 최소·최대, 표본 간 궤적 길이, 끝점 변위, 같은 프레임 proxy↔body 월드 거리와 실제 캐시 시각은 동반 JSON에 있다. 표본 간 궤적 합은 정확한 서브프레임 애니메이션 곡선 길이가 아니다.

## 접촉 손 겹침 보정과 중간 후보 보존

Candidate A/Full F에서 손이 중앙에서 겹치는 사진을 root가 확인해 B에서는 owner hand goal을 depth25~90cm, side절댓값12~42cm, height−38~−14cm로 제한했다. 조절 가능한 목표값이며 모든 실제 손/메시 정점이 반드시 이 구간 안에 있다는 주장은 아니다. 원본 포즈·게임플레이 시계와 소유자 팔 회전4개의 경계는 유지했다.
