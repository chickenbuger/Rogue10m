# 2026-09-10 기본 직업 좌우 공격과 차징 어퍼컷 개발

## 작업 목표와 기획
기본 직업 Unarmed에 좌클릭 왼손 → 오른손 연계, 우클릭 기본/차징 어퍼컷, 실제 머리 움직임에 연결된 1인칭 카메라, 일반 점프 표현을 적용한다. Sprint#4-25-basic-brawler-inputs에서 기획 1·개발 2·검증 2 역할을 단계별로 운용한다.

## 개발 내용
전용 BasicBrawlerComponent가 입력 수락·한 개의 입력 예약·차징·취소를 소유한다. Editor에서 전용 공격 데이터 4개와 Unarmed 프로필 연결을 적용했다. 기존 CameraComponent와 조준 입력을 유지하면서 평가된 머리 자세를 표시용 카메라에 전달한다.

## 중간 검증과 수정
UE 5.8.2 C++ 빌드와 Editor 자산 적용이 통과했다. 첫 실제 480프레임 검증에서 좌우 공격, 위로 올라가는 어퍼컷, 차징 오른쪽 회전, 점프·착지를 확인했다. 비용 0인 기본 공격을 스태미나 부족으로 거부할 것이라 가정한 테스트 오류는 수정 중이다. 독립 시각 검토에서 충전 손이 화면 밖으로 내려가고 어퍼컷 정점 팔이 삼각형으로 늘어지는 문제를 발견해 보정 중이다. 손 움직임보다 피해가 먼저 표시되는 기존 실행 경로도 전용 지연 시점으로 보완한다.

## 레퍼런스 확인 상태
사용자가 전달한 YouTube Shorts cci0hNBFiZI, M_4S6WFM-wM은 정확한 URL을 확보했다. 웹의 Shorts/watch 조회가 Cache miss이고 네이티브 및 브라우저 도구가 Windows sandbox ACL 오류로 시작되지 않아 직접 영상 재생은 아직 확인하지 못했다. 시청·장면 분석 완료로 기록하지 않는다.

## 추가 검증 완료 — 기본 직업 동작 보정
충전 오른손이 화면 밖으로 내려가던 문제와 어퍼컷 정점 팔 변형을 실제 연속 프레임으로 확인하고 수정했다. 주먹은 0.34초, 어퍼컷은 약 0.633초 뒤 첫 피해를 실행해 상승/신전 시점에 맞췄고, 왼손 타격 후 오른손이 이어지도록 연계창을 0.40~0.55초로 조정했다. 차징은 실제 연결 자산 기준 0.85초다.

첫 타격 전에 점프·무기·차단 UI로 취소하면 예약 피해도 제거한다. 공중 기본 LMB는 지상 공격 규칙에 맞춰 자원·쿨다운·공격 순서를 소비하기 전에 거절한다. 자원 부족 fixture의 비용 0 가정과 오른손 측정의 이전 왼손 회수 합산 오류도 바로잡았다.

최종 결과: Editor 빌드 8.57초 성공, 자산 4개 검증 통과, 실제 기본 직업 480프레임 실패 0, 기존 너클 120프레임/시야 3조건 실패 0. 기획 1·개발 2·검증 2의 독립 검토를 마쳤다. 실제 10초 GIF는 Feature/doc/images/basic-brawler-20260910/basic-brawler.gif에 저장했다.

원본 영상 두 개의 재생과 직접 비교는 도구 접근 오류로 남아 있어 전체 목표는 완료 처리하지 않았다. 기존 작업은 보존했고, 이번 기존 자산 변경은 기본 Unarmed 프로필 하나이며 새 공격 데이터 4개를 추가했다. 커밋·푸시는 하지 않았다.

## 원본 영상 비교 대기
구현 이후 연속 재확인에서도 YouTube 두 URL은 Cache miss이고 브라우저 도구는 windows sandbox failed: apply deny-read ACLs로 시작되지 않았다. 이전 재시도는 추가 진전이 없는 턴으로 분류한다. 원본 영상 파일 제공이나 도구 복구 없이는 장면을 직접 검토할 수 없어 전체 목표를 blocked로 기록한다. 이는 완료 판정이 아니다. 현재 기획·C++·Editor 자산·실게임/회귀/시각 검증 결과는 그대로 유지하며 추가 코드 변경은 하지 않는다.

## 2026-09-10 추가 작업 — 자연스러운 기본 격투가 모션
사용자가 더 자연스러운 움직임을 요청해 Sprint#4-26-natural-brawler-motion 브랜치에서 개선했다. 기획 1·개발 2·검증 2를 분리했고, 기존 작업은 보존했다.

직선 왕복을 작은 준비→빠른 신전→즉시 팔꿈치 접기/곡선 회수로 바꾸고 직전 손 위치부터 다음 공격을 잇는다. 비대칭 가드·반대 손 방어·상체 선행/머리 후행을 추가했다. 기본 Unarmed 카메라는 실제 머리 변화만 임계감쇠로 추종한다. 일반 취소는 부드럽게 복귀하며 사망·무기·강도0에서는 속도까지 초기화한다.

시각 검토에서 어퍼컷 해제 후 준비가 긴 점을 확인해 전용 두 자산의 재생 속도를1.5로 조정했다. 타격 시점도 함께 약0.63→0.42초로 이동하며 차징0.85·피해·비용·쿨다운은 그대로다. 자산은 Editor로 적용했다.

검증 결과: UE5.8.2 빌드40.23초 성공, 기본480프레임 실패0, 너클120프레임/시야3조건 실패0, 독립 소스·시각 검증 통과. 30fps 실제10초 GIF를 Feature/doc/images/natural-brawler-20260910/natural-brawler.gif에 저장했다.

요청한 컴퓨터 플러그인으로 유튜브를 직접 확인하려 했지만 @oai/sky 초기화부터 trusted Node 종료/Windows deny-read ACL 오류로 실패했다. 브라우저/영상 프레임을 읽지 못했으므로 시청 완료로 기록하지 않는다.
