[작업] Sprint#8-1 월드 맵 메이커 — 자정 이후 최종 검토와 게시

10월 24일 시작한 맵 메이커 제작을 이어서 마무리했다. Editor 빌드(18.62초), 최종 자동화 3개(42.39초), 실제 OpenRunMap 읽기 확인과 독립 리뷰가 통과했다. 원본 맵·외부 패키지 1,260파일 SHA256 변경 0, Content 변경 0이며 임시 QA 외부 패키지도 네이티브 Editor API로 정리했다.

기능: 기존 World Partition 위의 256m 편집 격자, 소유 영역 로드/해제, 환경물 선택·지형 배치·그룹 이동, 실행 취소/다시 실행, 맵과 외부 액터 저장, 기존 Landscape/WP 도구 연결. 실제 렌더 UI·전체 런·Shipping은 이번 검증 범위 밖이다. 검증 경고 4개와 초기 실패 자료를 결과 문서에 그대로 보존한다.

사용자 상시 승인에 따라 명시된 에디터 모듈·등록·테스트·문서·증거만 커밋하고 develop→test→main으로 승격·공개 게시한다. 최종 원격 SHA는 성공 뒤 덧붙인다.

[추가 완료] Sprint#9-1 — 실제 맵 메이커 GUI 조작과 회귀 검증

좁은 패널에서 글자가 잘리던 격자는 400px 가독 폭과 축소 금지 가로 스크롤로 고쳤다. 약 362px 창에서 스크롤을 양 끝까지 실제 드래그해 좌표와 개수가 읽히고 모든 열에 접근하는 것을 확인했다. 새 독립 창 기본 크기는 560×900이다. 기존 사용자 레이아웃은 유지한다.

구역 포커스는 -70도에서 야영지가 개선됐지만 최외곽 남동 구역 (3,-4)에서 다시 벽에 가렸다. 같은 구현을 반복하지 않고 Reviewer/Architect로 돌아가 경계와 카메라 거리를 검토한 뒤 -80도로 보완했다. 최종 외곽 카메라는 Y=-86,763.94cm·Z=27,079.81cm이며 야영지에서도 -80도 내려다보기 화면을 확인했다.

실제 UI에서 기존 Engine Cube를 선택하고 높이 125cm, 회전 45도, 크기 20을 입력해 배치했다. 위치는 (12,800,-64,000,3,609.155)cm다. Ctrl+Z로 큐브 0개·dirty 0개가 되고 Ctrl+Y로 같은 액터 1개가 복원됐다. OW_MM_Cube 이름 필터로 1개를 선택한 뒤 목적지 (1,-3)의 이동 버튼으로 (38,400,-64,000,3,609.155)cm로 옮겼다. 높이·회전·크기는 유지됐다.

Landscape와 World Partition 기본 도구 열기, Simulate 중 모든 편집 버튼 차단과 종료 후 복귀, 다른 맵 편집 거절과 원본 복귀, 변경 없는 맵의 저장 버튼 성공도 실제 화면으로 확인했다. 지형 sculpt/paint는 실행하지 않았고 생산맵의 임시 배치는 저장하지 않았다. 실제 변경의 저장·독립 재로드는 별도 WP 자동화 fixture에서 검증했다.

공식 Live Coding 요청은 제한 시간을 넘겼다. 이후 UBT 성공과 별개로 런타임 패치의 LNK2011/LNK1120 실패를 확인해 실패 자료를 보존했다. 불명확한 요청을 재전송하지 않고 에디터 정상 종료 후 정식 빌드 115.11초 성공으로 복구했다. 최종 자동화는 3개 모두 Success, 실패·오류 0, 57.22초, 실행기/에디터 종료코드 0이다. 네이티브 경고 4개를 원본 보고서에 남겼다.

정리 직전 임시 액터와 폴더의 dirty 패키지 2개만 있는 것을 확인하고 새 빈 맵으로 전환해 변경을 폐기한 뒤 원본을 다시 로드했다. 최종 로드 액터 1,243개, 맵 메이커 액터 0개, dirty map/content 각 0개이며 에디터를 정상 종료했다. Content 변경도 0개다. 자동화 전후 원본 맵 1,260파일 해시 변경은 0개이며 GUI 종료 후 최종 해시·명시 범위 검사는 게시 전 Exit Gate에서 확정한다.
