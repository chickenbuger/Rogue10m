[캐릭터 선택창 — 이미지 생성 시안]
캐릭터 선택창을 이미지 생성 도구로 제작해 달라는 요청에 따라 기존 성채 테라스 배경과 로비 화면을 조사했다. 직업 선택이 아닌 세 개의 저장 프로필을 선택하는 구조, 인간·드워프·오크와 남녀 지원, 생성·삭제·접속 관계를 유지했다.

밝은 석재 배경에 금색과 남색을 맞추고 중앙 선택 이름표와 게임 접속 버튼을 강조한 시안을 한 장 제작했다. 두 예시 캐릭터와 빈 슬롯을 배치했으며 예시 캐릭터는 실제 게임 모델 교체나 보유 에셋 확인 결과가 아니다. 내장 이미지 생성 도구를 사용했고 외부 API나 명령줄 대체 도구는 사용하지 않았다.

결과는 SourceArt/UI/CharacterLobby/2026-11-19/character-select-v1.png, 최종 프롬프트는 같은 폴더의 character-select-v1.prompt.txt에 보존했다. 1672×941 RGB 이미지 2,361,160바이트이며 SHA256은 2A76FA197CE616EEAD7901CA72523E4E3DDF631B8963FDF780B06F0DF273DAA6이다. 별도 검토자를 포함한 육안 검수에서 세 슬롯·전신·한글 문구·선택 강조·기본 액션을 확인했다. 원본과 기존 참고 자료는 유지하고 최종 시안 하나만 공개 추적 예외로 지정했다.

현재 완료 범위는 디자인 시안이다. 실제 언리얼 위젯 적용·입력·프리뷰 연결 검증은 아직 수행하지 않았다. 코드·맵·세이브·애니메이션·바이너리 자산 변경이 없어 에디터·빌드·플레이 검사는 실행하지 않았다. 기존 몬스터 자산과 전날 로그 등 다른 작업은 보존하고 별도 작업 브랜치에서 이번 시안만 게시한다. 전체 맵 제작 게이트에 따라 통합 브랜치 승격은 보류한다.

[시안 파일 검사]
이미지 디코딩·치수·해시와 검수 JSON 파싱, 생성물 경로 검사, 변경 문서의 공백 검사를 통과했다. 전체 작업 트리 검사에 나타난 기존 몬스터 바이너리 변경은 이번 시안 스테이징 대상에서 제외했다. 시안과 프롬프트, 기획·결과·검수 기록, 단일 이미지 추적 예외, 스프린트 변경 이력과 오늘 기록의 여덟 파일만 커밋 대상으로 삼았다.
