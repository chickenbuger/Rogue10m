보관해 둔 북쪽 지형을 기존 OpenRunMap의 같은 Landscape 격자에 적용했다. 중앙로 300m와 H·M·T 마을 터는 높이 96m로 이어지고, 도로에는 풀 가장자리를, 마을 터에는 갈색 흙을 복구했다. 남쪽과 서쪽에서 들어오는 길은 기존 지형과 높이를 맞췄다.

지하 훈련고와 지하 작업함에는 연속 암벽과 천장, 출입 경사로, 비밀방과 지름길을 복구했다. 보관본을 연결하지 않은 새 Unreal 프로세스에서 동굴 네 액터의 54개 컴포넌트와 712개 인스턴스를 확인했다. 지형 높이는 저장 전 목표값과 일치했고 중앙로·마을 바닥의 충돌 검사 45지점이 평탄면 조건을 통과했다.

카메라 검사는 두 동굴의 입구 안팎, 굽은 길, 비밀방과 돌아가는 경로에서 기본 3인칭 카메라를 사용했다. 첫 검사의 작업함 입구 탐침은 경사로 끝선 아래의 지형에 닿았다. 입구 안팎을 각각 표본으로 잡은 재검사에서 48시야 모두 통과했다. 카메라 최소 거리 235.69cm, 최대 당겨짐 95.55cm였다.

별도 QA 저장에서 시작 마을 포탈을 걸어서 통과했다. 보스 전투를 준비한 검증에서는 플레이어의 마지막 타격, 승리 정산, Enter로 시작 마을 귀환, 새 프로세스에서 저장 읽기까지 확인했다. 포탈 17항목, 본 실행 77항목, 저장 재로드 17항목이 통과했다. 런 로그에는 이전부터 있던 StylizedCharacter 의존성 누락 메시지가 남는다.

[캐릭터 선택창 시안 실제 적용]

최종 Editor 빌드 6개 작업을 27.93초에 통과했고 선택창·외형·상속·화면 흐름 자산 검사 네 개와 해당 Editor 로그 오류 0건을 확인했다. 실제 1920×1080 렌더 C1119는 238검사·실패0, 40.834초다. 기존 저장 493개는 모두 바이트가 같았고 새 QA 파일 두 개만 추가했다. 앞선 B1119에서는 기존 저장 491개를 보존했고, 실제 마우스로 이름표 선택·캐릭터 프리뷰 선택·접속을 확인했다. 일반 전투 런 완주는 검증하지 않았다.

전체 런타임 로그 검사는 기존 vendor skeleton의 제거된 Humanoid 참조 오류 5건 때문에 여전히 실패한다. 회색 몸체 Debug 재질의 SkeletalMesh usage 경고도 남아 있다. UI 적용·입력 검증 통과와 기존 외형 자산 호환성 해결을 구분하며, 오류를 숨기거나 원본 skeleton을 임의 수정하지 않았다.

2026.11.19 | 맵 1차 마감

시작 마을과 오픈 월드의 제작분을 캐릭터 선택창·외형 자산 호환성 수정과 함께 통합했다. 합친 프로젝트에서 에디터를 빌드하고 포탈 보행, 두 동굴 카메라, 보스 승리와 귀환, 저장 재로드, 캐릭터 선택을 다시 검사했다. 캐릭터 선택 검증 스크립트는 별도 작업 폴더에서도 Python 실행 파일을 직접 지정할 수 있다.

앞서 진행한 한 번의 연속 플레이는 중앙로와 두 동굴을 지나 보스 방에 도착했다. 걷는 동안 카메라 표본 4,457개에서 가림이 없었다. 보스전은 시간 초과로 시작 마을에 귀환했다. 승리 후 정산과 저장은 별도 통합 검사에서 통과했다.
