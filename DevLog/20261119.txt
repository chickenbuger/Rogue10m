[캐릭터 선택창 — 이미지 생성 시안]
캐릭터 선택창을 이미지 생성 도구로 제작해 달라는 요청에 따라 기존 성채 테라스 배경과 로비 화면을 조사했다. 직업 선택이 아닌 세 개의 저장 프로필을 선택하는 구조, 인간·드워프·오크와 남녀 지원, 생성·삭제·접속 관계를 유지했다.

밝은 석재 배경에 금색과 남색을 맞추고 중앙 선택 이름표와 게임 접속 버튼을 강조한 시안을 한 장 제작했다. 두 예시 캐릭터와 빈 슬롯을 배치했으며 예시 캐릭터는 실제 게임 모델 교체나 보유 에셋 확인 결과가 아니다. 내장 이미지 생성 도구를 사용했고 외부 API나 명령줄 대체 도구는 사용하지 않았다.

결과는 SourceArt/UI/CharacterLobby/2026-11-19/character-select-v1.png, 최종 프롬프트는 같은 폴더의 character-select-v1.prompt.txt에 보존했다. 1672×941 RGB 이미지 2,361,160바이트이며 SHA256은 2A76FA197CE616EEAD7901CA72523E4E3DDF631B8963FDF780B06F0DF273DAA6이다. 별도 검토자를 포함한 육안 검수에서 세 슬롯·전신·한글 문구·선택 강조·기본 액션을 확인했다. 원본과 기존 참고 자료는 유지하고 최종 시안 하나만 공개 추적 예외로 지정했다.

현재 완료 범위는 디자인 시안이다. 실제 언리얼 위젯 적용·입력·프리뷰 연결 검증은 아직 수행하지 않았다. 코드·맵·세이브·애니메이션·바이너리 자산 변경이 없어 에디터·빌드·플레이 검사는 실행하지 않았다. 기존 몬스터 자산과 전날 로그 등 다른 작업은 보존하고 별도 작업 브랜치에서 이번 시안만 게시한다. 전체 맵 제작 게이트에 따라 통합 브랜치 승격은 보류한다.

[캐릭터 선택창 시안 실제 적용]
승인한 이미지 시안을 실제 캐릭터 선택창에 적용했다. 기존 성채 배경 위에 남색·금색 헤더와 이름표, 선택 배지, 빈 슬롯 생성 버튼과 접속 버튼을 배치했다. 이름·종족·성별은 실제 프로필에서 읽고, 생성·취소·삭제 두 번 확인·접속을 기존 기능에 연결했다. 기존 위젯과 필수 바인딩을 보존하는 방식으로 자산 하나만 저장했다.

실제 화면에서 처음 발견한 창 원점만큼의 테두리 어긋남과 작은 A-pose 프리뷰를 수정했다. 캐시된 루트 좌표와 화면비 기반 구도를 사용하며, 캡처 직전에 기존 Manny와 종족별 리타깃의 대기 포즈를 동기 평가한다. 새 Tick이나 애니메이션 자산 수정은 없다. 기존 캐릭터 모델·의상·재질은 유지했다.

최종 Editor 빌드 6개 작업을 27.93초에 통과했고 선택창·외형·상속·화면 흐름 자산 검사 네 개와 해당 Editor 로그 오류 0건을 확인했다. 실제 1920×1080 렌더 C1119는 238검사·실패0, 40.834초다. 기존 저장 493개는 모두 바이트가 같았고 새 QA 파일 두 개만 추가했다. 앞선 B1119에서는 기존 저장 491개를 보존했고, 실제 마우스로 이름표 선택·캐릭터 프리뷰 선택·접속을 확인했다. 일반 전투 런 완주는 검증하지 않았다.

전체 런타임 로그 검사는 기존 vendor skeleton의 제거된 Humanoid 참조 오류 5건 때문에 여전히 실패한다. 회색 몸체 Debug 재질의 SkeletalMesh usage 경고도 남아 있다. UI 적용·입력 검증 통과와 기존 외형 자산 호환성 해결을 구분하며, 오류를 숨기거나 원본 skeleton을 임의 수정하지 않았다.

첫 동시 편집 빌드 실패, 적용 도구의 경로·Python API·중간 바인딩 오류, 첫 시각 실패의 원인과 최종 수정 결과를 Feature 문서에 남겼다. 대표 실제 화면은 DevLog/20261119_CharacterSelect/character-selection-final.png 한 장만 보관한다. 추가 상태 사진 세 장과 고유 실패 한 장은 기능 증거에 보존하며 임시 연속 캡처를 통째로 복사하지 않는다.
