기존 2건과 새 작업 1건을 보존했고 저장 후 해당 작업 blocked·일시정지 true·진행 작업 없음·엔진 blocked를 확인했다. SprintChangeLog와 후속 목록 결과 문서에 중단 상태를 반영했다. 현재는 게임 코드·에셋 수정 및 UE 빌드/QA 미실행이다. Studio/EXECUTION.md의 사용자 재검토 규칙에 따라 원인과 읽기 전용 확인 명령을 제시하며 완료 처리하지 않는다. 커밋·푸시는 없다.

### 아린 서비스와 탐험 보상

아린의 대화에 회복 물약 구매, 장착 주무기와 몸통 방어구 강화, 활력·힘 특성 강화, 쉬움·보통·어려움 선택을 연결했다. F로 대화, 방향키로 선택, Enter로 실행하고 Esc로 닫는다. 물약10골드, 강화 다음 단계×25골드·최대+5, 공격/방어 단계당+2다. 레벨 상승 포인트로 활력 최대HP+10 또는 힘 공격+2를 얻으며 각5단계까지다. Data Asset으로 비용과 보너스를 조정한다. 범위·생존·마을·출발 전·메뉴·저장 준비 조건을 확인하고 실패 사유를 대화에 표시한다.

선택 난이도는 새 몬스터의 HP·공격·XP에 한 번씩 적용한다. 쉬움0.75배, 보통1배, 어려움 HP1.5·피해1.25·XP1.5배다. 몬스터 처치는 XP와 골드를 제공한다. 동시 추가된 테스트 몬스터 보상 차단 플래그를 보존했고 일반 몬스터의 난이도와 실제 보상도 다시 확인했다.

### 프로필별 저장과 안전한 복원

성장·XP·수련/토벌 횟수·스킬 해금/공격 배치·장비·그리드/기존 슬롯·가방·골드/크리스탈·소모품 퀵슬롯·개별 아이템 GUID/강화·특성 실제 보너스·난이도 배율·보급 수령 기록을 프로필 GUID별 SaveGame에 저장한다. 변경1초 뒤 자동 저장하고 포탈과 캐릭터 종료 전 즉시 저장한다. 같은 클래스의 프로필을 전환해도 성장과 보급 수령이 섞이지 않으며 포탈에서 보급품을 복제하지 않는다. 강화 아이템은 장착 해제·드롭·줍기에서 상태를 보존한다.

저장 버전 불일치나 누락 에셋·잘못된 배치를 거절하고 실패 시 전체 진행을 되돌린다. 오류 파일은 덮어쓰지 않고 서비스·보급·후속 저장을 막으며, 검증된 현재 상태의 디스크 쓰기 실패는 재시도할 수 있게 했다. 로컬 단일 플레이 저장을 지원한다. 현재 런·체력/마나/스태미나·쿨다운·월드 드롭 액터는 저장하지 않으며 물리 스킬 키 설정은 기존 공통 저장을 유지한다.

### 빌드와 실제 게임 검증

일반 몬스터5종과 아자토르가 플레이어를 인식하고 추적해 공격하도록 보강하고, 공격 발동과 실제 명중에 종별 효과를 연결했습니다.

### 구현 내용
- Sprint#5-28-monster-effects-chase 관리 worktree에서 개발했습니다. 다른 채팅의 특성 개발 전 안정된 사본으로 검증한 뒤 이번 소스7개와 Niagara8개·공격 프로필6개만 원본에 반영했습니다. 기존 특성·저장·보상·스탯·애니메이션 변경을 보존했습니다.
- 시야360도·정지 콜백 차단·재개 시 시야 재수집·리시 밖 재인식 차단을 적용했습니다. 이동 Actor 경로를 반복 중단하지 않도록 수정했습니다. F6 자동 AI에서 가짜 피해 자극을 제거했습니다.
- 녹색 산성 방울·포자·붉은 잔불·금속 불꽃·가시 궤적·심연 파편·정면 파동·영역 분출을 Niagara 에셋으로 제작했습니다. 단회 CPU Sprite burst, 0.2~1.1초 입자 수명, AutoRelease 풀링을 사용합니다.
- 공격 효과는 발동 시, 명중 효과는 실제 양수 피해 시 표시합니다. 완료 델리게이트에서 풀링 참조를 정리하며 AI 정지·취소·사망에 잔여 효과를 제거합니다.
- 초록 점액체 수동 테스트의 사거리 경계 오차를 수정했습니다. 다중 Editor Remote Execution을 프로젝트 경로로 선택하도록 보강했습니다.

### 실제 검증과 결과
- 최종 격리 QA110확인·실패0, 특성 개발 코드와 함께 원본 통합 QA110확인·실패0. 기존 F6 UI 키·마우스·패턴·정리·보상 회귀80확인·실패0.
- Niagara8개를 Editor에서 열어 검사했습니다. 모두 UpToDate, 컴파일·스택 오류0/경고0입니다. 실제6종과 보스 특수 효과 화면을 캡처했습니다.
- 원본 Editor 통합 빌드32.42초 성공. CheckGeneratedChanges·관련 diff --check·Python4개 문법 검사 통과.
- 최초 QA의 시야 사각·정지 후 효과 잔여, 추가 QA의 짧은 사거리 UI 경계 문제를 수정했습니다. 최초 통합의 오래된 헤더 수정 시간은 소스 시간 갱신 후 정식 UHT 빌드로 해결했습니다. 실패 증거도 보존했습니다.
- 커밋·푸시 없음. Shipping 패키징·네트워크 효과 전달은 이번 로컬 단일 플레이 검증 범위에 포함하지 않았습니다.

## 특성 16종과 독립 강화 UI 실제 적용 (2026-10-11)

### 개발 목표
설계한 특성16종을 실제 게임에 적용했습니다. 마을 아린에게 독립 강화창을 연결하고 캐릭터별 투자·무료 재분배·영구 저장을 제공합니다. 인벤토리·스킬·성장은 기존 화면과 관리 영역을 유지했습니다.

### 구현 내용
- 전체/전투/생존/기동/탐험 필터와 아이콘16개 카드, 현재·다음 효과, 비용·남은 포인트, 잠금/최대/부족 상태를 네이티브 UMG로 제작했습니다. 아린 가까이에서 F로 대화한 뒤 특성 강화 창을 선택하고 Enter로 엽니다. 방향키·Enter·마우스로 조작하고 R로 무료 재분배, Esc로 취소/닫습니다.
- 치명·공격·방어·최대 체력/스태미나·이동·회피 비용·재생·물약·보스 피해를 적용했습니다. 같은 적3회 연격, 실제 회피 후 첫 공격 반격, 직접 처치 회복, 경험치를 유지하는 금화 증가와 탐험당1회 불굴을 실제 이벤트에 연결했습니다.
- PlayerState에 투자 단계·실제 지불 비용·구매 누적 효과를 저장하고, 순간 버프·불굴 사용·소수 금화는 별도 런 상태로 초기화합니다. 전체 투자52포인트, 레벨당1포인트이며 불굴은 LV20·3포인트입니다.
- 기존 활력/힘 ID와 맞춤 보너스를 보존해 저장 버전1을2로 옮깁니다. 손상·미래 버전·잘못된 프로필과 초과 예산은 원본을 덮어쓰지 않습니다. 쓰기 실패는 현재 세션을 유지하고 추가 투자를 막으며 정상 복원된 프로필만 재시도합니다.
- 재분배는 실제 사용한 포인트만 환급합니다. 레벨·스킬·아이템·재화는 유지하고 HP/스태미나/마나 절대량을 보존해 무료 회복을 방지합니다. UI 아이콘 Texture는 공식 Unreal 도구로 임포트·저장했습니다.

### 검증과 수정
- 최종 Editor 빌드9.76초 성공. 실제 효과100, 저장 독립 Write125/Read227, UI1080p·720p260, 기존 서비스85와 포탈/런57, 총854검사·실패0입니다. QA 저장 슬롯을 분리하여 일반 프로필 투자를 변경하지 않았습니다.
- 실제 Slate 키·마우스 hit-test, held Enter 중복 방지, 잠금·상한, 재분배 취소/확정, 쓰기 실패 후 저장 버튼, 범위 이탈과 입력 복구를 검증했습니다.21개 잘못된 저장 원본 바이트 보존과 실제 파일 쓰기 실패/복구도 통과했습니다.
- 초기 프로필 이름·QA 배열 오류·화면 캡처 경합·카드 글자 배치·모달 정렬을 수정했습니다. 스크롤 밖 행의 좌표 실패가 두 번 반복되자 Architect/Reviewer로 돌아가 엔진 소스를 확인했습니다. 미페인트 자식의 이전 좌표가 원인이므로 실제 스크롤·렌더 후16개 전체를 검사하도록 재설계했고 통과했습니다. 실패 증거는 보존했습니다.
- 독립 저장·효과 및 UI 검토에서 차단 결함을 찾지 못했습니다. 생성 출력 경로와 범위 내 공백 검사를 통과했습니다. 에디터는 미저장 패키지0에서 정상 종료·재빌드 후 기존 OpenRunMap으로 다시 열었고 클래스3개·16종·UI Texture 재로드와 dirty0, PIE종료 상태를 확인했습니다.

### 작업 경계와 문서
