# 아자토르 기본 훅 애니메이션 기록

- 실제 배치된 인간형 아자토르가 사용하는 `DA_HumanBoss_AttackProfile`, `AM_HumanBoss_Attack`, `A_HumanBoss_Hook_Raw`는 `/Game/Rogue10m/Characters/Boss/AzathorHuman20261110/`의 기존 에셋이다. 걷기는 이전에 접지를 다듬은 `A_HumanBoss_Walk`다.
- 걷기에서 기존 몽타주로 넘어가는 게임 내 보간 속도만 조정했다. 원래 몽타주의 0.08초는 정지에서 사용하고, 걷기에서 기본 공격이 수락될 때 0.22초를 실행 중 복제본에 적용한다. 기존 모션 파일을 보존했다.
- StartHub에서 실제 보스의 기본 공격 수락 경로를 격리 프로그램 검사로 실행했다. 최초 피해 틱 60과 회복 틱 143, 몽타주 0.500000초를 60Hz로 기록했다. 첫 피해·회복 때 실제 입력 방향과 표시 자세를 관측했고, 물리 입력과 일반 필드 플레이는 검증 범위 밖이다.
- 비교 기준 `9cd829f3`과 최종 통합 기반 `3b9c1c36`. [변경과 검증 상세](../../Feature/doc/2026-11-21_azathor-walk-hook-handoff.md)
