# 2026-09-30 — 격투가 스킬트리·테스트 해금·키 설정

## 요구와 구현
맨손 및 너클의 기존 동작을 활용해 K 스킬트리에 기본기4와 무공10의14개 노드를 연결했다. 공격13개와 상시 심법1개를 제공하며 전용 애니메이션·피해·자원·차징·연타·수련/토벌 조건은 보존했다. 현재 트리 전체 해금 버튼을 추가했고 수련 횟수나 토벌 기록은 조작하지 않는다. 테스트 해금은 세션 단위이며 Shipping에서는 제공하지 않는다.

## 키 설정과 역할 분리
선택한 공격에 단일 키보드 키를 지정·해제하고 로컬 SaveGame에 저장하도록 구현했다. Enhanced Input 컨텍스트와 전용 컴포넌트를 사용하며 기존 조작·동일 트리 중복 키는 거부한다. 차징·공중 조건, 기존 GAS·자원·공유 쿨다운 검사와 메뉴·무기전환·일시정지·키 변경 시 차징 취소를 연결했다. 전투/입력과 UI 담당을 분리하고 서로의 변경을 독립 검토했다. 공통 에셋 적용·테스트·문서는 통합 담당자가 맡았다.

## 검증과 개선
UE 빌드와 Editor 프로필/위젯 검증을 수행했다. 검토에서 QA 저장 슬롯 가드와 같은 프레임 재바인딩의 이전 자체 Action 오판 문제를 찾아 수정했다. 최초 실제 게임 검증은94개 중92개 통과였으며 점프 테스트의 위치 복원 누락 때문에 다음 지상 차징 기술이 거부된2개 항목을 확인해 테스트 환경 복원을 보완했다. 실제 캡처에서 상세 설명 겹침을 발견해 고정 줄바꿈 폭과 노드 크기를 정리했다. 최종 재검증 결과는 아래에 이어 기록한다.

## 최종 검증 결과
최종 UE Editor 빌드는10.44초에 성공했고 실제 Editor의14노드·두 프로필·신규 위젯 연결도 통과했다. 최종 격투가 런타임107항목/공격13개 발동·몽타주 실패0, 새 게임 프로세스 키 복원과 실행2항목 실패0이었다. 기존11무기 전환, 9종840프레임과 실제14회 피해도 통과했다. 새 자세118,581행 구조 PASS·비유한0·머리회전 기여7.0021도를 확인했다. 1920×1080 실제 창에서 키 설정/해금 버튼과14노드, 겹침 수정 결과를 직접 확인했다.

키는 단일 키보드 입력만 지원한다. 테스트 해금은 세션 단위이고 일반 키 설정만 저장한다. 13개 기술의 모든 상황별 피해를 검사한 것은 아니며 실제 피해 명시 검증은 첫 잽과 별도9종 전투 회귀다. 온라인 복제·영구 수련 저장은 범위 밖이다. 작업 브랜치에서 기존 변경을 보존했고 커밋·푸시는 없다.

## 독립 최종 검토
전투·입력 담당과 UI 담당이 서로의 변경 및 최종 실행 증거를 검토했다. 107개 런타임 검사, 새 프로세스 키 복원 2개, 11종 무기 전환, 840프레임 전투와 실제 피해 14회를 독립 집계했고, 최종 화면의 14개 노드·전체 해금·키 설정 표시도 확인했다. 발견했던 입력 Action 세대 충돌과 QA 저장 슬롯 문제는 해결되었으며 검토 범위에 남은 완료 차단 사항은 없다. 두 검토 결과는 input-review.md와 ui-content-review.md에 보존했다.

## 내장 AI Assistant 웹 인증 오류 직접 처리

사용자가 제시한 Cloudflare iframe 스크립트 차단과 IsAvailable 취소 메시지를 확인하고, 직접 수정 요청에 따라 프로젝트의 실험적 AIAssistant 플러그인만 비활성화했다. Epic 내장 AI 창은 꺼지며 별도 Codex CLI 기반 Studio와 외부 Unreal MCP·도구 설정은 유지한다. 엔진 코드나 웹 보안 제한을 바꾸지 않았고 기존 게임·에셋 변경도 보존했다.

Sprint#5-5-editor-ai-assistant-error 브랜치에서 UE Editor 빌드 120.41초 성공, 새 에디터 프로세스 시작·프로젝트 로드·정상 종료 코드 0을 확인했다. 새 로그의 AIAssistant 마운트와 LogAIAssistant 메시지는 0건이며 MCP·AllToolsets·PythonScriptPlugin은 로드되었다. JSON·변경 검토 및 diff 검사를 통과했다. 기존 엔진 자동화 초기화의 Condition failed 15건은 변경 전에도 같은 수로 존재하므로 모든 오류 제거를 주장하지 않는다.

이 처리는 프로젝트에서 오류를 내는 내장 웹 연결을 끈 것이며 Cloudflare 인증 서비스 자체의 복구가 아니다. 결과와 복원 방법을 Feature/doc/2026-09-30_editor-ai-assistant-error.md 및 Docs/UE58MCPSetup.md에 기록했다. 커밋·푸시는 없다.
