[2026-09-09] Sprint#4-21 참조 이미지 기반 금속 전투 HUD 완료

작업 배경
사용자가 첨부한 어두운 금속 프레임·중앙 원형 게이지·좌우 체력과 자원 바 구성을 현재 UE5.8 UI에 적용했다. 전날의 화면 비율 대응 구조를 유지하면서 시각 구성을 바꿨다.

주요 변경
- 공통 코어1200×208, 아래56·좌우24 여백, 단일 DPI와 균등 축소.
- 검은 금속 프레임을 이미지 생성 도구로 제작하고 UV3조각으로 배치.
- 프레임 연결부가 드러난 첫 캡처를 보완하여 중앙 장식 뒤로 날개를 중첩.
- 중앙156×156 원형 게이지가 실제 자원0~100%를 표시. 자원 없음은 -- 표시.
- 아이콘64×64 아래 입력 표기를 두고 LMB/RMB/HOLD LMB/HOLD RMB/E 유지.
- 실제 그림이 없는 스킬 및 직업 문장에 기존 그림을 UI에서만 대체 표시.
- 자원 존재 시 직업명과 겹치던 기존 수평 아이덴티티 막대 연결 제거.
- 현재 행동5개·잠금 아이템4개 및 실제 로그·타이머·쿨다운 연결 유지.

좁은 화면은 코어816.6×141.5와 원형 문장106.2×106.2로 균등 축소.
별도 시각 검증자가 최종3장 확인: 프레임 연결·문장 표시·비율·키·잠금의 잘림과 겹침 없음.

[2026-09-09] Sprint#4-24 몸통 동작과 카메라가 연결되는 근접 공격

작업 배경
사용자가 전신 체중 이동을 활용한 휘두르기와 카메라 동조를 요청했다. 기존 코드는 전신 몽타주에서 손 전진량만 읽어 몸통과 시야의 힘 전달이 사라지고 있었다.

주요 변경
- 현재 몽타주의 골반·척추·쇄골 변화를 1인칭 포즈에 반영하고 어깨 변환 이후 팔 IK 재계산.
- 손의 좌우·상하 궤적과 준비 후퇴, 반대손 가드 회수 추가.
- 같은 상체 모션을 기준으로 표시 카메라 이동·회전과 완만한 보간 적용.
- 실제 타격 CameraComponent와 ControlRotation은 유지해 판정 원점·방향 보존.
- 강도 0·무기 교체·사망·시점 전환 시 카메라 동조 초기화.
- 기획 1·개발 2·독립 검증 2 배정. 시각 검증은 구현에 참여하지 않은 별도 에이전트가 수행.

검증 결과
UE 5.8.2 최초 통합 빌드 25.95초, 사망 가드 보완 후 최종 증분 빌드 8.89초 성공.
최종 실제 촬영 120프레임 실패 0, 상하 시선 ±25도·2560×1080 추가 3조건 통과.
촬영 공격 3회에 이어 추가 공격 2회에서 활성 중 강도 0·무기 교체·사망 상태 초기화 확인.
척추 가드 대비 변화 11.396도, 손 수직 이동 3.900cm, 표시 카메라 최대 1.493도·1.922cm.
독립 소스 검토의 사망 가드 누락 수정. 최종 잔여 중대·중간 회귀 없음.
독립 시각 검토에서 공격 흐름 8장·타격 연속 8프레임·가드/복귀/상하/울트라와이드 5장 통과.
준비·신전·반대손 가드·복귀와 배경 동조를 확인했고 HUD 고정, 손목·손가락·팔 연결과 중앙 시야 유지.

레퍼런스와 범위
YouTube 웹 조회와 직접 브라우저가 실패해 외부 영상을 재생하지 못했다. Mixamo의 특정 파일을 내려받아 적용한 것도 아니다.
사용자가 설명한 전신 동작·카메라 동조 요구를 현재 프로젝트의 실제 전신 몽타주에 반영했다. 원본 영상과 프레임 단위 일치 여부는 미확인.
전신 전체를 1인칭 화면에 노출하지 않고 어깨·팔과 카메라를 통해 체중 이동을 전달한다.
새 바이너리 자산·HUD·실제 capsule 이동·피해·타이밍·사거리 변경 없음. 선행 미커밋 작업 보존, 커밋·푸시 없음.
