[2026-11-11] 게임을 안전하게 종료하는 UI 추가

■ 작업 배경
사용자가 게임 종료 UI도 필요하다고 요청했다. 메인 메뉴에는 바로 앱을 닫는 버튼이 있었지만 플레이 중 종료 흐름과 실수 방지 확인이 부족했다. 기존 설정 입력과 화면 디자인을 유지하면서 메뉴·캐릭터 선택·설정·탐험 결과 화면에 공통 종료 흐름을 연결했다.

■ 이번에 구현한 내용
플레이 중 Esc/O/F10으로 설정을 열면 오른쪽 위에서 게임 종료를 선택할 수 있다. 종료 확인창의 기본 초점은 취소이며 Esc, Backspace, 게임패드 B로 취소한다. 메인 메뉴의 기존 종료 버튼도 같은 확인창으로 연결했다. 위젯은 C++ UMG로 작성했고 맵이나 바이너리 자산은 수정하지 않았다.

종료 확인 직전에 현재 월드·캐릭터·선택 프로필·부착 프로필·런 ID를 다시 확인한다. 정상 부착 세션은 SaveNow 성공 후에만 앱을 닫는다. 저장 실패 시 오류를 보여 주고 앱을 유지해 재시도나 취소가 가능하다. 결과 화면은 탐험 정산 저장 완료도 확인한다. 확인 중 사망·시간초과 등으로 런 단계가 바뀌면 종료 확인을 닫고 기존 결과 화면으로 넘긴다.

■ 기존 정책을 유지한 부분
탐험 도중 종료는 이어하기 저장이 아니다. 정상 입장 마커와 기준잔액이 있는 미완료 탐험은 다음 StartHub 진입 때 기존 중단 복구 코드가 처리한다. 런에서 얻은 아이템·성장·습득 스킬은 초기화하고 새 캐릭터의 기본 인벤토리를 복구한다. 기본 무기가 인벤토리에 남는 것과 런 전리품 보존을 혼동하지 않도록 기록했다.
