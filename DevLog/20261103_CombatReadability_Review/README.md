# 실제 검증 화면 발췌

원본 54장 전체를 디코딩·해시 검사했고, 이 폴더에는 Root가 직접 확인한 대표 12장을 원본 바이트 그대로 복사했다. 전체 목록은 Feature/doc/evidence/combat-readability-20261103/final/png-manifest.json에 있다. 영상·공유·합성 화면은 사용하지 않았다.

보스 화면은 임시 시험 바닥, 저장에서 분리한 HP50000 플레이어, 보상 없는 F6 보스의 실제 준비·해결·회복 프레임이다. 공격력·범위·쿨다운 데이터는 바꾸지 않았다. 정면 가까이에서는 기본 바닥 경고가 시야 밖일 수 있어 실제 대상의 Windup HUD를 추가했다.

판정 화면은 실제 scene의 query 활성 단순 도형과 실제 공격 쿼리다. 검사 카메라를 사용한 참고 화면은 공격 판정 계산과 별개다. 보라=현재 단순 collider, 청록=실행한 overlap, 호박색 cone=Actor 각도 필터 참고, 녹색 점=양수 피해를 수락한 Actor 원점이며 접촉점이 아니다. 잠긴 다중 타격의 다음 pulse는 새 overlap을 그리지 않는다. 전체 collision 참고는 authored 월드 도형이며 실제 query 필터와 구분한다.
