

## 2026-09-26 — Appearance Mesh 머리 카메라와 실제 Boxing 기본 공격

### 작업 목적
별도 First Person Mesh 대신 캐릭터의 실제 외형 메시 머리에 카메라를 연결하고, 같은 외형의 애니메이션을 1인칭으로 본다. Sprint#4-39-appearance-head-camera에서 기존 변경을 보존하여 진행했다.

### 구현 내용
기획 1 / 개발 2 / 검증 2 역할로 설계·개발·검증을 진행했다. 실제 Appearance head 포즈로 카메라를 갱신하고 팔다리·몸통을 유지했다. 머리 안쪽 가림과 숨긴 head 스케일 문제를 처리했다. First Person Mesh는 렌더·애니메이션 평가를 끄고 Blueprint 직렬화 호환용으로만 남겼다. Animation Source Mesh는 기존 리타깃에 필요하여 유지했다.
Boxing 원본 기반 왼잽과 미러 오른잽 몽타주를 실제 좌클릭에 연결했다. 시간만 기존 타격 지연에 맞췄고 스킬 피해·범위·입력과 우클릭 기존 모션은 보존했다.

### 검증 결과
UE 5.8.2 Editor 최종 빌드 9.40초 성공. 애셋 제작·저장 검증 성공. 최종 게임 570프레임/자동 카메라 cache 570샘플 통과, 위치 오차0cm·회전 오차0.00000382도, 점프 높이89.99cm. 원본·공유 애셋7개 SHA256 보존. 생성 경로와 diff 검사 통과.
초기 모든 공격 명중 가정은 스트레이트에서 실패했다. 타격 시 머리가 약66도 옆으로 돌아 표적이 공격 상자 밖에 있음을 독립 충돌 검사로 확인했다. 범위나 표적을 바꾸지 않고 3회 명중과1회 정상 빗나감을 검증했다. 실패 로그도 보존했다.
실제 플레이 영상1280×720/30fps/19초 제작. 팔과 몸통·점프 움직임은 확인했으나 몸통/HUD에 가려 발 전체 가독성은 제한된다. 원본 머리 회전을 그대로 따르므로 공격 중 시야 회전과 팔 가림이 크다. 사망·외형교체·재빙의·멀티플레이 별도 실행 검증은 하지 않았다.
