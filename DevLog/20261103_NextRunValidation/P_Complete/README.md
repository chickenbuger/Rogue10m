실제 BasicRun1103P의 승리·다음 필드·포기 취소·포기 정산·마을 귀환 원본5장이다. 1280x720 전체 디코딩/SHA256와 Root 시각 검토를 마쳤다. 프로그램 입력이며 사람 직접 플레이/새 모션 검증/영상이 아니다.


## 대표 사진 보관 상태

사용자 요청에 따라 중복·이전·보조 사진을 정리했다. 현재 `20261103_NextRunValidation` 묶음에는 대표 1장을 보관한다. 이 문서의 촬영 개수·파일명·시각 판정은 당시 실행 이력이며, 현재 사진 목록은 [대표 사진 목록](../../README.md)을 따른다. 수치 결과·텍스트 실패 기록은 그대로 유지했다.
