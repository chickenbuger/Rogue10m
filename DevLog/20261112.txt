2026-11-12 | 실제 월드맵 제작 참조 통합
==================================================

요청과 반영
사용자가 이 대화의 기획과 생성 지도 전체를 실제 맵 제작에 참조하도록 요청했다. 별도 작업 브랜치 Sprint#9-31-world-map-production-reference에서 Docs/WorldMapProductionGuide.md를 만들고, 지도 원본 PNG·생성 기록·배치 JSON·획득처 JSON을 Docs/References/WorldMap에 보존했다. AGENTS.md와 기존 맵 편집/월드 구조 가이드에 제작 전 읽을 경로를 연결했다.

최신 결정
큰 마을3·전문초소5·사냥터5, 일반 몬스터15종과 별도 중간보스4/최종보스1, 직행60초·성장15분 입구·런20분을 기록했다. 무기별 동시/차징 선택 지원과 Ctrl 한 번→첫Q부터 고정 제한시간→QQQ 자동 마력미사일을 반영했다. 하위 입문서만 간단한 수련 보수로 직접 안내하고, 중상위 비급은 임무 지역 탐험으로 발견한다. 과거의 일률적 슬롯·의뢰완료 비급 택일 규칙을 복원하지 않도록 우선순위를 명시했다.

획득과 보존
우선3직업·후속8직업, 너클/대검20개와 마법3개 비급, 특정무기와 전수자 위치를 별도 계획 데이터로 연결했다. 지도는 실제 에디터 캡처가 아닌 콘셉트이며 작은 글자/아이콘/픽셀 위치보다 문서와 JSON을 우선한다. 수치·좌표·새 행동은 계획이고 실제 주행·AI·맵 제작 완료를 뜻하지 않는다.

검증과 범위
정적 JSON/연결/거리/비급정책·로컬링크·이미지 해시·생성경로를 검사하고 최종 결과를 Feature/doc/evidence/world-map-production-reference-20261112/validation.json에 남긴다. 기존 미커밋 Source·Config·Content·저장과 과거 기록을 보존했다. 이번 변경은 참조 문서/이미지/계획 데이터이며 UE·빌드·맵 에셋 편집은 실행하지 않았다.

[Notion 요약 후보]
실제 제작자가 대화의 최신 결정을 놓치지 않도록 월드맵 제작 기준과 생성 지도를 프로젝트에 저장했다. 배치/획득처 JSON과 AGENTS·맵 편집 가이드를 연결하고 최신 비급 발견·마법 커맨드·몬스터 분리 규칙을 명시했다. 실제 맵 적용은 별도 패킷의 에디터 조사·블록아웃·수직 검증부터 진행한다.

[월드맵 제작 참조 최종 검증]
정적 검사584개 실패0, 로컬링크36개 유효, 21노드·29도로·숨은 평면교차0과4경로 계산을 확인했다. 원본 지도1536×1024·4,306,713바이트 SHA가 일치하며, 기존 tracked dirty68개 중 이번 Sprint append를 제외한67개 해시가 보존됐다. 독립검토2건의 S/B 구분·Ctrl 진입/해제 미정·마력미사일 명칭을 반영했다. 생성경로 검사 통과, 기존 Unreal 바이너리 경고만 확인했다.
원격 fetch 결과 통합 브랜치보다 기존 작업 기준이28커밋 앞서 있어 해당 runtime 전체를 이번 문서 검증으로 승격하지 않는다. 문서 범위만 작업 브랜치 체크포인트로 공유하며 main 반영과 실제 맵 제작 완료를 주장하지 않는다.

2026-11-12 Landscape 월드 배치 1차 제작
==================================================

작업 범위
저장된 월드맵 기획·지도·배치와 획득처 자료를 기준으로 Sprint#9-32-landscape-world-blockout 브랜치에서 실제 맵 제작을 시작했다. 시작 연결, 직행로, 큰 마을, 작은 거점, 사냥터, 검증·기록의 패킷으로 나누었다. 기존 시작 마을과 아린·장비·보스·전투 관련 작업 중 변경은 별도 보존했다.

실제 제작
기존 맵을 재생성하지 않고 새 제작용 WorldLayout20261112 맵을 World Partition과 Landscape로 만들었다. 1.8km 지형에 256개 지형·충돌 컴포넌트와16개 스트리밍 프록시, 편집 레이어1개를 확인했다. 새 전용 C++ 제작 함수만 추가했으며 기존 OpenRunMap 전용 보호는 유지했다. 정규 에디터 빌드2회가 성공했고, 생성 직후 외부 액터를 무관한 dirty 맵으로 오인하던 가드를 해당 후보의 외부 패키지만 허용하도록 고쳤다.

마을과 동선
수렵촌의 회관·오두막, 풍차장터의 풍차·상점·부스, 마탑·외부 서고와5초소·5사냥터 외형을 실제 배치했다. 건물 모서리는 평탄대 내부에 놓고 도로8m를 침범하지 않도록 검사했다. 편집용 표식은 일반 몬스터15·NPC12·비급23·무기3개다. 표식은 NPC·대사·퀘스트·드랍·AI가 실제 구현됐다는 뜻이 아니다. 보스 경기장 지지면과 입구까지의 길을 배치했으며 최종보스 전투는 아직 붙이지 않았다.

시작 마을 보존
기존 포털2개·아린을 그대로 둔 채 새 필드용 포털과 안내를 외부 액터6개로 추가했다. 시작 마을 본체 파일은 백업과 바이트 해시가 일치한다. 기존 작업 중 파일68개의 기준 해시와 시작 마을 외부 패키지713개를 별도 작업 백업에 보관했다. 동시 작업이 바꾸는 공용 문서·Controller 소스는 이번 변경으로 덮어쓰지 않았다.

실제 보행 검증
별도 QA 저장 슬롯에서 정상 메뉴의 캐릭터 생성 콜백으로 캐릭터를 만들고 시작 마을에 입장했다. 시작 마을은 대기 상태·1200초이며 새 포털 통과 후20분 런이 시작됐다. 기본 장비의 실제 속도620cm/s를 변경하지 않고 캐릭터 이동 입력으로 걸어 보스 입구까지48.537초, 접지 이탈0프레임을 확인했다. 물리 키보드 입력이나15분 성장 동선·보스 전투 완료로 보고하지 않는다.

발견과 보정 중인 항목
첫 화면에서 길 표시가 횡경사 지형에 파묻혀 조각처럼 보이는 문제를 확인했다. 지형·충돌은 보존하고29개 지면 투영 길 표시로 바꾸는 별도 보정을 진행한다. 전체 도로의 최초 에디터 검사3431개 중20개가 실패했으며, 원본 증거를 보존했다. 대부분5m 직선 캡슐 검사와 평탄대 어깨의 지형 접촉이며1개는 정확한 지형 타일 경계의 광선 누락이었다. 원인을 구분해 지면을 따라가는 세부 검사와 경계 진단을 추가한다. 전체 지형 삼각형의 횡경사가12도를 넘는 국소 지점은 후속 다듬기 대상으로 명시한다.
