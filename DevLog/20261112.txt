요청과 반영
사용자가 이 대화의 기획과 생성 지도 전체를 실제 맵 제작에 참조하도록 요청했다. 별도 작업 브랜치 Sprint#9-31-world-map-production-reference에서 Docs/WorldMapProductionGuide.md를 만들고, 지도 원본 PNG·생성 기록·배치 JSON·획득처 JSON을 Docs/References/WorldMap에 보존했다. AGENTS.md와 기존 맵 편집/월드 구조 가이드에 제작 전 읽을 경로를 연결했다.

최신 결정
큰 마을3·전문초소5·사냥터5, 일반 몬스터15종과 별도 중간보스4/최종보스1, 직행60초·성장15분 입구·런20분을 기록했다. 무기별 동시/차징 선택 지원과 Ctrl 한 번→첫Q부터 고정 제한시간→QQQ 자동 마력미사일을 반영했다. 하위 입문서만 간단한 수련 보수로 직접 안내하고, 중상위 비급은 임무 지역 탐험으로 발견한다. 과거의 일률적 슬롯·의뢰완료 비급 택일 규칙을 복원하지 않도록 우선순위를 명시했다.

획득과 보존
우선3직업·후속8직업, 너클/대검20개와 마법3개 비급, 특정무기와 전수자 위치를 별도 계획 데이터로 연결했다. 지도는 실제 에디터 캡처가 아닌 콘셉트이며 작은 글자/아이콘/픽셀 위치보다 문서와 JSON을 우선한다. 수치·좌표·새 행동은 계획이고 실제 주행·AI·맵 제작 완료를 뜻하지 않는다.

검증과 범위
정적 JSON/연결/거리/비급정책·로컬링크·이미지 해시·생성경로를 검사하고 최종 결과를 Feature/doc/evidence/world-map-production-reference-20261112/validation.json에 남긴다. 기존 미커밋 Source·Config·Content·저장과 과거 기록을 보존했다. 이번 변경은 참조 문서/이미지/계획 데이터이며 UE·빌드·맵 에셋 편집은 실행하지 않았다.

[Notion 요약 후보]
실제 제작자가 대화의 최신 결정을 놓치지 않도록 월드맵 제작 기준과 생성 지도를 프로젝트에 저장했다. 배치/획득처 JSON과 AGENTS·맵 편집 가이드를 연결하고 최신 비급 발견·마법 커맨드·몬스터 분리 규칙을 명시했다. 실제 맵 적용은 별도 패킷의 에디터 조사·블록아웃·수직 검증부터 진행한다.
