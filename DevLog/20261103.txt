

# 2026-11-03 남은 개발 계획과 마을 메뉴 일시정지

최신 코드와 DevLog를 대조해 보스 승리·정산·마을 귀환까지의 기존 검증과, 아직 실행되지 않은 동일 프로필 다음 판 연결을 구분했다. 기존 next-run 미커밋 코드/사진/저장을 보존하고 Sprint#9-25-safe-menu-pause에서 개발했다.

출발 전 StartHub에서 인벤토리·장비·스킬·설정·특성 창을 열 때만 게임을 정지한다. 마지막 창을 닫거나 런을 시작하면 메뉴가 소유한 정지만 해제한다. 필드 메뉴의 월드·런 타이머 진행과 다른 기능의 pause는 유지한다. 메뉴를 닫고 늦게 마우스를 놓아도 이전 차징 입력이 발사되지 않게 했으며 이미 수락된 공격 시간·피해·쿨타임은 취소하지 않는다.

최종 실제 C++ 빌드47.69초 성공, NullRHI71/0과 D3D11 화면 렌더71/0, 기존 전투·조건·교체·쿨타임·재화30/0이 통과했다. 지역변수명 충돌 빌드 실패와 바깥 셸의 오래된 종료코드 오인은 보존하고 수정한 결과와 구분했다. 런처 기존 파일 거부2개·AST 검사도 통과했다.

실제1280x720 사진3장을 DevLog/20261103_SafeMenuPause_MenuPause1103R에 보존하고 디코딩·해시·시각 검토를 마쳤다. 장비 스탯 글자 잘림은 기존 UI 후속 과제로 남긴다. 영상은 재시도하지 않았다. 시작 저장356개는 모두 동일하고 새 QA4개만 추가해360개다. 원본 에셋·맵·저장 스키마·밸런스 변경은 없다.

사람 직접 입력·실제 다음 판 왕복·정상20분·새 모션·패키징 완료를 뜻하지 않는다. 안전 마을 타이머는 원래 대기 상태며, 활성 타이머는 별도 명시적 QA 런으로 검사했다. 다음 순서는 동일 프로필 다음 판/포기 왕복 → 액티브4슬롯·무기별 프리셋 → Discovery 정보 UI → 시야/보스 대응·60초 동선 → 선택형 필드 성장 → 자원 융합 → 패키징이다. 미정 수치를 임의로 확정하지 않았다.
