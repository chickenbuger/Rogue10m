

## 2026-10-29 — 너클 시작과 런/로비 성장 분리
정상 새 캐릭터의 시작 무기를 너클로 맞추고 테스트 무기 무료 지급을 제거했다. 런 성장과 로비 강화의 구매 예산을 분리했고, 승리·사망·시간초과 후 실제 허브 귀환에서 런 성장·재화·아이템·배운 기술을 초기화한다. 로비 강화·재화와 습득 정보 기록은 남긴다. 기존 슬롯은 보존하고 v4 별도 저장을 사용한다.

검증 결과: Editor 빌드 성공, 기존 회귀24개 PASS, 실제 귀환 포함68/68/69항목 PASS, 렌더링 프로그램 입력34항목 PASS. 102개 세이브와 기존 증거66개 파일 SHA256 불변. PNG9개 보존 및 디코딩 확인. 수동 한 판 완주와 60초 실측은 미실행. 로비 보상1/처치+10/승리는 임시값이며 퀘스트·필드보스 추가 가산과 정산 UI는 후속이다. 원격 push/병합 없음.

[Notion 요약 후보]

- 중복 지급·저장 실패·실제 귀환·정보용 Discovery 경계를 검증.

## 설정에서 탐험 포기와 재시도
설정 창에 탐험 포기 버튼과 확인 창을 연결했다. 마을 준비 비용은 돌아오지 않고, 이번 판 물품·숙련·배운 기술은 초기화되며 공개한 기술 정보는 남는다고 안내한다. 취소·닫기는 탐험 상태를 바꾸지 않는다. 프로필·런이 바뀐 확인창은 다시 열어야 한다. 저장 실패 중 결과와 값을 유지하며 재시도 후 허브로 돌아간다.
Editor 빌드, 기존 회귀30개와 최종 메뉴 198항목을 통과했다. 실제 UMG 이벤트·합성 Slate 키의 프로그램 검증이다. 데스크톱 재연결 후 실제 렌더링 PNG6장을 남기고 글자 줄바꿈·내용 폭을 다듬었다. 기존 세이브190개·증거248개 해시 불변. 물리 입력·수동 완주·강제종료는 미검증이며 push/병합은 하지 않는다.
[Notion 요약 후보] 설정 확인 → 포기 저장 대기/재시도 → 허브 귀환을 완성했다. 마을 지출·재화 복원·런 초기화·Discovery 유지와 중복 제출 방어를 검증했다. 다음은 실제 필드와 물리 입력 확인이다.


## 기존 카메라를 보존한 1인칭 무게감 프로토타입
이미1인칭인 외형 카메라 위에 선택형 프로필을 얹었다. 시야각과 머리 흔들림 예산, 손의 작은 무게 이동을 조절한다. 공격 접촉 구간은 보정을 비우고 조건이 불확실한 공격은 기존 포즈를 쓴다. 원본 입력·타격 시각·속도·쿨타임은 유지했다. FPHeavy1로 시험하고0으로 돌아간다. 현재는 맨손 표시를 유지하며 향후 얻은 너클별 모델을 붙인다.
Editor 빌드, 회귀17개와 일반 렌더/2배속30fps 상한 QA를 통과했다. 실제 이동·명중·시선/trace·경계 복구를 프로그램 입력으로 확인하고 PNG9장을 남겼다. 기존 세이브204개와 증거312개 해시는 같다. 물리 입력·실제 필드 완주·전체 clipping은 아직 검증하지 않았다. 기존 sprint blur와 아주 가까운 QA 표적의 시야 가림은 남아 있다. 구매·에셋 생성·push/병합은 하지 않았다.
[Notion 요약 후보] 기존1인칭을 지키면서 무게감/안정화 프로필을 분리했다. ON/OFF 입력·공격 clock·원형 복원과 저장 보존을 검증했다. 현재 맨손 외형 확정, 향후 장착 아이템별 모델 연동·실제 필드 체감 점검이 다음 범위다.

## 콘솔 없이 켜고 되돌리는 1인칭 표현

기존 카메라는 이미 1인칭이다. 설정(O/Esc/F10)에 무게감 사용 체크박스, 동작 강도, 기존 표현 복원 버튼을 넣었다. 이번 실행에만 적용하며 진행 세이브·키 바인딩은 쓰지 않는다. 포기 확인창에서는 새 컨트롤을 숨기고 조작을 거부한다. 현재 너클의 맨손 표현은 그대로 유지했다.

Editor 빌드와 비렌더560항목, 기존 저장실패 메뉴97항목을 통과했다. 실제 렌더링 UI 사진8장을 남기고 글자와 배치를 확인했다. 렌더링 달리기 비교는 한 구간에서 W/Shift 입력이 함께 해제돼5건 실패했으므로 전체 성공으로 기록하지 않는다. 기존 블러0.35·색 번짐0.6은 새 모드와 분리된 PlayerFeedback 효과로 확인했다. 짧은 관측을 성능 개선율이나 전체 프레임 안정성으로 확대하지 않았다. 물리 입력·필드 완주·콜드 첫 공격 정지 원인은 후속 검증으로 남겼다.

기존 세이브216개와 증거390개의 보존 해시를 확인했다. 실패 로그와 QA 슬롯도 유지한다. 로컬 체크포인트를 만들며 원격 push/병합은 하지 않는다.
