# Rogue10m 개발 로그 - 2026-08-13

## Sprint#4-11 - 기본 이동 파티클 절제 조정

### 작업 배경

기존 걷기 및 기본 이동 파티클이 캐릭터와 화면을 과하게 가리고 밝은 파편이 반복되는 문제가 있었다. 참조 영상의 짧고 둥근 먼지 Poof 느낌에 맞춰 이동 효과의 크기, 밀도, 지속 시간을 줄였다.

### 주요 작업

- StarterContent 연기 파티클을 프로젝트 내부에 복제하고 UE 5.8 공식 Cascade→Niagara 변환기로 소프트 먼지 원본을 제작했다.
- 걷기, 뛰기, 점프, 2단 점프, 착지, 구르기 Niagara 6종을 같은 회백색 먼지 계열로 교체했다.
- 걷기 효과를 0.12배, 0.68초 간격, 0.08초 방출로 낮추고 첫 이동 입력 직후의 즉시 버스트를 제거했다.
- 뛰기와 점프 계열도 0.16~0.20배, 0.10~0.14초 방출 범위로 절제했다.
- 좌우 발 위치에 번갈아 생성되도록 발 오프셋을 적용했다.
- Niagara 시간 배율 3.0과 동작별 방출 종료 Timer를 적용해 반복 원본이 화면에 누적되지 않게 했다.
- AutoRelease 풀링과 이벤트 기반 처리를 유지하고 Tick은 추가하지 않았다.
- 공격 Niagara와 공격 Data Asset은 이번 보정 범위에서 변경하지 않았다.

### 검증 결과

- UE 5.8 `Rogue10mEditor Win64 Development` 빌드 성공
- 공통 애니메이션 구성 스크립트 성공
- 이동 상태 5종, Montage 5개, Niagara 12개, 절제 이동 VFX 6종, 종족 6종, 공격 8개, 점프 프로필 1/2 자동 검증 통과
- 공식 변환기가 만든 Niagara에 에디터 전용 변환기 패키지 의존성이 남지 않음을 확인
- Human Male 실제 PIE에서 몬스터와 스포너를 제거한 뒤 걷기, 점프, 구르기 입력을 직접 실행
- 기존 밝은 청색 이동 파편과 파티클 누적이 재현되지 않고 기본 동작이 화면을 가리지 않음을 확인
- 0.08~0.14초짜리 개별 먼지 Poof는 1인칭 HUD와 짧은 입력 타이밍 때문에 정지 화면으로 명확히 분리하지 못했으며, 지속 뛰기와 StoneFist 2단 점프는 자동 검증으로 확인

## Notion 요약 후보

> **Rogue10m 기본 이동 파티클 절제 조정**
>
> 과도했던 걷기·기본 이동 파티클을 참조 영상처럼 짧고 둥근 회백색 먼지 Poof 계열로 교체했다. 걷기는 0.12배 크기와 0.68초 간격으로 가장 작고 드물게 출력하며, 뛰기·점프·2단 점프·착지·구르기는 동작 강도에 따라 0.16~0.20배로 구성했다. 모든 이동 효과에 0.08~0.14초 방출 종료와 Niagara 시간 배율 3.0을 적용해 화면 누적을 막았다. 빌드와 자동 검증을 통과했고 실제 PIE에서 걷기·점프·구르기를 실행해 기존 밝은 파편 반복과 파티클 누적이 사라진 것을 확인했다.
