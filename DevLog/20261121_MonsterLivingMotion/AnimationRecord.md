# 몬스터 기본 공격·피격 애니메이션 기록

2026년 11월 21일 `Sprint#25-3-monster-combat-transitions`에서 `ad94906d` 기준의 표시 메시를 60Hz로 비교했다. 신규 시퀀스 없이 현재 `DA_OW_BasicAttack_*`의 Dungeon Mason 계열 공격과 피격 클립을 공용 `DefaultSlot`으로 연결했다. 대상은 초록·붉은 점액체, 스포어링, 철갑 등껍질 및 가시수호자다. 아자토르는 기존 네이티브 몽타주 경로를 대조했다.

보행 준비는 입력 구간 27프레임, 공격 시작 뒤 실제 첫 피해는 가시수호자 17프레임과 일반 네 종 21프레임이다. 가시수호자는 41프레임, 일반 네 종은 50프레임에 후딜이 끝났다. 60Hz 표시 메시의 최대 본 위치·회전 차이는 [기능 기록](../../Feature/doc/2026-11-21_monster-combat-transitions.md)에 남겼다. 프로그램으로 위치를 잡은 캐릭터를 향한 사거리·피해 판정이며 물리 입력과 전체 필드 클리어를 기록하지 않았다.
