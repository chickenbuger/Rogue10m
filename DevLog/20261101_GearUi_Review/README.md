## K: 실제 창 장착·20분 시간초과·저장·귀환 확인

K는 native 창이 보이고 최소화되지 않은 상태의 실제 Slate 경로를 검증했다. 클릭 leaf는 SBorder이고 경로의 위젯 19개에 SelfHitTestInvisible 타일 수신자가 포함됐다. RMB 한 번을 전달한 뒤 같은 GUID의 MainWeapon 단일 장착, 인벤토리에서 제거, GreatSword 타입과 실제 Primary 전환을 확인했다. 교체 직후 공유 공격 쿨타임은 0.500초였다. 이전 J의 실패 자료는 보존한다.

정상 메뉴·NPC·필드·처치 XP·UMG 학습·장착·보스 도달을 거쳐 게임 시간 1200초의 자연 시간초과가 발생했다. 정산 화면의 로비 재화 +6 저장, 마을 복귀, 선택한 런 값 초기화와 Discovery 유지까지 검증했다. 벽시계 1224.856초, OS/launcher 종료 코드는 모두 0이었다. 기존 저장 348개의 SHA는 모두 같고 QA 파일 2개만 추가되어 350개가 됐다. 마을 귀환 후 다음 필드 진입은 K에서 실행하지 않았으며, 기존 로비 B 왕복 시나리오와 구분한다.

보스 승리는 0이다. 보스 샘플 3239개에서 최저 HP는 9882.672, 마지막은 10000이었다. 보스 구간 플레이어의 최저 샘플 HP는 135였고 Alt 요청 14회가 모두 수락됐다. 수락은 모든 회피의 성공이나 사람의 반응성을 뜻하지 않는다. 현재 봇이 비용 10의 대시를 최소 회복 후 반복한 자원·공격 기회 문제를 별도로 분석하며 제품 수치는 바꾸지 않았다.

선별 사진 5장(장착 전후·보스·결과·귀환)을 직접 열어 보고 1280×720 디코딩과 SHA256을 확인했다. 보스 도달 사진에는 과도한 모션 블러가 있고, 귀환 사진에는 셰이더 준비·체커보드 재질·스카이 경고가 남는다. 원본을 숨기거나 화면 품질 PASS로 처리하지 않았다. 프레임별 입력 CSV는 120000행 상한으로 후반 프레임이 누락됐지만, 0.25초 일반 샘플·events·종료 및 reset 검사는 계속됐다.
