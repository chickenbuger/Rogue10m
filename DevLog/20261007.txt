[Sprint#5-16] Blender MCP 연결과 아린 NPC 실제 모델 제작

오늘의 목표
사용자가 지정한 codex_blender_mcp로 Blender를 실제 연결하고, 안내 NPC 아린을 사진 투영이 아닌 입체 모델과 FBX로 제작해 시작마을에 적용했다.

주요 변경
프로젝트 전용 Blender 4.5.14 LTS와 Python 환경, 원본 MCP 서버/애드온, loopback 9877 연결 및 Codex blender 항목을 설정했다. 재현 가능한 시작/호출 스크립트를 추가했다. 저장소에는 SKILL.md가 없으므로 MCP 설치와 스킬 설치를 구분했다. 원본 vendor를 수정하거나 재배포하지 않았다.

아린은 175개 입체 메시, 42,764개 삼각형, 23개 뼈와 2초 Idle이다. BLEND·FBX·GLB 및 정면/측면/뒤/얼굴 렌더를 저장했다. UE에는 전용 19개 에셋과 같은 Skeleton의 메시/Idle을 만들고 기존 안내 NPC의 외형만 연결했다. UE FBX armature root로 실제 본은 24개다.

확인한 결과
실제 MCP 연결과 Blender 실행, FBX 재수입 18/18, 실제 NPC 플레이 검사 64/64를 통과했다. 대화·물약 2개·중복 방지·가방 만석 재시도·물약 소모·실제 포탈 뒤 잔여 1개를 확인했다. 맵 해제 후 재로드와 보호된 설정 검사도 통과했고 실제 마을 화면을 캡처했다. Content 기준선 6,312개 중 기존 guide 관련 3개 변경·신규 19개·삭제 0개이며 나머지 6,309개는 크기/수정시각이 같다. 해당 비교는 SHA256 검사라고 주장하지 않는다.

한계와 후속 작업
v1은 단색 재질 15개의 스타일화된 프로토타입이다. UV·PBR 이미지·LOD·얼굴/손가락 리그가 없다. FBX 검사는 당시 소유 live Blender에서 수행했다. C++ 변경이나 전체 Editor 빌드, 패키징, 성능·네트워크 검사는 하지 않았다. 커밋과 푸시도 하지 않았다.

[Notion 요약 후보]
실제 Blender MCP와 새 입체 아린 모델을 시작마을 안내 NPC에 적용했다. FBX 18/18 및 실제 대화·보급·포탈 64/64가 통과했다. v1은 UV/PBR 없는 프로토타입이며 사용자 후속 요청에 따라 별도 품질 개선 브랜치에서 원본을 보존하고 개선한다.

[Sprint#5-17] 아린 품질 개선 시작 및 실제 렌더 결함 확인

사용자가 지정한 캐릭터 워크플로·에셋 검사·Unreal export·retopology·반복 개선 스킬 다섯 개를 실제 설치하고 지침을 읽었다. Q1~Q6 패킷을 기록하고 v1 원본/소스/렌더/검사 보고서를 동결했다. imagegen으로 전체·얼굴·옆모습·머리·의상/손 상세 참고 보드를 제작했다. 참고 이미지는 모델 투영 텍스처로 사용하지 않는다.

새 후보는 얼굴의 눈구멍/입술과 바지의 골반/가랑이를 연결하고 손·망토·의상·부츠·가방을 개선한다. 실제 Blender 후보1은 50,274개 삼각형이며 첫 렌더에서 안구가 눈 위로 돌출되고 셔츠가 어깨 망토를 뚫는 결함을 발견했다. 후보를 보존하고 눈의 깊이·크기, 망토/셔츠 여유 공간을 소스에서 수정한 뒤 같은 화면으로 재검사한다.

UV atlas 네 섹션과 실제 컬러/roughness/metallic/normal bake, 선형 스키닝, 새 프로세스 BLEND/FBX/GLB 검사와 UE 재수입 도구를 준비했다. 반복 검토에서 join 후 무효 객체 재참조, UV 여백과 bake padding, Blender와 UE 스키닝 차이를 사전에 수정했다. 실제 Content 6,331개 SHA256 기준선을 보관했다. 최종 검증과 엔진 적용은 진행 중이며 완료라고 기록하지 않는다.

[Notion 요약 후보]
스킬 설치와 참고 보드에서 끝내지 않고 실제 메시 형태를 개선하고 있다. 첫 실제 렌더의 눈/의상 돌출은 품질 실패로 기록해 원인부터 수정하며, UV/PBR와 FBX·언리얼 검증을 통과한 후보만 최종 모델로 유지한다.

[Sprint#5-17 완료] 아린 입체 모델 품질 개선과 Unreal 최종 적용

오늘 선택한 방법
캐릭터 형태 수정, 변형에 맞는 연속 면과 웨이트, 고유 UV/PBR bake, 실제 FBX 재수입, 엔진 LOD 시각 검사를 이어서 수행했다. 이미지 생성 결과는 형태와 색상 참고로만 사용했다. 사용자가 지정한 다섯 스킬을 설치했고, 실제 Blender 모델을 수정해 Unreal에 적용했다.

모델에서 개선한 부분
얼굴의 눈구멍·안구·입술과 볼/턱, 두피와 땋은 머리, 손가락/엄지/손톱, 외투와 셔츠의 여유 공간, 연결된 바지와 부츠·가방·물약을 개선했다. 무릎 굽힘에서 외투와 앞치마가 다리를 따라 움직이도록 웨이트를 수정했다. 뒤쪽 셔츠의 흰 돌출과 작은 두피 노출을 같은 카메라에서 재검사해 제거했다. 실패 후보와 보고서는 남겨 두었다.

최종 산출물
편집 가능한 부위 174개, 런타임 메시와 재질 각각 4개, 삼각형 51,634개, 제작 본 23개와 2초 Idle이다. 피부·헤어·의상·장비를 네 UV atlas로 구성했고 실제 BaseColor/Roughness/Metallic/Normal PNG 16장을 bake했다. 의상은 4k, 다른 atlas는 2k이다. 최종 BLEND·편집 부위 BLEND·결합/분리 FBX·GLB·다각도 렌더·2초 GIF를 저장했다. 소유 Blender 창에 최종 원본도 열었다.

Unreal에서 확인하고 수정한 내용
시작마을 기존 안내 NPC 외형을 RefinedV2 전용 에셋 24개로 연결했다. 실제 신장 170cm, 추가 Arin_Rig 루트를 포함한 본 24개, 같은 Skeleton의 2초 Idle과 네 PBR 슬롯을 확인했다. 일부 텍스처가 임시 리소스 32px로 남는 문제는 속성을 한 번에 반영하고 공식 텍스처 컴파일 완료 명령으로 해결했으며 실제 2k/4k를 검증했다.

첫 자동 LOD는 실제 비율 1/.25/.125였고 조끼 흰 패치와 눈동자 손실이 보였다. 원본 LOD0를 보존한 채 LOD1=.85, LOD2=.65, 경계 잠금으로 바꿨다. 실제 UE 정점은 40,211/35,681/28,851, 각 재질 section은 4개다. 최종 엔진 화면 9개에서 의상 패치가 사라지고 최저 LOD 홍채가 유지됐다. 정확한 엔진 삼각형 수는 노출되지 않아 추산하지 않았다. 촬영용 카메라·강제 LOD·애니메이션 갱신·백그라운드 제한 설정은 복원했다.

검증과 보존
새 Blender 프로세스에서 BLEND/FBX/GLB 검사와 최종 FBX 22개 자세 화면을 확인했다. 최종 실제 PIE 67/67, 맵 해제·재로드, 별도 Unreal Cmd 프로세스의 저장된 메시/텍스처/재질/LOD/NPC 참조 검증을 통과했다. 대화·물약 2개·중복/만석 재시도·물약 실제 소모와 포탈 후 잔여 1개가 유지됐다. Content 6,331개 전체 SHA256 감사에서 기존 안내인 DA/BP/소유 외부 액터 3개만 바뀌고 신규 24개가 추가됐으며 삭제는 없다. 나머지 6,328개는 해시가 같다. Python AST 24개·diff·하네스 경로 검사를 통과했다.

남은 한계
근접 얼굴·헤어는 단순한 스타일이며 목의 별도 메시 음영 경계와 고정 망토의 한계가 남는다. 얼굴 표정·립싱크·손가락 개별 리그와 보행/전투 동작은 이번 산출물에 없다. 전용 골격이라 Manny 자동 호환을 주장하지 않는다. C++ 변경과 전체 Editor 빌드, 패키징·출시 성능·네트워크 검사는 이번 범위에서 수행하지 않았다. 기존 미커밋 작업을 보존했고 커밋·푸시는 하지 않았다.

[Notion 요약 후보]
아린을 실제 Blender 입체 모델과 UV/PBR로 개선하고 시작마을 NPC에 적용했다. 네 atlas·16PNG·23제작 본·2초 Idle·세 Unreal LOD를 제공한다. 새 프로세스 3포맷 검사·최종 FBX 22뷰·엔진 LOD 9뷰·PIE 67/67·저장 재검증을 통과했다. 초기 LOD 품질 실패도 수정 후 재검사했고 다른 Content 6,328개의 SHA256를 보존했다. 모델 원본과 FBX, 실제 렌더 및 남은 리그/미술 한계를 함께 전달한다.

최종 전달 확인
최종 파일 6개·bake 텍스처 16장·제작 소스 6개의 SHA256가 보고서와 같은지 다시 대조했다. Unreal 저장 의존성 24개와 실제 엔진 이미지 9개의 해시도 final-handoff.json에 기록했다. 독립 최종 검토는 현재 서 있는 튜토리얼 NPC 범위를 수용했다. 검증 종료 당시 에디터는 PIE가 종료된 StartHub였으며 소유 Blender에 최종 Arin.blend를 열었다. 실제 렌더 검토 시트를 Codex 패널에 열도록 요청했고 원본·FBX와 함께 전달한다.

이어하기 요청 후 추가 확인
최종 파일 링크와 문서를 확인했다. 현재 live Remote Execution 노드는 발견되지 않았으며 이전에 소유한 Unreal/Blender 프로세스 번호도 조회되지 않는다. 실행 중인 창 상태를 새로 확인했다고 주장하지 않는다. 연결 확인에서 자산은 변경하지 않았고, 저장된 최종 산출물과 별도 프로세스 재검증 결과는 유지된다. 진단은 final-editor-state.json에 기록했다.
