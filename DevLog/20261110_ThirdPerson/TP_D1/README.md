# TP_D1 최종 3인칭/입력 검증

- D native binary, 실제 UE D3D11 1280×720 RenderOffScreen, 첫 캡처 전에 로드된 메시/머티리얼 컴파일 완료를 기다렸다.
- 결과: 786개 체크 실패0, 663개 POV 유한 값 샘플, 엔진 Error/Ensure/Fatal0, 마우스13/13. FOV90/전신·머리 표시/1인칭 비활성/설정창 복귀는 별도 정적 상태 체크이다.
- 카메라 331.247650→140.780243→331.247650cm, W 이동169.615646cm, 자유 회피248.077042cm, 벽 회피39.971264cm.
- 실제 DA_Dodge_Unarmed 제작값1000cm/0.16초를 읽어 검사했다. 초기 속도를 정하는 거리 값과 실현 이동거리를 같은 것으로 취급하지 않았고, gameplay 값을 바꾸지 않았다.
- 실제 신규 고정 주먹 /Game/DataAsset/AttackSkill/BasicBrawler/DA_BasicBrawler_LeftJab 사용 횟수 +1. Q/E/R·RMB·Ctrl은 무기 능력을 실행하지 않았다. 다른12개 케이스는 일시 GreatSword 프로필/스킬의 정확한 사용 횟수 검사이다.
- 01 기본, 02 카메라 벽 수축, 03 W 이동, 04 실제 LeftAlt 활성 회피, 05 벽 앞 회피 결과. 5장을 직접 확인했다. 벽 수축 시 낮은 몸 부분은 프레임 밖이며, 회피 중 모션 블러가 보인다.
- 별도 일시 바닥/벽이다. 저장된 맵/동선 변경 없음. 기존 저장390개 SHA256 보존, 새 격리 QA 저장2개만 추가.
- 입력은 Controller InputKey 프로그램 입력이다. 물리 키보드/마우스, 저장 후 재시작, 일반 필드 완주, 실제 근접 무기/보스 접촉 검수는 하지 않았다.
- 기존 회피 모션을 변경하지 않았다. 이 캡처는 준비/접촉/회복 전체나 손·무기 궤적 검증이 아니며 모든 모션/벽의 클리핑 없음 인증도 아니다.
- TP_A1(이름 길이 fixture)와 TP_C1(임의 회피 상한 fixture)의 실패 로그/이미지는 그대로 보존했다. 1인칭 개발/검수는 중단 상태이다.
