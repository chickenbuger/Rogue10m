# TP_C1 3인칭 카메라 검증 기록

- 실제 UE 렌더링 1280×720, C3 native binary, 2026-11-10. 카메라/입력 검증용 일시 바닥과 벽이며 저장된 맵 변경은 없다.
- 01: 기본 3인칭 전신/머리/중앙 시야, 02: 벽에 따른 카메라 수축, 03: 실제 W 이동, 04: 실제 LeftAlt 회피 중 캡처, 05: 벽 앞 회피 결과.
- 264개 POV 샘플에서 유한 값을 확인했다. 별도 정적 체크에서 FOV90과 기존 1인칭 비활성 상태를 확인했다. 카메라 331.247650→140.780243→331.247650cm, W 이동169.616241cm, 자유 회피248.454971cm, 벽 회피39.971260cm.
- 이 후보의 실패는 임의 QA 상한 free_dodge<200cm 한 항목이다. 실제 제작 회피 설정을 기준으로 검사하도록 후속 D에서 테스트만 수정했다. 마우스 케이스는 0개였으므로 통과를 주장하지 않는다.
- 기존 저장388개 SHA256이 보존됐으며 새 QA 저장2개만 추가됐다. 자체 engine red log는 잘못 둔 회피 assert 한 항목뿐이다.
- Controller InputKey를 사용하는 프로그램 입력이다. 물리 키보드/마우스와 일반 필드 완주는 하지 않았다.
- 기존 회피 애니메이션을 변경하지 않았다. 04는 회피 활성 프레임을 보여주지만 준비/접촉/회복 전체 또는 손·무기 궤적 검증이 아니므로 애니메이션 품질 통과 자료로 쓰지 않는다.

## 대표 사진 보관 상태

사용자 요청에 따라 중복·이전·보조 사진을 정리했다. 현재 `20261110_ThirdPerson` 묶음에는 대표 1장을 보관한다. 이 문서의 촬영 개수·파일명·시각 판정은 당시 실행 이력이며, 현재 사진 목록은 [대표 사진 목록](../../README.md)을 따른다. 수치 결과·텍스트 실패 기록은 그대로 유지했다.
