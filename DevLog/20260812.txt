# 2026-08-12 개발 로그

## Sprint#4-3 - Obsidian 아키텍처 결합도·응집도 연동

### 작업 배경

현재 Rogue10m 프로젝트의 C++ 파일 의존 관계를 문서와 분리된 일회성 표가 아니라, 기존 Obsidian Vault 안에서 반복 갱신하고 탐색할 수 있는 형태가 필요했다.

### 주요 작업

- `Source/Rogue10m`의 헤더와 cpp 파일에서 프로젝트 내부 `#include` 관계를 추출하는 PowerShell 분석기를 추가했다.
- 파일별 유입 결합도(Ca), 유출 결합도(Ce), 총 결합도와 같은 폴더 의존 비율을 계산했다.
- 폴더별 내부선, 유입선, 유출선, 응집도와 불안정도를 계산했다.
- 원본 C++ 파일 97개에 대응하는 Obsidian 노트 97개를 생성하고 유입·유출 파일을 Wiki Link로 연결했다.
- 폴더 의존 Mermaid 그래프와 Obsidian Canvas, 후속 분석용 `metrics.json`을 생성했다.
- 프로젝트 문서 영역 `Docs/Obsidian/ArchitectureMetrics`에 대시보드 진입점을 구성했다.
- 분석·검증 후 Obsidian 대시보드를 여는 PowerShell 스크립트와 더블클릭용 배치 파일을 추가했다.
- Windows PowerShell 5.1에서 한국어가 손상되지 않도록 신규 PowerShell 스크립트를 UTF-8 BOM으로 저장했다.

### 검증 결과

- 분석 파일: 97개
- 프로젝트 내부 include 관계: 197개
- 분석 폴더: 10개
- 생성 파일 노트: 97개
- `Scripts/TestObsidianArchitectureMetrics.ps1` 통과
- 생성 Wiki Link, Canvas JSON, 결합도·응집도 범위 검증 통과
- Obsidian 실행 스크립트 PowerShell 구문 검증 통과
- C++ 및 Unreal 바이너리 에셋 변경 없음

### 해석 메모

- 총 결합도 상위 파일은 `Rogue10mCharacter.h`(20), `Rogue10mPlayerController.cpp`(18), `Rogue10m.h`(15)였다.
- 폴더 응집도 하위는 `Enemy`(8.3%), `UI`(20.0%), `Components`(24.1%)였다.
- 현재 지표는 include 정적 관계만 반영하므로 Blueprint와 런타임 의존성을 합친 절대 품질 점수로 사용하지 않는다.

## Sprint#4-8 - 묵직한 전리품 주머니 Actor 제작

### 작업 배경

인벤토리에서 월드로 버린 아이템과 사냥으로 생성되는 전리품을 작은 개별 메시 대신 한눈에 알아볼 수 있는 묵직한 주머니 형태로 표현할 공통 Actor 에셋이 필요했다.

### 주요 작업

- 기존 `ARogue10mDroppedItem`을 부모로 사용하는 `/Game/World/Loot/BP_HeavyLootBag` Blueprint를 Unreal Editor API로 생성했다.
- 넓고 낮게 눌린 본체, 모아진 주머니 목, 매듭, 좌우로 처진 끈의 5개 StaticMeshComponent로 실루엣을 구성했다.
- Stylized Village의 어두운 천 머티리얼과 따뜻한 목재 계열 머티리얼을 재사용했다.
- 주머니 본체는 `OverlapAllDynamic` 충돌을 사용하고 장식 컴포넌트는 `NoCollision`로 설정했다.
- 아이템 Data Asset의 개별 `DroppedWorldMesh`가 공통 주머니 외형을 덮어쓰지 않도록 상속된 `ItemMesh`는 숨겼다.
- 상속된 `ItemNameText`는 금빛 색상과 World Size 15로 조정해 실제 아이템 이름 표시 기능을 유지했다.
- Tick과 동적 조명은 추가하지 않았다.
- 에셋을 반복 생성할 수 있는 `BuildHeavyLootBagActor.py`와 새 프로세스 재로드 검증용 `ValidateHeavyLootBagActor.py`를 추가했다.

- UnrealEditor-Cmd Blueprint 생성, 컴파일, 저장 성공
- 새 UnrealEditor-Cmd 프로세스에서 부모 클래스와 5개 시각 컴포넌트 재로드 확인

## Sprint#4-9 - 던전 보상 보물상자 Actor 제작
