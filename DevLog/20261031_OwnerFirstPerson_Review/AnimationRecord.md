# 소유자 팔 시점: 기존 애니메이션 관측 기록

이번 묶음에서 애니메이션 에셋·몽타주·접촉 시계·재생률은 수정하지 않았다. 소유자 팔 기하와 몸체 가시성을 분리했고, 기존 모션을 실제 입력 경로로 관측했다.

중앙 몸통 가림은 제거됐지만, 중립 손 프레이밍과 극하향·벽 근처 팔 절단면 표현은 미완료다. **시각 게이트는 부분 실패이며 제품 기본값은 OFF**다.

자동 입력·실제 D3D11 Offscreen 렌더링이다. 물리 키보드 입력, 일반 필드 완주, 모든 프레임의 clipping-free 동작을 검증한 것은 아니다. 이 분석 작업은 사진 43장의 전수 디코딩·크기·SHA256 검증을 수행했으며 사진 내용의 직접 판정은 별도의 root 검토와 구분한다.

## 실제 에셋과 수정 경계

- 스킬: `/Game/DataAsset/AttackSkill/ClassCombat/Knuckle/DA_Attack_Knuckle_Primary01`
- 몽타주: `/Game/Rogue10m/Animation/Combat/FistAuthored/AM_Knuckle_Jab`
- 시퀀스: `/Game/Rogue10m/Animation/Combat/FistAuthored/A_Knuckle_Jab`
- 소스 애니메이션 메시: `/Game/Characters/Mannequins/Meshes/SKM_Manny_Simple`
- 원본 클립 구간 0~1초, 몽타주 길이 1초, authored 재생률 1.34, authored 접촉 지연 0.15 몽타주초. 실제 재생률은 캐릭터 공격 속도 배율을 포함하므로 아래 측정값을 사용한다.

## 준비 → 수락 → 피해 관측 → 회복

준비는 LMB 입력 이전, 수락은 스킬 사용 횟수 증가를 처음 본 프레임, 접촉 기록은 적 체력 감소를 처음 본 프레임이다. 회복은 실제 action·쿨타임·combo가 모두 종료된 관측 시점이다. 사진은 요청을 처리한 실제 렌더 프레임에 촬영되며, 요청→촬영 지연은 각 기록에 표시한다. 따라서 정확한 서브프레임 접촉 사진이라고 표현하지 않는다.

## 다음 수정의 첫 단계

현재 6개 팔 메시와 실패 캡처를 보존한다. 먼저 몸체 그림자와 실제 스킨 정점의 근평면 투영을 격리 측정한 뒤 소유자 표현만의 포즈·프레이밍을 검증한다. 단순 카메라 후퇴, 본체/공격 소스 포즈 변경, 눈대중 팔 전진으로 해결됐다고 처리하지 않는다.


대표 사진 정리: 위 촬영·수치·실패 서술은 당시 검증 기록이다. 현재 사진은 [대표 목록](../README.md)만 보관하며, 삭제된 보조 사진을 성공 이미지로 대신 표시하지 않는다.


## 대표 사진 보관 상태

사용자 요청에 따라 중복·이전·보조 사진을 정리했다. 현재 `20261031_OwnerFirstPerson_Review` 묶음에는 대표 0장을 보관한다. 이 문서의 촬영 개수·파일명·시각 판정은 당시 실행 이력이며, 현재 사진 목록은 [대표 사진 목록](../README.md)을 따른다. 수치 결과·텍스트 실패 기록은 그대로 유지했다.
