1. 목표
검증이 끝난 독립 경로·시간 예산 도구를 다른 작업과 충돌하지 않는 Tools/RouteBudget 폴더에 바로 적용했다. 최신 사용자 기준인 성장 후 보스룸 도착 약15분을 유지했다.

2. 변경
기존 파일은 그대로 두고 도구·테스트·입력 fixture·검증 기록기·문서만 새 폴더에 추가했다. 실제 설계 JSON을 기본 입력으로 연결하고 자동 회귀는 고정 fixture로 분리했다. 검증은 실행별 새 디렉터리에 기록하며 원본 입력과 검증기를 같은 바이트 스냅샷으로 실행한다.

3. 검증 결과
자동 회귀47개와 실제 기존 정적 검사199개를 새로 실행해 모두 통과했다. 노드 방향별90개 경로와 마을 미방문32개 조합을 확인했다. 같은 입력의 보고서는 바이트 단위로 재현됐고 원본 입력·검증기 해시도 실행 전후 같았다. 이전 실행 증거8개 역시 해시가 같아 보존됐음을 확인했다.

4. 불일치와 미검증 범위
기존 architect의 보스 처치15분과 최신 JSON의 보스룸 입구15분은 불일치로 남겼다. 지도 배치·실제 지형·이동 속도·퀘스트 상태·입력·풀런은 구현 또는 측정하지 않았다. 도구 통합을 게임 경로 구현이나 실측 완료로 표시하지 않는다.
