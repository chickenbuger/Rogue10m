# 독립 경로·시간 예산 검증 계획

작성일: 2026-11-10. 모든 작업은 이 임시 폴더로 한정한다.

입력은 기존 `Feature/doc/evidence/five-village-route-spec-20261110/route-plan.json`의 바이트 단위 스냅샷이다. 10개 노드·19개 왕복 간선과 두 900초 입구 예산을 재사용한다. 별도 세계 배치나 새로운 강제 코스를 설계하지 않는다. Unreal Editor·빌드·소스·에셋·사용자 세이브·Git 상태는 변경하지 않는다.

## 계약

- 모든 거리·속도·시간은 설계 가정에서 계산한 수치이다. 저장 좌표도 현재 런타임 측정치로 간주하지 않는다.
- 사용자 목표는 기본 보행 직행 입구 60초 이내, 성장 후 입구 약900초이다. 보스 전투180초·여유120초는 추가 가정이며 1200초 활성 런 한도와 비교한다.
- 경로 이동은 간선의 2D 유클리드 거리 / 가정 속도. 활동 예산의 travel 항목에는 이 이동이 이미 들어 있다. 민감도 변경 시 기하 이동만 교체하고 기존 이동 여유는 보존해 이중 합산을 막는다.
- 서로 같은 콘텐츠를 참조하는 활동에는 선택적 coverage_keys를 부여해 이중 계상한다면 거부한다. 원본 입력에는 이 키가 없으므로 같은 조우의 의미상 중복을 자동 확인했다고 주장하지 않는다.
- 왕복은 현재→의뢰 마을→현재→보스 입구 순으로 계산한다. 남은 목표·보고·보스·여유를 더하며, 0초에 패배하므로 전투 완료가 한도와 같으면 불가능으로 판정한다. 여유를 모두 쓰면서 전투가 한도 전 끝나는 경계는 별도 표시한다.
- 그래프 연결성은 실제 충돌·지형·동적 차단·퀘스트 상태·입출력·일시정지 구현을 입증하지 않는다.
- 기존 PowerShell 검증기는 임시 복사본과 임시 보고 경로로만 실행한다. 프로젝트의 일지/스프린트 변경로그 갱신은 통합자가 수행할 후보 문서로 제공한다.
